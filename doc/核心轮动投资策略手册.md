`股债收益比 = 中证红利股息率 ÷ 10 年期国债收益率`（仍是主键）

> **执行口径**：
>
> 1. **情景判定**优先用股债收益比 + 红利PE分位 + 成长占优信号三元组合（详见二章）；
> 2. 在情景区间内，**每类资产再用本章指标做±5–10pp 微调**（详见二~七章）；
> 3. 任意一类 **0%–100%** 自由配置；当且仅当六类全部加总 = 100%；
> 4. 总仓位之外保留 6–12 个月生活费现金（应急金，**持有现金、不计入本策略六只标的**）；
> 5. **通道优先级**：QDII（纳指100）与利率债优先走场外；仅当场外限购 / 额度紧张时，才用场内 ETF 代理，并需先检查溢价率。

## 二、情景判定 · 三维联合信号

| 维度    | 关键指标                       | 防御/低估 | 均衡震荡    | 成长/牛市           |
| ----- | -------------------------- | ----- | ------- | --------------- |
| 股债收益比 | 中证红利股息率 ÷ 10Y国债            | > 2.5 | 1.5–2.5 | < 1.5           |
| 估值锚   | 中证红利10年PE分位                | < 30% | 30%–70% | > 70%（或科创PE比<3） |
| 成长占优  | 创业板连续5日跑赢中证红利 + 两市成交>2.3万亿 | 否     | 否       | 是               |

**三元组合规则**：

- 三个指标**同时支持同一情景** → 切换；任何维度矛盾 → 留在更防御的一档；
- 当股债收益比**边际**突破2.5但红利PE分位仍高 → 仍判均衡震荡（v1.0 经验，避免假突破）；
- 当科创/纳指出现拥挤度极值或美元/美债异动 → 单独触发各类资产的微调，不强行切换情景。

## 三、中长债策略（稳定器）

### 3.1 关键指标

- **10年期国债收益率**（最核心）
- **利率周期方向**（上行/下行）
- **央行流动性投放**（MLF/买断式逆回购净投放）

### 3.2 配置信号

| 10Y国债收益率  | 信号            | 中长债操作          |
| --------- | ------------- | -------------- |
| > 3.0%    | 票息性价比高        | **买入**（多配至上限）  |
| 2.5%–3.0% | 偏多            | 偏多配            |
| 2.0%–2.5% | 中性            | 持有（情景中枢）       |
| 1.5%–2.0% | 票息薄           | 压至区间下限，**不操作** |
| < 1.5%    | 极度便宜利得 / 极度脆弱 | **卖出**至5%以下    |

### 3.3 利率方向加成

- **利率下行**（连续数周10Y回落）→ 003377（≈10Y 久期）吃资本利得，可配至区间上限；
- **利率上行**（连续数周10Y上行）→ **压 003377 仓位**控制久期风险（本策略不切换短久期标的，久期风险靠仓位而非换券管理）；
- **央行加量续作 MLF/买断式逆回购** → 流动性宽松支持利率下行，利好中长债。

### 3.4 标的（唯一：003377）

| 项目     | 内容                                                    |
| ------ | ----------------------------------------------------- |
| 场外主仓   | **003377** 广发中债 7-10 年国开债指数 C（中债 7-10 年国开债，久期 ≈10Y）     |
| 场内信号代理 | 511260 十年国债ETF国泰（只看利率与动量，不交易）                          |
| 池内编号   | #56（2026-09 新增，规模 / 风险等级待下次公告快照补录）                    |

- **久期管理方式**：本策略不切换短久期标的，**只用 003377 一只**；利率上行期通过 3.2 的**仓位上下限**压敞口（而非换券），必要时降至区间下限甚至 0%；
- 不配置二级债基（含权益，破坏防御属性）、不配置信用债 / QDII 债；
- 应急现金以**现金形式**持有，不再额外配置短债基金。

## 四、中证红利策略（防御底仓）

### 4.1 关键指标

- **股息率**（TTM，>3%是底线）
- **PE 分位**（10年）
- **股债收益比**（与10Y国债）
- **成分股暴雷/下调分红**（红线）

### 4.2 配置信号

| 指标              | 买入     | 持有        | 卖出/停加        |
| --------------- | ------ | --------- | ------------ |
| 股债收益比           | > 2.5  | 1.5–2.5   | < 1.5        |
| 中证红利 PE 分位（10年） | < 30%  | 30%–70%   | > 70%        |
| 股息率             | > 4.5% | 3.5%–4.5% | < 3.5%       |

### 4.3 中证红利内部节奏（原"红利低波"已折叠，不再单独配置）

- **组合方式**：本策略的红利仓**只有 012644 一只**；原"红利低波节奏仓"已折叠，不再单独持有红利低波 / 沪港深红利 / 自由现金流等其他红利类基金；
- **停加规则**：当中证红利 PE 分位 > 70%（见 4.2）即整体**停止加仓红利**；
- **集中度管理**：因不再做低波拆分，需更关注 4.4 的银行 / 地产 / 能源权重风险，触发时用仓位上限（≤25%）而非换基应对。

### 4.4 风险红线

- 中证红利前十大权重中 **≥ 2 只业绩暴雷**，或 **≥ 3 只下调分红预告** → 暂停加仓并压力测试；
- 银行净息差持续恶化 + 地产频繁暴雷 → 红利策略触发系统性风险。

## 七、科创50策略（成长卫星）

> 严格指**上证科创板50（000688）**，由科创板中市值大、流动性好的 50 只硬科技龙头组成（半导体/信息技术权重大），区别于原科创创业50（931643）。

### 7.1 核心指标

**指标1 · 估值差（PE 比）— 主信号**  
`PE比 = 科创50 PE ÷ 中证红利 PE`

| PE 比                  | 科创50操作                              |
| --------------------- | ----------------------------------- |
| < 3.0 + 拥挤度<60% + 动量强 | **买入**（极低估时战略性加仓）                   |
| 3.0–5.0               | 持有                                  |
| 5.0–6.0               | 减仓 / 不操作                            |
| > 6.0                 | **禁超配**（科创仓&#x4F4D;**≤** 35% 且触发下调） |

**指标2 · 拥挤度（TMT成交占比 / 成长持仓分位）— 过滤器**

| 拥挤度     | 动作                   |
| ------- | -------------------- |
| > 85%   | 在指标1比例上**下调 5–10pp** |
| 60%–85% | 维持，不追高               |
| < 60%   | 若指标1支持可加回上限          |

**指标3 · 动量（近20日相对强弱）— 顺势确认**

- 近期出现"杀成长"（科创 -3% 量级 + 红利走强）→ **不追高**；等动量衰减到顶背离再做减仓决策；
- 连续3–5日科创强势 + 成交>2.3万亿 → 偏多，但与 PE 比 > 5.0 矛盾时**只取上限小仓**。

**指标4 · 美联储利率状态机（外部联动）**

- 美联储降息预期升温 + 美债下行 → 偏科创；
- 美元指数上行 + 美债利率走高 → 减科创（不利于全球风险资产）。

### 7.2 红线

- 科创 PE 比 > 7.0 → **完全规避**，占比降至 0%；
- TMT 拥挤度持续 > 90% → **禁止加仓**。

### 7.3 标的（唯一：011609）

| 项目     | 内容                                           |
| ------ | -------------------------------------------- |
| 场外主仓   | **011609** 易方达上证科创板 50 ETF 联接 C（规模最大 140 亿级，流动性最佳，R4） |
| 场内信号代理 | 588000 科创50ETF华夏（只看 PE / 动量 / 拥挤度，不交易）        |
| 池内编号   | #2                                           |

- 拥挤度（TMT 成交占比）与动量**改用指数 / 全市场成交数据直接计算**，不再借助半导体、AI、软件、通信等行业基金做代理观测，这些行业基金**不参与本策略**；
- 只有当 7.1 指标1（PE 比）与指标2（拥挤度）同时支持时，才用 011609 做实际加仓。

## 十、风险控制总纲

- **单一资产上限**：以本章区间为准，但**单类占比建议 ≤ 40%**（控制单点风险）；
- **回撤线**：组合回撤 > 15% 触发复盘，审视是否误判风格或忽略暴雷；
- **行业上限**（中证红利 012644 内）：金融、地产、能源合计 ≤ 35%（按指数成分权重直接核算，不配置行业基金对冲）；
- **现金储备**：保留 6–12 个月生活费的现金在策略之外；
- **流动性**：优选规模 > 20亿、费率<0.6%、跟踪误差<0.3%的场外联接（场内 ETF 仅作信号代理）；
- **QDII 溢价警示**：场内溢价 > 5% 时强制走场外；
- **黄金拥挤警示**：月涨幅 > 10% 强制暂停加仓；
- **成分股风险**：中证红利前十大 ≥ 2 只暴雷或 ≥ 3 只下调分红 → 暂停加仓。

## 十三、核心提醒

- **六类是分工，不是排名**：防御 / 中枢 / 进攻 / 避险各有分工，结果比个股重要；
- **指标是温度计不是预测器**：阈值反复触发矛盾时，回到股债收益比 + 美元 + 实际利率三个最终锚；
- **纪律 > 预测**：每半年复核参数，但**不频繁变动**框架；
- **强相关性资产的边际替代**：中证红利 vs 黄金（防利率上行）、纳指 vs A500（防单一市场风险）；
- **任何策略都有失效情景**（如长期成长占优挤压红利、美元长期强势压制黄金），以**股债收益比 + 实际利率 + DXY** 为最终锚。
