## 0. 策略定义（按图片复述）

- **方案 B v1（利率动量 20 日轮动）**：`y10(t) − y10(t−20) < 0` → 长债 80%；`≥ 0` → 20%。每周五收盘判定，下周一（下一交易日）执行，周内不动。
- **方案 B v2（v2 带噪声带，第二张图）**：`Δy = y10(t) − y10(t−20)` 单位 bp；`|Δy| ≤ 3bp` → 50%（噪声区不动）；`Δy < −3bp` 线性升仓至 `−15bp` 满仓；`Δy > +3bp` 线性降仓至 `+15bp` 清仓；每周五判定、下周执行。
- **方案 C（趋势连续仓位）**：`dev = 511260净值/MA20 − 1`，`w = 20% + (clip(dev, ±1%) + 1%) / 2% × 60%`，clip 到 20%~80%；每日计算、T+1 执行（不会一夜清仓）。
- **长债腿**：图片写「10年国债ETF」，本测试用 `511260`（国泰上证10年期国债ETF）的**累计净值**；另给 `003376`（7-10 年国开 A，本家族主用长腿）作对照。另一半仓位用 `002864`（短债 A），并给 `000198`（余额宝）对照。

> 口径提醒：图片的数字来自外部，未给标的/成本/窗口细节；下表是**本仓库口径下的复现**，数字与图片不完全一致属正常，重点看方向是否成立。

## 6. 结论

- 近 6 年、10bp 单边成本：B v1 **+2.11% / 回撤 -1.25% / 夏普 0.55 / Calmar 1.68**；B v2 **+2.29% / 回撤 -1.46% / 夏普 0.72 / Calmar 1.57**；C **+2.10% / 回撤 -1.47% / 夏普 0.62**。
- **图片数字费前基本能复现**：0bp 下 B 年化 +3.41% / 回撤 -1.13% / 夏普0 2.74（图片 3.37% / −1.25% / 2.46），C 年化 +3.35% / 回撤 -1.12% / 夏普0 2.95（图片 2.72% / −1.12% / 2.03）—— 量级与回撤基本对上（C 的 −1.12% 完全一致），说明图片算的是**费前毛收益 + rf≈0**，且窗口/标的口径略有差异。
- **B v2 的「改进」是费前口径下的，费后不成立于回撤/Calmar**：0bp 下 B v1 回撤 -1.13% / Calmar 3.00 → B v2 回撤 -1.06% / Calmar 3.18（与图片 −1.25%→−1.13%、Calmar 2.51→2.66 方向一致）；但 10bp 下 B v2 回撤 -1.46% / Calmar 1.57，反而**差于** B v1 的 -1.25% / 1.68。年化与夏普确有改善（+2.11%/0.55 → +2.29%/0.72），但 40bp 下 v2 仍为负；它换手更高（86 vs 76），不是「更少无效换手」。
- **§3.5 参数网格证伪了「±3bp 最优」**：10bp 下噪声带从 ±1 放宽到 ±8、满仓阈值从 ±8 放宽到 ±30，夏普单调改善（0.30 → 1.52），说明本样本里最好的「噪声带」其实是**几乎不动手**。图片选的 ±3/±15 在网格里只是中低档，谈不上实盘最优标定。
- **费前不等于能成交**：初版 B/C 六年换手 76 / 64（双边 ≈ 150 / 128 次单边），10bp 单边成本吃掉年化 1.3pp，40bp 直接变成负收益。图片说「交易成本已计入」与本口径不符（大概率按 C 类免赎回费或零成本算的）。
- 三个方案在 10bp 下都**跑不赢固定 50/50**（年化 3.28% / 回撤 −1.23% / 夏普 1.82），更远低于固定 20/80（夏普 2.29）—— 过去 6 年是债牛，减仓就是少赚，择时省下的那点回撤不够抵收益损失。
- 三者都只在「长债占比」一个维度做择时，与 `research/compare_all` 里v1/v3/v5/v6/v8 的失败假设同类 —— 看回撤改善是否值回换手，不能只看牛市年化。
