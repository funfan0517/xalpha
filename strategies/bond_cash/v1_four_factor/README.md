## 1. 定位：V1 只改「债腿内部久期」，不改额度

v0 的债腿 30pp 里，7-10 年国开 A（`003376`）**固定占 70%**。
V1 把这个比例变成状态变量 `w_long`：

| | v0（基准） | V1 |
|---|---|---|
| 债腿总额度 | 30pp | **30pp（不变）** |
| 长端 `003376` | 固定 70%（21pp） | 35% ~ 70%（10.5 ~ 21pp），四因子打分决定 |
| 底仓 `011983` | 固定 30%（9pp） | 债腿剩余（65% ~ 30%） |
| 现金腿 10pp | 5pp `000198` + 5pp `014437` | **完全不变** |
| 择时依据 | 无（可选动量开关默认关） | 债券晴雨表温度 + 四因子 score + 情景概率 |

**为什么把 bond_rules 的「仓位」映射成「久期占比」**：
文档 §4 的仓位对象是「一笔独立的债券 ETF 仓位」（基准 20%、带宽 10~30%）；
本策略的债券额度已被 v0 钉死为 30pp。直接把 10~30% 套到 30pp 上会得到 3~9pp 这种荒谬数字。
所以保留公式形状 `基准 + score/4 × (上限−基准) × 折扣`，把对象换成债腿内部的**长端占比**：
基准 35%、上限 70%（= v0 的进攻档）、下限 0（= 100% 3-5 年）。

## 3. 两处必须解释的换算（否则数字对不上）

### ① 滞后带按带宽放缩：1.5pp → 5.25pp

R-18 的「1.5pp」是在**原规格 10pp 带宽**（20% 基准 / 10~30%）上的尺度。
V1 把带宽映射成 35pp（35%→70%），滞后带必须按同一比例放缩：

```
1.5pp × (0.70 − 0.35) / 0.10 = 5.25pp
```

不放缩的后果是真实的：低置信度（几乎天天低）score=±1 时目标移动 4.375pp > 1.5pp，
会天天翻仓 —— 实测 **72 次/年**；放缩后降到 **14 次/年**。
R-18 的意图是「小变化不动手」，按原数值照抄反而违背规格。

### ② 动能温度用累计净值，不用行情涨跌幅

基准 `511260` 的场内行情不含分红（约 2.4pp/年），用它算 250 日区间位置会把动能温度系统性做低。
`data.load_nav` 走 `xalpha.fundinfo('511260').totvalue`，与债腿收益口径一致。

## 5. 回测：诚实结论（完整表见 `backtest/_v1_bt.md`）

| 窗口 | 方案 | 年化 | 最大回撤 | 夏普 | 换手 |
|---|---|---:|---:|---:|---:|
| 长窗 2018-08~2026-11（底仓 `001512`） | **V1 四因子** | +2.94% | −4.47% | 0.97 | 138 次（13.6/年） |
| | v0 旧配比 70/30（2026-11-20 前） | **+3.83%** | −4.69% | **1.31** | 0 |
| | **基准 v0 固定中性 35/65** | +3.19% | −4.47% | 1.12 | 0 |
| 现行窗 2023-07~2026-11（底仓 `011983`，信用可用） | **V1 四因子** | +3.82% | −2.14% | 1.67 | 74 次（14.2/年） |
| | v0 旧配比 70/30（2026-11-20 前） | **+4.45%** | −2.38% | **1.80** | 0 |
| | **基准 v0 固定中性 35/65** | +4.15% | −1.98% | **1.87** | 0 |

**V1 用收益换回撤，两个窗口都跑不赢基准（v0 固定中性 35/65）**：长窗夏普 0.97 vs 1.12、
现行窗 1.67 vs 1.87。2026-11-20 v0 改 35/65 后差距比原来（对 70/30）更大 ——
因为 V1 的 87% 时间都停在中性 35%，等于**付了择时的换手成本去做和基准一样的事**。
原因在信号分布：长窗 2011 天里偏多仅 133 天、偏空 128 天，**1750 天震荡观望**（87%），
置信度高仅 9 天、低 1970 天 —— 四因子天然互斥（估值贵时往往趋势偏多），
互斥规则把绝大多数日子压回 35% 中性，剩下的换手主要贡献成本。

成本敏感性：单边 0 / 10 / 40bp → 长窗 +3.22% / +2.94% / +2.10%，
现行窗 +4.14% / +3.82% / +2.86%。40bp 时 V1 明显不如不动手。

> 这是**照搬规格未调参**的结果（温度权重、因子阈值、带宽全部来自文档），
> 不是对规则的否定：文档自己也说「温度只定赔率、不定方向」「预测力弱」。
> V1 的价值是把晴雨表、因子、情景概率做成可复核的每日读数；真要拿它替代 v0，
> 需要它先在样本外稳定跑赢「固定中性」，目前没有证据。

## 6. 已知边界

- 信用利差是近似口径（AAA 中短票 3Y − 国债 1Y，非同期限），且 akshare 曲线只有 2023 年起 →
  长窗覆盖 3/4 项、现行窗 4/4，两者不可直接比
- 情景桶样本来自 `511260` 净值（2017-08 起），long-only 债牛样本偏多；换基准会换概率
- 事件日历 `POLICY_DATES` **人工维护**，目前为空；不填等于 R-19 永远不触发
- 温度/阈值在文档 2013-2026 样本上定标，本回测没有再调参，不构成严格样本外
- `w_long` 状态文件是机械执行的影子仓位；若你的真实持仓没跟上信号，手工改
  `daily/_v1_state.json` 的 `w_long` 即可校准（下次运行按新值算滞后带）
