# V4 · 股债对冲三票（Carry + Trend + Hedge）

> 规则来源（2026-11-19 联网研究）：
> - **Newfound Research**（2018-10）*A Carry-Trend-Hedge Approach to Duration Timing*：
>   Carry（期限利差分位）+ Trend（21/252 EWMA 双确认）+ **Hedge（股票动量极端分位反向映射债券）**，
>   合成 Sharpe 0.49~0.58 vs long-only 0.27。
> - **国泰海通**（2026-06）*从利率择时到久期轮动*：久期轮动 + 权益风格择时的「股债增强」年化 11.00% / 夏普 1.70。
>
> 基准：v3 的双票（Carry + Trend，`../v3_carry_trend/`）。**V4 = v3 + 第三条 Hedge 腿**，
> carry / trend 两票逐行同源，所以「V4 − V3」的差值就是 Hedge 票的独立贡献。
> 参数权威源：`rule.py::CFG`。

---

## 1. 三票规则

| 票 | 构造 | 映射 |
|---|---|---|
| **Carry** | 中债 `10Y − 1Y` 期限利差的近 3 年滚动分位 | ≥66.7% → **+1**，≤33.3% → **−1**，中间 0 |
| **Trend** | 10Y 国债收益率 `MA5<MA20` 与 `MA20<MA60` 各一票 | 两票都指向利率下行 → **+1**；都上行 → **−1**；否则 0 |
| **Hedge** | 沪深300 近 **252 日**累计收益的 **5 年**滚动分位 | ≥90%（股票过热）→ **−1**（减久期）；≤10%（避险）→ **+1**（加久期）；中间 0 |

`score = carry + trend + hedge ∈ [−3,+3]` → 长端 `003376` 占债腿：

| score | −3 | −2 | −1 | 0 | +1 | +2 | +3 |
|---|---:|---:|---:|---:|---:|---:|---:|
| `003376` | 0% | 12% | 23% | **35%** | 47% | 58% | 70% |
| `011983` | 100% | 88% | 77% | 65% | 53% | 42% | 30% |

月度最后交易日算分、T+1 承担；滞后带 1.5pp；单边 10bp；40pp 额度与现金腿（5pp `000198` + 5pp `014437`）完全不动。

**Hedge 票的方向**取自「股债跷跷板」：股票动量打到 5 年分位顶 → 风险偏好过热 → 压久期；
打到分位底 → 避险 → 拉久期。指数用**点位**（不含分红），只做动量分位，不做收益归因。

## 2. 回测（完整表见 `backtest/_v4_bt.md`）

窗口 2023-05-30 ~ 2026-11-18（842 交易日；受曲线 3 年分位限制）：

| 方案 | 年化 | 波动 | 夏普 | 最大回撤 | Σ\|Δw\| |
|---|---:|---:|---:|---:|---:|
| **V4 三票** | +3.73% | 1.44% | 1.61 | **−1.79%** | 3.5 |
| V3 口径双票（无 Hedge） | **+3.81%** | 1.48% | **1.63** | −1.91% | 3.1 |
| 纯 Hedge 票 | +3.12% | 1.39% | 1.24 | −1.66% | 11.2 |
| v0 固定哑铃 70/30 | **+4.39%** | 1.79% | 1.67 | −2.38% | 0 |
| 固定中性 35/65 | +3.93% | 1.48% | **1.71** | −1.98% | 0 |
| 全防守 100% 3-5 年 | +3.46% | 1.21% | 1.71 | −1.66% | 0 |
| 全进攻 100% 7-10 年 | +4.79% | 2.09% | 1.62 | −2.80% | 0 |

**结论：Hedge 票的独立贡献是 −0.08pp 年化（回撤改善 +0.12pp、夏普 −0.02）。基本为零，方向为正但量级在噪声内。**

原因在状态分布里看得很清楚：

| 票 | −1 | 0 | +1 |
|---|---:|---:|---:|
| hedge | **291** | 966 | **3** |

3.5 年里股票动量打到 5 年分位顶的有 291 天（2024Q4 那波），打到分位底的只有 3 天 ——
Hedge 票实际上退化成「股票强势时减久期」的单边开关，而 2024Q4 之后债市并没有走熊，
所以它只是让组合少赚了一点。阈值网格 80/20 → +3.76%（夏普 1.65）、95/5 → +3.72%（1.60），
结论不随阈值变化：**本样本不支持 Hedge 票有独立增量价值**。

成本敏感性：0 / 10 / 40bp → +3.94% / +3.73% / +3.10%（换手极低，成本不是主要问题）。

## 3. 与其它变种的分工

| 变种 | 回答的问题 | 与 V4 的关系 |
|---|---|---|
| v0 | 债腿固定 70/30，不做择时 | 基准 |
| v1 | 净值/曲线/资金/信用四温度打分 → 长端占比 | 信号含基金净值噪声 |
| v2 | 7 只债基横截面动量轮动 | 回测为负，对照 |
| v3 | 曲线 carry + 趋势双票 | **V4 的直接母体**（差一条 Hedge 腿） |
| **v4** | 再加股票动量极端分位这条腿有用吗 | 结论：本样本无用 |
| v5 | 不预测方向，按已实现波动缩放敞口 | 与 V4 正交（风险预算 vs 方向） |
| v6 | 期限利差定久期 × 信用利差定品种 | 品种轴，V4/v5/v6 都只改债腿内部 |

## 4. 边界

- 样本仅 3.5 年、几乎全债牛，股票极端动量样本极少（−1 占 291 天、+1 仅 3 天），统计意义有限
- 沪深300 用指数点位，不含分红；只看动量分位，未做波动/估值调整的股票信号
- 原文的 Carry 用 10 年日度分位、Trend 用债券超额收益 EWMA、Hedge 用股债相关性变化，本仓库均做了可得性替代
- 不做空、不配 30 年超长、不含 ECFC/社融/DR007 等宏观数据
