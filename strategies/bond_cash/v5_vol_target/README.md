# V5 · 波动率目标（Volatility Targeting）

> 规则来源（2026-11-19 联网研究）：
> - **Moreira & Muir (2017)** *Volatility-Managed Portfolios*：按已实现波动反向缩放敞口，
>   夏普提升约 20~40%；机制是「波动高度持续、收益不持续」。
> - **目标波动率资产组合管理**（中国股/债/商品，7.5 年实证）：三档目标 9.5% / 17.3% / 28.0% 年化，
>   夏普均 >1.8、卡玛 >1.3，显著优于静态配置。
> - **兴证《利率债收益预测框架》**（2020-05）：VaR 方法的久期择时在**不降低收益**的前提下大幅压回撤
>   （VaR25%：年化 5.3% / 回撤 2.9% / 夏普 2.37，基准 1.85）。
> - **国泰海通《从利率择时到久期轮动》**（2026-06）：资金条件维度用长短期均线相对位置识别松紧。
>
> 参数权威源：`rule.py::CFG`。V5 **不预测利率方向**，只按风险预算缩放敞口 ——
> 这是它相对 v1~v4（全是方向票）唯一的、也是最本质的差别。

---

## 1. 规则

- **波动源**：长端腿 `003376`（7-10 年国开 A）的日对数收益，σ21 与 σ63 两个年化已实现波动取**较大者**（保守）
- **敞口**：`w = 70% × min(1, 1.50% / σ)`，clip 到 `[0, 70%]`（不允许加杠杆）
- **熔断**：`σ > 2 × 1.50% = 3.00%`（赎回潮/债灾形态）→ 长端直接清零，100% 放 `011983`
- **调仓**：月末最后交易日（默认）或每 10 个交易日（双周）；T+1 承担；滞后带 1.5pp
- **额度**：债腿 30pp、现金腿 10pp（5pp `000198` + 5pp `014437`）与 v0 完全一致

σ 上去了就自动减久期、σ 回落就自动加回来；`target_vol = 1.50%` 取自 `003376` 的长期波动的中枢
（**在样本内标定**，见 §4）。

---

## 2. 回测（完整表见 `backtest/_v5_bt.md`）

窗口 2021-12-09 ~ 2026-11-18（1197 交易日；V5 不依赖曲线缓存，所以样本比 v3/v4/v6 长 1.5 年）：

| 方案 | 年化 | 波动 | 夏普 | 最大回撤 | Σ\|Δw\| |
|---|---:|---:|---:|---:|---:|
| **V5 波动率目标（月末）** | +4.15% | **1.53%** | 1.80 | **−1.66%** | 5.4 |
| V5（每 10 日 / 双周） | +3.88% | 1.56% | 1.59 | −1.94% | 9.3 |
| V5（无滞后带） | +4.15% | 1.53% | 1.80 | −1.66% | 5.4 |
| **反面：高波动加久期（机制对照）** | +4.25% | 1.71% | 1.66 | −2.38% | 4.4 |
| v0 固定哑铃 70/30 | **+4.49%** | 1.72% | 1.79 | −2.38% | 0 |
| 固定中性 35/65 | +4.15% | 1.47% | **1.87** | −1.98% | 0 |
| 全防守 100% 3-5 年 | +3.81% | 1.28% | 1.89 | −1.66% | 0 |
| 全进攻 100% 7-10 年 | +4.78% | 1.97% | 1.72 | −2.80% | 0 |

**结论：V5 用 0.34pp 年化换 0.72pp 回撤，夏普与 v0 打平（1.80 vs 1.79）。它不是 alpha，是一层风险预算。**

关键的**机制对照**：把方向反过来（高波动加久期）拿到 +4.25% 年化但回撤回到 −2.38%、夏普 1.66 —— 
收益几乎一样、回撤差 0.72pp，说明「回撤更浅」确实来自按波动缩放这个机制，而不是样本本身的运气。
但也要看清：**正向与反向的收益只差 0.10pp**，这段样本的收益主要由「平均敞口高低」决定
（V5 平均长端 50.3%，v0 是 70%）。

其它证据：

- **目标波动敏感性**：1.0% / 1.5% / 2.0% / 2.5% → 年化 +3.97% / +4.15% / +4.27% / +4.43%，
  夏普 1.83 / 1.80 / 1.76 / 1.79，回撤 −1.66% / −1.66% / −2.05% / −2.17%。
  **往 2.5% 走就退化成「基本不动手」**（平均长端 66.5%、Σ|Δw| 仅 1.5），这是典型的「少交易更好」，
  不是 vol targeting 的功劳。
- **敞口分布**：平均 50.3% / 中位 59.2% / 最低 0% / 最高 70%；熔断触发 **155/1197 天（12.9%）**；
  区间 σ 分位 25% 1.37% / 中位 1.82% / 75% 2.44%。
- **双周比月末更差**（+3.88% vs +4.15%，回撤 −1.94% vs −1.66%）：境内债基的波动变化慢，
  提高调仓频率只增加成本（Σ|Δw| 5.4 → 9.3）。
- **无滞后带与有滞后带完全相同**：说明 vol targeting 的权重跳变幅度本来就大于 1.5pp，滞后带不构成约束。
- 成本：0 / 10 / 40bp → +4.38% / +4.15% / +3.48%。

## 3. 怎么用

- **不建议替代 v0**：v0 的夏普（1.79）与 V5（1.80）相同，而 V5 多一层「信号解释成本」。
- **推荐定位**：给「我不想在赎回潮里扛 −2.4% 回撤」的人 —— 把 `target_vol` 设到 1.5%、
  月末调仓，就得到「收益打平、回撤浅 0.7pp」的版本；`target_vol` 调高会平滑退化为不动手。
- **不要**：拿它做收益增强（它不产生 alpha）、不要提高调仓频率、不要加杠杆（cap 固定 70%）。

---

## 4. 边界

- 样本 2021-12~2026-11 仅 5 年；`target_vol=1.50%` 取自 `003376` 的长期中枢，**样本内标定**
- 波动率预测的是**风险**不是收益：债牛里波动抬升的几段往往也是上涨段，V5 必然少赚（2024 少 1.19pp）
- 「熔断」用 σ 阈值近似 VaR，不是真正的在险价值；跨资产波动目标、杠杆腿均未实现
- 只覆盖 7-10 年 vs 3-5 年两档，不含 30 年超长与信用下沉
