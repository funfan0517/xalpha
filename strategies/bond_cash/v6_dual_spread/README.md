# V6 · 双利差锚（期限利差定久期 × 信用利差定品种）

> 规则来源（2026-11-19 联网研究）：
> - **国信证券**《基于双利差锚的周期划分和债券投资策略》（《金融经济》2021-04）：
>   以**期限利差 + 信用利差**为锚划分货币-信用周期，双利差领先于债市回报。配置结论：
>   期限利差**上升缩短久期、下降拉长久期**；信用利差**上升选长久期国债、下降下沉信用**。
> - **国泰海通**《债券择时从多空到轮动：信用—利率与久期的双层策略》（2026）：
>   第一层「信用 vs 利率」、第二层「久期轮动」，双层优于单一方向信号；因子体系含期限利差、信用利差、多资产比价。
>
> 参数权威源：`rule.py::CFG`。**V6 是家族里第一个同时回答「久期多长」和「拿利率还是拿信用」的变种**。

---

## 1. 两轴正交

### 久期轴（期限利差，10Y − 1Y）

| 票 | 构造 | 映射 |
|---|---|---|
| **Carry** | 期限利差近 3 年滚动分位 | ≥66.7% → +1，≤33.3% → −1，中间 0 |
| **Slope** | 期限利差的 **60 日变化** Δs | Δs ≤ −10bp（牛平）→ **+1**；≥ +10bp（熊陡）→ **−1**；中间 0 |

`score = carry + slope ∈ [−2,+2]` → 长端 `003376` 占债腿 `0 / 17.5 / 35 / 52.5 / 70%`，其余放底仓。

### 品种轴（信用利差，AAA 中短票 3Y − 国债 3Y）

| Δcs（60 日变化） | 底仓 |
|---|---|
| ≤ −5bp（信用收窄 = 风险偏好修复） | **`000032` 易方达信用纯债 A** |
| ≥ +5bp（信用走阔 = 避险） | **`011983` 永赢 3-5 年政金 A** |
| 中间 | 维持上次选择（用「保持」而不是回默认，避免锯齿） |

两条轴**互不影响**：久期轴只动 `003376` 与底仓的比例，品种轴只动「底仓是谁」。
月末最后交易日调仓、T+1 承担；滞后带 1.5pp；单边 10bp；40pp 额度与现金腿完全不动。

## 2. 回测（完整表见 `backtest/_v6_bt.md`）

窗口 2023-05-30 ~ 2026-11-18（842 交易日；受曲线缓存 + 3 年分位限制）：

| 方案 | 年化 | 波动 | 夏普 | 最大回撤 | Σ\|Δw\| |
|---|---:|---:|---:|---:|---:|
| **V6 双轴** | +3.14% | **1.14%** | 1.52 | **−1.58%** | 15.1 |
| 只久期轴（底仓固定 `011983`） | **+3.79%** | 1.41% | **1.69** | −1.98% | 3.7 |
| 只品种轴（长端固定 70%） | **+4.13%** | 1.67% | 1.63 | −2.21% | 4.8 |
| v0 固定哑铃 70/30 | **+4.39%** | 1.79% | 1.67 | −2.38% | 0 |
| 固定中性 35/65 | +3.93% | 1.48% | **1.71** | −1.98% | 0 |
| 全防守 100% 3-5 政金 | +3.46% | 1.21% | 1.71 | −1.66% | 0 |
| 全进攻 100% 7-10 国开 | +4.79% | 2.09% | 1.62 | −2.80% | 0 |
| 固定 70/30 但底仓用信用债 | +4.12% | 1.64% | 1.66 | −2.21% | 0 |
| 满仓信用债 `000032` | +2.57% | 0.73% | 1.62 | −0.97% | 0 |

**结论：双轴互相抵消，年化 3.14% 同时输给两个单轴（3.79% / 4.13%）和 v0（4.39%）。**

三条证据：

1. **久期轴把长端压到平均 25.8%**（v0 是 70%）。3.5 年里 `slope` 票有 261 天投 −1（利差走阔），
   叠上 `carry` 长期在 0/−1，`score` 很少到正区间 → V6 的默认状态就是「短久期」。
   这跟 v3 的病一样（两票常在反方向），区别只是 v3 换成 carry+trend、V6 换成 carry+slope。
2. **品种轴的「超额」其实是信用债本身的收益**：只品种轴 +4.13% 与「固定 70/30 但底仓换信用债」
   +4.12% 几乎相等 —— 说明按月切换品种没有择时价值，只是 71.3% 的时间持有信用债。
3. **成本把双轴吃穿**：Σ|Δw| 15.1（是 v3 的 3 倍），单边 40bp 时年化崩到 **+1.79%**。
   原因在品种切换：换底仓一次等于卖出 (1−w) + 买入 (1−w)，Σ|Δw| = 2(1−w)。

唯一亮点：**2025 年是 V6 唯一跑赢 v0 的年份（+0.65% vs −0.13%）** —— 那年是债熊，
短久期 + 信用债的组合确实抗跌。这与「双利差锚是周期划分工具、不是月度轮动工具」的定位一致：
**用它判断「现在该不该拉久期」，比用它每月切品种靠谱。**

死区网格（期限 5/10/20bp × 信用 3/5/10bp）全部落在 +3.07%~+3.38%、夏普 1.48~1.74，
结论不随参数变化：**问题在结构，不在参数**。

## 3. 与其它变种的分工

| 变种 | 回答的问题 |
|---|---|
| v0 | 固定 70/30，不动手（基准） |
| v1 | 四温度打分 → 长端占比（净值噪声大） |
| v2 | 横截面动量轮动（回测负） |
| v3 | 曲线 carry + 趋势 |
| v4 | v3 + 股票动量 Hedge 票 |
| v5 | 按已实现波动缩放敞口（不预测方向） |
| **v6** | **久期轴 × 品种轴（利率 vs 信用）** |

V6 是家族里唯一引入**信用品种**的变种，`000032` 也只在这个变种里进债腿。

---

## 4. 边界

- 样本 3.5 年（曲线缓存 2022-06 起 + 3 年分位），且期间信用利差整体收窄 → 品种轴天然偏向信用债
- `000032` 是**主动信用纯债**（非指数），信用下沉程度与跟踪误差不可控
- 券种切换只按利差动量，不含流动性/估值/赎回费结构；按单边 10bp 近似，40bp 时策略失效（见上）
- 信用利差只用 AAA 3Y，未做评级下沉阶梯；期限利差只用 10Y−1Y 单点，未做 2s5s10s 蝶式分解
- 月度调仓照搬国信的「周期划分」框架，但原文是季度/半年度尺度 —— 频率不匹配可能正是双轴互相抵消的原因
