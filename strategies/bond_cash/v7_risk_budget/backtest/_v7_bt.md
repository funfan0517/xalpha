## 结论与边界

- V7（ERC+约束）年化 **+3.62%** / 回撤 **-2.03%** / 夏普 1.93；无约束 ERC +3.54% / -1.71% / 1.95；逆波动 +3.58% / -2.67% / 1.57。
- 门派基准：全利率 +3.46% / -4.26% / 1.31；全信用 +3.20% / -1.89% / 2.11；全转债 +5.39% / -22.18% / 0.37；等权 +4.15% / -5.94% / 0.77；人工 70/20/10 倾斜 +3.66% / -2.36% / 1.47。
- ERC 的价值在**风险贡献表**：平均权重与平均风险贡献的差就是「谁在偷风险」。如果某一类权重只有 10% 却贡献 40% 的风险，那就是配比失衡的客观证据 —— 这比收益表有用。
- 边界：回测只覆盖**债腿内部**，现金 10pp 在外；转债只有 1 只主动型壳（470058），它的收益含少量股票 beta，不等于转债指数；样本起点由四腿净值交集决定（2026-11-25 中端由 011983 换成 001512 后，净值交集起点由 2021-09 前移到 2016-09、回测起点由 2021-12 前移到 2016-12），窗 60 日的协方差估计在样本内选定，不构成严格样本外。
- 不追求跑赢全利率：4 类资产的期望收益差只有 1~3pp/年，而估计误差更大；V7 的定位是「配比体检 + 失衡告警」，不是收益增强。
