## 结论与边界

- V7（ERC+约束）年化 **+3.48%** / 回撤 **-1.51%** / 夏普 1.75；无约束 ERC +2.93% / -1.63% / 1.52；逆波动 +3.73% / -1.82% / 1.55。
- 门派基准：全利率 +4.51% / -2.38% / 1.78；全信用 +2.50% / -1.77% / 1.52；全转债 -0.85% / -22.18% / -0.21；等权 +2.16% / -5.88% / 0.21；人工 70/20/10 倾斜 +3.61% / -1.87% / 1.36。
- ERC 的价值在**风险贡献表**：平均权重与平均风险贡献的差就是「谁在偷风险」。如果某一类权重只有 10% 却贡献 40% 的风险，那就是配比失衡的客观证据 —— 这比收益表有用。
- 边界：回测只覆盖**债腿内部**，现金 10pp 在外；转债只有 1 只主动型壳（470058），它的收益含少量股票 beta，不等于转债指数；样本 2021-12 起（受 011983 成立限制），窗 60 日的协方差估计在样本内选定，不构成严格样本外。
- 不追求跑赢全利率：4 类资产的期望收益差只有 1~3pp/年，而估计误差更大；V7 的定位是「配比体检 + 失衡告警」，不是收益增强。
