# V8 · 久期阶梯风险预算：六个债腿各配多少（0~100%，合计 100%）

> 需求来源（2026-11-20，用户原话摘要）：「参考 v7 创建一个 v8，门派只有利率债和信用债两类，
> 标的 #603 1-3 农发 / #604 3-5 国债 / #605 3-5 政金（底仓）/ #606 7-10 国开（进攻）/
> #608 易方达信用债 A / #609 汇添富 AAA 0-3 A，动态调整每个标的的比例（0-100）合并 100，
> **达到夏普大于基准**」。
>
> 参数权威源：`rule.py::CFG`。**默认 `daily.enabled=false`（研究变种，不进每日操作报告，见 `AGENTS.md` §9）**。
> 回测报告：`backtest/_v8_bt.md`；当日读数：`daily/_v8_daily.md`。

---

## 1. 先回答那个问题：为什么是「久期阶梯」而不是 v7 的 ERC

v7 用等风险贡献（ERC）解四门派的配比，结论是 **ERC ≈ 约束下的逆波动**（夏普 1.75 vs 逆波动 1.55），
提供不了额外 alpha。这一条在 v8 里被进一步验证并**否掉**：

| 方案（v8 实测，2021-12~2026-11，债腿内部 100%） | 年化 | 波动 | 夏普 |
|---|---:|---:|---:|
| v7 式 ERC（六腿滚动等风险贡献，同窗口） | +2.90% | 0.91% | 1.65 |
| 六腿逆波动（1/σ 加权） | +2.99% | 0.93% | 1.72 |
| 六腿等权 1/6 | +3.25% | 1.06% | 1.74 |
| **v8 久期阶梯（本文规则）** | **+3.56%** | **1.18%** | **1.83** |

根因不是「算法不够好」，而是**夏普公式里的 rf 是硬扣项**：rf=1.4%，债基年化只有 2.5~4.8%。
ERC 把组合波动压到 0.9% 的同时也把收益压到 2.9%，超额只剩 1.5pp → 夏普反而上不去。
**要抬夏普，必须让风险落在「每单位波动能换来更多收益」的腿上，而不是平均分摊。**

所以 v8 回到**权重空间**做预算：不问「谁承担多少波动」，直接问「钱按久期阶梯怎么摆」。

## 2. 规则

### 2.1 结构层：久期阶梯四档（占债腿，和 = 100%）

| 档 | 腿 | 结构预算 | 理由 |
|---|---|---:|---|
| 长端 7-10（进攻） | `003376` #606 | **20%** | 久期 7.68 是中端的 2 倍，多承担 0.7pp 波动只多赚 ~1pp/年，边际夏普 ≈1.4 < 组合 1.8 |
| 中端 3-5（底仓） | `011983` #605 / `001512` #604 | **45%** | 用户指定 #605 为底仓；两壳同久期，**同档择一不双持**（家族惯例：两壳择一） |
| 短端 1-3 | `005623` #603 | **5%** | 久期 1.5 的现金替代，压波动用；给多了会把债牛也砍掉（v0 §3 已证） |
| 信用 | `000032` #608 (2/3) + `006884` #609 (1/3) | **30%** | 两个门派里的分散来源：与利率腿相关 0.68~0.83，是唯一真正的分散项 |

**把长端压到 20% 是 v8 全部收益的来源**，代价是少赚约 1pp/年（见 §3）。
注意：2026-11-20 v0 自己改成 35/65 后，v8 的「降长端」不再是独有优势 —— 见 §5 的对比。
这不是回测拟合：长端久期 7.68、中端 3.76，两种久期的「波动/收益」比价是债券的算术，
2019-2026 与 2021-2026 两个窗口的单腿夏普结论一致（长端 1.61/1.72，中端 0.99~1.96）。

### 2.2 动态层：两处，都只管风险、不预测方向

| 机制 | 做什么 | 参数 |
|---|---|---|
| **同档择一** | 中端档 45% 整份给「近 **504 日夏普**更高」的壳；领先不足 **0.15** 维持原持仓（防抖） | `pick.sr_win=504`、`pick.deadband=0.15` |
| **进攻档波动煞车** | `003376` 权重 × `(σ252/σ60)^1`，**只夹在 [0.60, 1.00]** —— 波动升温最多砍到 60%，降温**不追高** | `vol_feedback={003376:1.0}`、`vol_feedback_clip=(0.60,1.00)` |

为什么要「只煞车不追高」：对称缩放（clip 到 1.67）在回测里是 **1.82 < 1.83**，因为「低波动期加仓」
等价于在长端涨完之后追进去（2024 年长端 +8.9%），是典型的追涨。砍仓不追高才是风险纪律。

### 2.3 交易与约束

- 月频：月末最后交易日解一次，**T+1 承担**；滞后带 1.5pp（变动 <1.5pp 不动手）
- 单腿上障 **50%**（任一只不得超过债腿一半）；下障 0（允许某只被规则排除到 0，符合「0-100」）
- 成本：其余腿 `Σ|Δw| × 单边 10bp`；长端腿按**真实赎回费阶梯**逐笔计（见 §2.5）。
  回测实测：不开闸门 Σ|Δw| = 1.5（5 年 12 次，2.4 次/年）；开闸门 12.6（42 次，8.5 次/年）
- 现金腿 10pp = 5pp `000198` + 5pp `014437`，**固定在外、不参与配比**（家族口径）

### 2.4 两条纪律（从 v1 继承，默认 ① 开 / ② 关）

| 纪律 | 做什么 | 默认 | 实测 |
|---|---|---|---|
| **① 缺数据降级** | 某档腿缺净值时，该档预算**移交最短久期腿 `005623`**，并在产物标 `degraded` | **开** | 样本内 0 触发，数字不变 |
| **② 信用腿冻结** | 信用腿 σ60/σ252 > 1.5 → 随后 2 个调仓周期「预算 × derisk + 只许减不许加」 | **关** | 触发 9 次；derisk 1.0/0.85/0.7/0.5/0.0 → 夏普 **1.83/1.82/1.81/1.79/1.75**，回撤 −1.59→−1.67 |

① 修的是一个**真实隐患**：原实现缺档时把该档预算按比例摊给其他档，等于「某腿数据缺失 → 悄悄给别的腿加杠杆」。
② 反过来是**反面教材**：信用腿正是 v8 的分散来源，在信用波动升温时砍它 = 在最糟的时刻卖掉分散，
所以降险越狠越差；开关保留给极端信用事件（违约/流动性冲击）手动启用。顺带一个更隐蔽的坑：
只做「禁止加仓」（derisk=1.0）时**权重一字未改** —— v8 的信用预算本来是固定 30%，
禁止一件从不发生的事等于没有规则。这条已写进 `rule.py` 注释，避免以后有人「补上一个看起来更严的版本」。

### 2.5 ③ 长端趋势闸门（日频，2026-11-20 装）

| 机制 | 做什么 | 参数 |
|---|---|---|
| **长端趋势闸门** | `003376` 的 **30 日累计净值动量**转负 → 该腿 20% 整块退 `000198`（退货基）；转正且离场满 `min_hold` 才回场 | `mom_win=30`、`min_hold=7`、`to=000198` |

`min_hold` 是**双向**最短持有：刚回场不满 7 个交易日时，动量转负也**不卖**。单向冷却（只在离场后等 7 天）
在实测里会造出「持有 1 个交易日就卖」的份额，卖出直接落进 1.50% 赎回费档 —— 一个来回吃掉半年收益。

**成本口径是本条最重要的结论**（`rule.py` 的 `redeem_ladder` / `buy_fee`）：

| 口径 | 年化 | 夏普 | 最大回撤 | 最差单年 |
|---|---:|---:|---:|---:|
| 不开闸门（单边 10bp） | +3.56% | **1.83** | −1.59% | +0.22% |
| 开闸门·**费前**（fee=0，只看信号） | +3.55% | 1.98 | −1.33% | +0.36% |
| 开闸门·**A 类真实申赎费** | +3.22% | **1.65** | −1.60% | −0.03% |
| 换 C 类 `003377` + 网格最优（20/40） | +3.37% | 1.91 | −1.31% | +0.55% |

`003376` 是 A 类，赎回费按**持有自然日**阶梯：<7 日 1.50% / 7~30 日 0.50% / 30~365 日 0.10% /
365~730 日 0.05% / ≥730 日 0。日频闸门造出大量「持有几周」的份额，按 10bp 单边统一近似会
**系统性低估**成本。引擎现在逐笔按实际持有天数取费率、买入按 `buy_fee` 计，并从统一 `fee_side`
里扣掉长端部分（不重复收费）。

**结论**：费前那 1.98 **不可实现**，不能引用。A 类实盘口径（1.65）低于不开闸门（1.83）；
换 C 类（申赎费≈0，但净值每年少 0.35pp 销售服务费）后最优也只有 1.91，且最优参数是网格里
挑出的单点（相邻格子 1.55~1.91 抖得厉害，没有稳定区域）。**这条闸门买的是「回撤更浅」，
不是「夏普更高」**；在 A 类份额上是负贡献。

## 3. 回测（完整表见 `backtest/_v8_bt.md`）

窗口 2021-12-07 ~ 2026-11-19（1200 交易日，受 `011983` 成立 + 60 日预热限制）；债腿 100% 内部：

| 方案 | 年化 | 波动 | 夏普 | 最大回撤 | 最差单年 |
|---|---:|---:|---:|---:|---:|
| **V8 久期阶梯** | +3.56% | 1.18% | **1.83** | **−1.59%** | **+0.22%** |
| V8 关择壳（中端固定 011983） | +3.54% | 1.19% | 1.80 | −1.59% | +0.22% |
| V8 关波动煞车（κ=0） | +3.61% | 1.20% | 1.84 | −1.62% | +0.24% |
| V8 两项动态全关（静态 20/45/5/20/10） | +3.63% | 1.20% | 1.85 | −1.62% | +0.24% |
| **基准 v0 固定中性 35/65（003376+011983）** | **+4.20%** | 1.50% | **1.87** | −1.98% | +0.02% |
| 基准 v0 旧配比 70/30（2026-11-20 前） | +4.53% | 1.74% | 1.80 | −2.38% | −0.13% |
| 六腿等权 1/6 | +3.25% | 1.06% | 1.74 | −1.45% | +0.45% |
| 全底仓（100% `011983`） | +3.86% | 1.31% | 1.88 | −1.66% | +0.16% |
| 全长端（100% `003376`） | +4.82% | 1.98% | 1.73 | −2.80% | −0.26% |

**四条硬结论，一条都不遮**：

1. **⚠ 2026-11-20 基准变了，结论翻面**：v0 由 70/30 改为 35/65 后，基准夏普从 1.80 升到 **1.87**，
   v8 的 1.83 就从「领先 0.03」变成「**落后 0.04**」（六腿等权 1.74 仍最低）。年化少赚 0.64pp，
   换来回撤浅 0.39pp、最差单年 +0.02% → +0.22%。**「夏普大于基准」已不成立。**
   对旧 70/30 的结论（领先 0.03、回撤浅 0.79pp）只在下表那一行里有效。
2. **动态项没有 alpha，甚至是负的**（关择壳 1.80 → 两项全关 1.85）：真正抬夏普的是**结构**
   （长端压到 20%），不是择时。v8 保留两项动态是因为它们是**风险纪律**（换掉更差的壳、
   长端波动升温时减仓），不是收益来源 —— 与 v1~v6「择时久期不划算」的结论一致。
   而这条「结构」本身，v0 的 35/65 用一个数字就拿到了，所以 v8 现在没有相对优势。
3. **全底仓 1.88 是表里最高，但不能这么读**：那是单腿集中，赌一只政金债不出事；
   v8 的约束是「六腿各 0~100%、合计 100%、两个门派都要有」，两者不可比。
4. **长窗（2019-06 起，中端只能用 `001512`）V8 1.58 vs 基准（35/65）1.41 vs 五腿等权 1.81
   → 长窗里 v8 反而跑赢基准 0.17，与短窗结论相反。** 两个窗口打架的原因是「底仓壳的质量」：
   `011983`（政金 3-5）比 `001512`（国债 3-5）同窗多 +0.67pp/年，短窗比的是「有 011983 的基准」，
   长窗里基准被换成了更弱的 001512。**别只引一个窗口**，如实写在这里。

敏感性：择壳窗 252 / 504 / 756 日 → 夏普 1.79 / 1.83 / 1.84；成本 0 / 10 / 40bp →
1.86 / 1.83 / 1.73（月频、Σ|Δw|=1.5，10bp 以内成本可忽略，40bp 会吃掉超额）。

## 5. 与其它变种的分工

| 变种 | 回答的问题 | 关键结论 |
|---|---|---|
| v0 | 固定中性 35/65，不动手（**基准**） | +4.20% / −1.98% / **夏普 1.87** |
| v1 / v3 / v4 | 用方向票（温度 / 曲线 / 股票）择时久期 | 全部跑不赢 v0 |

与 v7 的关键差别：v7 把资产归成 3 个「门派」解风险贡献（组合波动压到 1.0% 以下，夏普上不去）；
v8 把 6 个标的按**久期档**直接摆权重，让组合波动停在 1.2% 附近 —— 这是 rf=1.4% 环境下
「夏普能站住」的波动区间。

## 6. 边界

- 样本 2021-12~2026-11 仅 5 年（受 `011983` 2021-09 成立限制），且全程是债牛 + 2025 债熊一小段
- 结构预算 20/45/5/30、择壳窗 504 日、死区 0.15、煞车指数 1.0 全部取自同一份历史，
  **不构成严格样本外**；只做了窗口/成本/择壳窗三项敏感性
- 长窗只能拿 `001512` 顶中端档（`011983` 没有 2021 前净值），两个窗口的结论不一致，已如实列出
- 只覆盖债腿内部；现金 10pp 固定在外，「四门派合计 40pp」由卡片叠加显示
- 未做：信用利差择时（v6 已证无效）、转债（用户这次的池里没有）、跨资产统一预算
- 成本口径：**闸门腿（`003376`）已按 A 类真实赎回阶梯 + 申购费逐笔计**；其余腿仍按单边 10bp 近似
  （信用债/转债的赎回费与到账时滞未细分）。闸门的费前/真实差异见 §2.5，**不要引用费前夏普**

## 7. 从 v1~v6 继承 / 否决了什么（同窗口实测）

2026-11-20 把 v1~v6 的机制逐条搬到 v8 的引擎上跑（同窗口、同成本、月频），结果如下 ——
**信号层面几乎借不到东西，能借的是两条纪律（见 §2.4）**：

| 借鉴点 | 出处 | v8 实测（年化 / 夏普） | 结论 |
|---|---|---|---|
| 波动煞车（现用） | v5 | 基线 **1.83** | 已吸收 |
| 煞车下界 0.6 / 0.4 / 0.2 / 0 | v5 | **全部 1.83，完全相同** | 债腿 σ60/σ252 最高只到 ~1.7，从没逼近 0.6 |
| 硬熔断（σ>2× 中枢 → 长端清零） | v5 `guard_mult` | **1.83，一次都没触发** | 不借（债腿波动比很少翻倍） |
| σ=max(σ21,σ63) 保守短窗 | v5 | 21/63/120 日 → **1.84** | 可借但属噪声级 |
| 择壳改用 126 日动量 | v2 | **1.81** | 不借（504 日夏普 1.83 更好） |
| 期限利差分位 → 长端预算 15~25% | v3 / v6 | **1.82** | 不借 |
| 信用利差分位 → 信用预算 25~35% | v6 | **1.82** | 不借 |
| 双轴同时（复刻 v6） | v6 | **1.81** | 不借 |
| 绝对动量降落伞（夏普<0 清零） | v2 | 长端清零 **1.81**；再退短端 **1.76** | 不借（长端滚动夏普为负只占 5.3% 交易日，砍在噪声上） |
| 缺数据折扣（数据不全就缩敞口） | v1 `temp_min_coverage` | 样本内 0 触发，数字不变 | **借（① 降级）** |
| 事件冻结「只许减」 | v1 `freeze_days` | 降险越狠越差（1.83→1.75） | 装好但**默认关**（② 冻结） |

两条经验值得记住：

1. **「禁止加仓」这种规则在固定预算策略里等于没有规则** —— ② 的 derisk=1.0 触发 9 次而权重一字未改。
   写风控规则时先问「这条规则约束的那个动作，在本策略里到底会不会发生」。
2. **分散腿不能在它波动的时候砍** —— 信用腿是 v8 唯一的跨门派分散来源，赎回潮里砍它
   等于把相关性最高的时刻当成最该卖的时刻。
