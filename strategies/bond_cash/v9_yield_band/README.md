# V9 · 10Y 国债收益率阈值久期切换

> 需求来源：2026-11-27 用户先要求按 10Y 分位/阈值做纯债久期切换，同日三次迭代：
> ① 三档配置改为 HIGH 长3:中6:短1 / MID 长6:中3:短1 / LOW 长1:中3:短6；
> ② 指出 MID 8.4% 太少 → high 抬到 3.5（MID 66%）；
> ③ 又嫌 MID 太长、要求调参优化夏普并降低回撤 → high 收到 **3.0**。
> 终版阈值 **2.0/3.0**，MID 占比 **40.5%**；再叠加**波动目标 1.0%**（2026-11-27 用户确认设为默认）：
> 夏普 **1.47**、回撤 **−3.01%**（不带缩放的口径为 1.21 / −4.03%）。
>
> 参数权威源：`rule.py::CFG`。**`daily.enabled=false`（研究变种，不进每日操作报告，见 `AGENTS.md` §9）**；
> 没有 `daily.runner`，不随每日操作跑。回测 `backtest/_v9_bt.md`，阈值研究
> `research/threshold_tuning/_threshold_tuning.md`，降回撤研究
> `research/drawdown_control/_drawdown_control.md`，手动读数 `daily/_v9_daily.md`。

## 1. 规则（2026-11-27 终版）

| 10Y 国债收益率 | 档位 | 长 : 中 : 短 | 债腿目标（占 30pp 债腿） |
|---|---|---|---|
| **> 3.0%** | HIGH | **3 : 6 : 1** | `003376` 30% + `001512` 60% + `002864` 10% |
| 2.0% ≤ 10Y ≤ 3.0% | MID | **6 : 3 : 1** | `003376` 60% + `001512` 30% + `002864` 10% |
| **< 2.0%** | LOW | **1 : 3 : 6** | `003376` 10% + `001512` 30% + `002864` 60% |

- **三区直接映射（默认，`hysteresis=false`）**：每天按 10Y 落在哪区就配哪档。原带记忆状态机
  从 HIGH/LOW 永远回不到 MID，使 MID 档形同虚设，已保留为回测对照。
- **交易**：月末最后交易日再平衡；档位变化后**下一交易日**执行（T+1）；权重变动 <1.5pp 不动手；
  单边成本默认 10bp（网格 0 / 10 / 30bp）；分红再投资口径（场外累计净值）。
- **低回撤叠加（默认开启，`vol_target.enabled=True`）**：在档位权重上乘缩放系数
  `scale = clip(1.0% / 过去 60 日已实现年化波动, 0.40, 1.00)`，**月末计算、下月执行**，
  变动 <10pp 不调；剩余仓位给短债 `002864`，即 `w = w_state × scale + (1−scale) × 短债`。
  该层只压波动/回撤，不改阈值与三档比例；`rule.CFG['vol_target']['enabled']=False` 可回到无缩放口径。
- **口径边界**：回测在家族**债腿 30pp 内部**（权重和 100%）做；现金腿 10pp 固定在外。
  视频旧标准 3.2%、初版 1.8/2.5、上一版 2.0/3.5 都只作历史对照，不进入信号。

## 2. 阈值迭代与多目标优化

`1.8/2.5` → `2.0/2.5` → `2.0/3.5` → `2.0/3.0`：

1. 初版 `2.0/2.5` 下 MID 只占 8.4%（利率长期在 2.5% 以上或快速跌破 2.0%）。
2. `2.0/3.5` 把 MID 拉到 66.1%，但用户指出 MID 太长，且回撤加深到 −4.99%。
3. 第三轮在 317 组网格上加了**多目标约束**：MID 占比 25%–55%、三档都保留、
   最大回撤浅于 −4.2%，先按邻域平台再按夏普挑参数（详见 `research/threshold_tuning`）。
   胜出的是 `2.0/3.0`：
   - MID 66.1% → **40.5%**（HIGH 39.9% / LOW 19.5%，三档接近均衡）；
   - 夏普 1.18 → **1.21**，年化 +3.26% → **+3.20%**，回撤 −4.99% → **−4.03%**，
     卡玛 0.65 → **0.79**；
   - **月胜率 75.6% → 75.6%，没有下降**（用户担心的「MID 变短胜率降低」在组合层面未发生）；
   - 代价：walk-forward 平均 OOS 夏普 1.81 → 1.70（仍远高于初版 1.8/2.5 的 1.41）。
4. 邻域 `1.9/3.0`（夏普 1.22 / 切换 15 次）与 `2.1/3.0`（1.19 / 17 次）表现接近，
   `2.0/3.0` 因切换更少（11 次）、邻域平台略优而中选。

### 分段

| 窗口 | V9 年化 / 夏普 | 基准 35/65 | 长债持有 | 短债持有 |
|---|---:|---:|---:|---:|
| 全期 | +3.07% / 1.47 | +3.17% / 1.11 | +4.13% / 1.15 | +2.68% / 3.63 |
| 2016–2020（实际 2016-09 起） | +2.79% / 1.05 | +2.64% / 0.65 | +3.03% / 0.57 | +3.37% / 5.32 |
| 2021–2026 | +3.28% / **1.93** | +3.56% / 1.62 | +4.94% / 1.84 | +2.18% / 2.34 |

两段的夏普都赢基准；后段 1.93 也高于长债持有的 1.84，但年化仍低于基准（+3.28% vs +3.56%）。
短债持有 3.63 仍是样本最高，原因是 rf=1.4% 下低波动资产的算术优势。

### 稳健性

- 阈值邻域（含波动目标）1.9/3.0 → 1.46、2.0/3.0 → 1.47、2.1/3.0 → 1.47，回撤都是 −3.01%（平台平稳）。
- 波动目标 1.0 / 1.2 / 1.4 / 1.6% → 夏普 1.47 / 1.37 / 1.34 / 1.33、回撤 −3.01% ~ −3.51%，
  **是平台不是单点最优**；1.0% 偏回撤优先，1.2% 偏收益/回撤平衡。
- 分位口径最好的是 10 年 30/70 → 1.51，5 年 30/70 → 1.16；分位只作诊断，不改默认。
- 月末 / 周末再平衡 1.47 / 1.46；成本 0 / 10 / 30bp → 1.64 / 1.47 / 1.10。
- 滚动 3 年窗口：2022-09 后 V9 开始跑赢长债持有，最后一段 1.85 vs 1.66。

## 5. 边界（务必连同回测数字一起读）

1. 10Y 只是大方向，不是保本信号；信用违约、流动性、基金杠杆/久期漂移都会改变实际结果。
2. 2.0%/3.0% 是 317 组网格 + 邻域平台 + walk-forward 的多目标选参结果，**不是经济理论推出的铁律**；
   相对上一版 3.5% 牺牲了 OOS 均值（1.81 → 1.70）、换来了更均衡的三档占比和更浅回撤。
3. 中债指数在仓库里没有可复现净值，代理不是指数本身；`003376` 2016-09 才成立，2016 段不满一年。
4. 场外 A 类申赎费按统一单边成本近似，未逐笔按持有期阶梯计费（v8 已有真实阶梯引擎，需要时复用）。
5. 当前读数（2026-11-24）：10Y = **1.5853%**、近 5 年分位 **0.2%**、LOW 档；
   债腿内 3pp `003376` + 9pp `001512` + 18pp `002864`，现金腿固定 10pp `000198`。
6. 波动目标是**路径依赖的缩放，不是免费午餐**：按 60 日已实现波动月末缩放到 1.0%，
   把最大回撤从 −4.03% 压到 **−3.01%**、夏普 1.21 → 1.47，代价是年化 +3.20% → +3.07%、
   调仓 11 → 48 次（约 5 次/年）；波动飙升后若市场快速反弹会被动低配、跑输无缩放口径。
   1.0% 也是样本内选的（1.0~1.6 呈平台，见 `research/drawdown_control/_drawdown_control.md`），
   应按「低回撤模式」理解。**已按用户 2026-11-27 确认设为默认**，
   `rule.CFG['vol_target']['enabled']=False` 可关闭作对照。
