## 2. 打分模型

```
总分(0–100) = 60% × 业绩分 + 40% × 价值分

业绩分 = Σ w_W·窗口分_W / Σ w_W,  w = 3年 50% / 5年 30% / 10年 20%   ← 3 年权重最高
        窗口分_W = 60% × 收益分 + 40% × 回撤分（池内横截面分位）
价值分 = PE(20) + PE分位(20) + 股息率(20) + 股债收益比(20) + RSI14(20)   ← 五项各 20 分
股债收益比 = 指数股息率(%) ÷ 10Y国债(%)
RSI14     = Wilder RSI，<40 → 满分 20；>70 → 0 分；之间线性
```

**为什么是 3 年权重最高**：由 `backtest_rank.py` walk-forward 确认 —— 选择边际
3年70/5年20/10年10 **+66.3bp**、3年50/5年30/10年20 **+60.7bp**，而等权 1/3 **−14.7bp**、
10 年主导 **−40.8bp**。

**为什么用股债收益比换掉「趋势(近6月)」**：原趋势分是**短周期动量**，与 PE / PE分位 / 股息率三项
口径不同源；换成股债收益比后前四项统一为**相对估值口径**，且与手册 §4 的股债收益比一脉相承
（分母取仓库共用缓存 `data/_bt_caches/bond10y_m.csv`）。

**为什么再加 RSI14**：前四项讲的都是「贵贱」（估值 / 收益），缺「短期是否已经跌过头」的位置信息。
RSI14 用基金**累计净值**（与业绩分同源，场内 / 场外同口径）补上这一维。五项均分（各 20）意味着
**估值与短期位置同权**，不再让估值项主导。

> **口径提醒**：业绩分奖励「近期强势」，RSI14 奖励「近期弱势」，两者方向相反，总分是两个反向力量的净结果。
> 这是有意为之（RSI 负责识别跌过头），但需知悉其相互作用。

## 3. 数据来源与覆盖

**全部走真实数据源（2026-09-12 修订：不使用任何表格数据）**

| 维度 | 真实来源（**打分口径以中证官网为单一源**，保证 PE 水平与分位同源） |
|---|---|

## 7. 口径与已知边界

- **PE 分位**用中证官网 `peg` 的「过去最多 10 年」累计分位（窗口未满 10 年时退化为扩张窗口，
  因果无前视）—— 因此**普遍高于**用户表 / 蛋卷的更长窗口分位（如中证红利：10 年窗重建 ≈71% vs 蛋卷 ≈83%），
  **不能与蛋卷分位混着比**。
- **RSI14 用累计净值**而非场内价格：场外基金无价格序列，全池统一口径才能横向比较。
- 业绩分用**区间年化 + 最大回撤**，不做复权对齐以外的人工调整。
- 回测为**月度再平衡**口径，未扣 ETF 跟踪误差与场外申赎费（C 类通常 0 持有费，短期赎回费另计）。
- 本策略是**打分/排序层**，故 `strategies.json` 不设 `raw_out`，`run_flow backtest --codes` 不适用；
  直接跑 `backtest_rank.py`。
