> 规则文件是唯一权威；代码参数见 `rule.py`，回测产物见 `backtest/_v5_report.md`。

## 一、指标与贵度

```
股债利差 spread = 税后股息率 − 10Y 中债收益率      （单位 pp，A 股税制系数 1.0）
贵度 q          = 1 − 分位(spread)                 # 扩张窗口 ≥36 月、≤120 月
```

**数据源**：股息率 `data/_div_yield_m.csv`、国债 `data/_bt_caches/bond10y_m.csv`（跨策略共享）。
当月国债未更新时沿用上月末（`ffill`），否则 2026-10 这类月份会整列缺失。

---

## 二、与 `v1_spread`（V1）的区别

| | V1 `v1_spread` | V5（本策略） |
|---|---|---|
| 标的 | 单标的 `000922` | **7 只基金池** |
| 收益口径 | 指数全收益 `H00922` | **基金累计净值（可执行）** |
| 阈值 | 分位 70/20 | 贵度 0.80/0.50 |
| 维度 | 只做时间择时 | 时间 + 横截面 |
| 样本 | 2018-06 ~ 2026-09 | 2020-01 ~ 2026-10 |

V1 已证明「单标的利差分位择时」在时间维度不成立（分位长期贴顶、信号稀疏）。V5 换到池层面复验，
并补上横截面 —— 结论见下：**时间维度同样不成立，横截面也不是新信息**。

---

## 三、决策规则

| 维度 | 规则 |
|---|---|
| 时间（板块） | `q̄ ≥ 0.80` → 清仓，`0.50 ≤ q̄ < 0.80` → 减半，否则满仓 |
| 横截面 | 每月选 **利差最大（最便宜）的 2 只**等权 |
| 频率 / 成本 | 月末信号下月生效；单边 0.03% |

## 四、回测（2020-01 ~ 2026-10，82 月）

| 方案 | 年化 | 最大回撤 | Calmar |
|---|---:|---:|---:|
| 基准：7 只等权 | 8.2% | −9.1% | **0.91** |
| 时间：板块贵度择时 | 8.2% | −9.1% | 0.91 |
| 横截面：最便宜 2 只 | 8.2% | −9.4% | 0.87 |
| 横截面 top2 + 时间择时 | 8.2% | −9.4% | 0.87 |

- **时间维度一次都没触发**：本样本内板块贵度 `q̄` 从未达到 0.50 减半线（当前 0.34）。
  原因是利差分位在 2020–2026 长期贴顶（利率 3.5% → 1.7% 单边下行），贵度永远很低。
- 与 V3（股息率）的持仓在 **82 个月里差异 0 个月**（`backtest.py` 里用代码验证）。

**结论：V5 没有独立信息。** 横截面上 `spread = dy − y10`，`y10` 对所有标的相同 →
「按利差挑最便宜」与「按股息率挑最高」是同一排序。时间维度又因分位贴顶完全失效。
它的价值只剩**可解释性**：同时把股和债放在一个数里，读数比单看股息率更有信息量。
