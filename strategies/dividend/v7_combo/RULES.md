# V7 · 多指标组合：规则、搜索与最终优选 v1.0

> 规则文件是唯一权威；候选定义与阈值见 `rule.py`，搜索与报告见 `search.py` →
> `backtest/_v7_report.md`。本目录不产生自己的策略信号，只负责**横向对比与优选**。

---

## 一、组合原则（先定规矩，再看数据）

1. **不搜索权重。** 82 个月 × 7 只标的上拟合出的最优权重没有样本外意义。
   组合只用等权 / 投票 / 仓位平均三种"零参数"方式。
2. **按信息独立性分组。** V5/V6 与 V3 的横截面排序完全等价（`y10` 是共同项），
   所以「dy+spread+ratio 等权」实际是把股息率复制三遍。
3. **阈值沿用各指标的自身口径**：估值类 0.80/0.50，RSI 0.70/0.50。

---

## 二、候选

| 代号 | 构成 | 说明 |
|---|---|---|
| `all4` | dy + spread + ratio + rsi 等权 | 名义四维，实际 75% 权重在同一个估值信号上 |
| `val` | dy + spread + ratio 等权 | 三胞胎（≈ 单用股息率） |
| `dy_rsi` | dy + rsi 各 50% | 两个独立信息源，理论上最合理 |
| `rsi` | 仅 rsi | 单指标对照（= V4） |
| `vote` | 4 个指标里 ≥2 个认为便宜 | 非加权，抗单指标噪声 |
| `mix｜RSI 择时 + 股息率选品` | 时间维度用 RSI，横截面用 dy | 分工：各用最适合的维度 |
| `mix｜股息率择时 + RSI 选品` | 反之 | 对照 |
| `pos_vote` | 4 个指标各给 0/0.5/1 仓位，取平均 | 避免「先平均 q 再套阈值」搅乱阈值含义 |

**两处合成口径不同，别混用**：
* `q`（时间维度）：各指标自身分位贵度的均值，都在 0–1 且方向一致，可直接平均；
* `xs`（横截面）：各指标**当月横截面排名**的均值 —— 股息率是 4.x%、RSI 是 60，量纲不同，
  必须先每月内标准化再平均。

| 候选 | 时间 | 横截面 | 叠加 | 叠加年化 | 剔除 3 月后 |

单指标（同一口径）：`dy` 0.79 / `spread` 0.87 / `ratio` 0.87 / **`rsi` 1.44**。

## 四、最终优选

**最优 = V4（RSI14 单指标）**，不是任何组合。

理由：

1. 所有真正的组合落在 **0.87–1.05**，没有一个超过纯 RSI 的 **1.44**；
2. 根因是**估值三项在本样本已失效**（时间维度 0.91 = 基准且从不触发，横截面 0.87 < 基准）。
   把无效信号掺进组合只会摊薄唯一有效的信号 —— 这是本轮最重要的**否定结果**；
3. RSI 的领先不是靠个别月份（剔除 3 月后 11.6% vs 基准 10.1%），
   且三档阈值（70/50、80/50、60/40）全部优于基准。

**但必须同时接受 RSI 的代价**：平均仓位 72%，2020/2021/2024 三年都落后基准；
它赢的是回撤（−7.5% vs −9.1%），不是收益的持续性。强趋势钝化是它的固有缺陷。

---

## 五、结论与后续

- **别再往组合里加"估值类三胞胎"** —— 它们的信息量是 1 份不是 3 份。
- 若将来要提升，方向不是"加指标"，而是：① 补 PB / 质量类**真正独立**的维度；
  ② 把样本拉到 2015 年前后（需要更长的股息率历史）；③ 对 RSI 做趋势过滤（如 MA200 之上不因 RSI 减仓）。
- 以上全部建立在 82 个月、7 只高度相关红利基金上，8 个候选 × 3 变体 = 24 次比较，
  最优结果天然偏高 —— 阈值敏感性全过是它比其它候选更可信的唯一理由。
