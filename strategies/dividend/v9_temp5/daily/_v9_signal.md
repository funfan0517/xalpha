## 四、口径与边界（必读）

1. **股债收益差 = 股息率 − 10Y**（不再是 100/PE）：股息率取 `data/_div_yield_m.csv`（月度）——000922 / H30269 为真实序列（全收益指数 − 价格指数），930955 / 931468 / 000824 / 000825 为 000922 变化率代理 + 各自官网快照校准。
2. **PE / PB 同源等权**：估值链已从「中证加权 PE + `PB = PE × ROE` 合成」换成 etf.run **等权 PE + 真实 PB**（日频，6 只有估值标的全部覆盖：000922 / H30269 / 930955 / 931468 / 000824 / 000825）；**全池同一口径**，温度可横比。PE + PB 仍占 36% 权重。
3. **温度算在跟踪指数上**（规则 R0-2）：基金有费率与跟踪误差，估值只有指数口径。
4. **两个标普系列无估值**（008163 / 005125）：中证官网、蛋卷、东财指数库三源皆无条目，只算价格温度并标 †，不进排名、不进横截面。价格用 501029（主，2017→）；562060 实测与 501029 全期日收益 corr≈0.44（仅近 250 日 0.89），长期背离，仅作回退、不替换。
5. **回测结论**：样本（2020-02~2026-09，80 月）：基准 6 只等权 Calmar 1.03；按分位减仓 1.26（年化 10.2% vs 9.6%）；横截面 top2 0.88；绝对档 ≥65 减半 / ≥75 清仓 平均仓位 92%（几乎不触发）。**分位减仓有边际改善（回撤压得比收益让渡更多），但改善集中在少数月份、阈值又是样本内选的，不作为择时信号；横截面选品仍未跑赢基准。**
6. 数据分位窗口「近 2 年（730 日历日）」，需 ≥300 个日频观测才给分位；窗口内不足 300 个观测则不出温度（不拿全历史冒充）。
7. **股息率代理说明**：4 只 proxy 的股息率形状基本等同中证红利，其「利差分位」与 000922 高度相关，不宜当作彼此独立的信号。
