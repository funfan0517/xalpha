## 规则（与 `rule.py` 参数唯一权威源一致）

核心逻辑：**短 EMA12 跟踪趋势速度、长 EMA26 判定趋势方向，金叉做多、死叉空仓**。

| # | 规则 | 触发条件（当日收盘判定，次日开盘执行） |
|---|---|---|
| 1 | 买入（金叉） | 昨 `EMA12 ≤ EMA26` 且今 `EMA12 > EMA26`；且两线差距 `≥ 0.3%`（阈值过滤）；且 `收盘 > EMA26`（趋势过滤） |
| 2 | 卖出（死叉） | 昨 `EMA12 ≥ EMA26` 且今 `EMA12 < EMA26`；且两线差距 `≥ 0.3%` |
| 3 | 持有 | 无金叉/死叉时维持原仓位，不手动止盈止损、不中途加减仓 |
| 4 | 锁仓 | 距上次实际交易不足 5 个交易日，忽略新信号（防震荡反复打脸） |
| 5 | 成本/时点 | 单边 0.03%（场内 ETF 佣金）；信号次日开盘成交（回测/实盘一致，无前视） |

> 阈值 0.3% 与锁仓 5 日为手册第五章「实盘增强过滤」，会把两线贴合的毛刺交叉大量过滤，
> 因此交易笔数天然偏少（这是减少无效磨损的预期效果，不是引擎缺陷）。

参数定位：经典 EMA12/26 不寻优；手册允许的备选稳健参数 MA20/MA60 未启用（可对照 `rule.ALT_*`）。

读法（数据驱动，与手册的“优缺点”自洽）：

- **强项是回撤控制**：全池平均最大回撤从 -46.9% 压到 -27.8%（改善约 19 个点），熊市空仓规避生效；
- **弱项是踏空慢牛**：10 年长牛/慢牛标的（纳指/标普/红利/黄金等）持仓占比极低、超额为负 —— 这正是手册承认的
  “极致单边慢牛行情卖飞”短板 + 增强过滤放大了空仓时间；
- **相对适用**：A 股高波动行业（软件/机器人/消费电子/传媒/光伏/券商/恒生科技）与白银商品，
  用“空仓躲大跌”换取了正超额。

（完整逐只表见 `_bt_report.md` / `_bt_dashboard.html` / `_bt_visual.png`，数字以 `python strategies/ema_cross/_reportbt.py` 输出为准。）

## 边界与组合定位

- 震荡市是双均线的固有短板（反复金叉死叉磨损 / 过滤后错过反弹），手册建议**只对 A 类高波动标的**推送信号；

  **择时 → 选股 → 配仓**闭环（手册第七章），本项目其余策略可交叉验证；
- 每日 automation 未创建（同 momentum_rotation 口径），确认 A 名单后可按 `run_daily_4d.ps1` 模板接入；
- 全部产物为机械规则回测，**不构成投资建议**，实盘前须人工复核。
