## 6. 结论

1. **净值口径（一次性本金）**：v1 年化 +11.30% / 回撤 -45.55% / 夏普 0.54 / Calmar 0.25；v0 年化 +9.42% / 回撤 -35.78% / 夏普 0.54 / Calmar 0.26。v1 多 +1.88pp 年化，但多扛 +9.77pp 回撤 —— **风险调整后（Calmar/夏普）两者非常接近，v1 只是「跑得更热」而不是「更准」。**
2. **定投口径**：同样每月 1000 元投到今，v1 总资产 15.0 万（XIRR +17.40%），v0 总资产 10.8 万（XIRR +7.99%）。
3. **手册数字不可直接照搬**：手册回测建立在创业板指(399006)上（15.59% / 79.5 万 / 26.68% 回撤），本仓库已切换到科创50(000688)，成长侧波动与比值分布都不同，那些数字不再对得上；且即便在创业板指口径下，本仓库也复现不出 26.68% 的回撤（实测净值 -45.19% / 资产 -28.17%），手册的回撤口径明显低估。**不要引用手册的 26.68%。**
4. **阈值才是 v1 的命门**：当前 0.20/0.31 → +11.30%；放宽为 0.16/0.36 → +21.21%，收紧到 0.24/0.28 → +9.05%（换仓更频、已与 v0 的 +9.42% 打平甚至更差）。换一组同样合理的阈值，结论就从「跑赢 v0」变成「不如 v0」—— 与手册自己提示的过拟合风险一致。
5. **反过来，v1 有一个 v0 没有的真实优势：可执行性**。v1 全期只换仓 2 次；v0 切换 64 次，其中 **15 段持仓不足 5 个交易日**。场外 C 类联接基金持有 < 7 天赎回费 1.5%，这些段在真实渠道里要么做不了、要么成本吃掉收益 —— v0 的高频切换在指数层面成立、在申赎层面打折。
6. **结论取舍**：v1 的高收益大半来自阈值拟合与更高的成长暴露，不具备样本外优势；v0 的规则形态（无量纲、自适应）更稳，但切换过频、落地成本高。**可行的合成是「v0 的信号形态 + v1 的执行节奏」**：用缓冲带/分位产生信号，但加冷却期与分批建仓把年切换次数压到个位数。这需要另开变种，不在本次范围内。

## 7. 已知偏差

- **红利端系统性低估**：中证红利是价格指数，股息率约 4.5%，两策略持有红利时段的收益都被少算约 4.5%/年 × 非成长暴露。v0 的非成长暴露（68%）高于 v1（32%），**所以这里对 v0 更不利**：把红利分红补回去，v0 与 v1 的差距会进一步收窄。（v0 自身报告里的「买入持有红利 +4.09%」也同样是低估的。）
- 未含滑点与场外确认时滞；赎回费只做了定性讨论（见结论第 5 条），未进回测。
- `R` 的绝对值依赖两只指数的基期：本仓库这段数据里 0.40 约是 R 的 40% 分位、0.62 约是 90% 分位，与手册的标定样本不完全一致 —— 同一组数字换个数据起点就会漂移。
- 全部为模拟结果，非投资建议。
