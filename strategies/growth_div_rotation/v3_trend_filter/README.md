# 成长/红利风格轮动 · 变种 **v3「绝对水位 0.35/0.65 + MA250 趋势闸门」**

> **2026-10-30 落地**：在 v2（`../v2_absolute_bands/`，阈值已挪到 0.35/0.65）之上，
> 叠加一条**绝对趋势闸门**（创业板指 vs 250 日均线），并加冷却期防场外赎回费。
>
> 这是 v2 的**结构性补丁**，针对 v2 的两个设计缺陷：①只看 R（相对强弱），不含绝对趋势；
> ②卖出后必须等 R 跌回 0.35 才买回（死锁）。

## 1. 与 v2 的差别

| 维度 | v2 | **v3（本变种）** |
| --- | --- | --- |
| R 层 | R ≤ 0.35 满仓 / R ≥ 0.65 空仓 / 中间带保持 | **完全相同**（`rule.RATIO_LOW/HIGH`） |
| 趋势层 | 无 | 创业板指 < MA250 时成长权重封顶 `TREND_CAP=0.5` |
| 叠加方式 | — | `w = min(w_R, TREND_CAP if 破线 else w_R)`（`engine.mode="cap"`） |
| 防摩擦 | 无（6 次切换） | `COOL_BARS=20` 交易日冷却（把 48 次压到 20 次） |
| 全期切换 | 6 次 | **20 次** |

## 2. 规则（`rule.py` 是唯一参数权威源）

每日收盘后：

1. `R = 创业板指(399006) ÷ 中证红利(000922)`
2. **R 层**：`R ≤ 0.35` → 目标满仓成长；`R ≥ 0.65` → 目标空仓成长；中间带 → R 层状态不变
3. **趋势层**：创业板指 < MA250 → 把目标权重压到 `TREND_CAP=0.5`（破线减半）
4. **冷却期**：距上次切换不足 20 个交易日 → 本次切换挂起，到期后若目标仍成立才执行
5. 用 `t-1` 的 R 与趋势状态决策，`t` 日起按新权重计收益（**无前视**）；单边费 0.03%

## 3. 结果与核心结论

| 组合 | 年化 | 最大回撤 | 波动 | 夏普 | Calmar | 总收益 |
| --- | --- | --- | --- | --- | --- | --- |
| **v3（0.35/0.65 + MA250 减半）** | +16.76% | -53.50% | 25.69% | 0.76 | 0.31 | +1174.37% |
| v2（同阈值，无趋势） | **+17.27%** | **-51.85%** | 26.90% | 0.75 | **0.33** | +1268.01% |
| 买入持有创业板指 | +5.74% | -69.74% | 31.06% | 0.34 | 0.08 | +149.97% |
| 买入持有中证红利 | +4.41% | -46.51% | 20.69% | 0.32 | 0.09 | +103.25% |

**四格矩阵（本次最重要的发现）**：

| 阈值 | 无趋势（纯 v2） | + MA250 趋势闸门 |
| --- | --- | --- |
| 0.30 / 0.70（原图口径） | +10.07% / -69.74% / Calmar 0.14 | **+11.23% / -60.75% / Calmar 0.18** |
| 0.35 / 0.65（v2 当前口径） | **+17.27% / -51.85% / Calmar 0.33** | +16.76% / -53.50% / Calmar 0.31 |

三句话读法：

1. **趋势闸门在原口径下是有效的**（Calmar 0.14 → 0.18，回撤 -69.74% → -60.75%）——
   它救的正是 2015 年：R 只有 0.679 摸不到 0.70，但指数早已跌破 MA250。
2. **但在 0.35/0.65 下它反而拖后腿**（Calmar 0.33 → 0.31）—— 因为 R 层在 2014-01（R=0.6555）
   就已经减仓了，2015 年那个病已经被治好；趋势闸门只剩 2024-2025 反复破线/复线的摩擦。
3. **两者是替代关系，不是叠加关系**。都在治同一个病，同时上不会叠加收益。

> 口径提示：上表「+趋势」列用 v3 默认参数（减半 + 20 日冷却）。若改成「破线清仓 + 不加冷却」
> （`research/_opt_probe.py` 口径），原阈值下是 +12.50% / -52.69% / Calmar 0.24 ——
> 回撤更低，但切换 56 次，场外 C 类基金做不了。

## 6. 已知边界

1. **在当前阈值下没有改善风险调整收益**（Calmar 0.33 → 0.31）。想靠这层拿到更高收益是不成立的。
2. **趋势闸门真正的价值是消除死锁**：v2 卖出后必须等 R ≤ 0.35 才买回；v3 在指数站上 MA250
   时即可恢复（`engine.mode="switch"` 是彻底版：中间带完全交给趋势。实测切换 108 次、
   加冷却后年化掉到 15.2%，执行成本吃掉收益）。
3. **阈值前视**：R 层 0.35/0.65 沿自 v2，仍是全样本选优（见 `../v2_absolute_bands/README.md` §4）。
   趋势层本身无前视（MA250 只用历史收盘），但「250 日」这个窗口值得单独做稳健性检验。
4. **红利端系统性低估**：中证红利是价格指数，股息率约 4.5%，非成长时段（约 57%）收益被少算。
5. 未含滑点与场外确认时滞；全部为模拟结果，非投资建议。
