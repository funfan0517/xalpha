**这张表是本次最重要的结论**：
1. 在**原口径** 0.70/0.30 下，趋势闸门把年化 +10.07% → +11.23%、回撤 -69.74% → -60.75%、Calmar 0.14 → 0.18 —— 它救的正是 2015 年（R 只有 0.679 摸不到 0.70 那段）。
2. 在**新口径** 0.65/0.35 下，趋势闸门反而让年化 +17.27% → +16.76%、Calmar 0.33 → 0.31 —— **因为 R 层已经把 2015 年解决了**（2014-01 的 R=0.6555 就减仓），趋势闸门无事可做，只剩 2024-2025 反复破线/复线的摩擦。
3. 所以两者不是叠加关系，而是**替代关系**：都在治同一个病（2015 年不防守）。**同时上两个，收益不会叠加。**
> 口径提示：上表「+趋势」列用的是 v3 默认参数（破线减半 `cap=0.5` + 20 日冷却）。若改成「破线清仓 + 不加冷却」（`research/_opt_probe.py` 的口径），原阈值下是 +12.50% / -52.69% / Calmar 0.24 —— 回撤更低但切换 56 次，场外 C 类基金做不了。

## 5. 结论与建议

1. **在 0.35/0.65 口径下，MA250 趋势闸门没有改善风险调整收益**（Calmar 0.33 → 0.31）。它是 0.70/0.30 口径缺防守时的补丁，阈值放宽后这个补丁就多余了。
2. **趋势闸门真正解决的问题是「死锁」**：v2 卖出后必须等 R 跌回 0.35 才买回；v3 在指数站上 MA250 时即可恢复。`engine.signal_weights(mode='switch')` 是彻底版（中间带交给趋势），但切换 108 次、加冷却后年化掉到 15.2% —— 执行成本吃掉收益。
3. **如果目标是降回撤**：MA120/MA200 + cap=0.5 能把回撤压到 -46%~-48%（年化 16% 左右），这是本报告里唯一「回撤明显改善、年化基本不损」的组合，但需要样本外验证。
4. **如果目标是提收益**：v3 做不到。v2 的 0.35/0.65 已经是本样本的最优区域，再叠任何一层都只会增加摩擦。

## 6. 已知边界

1. **阈值前视**：R 层 0.35/0.65 沿自 v2，仍是全样本选优（见 `../v2_absolute_bands/README.md` §4）。
2. **趋势层无前视**：MA250 只用历史收盘，判断用当日收盘、次日生效。唯一需要注意的是「250 日」这个窗口本身是通用口径，不是在本样本上搜出来的（搜出来的话 MA120 更好）。
3. **红利端系统性低估**：中证红利是价格指数，股息率约 4.5%，非成长时段收益被少算。
4. 未含滑点与场外确认时滞；全部为模拟结果，非投资建议。
