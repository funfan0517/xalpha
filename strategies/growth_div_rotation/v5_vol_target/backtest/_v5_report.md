# 成长/红利风格轮动 · v5「v3 + 波动率目标 18%」

> 生成 2026-11-06 17:46 · 数据 2010-06-01~2026-11-06（3990 交易日）· 分子 创业板指 399006 ÷ 分母 中证红利 000922

> 目标：在 v3 之上**再压回撤**。不动 R 层与趋势层，只在最外面加一层「按已实现波动缩放总仓位」。

## 0. 结论先行

**做到了，且不是靠少持仓换来的**：年化 +14.16%（v3 +15.58%，让出 1.4pp），最大回撤 -41.57% → **-26.74%（改善 14.8pp）**，夏普 0.77 → **0.88**，Calmar 0.37 → **0.53**（+41%）。

- 两层残余回撤同时被削平：2015 段 -41.6% → **-25.1%**；2024 段 -29.1% → **-19.4%**。
- 波动层平均缩放 0.80、最低 0.47：base 组合常年波动约 23%，高于 18% 目标，所以**缩放几乎从不等于 1**（仅 3% 的交易日满仓）。它不是「偶尔踩刹车」，而是**给组合定了一个风险预算**：平静期放到 1.0，高波动期压到 0.47，平均 0.80。
- 代价：切换 54 次 → 78 次；平均暴露 63%（v3 为 80%）。

## 1. 规则

| 层 | 规则 | 与 v3 的关系 |
|---|---|---|
| **R 层** | R ≤ 0.35 满仓成长 / R ≥ 0.65 满仓红利 / 中间带保持状态 | **完全相同** |
| **趋势层** | 创业板指 < MA200 → 成长侧减半；中证红利 < MA200 → 红利侧减半；削掉的转现金 | **完全相同** |
| **波动层** | `scale = min(1, 18% ÷ 120 日已实现年化波动)`，等比缩放成长+红利，腾出的进现金 | **v5 新增** |
| **冷却/死区** | 切换间隔 ≥ 20 日；缩放系数变化 < 0.15 则不动 | 冷却同 v3，死区新增 |

> 波动率只从**未缩放**的 base 净值估（避免 scale 与收益互为因果），且第 t 日只用 vol[t-1]，无前视。`VOL_USE=False` 或 `target_vol=0` 时完全退化成 v3。

## 3. 关键对照：这是「降风险」还是「择时」

降回撤最省事的办法就是一直少持仓。所以必须把暴露对齐再比：

| 方案 | 年化 | 最大回撤 | 夏普 | Calmar | 平均暴露 |
|---|---|---|---|---|---|
| 对照：恒定 44% 暴露（v3 权重 ×0.55） | +9.69% | -24.63% | 0.82 | 0.39 | 44% |
| 对照：恒定 52% 暴露（v3 权重 ×0.65） | +11.07% | -28.66% | 0.80 | 0.39 | 52% |
| 对照：恒定 64% 暴露（v3 权重 ×0.80） | +13.07% | -34.42% | 0.78 | 0.38 | 64% |
| **v5 目标 18%（暴露相当）** | **+14.16%** | **-26.74%** | **0.88** | **0.53** | 63% |

暴露最接近的是「恒定 64%」这一行：它年化 +13.07%、回撤 -34.42%、Calmar 0.38；v5 在几乎相同的暴露（63%）下是 +14.16% / -26.74% / Calmar 0.53 —— **年化多 1.1pp、回撤还浅 7.7pp**。这两项都不是「少持仓」能解释的。

道理也直白：恒定降仓在牛市里也少赚；v5 的缩放系数随波动变化 —— 平静期回到 1.0 吃满仓位，波动抬升才压下去，所以同样的平均暴露拿到了更高收益。

## 5. 防抖与可执行性（死区 / 最小间隔）

v3 的 COOL_BARS 只约束 R/趋势层。v5 多了一层缩放，若只在层内限速，仍会出现「t 日换档、t+1 日改缩放」这种前后只差一天的调仓 —— 实测产生**最短持仓 0 天、7 段不足 7 天**的持仓，踩场外 C 类 1.5% 赎回费。所以 v5 在**最终权重**上再加一道全局限速（`MIN_REBALANCE`），它同时管住「换档」与「改缩放」两种调仓。

## 8. 可执行性

- 持仓段 **79** 段（v3 为 54 段），最短 **1** 个交易日、中位 25、最长 350；**不足 7 日的段 1 个**。
- 切换 **78** 次（v3 为 54 次），其中缩放的档位变化占一部分；因死区 0.15 的存在，缩放不是每天微调，而是「跨档才动」。
- 缩放系数落在 0.47~1.00，平均 0.80。注意：只有 3% 的交易日系数等于 1 —— 因为 base 组合常年波动约 23%、高于 18% 的目标，这一层实际是**常驻的风险预算**，而不是偶发的刹车。
- 波动层只改「总仓位」，不改成长/红利之间的比例 —— 因此可以把它理解为「在 v3 给的仓位上再乘一个风险预算系数」，执行时只需按同一比例减两边。

## 10. 已知边界

1. **年化让出 1.4pp 是真实代价**：波动层在「波动抬升但随后继续上涨」的行情里也会降仓（2020 年二季度、2025 年部分时段），这部分少赚不可避免。要保收益就用 25% 档。
2. **波动率用 base 净值估算**（未缩放的策略净值），是为了切断 scale 与收益的循环依赖；实盘应改用实际组合收益滚动，估计会更灵敏一些，绩效不会完全一致。
3. **R 阈值前视**：0.35/0.65 沿自 v2/v3，仍是全样本选优 —— 这一层 v5 没有改，所以前视问题依然继承。
4. **波动目标与窗口是同一段样本上选的**：好在它们是平台不是尖峰（12%~25% × 60~120 日的 Calmar 都在 0.44~0.53），但仍属样本内。
5. **红利端系统性低估**：中证红利是价格指数，股息率约 4.5%；v5 现金占比更高，持有红利时段更少，受影响比 v3 大。
6. 未含滑点与场外确认时滞；全部为模拟结果，非投资建议。
