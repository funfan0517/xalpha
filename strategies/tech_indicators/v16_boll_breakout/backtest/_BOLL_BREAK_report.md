# 技术指标策略 · 变种 16（BOLL_BREAK）· BOLL 上轨突破全池回测
> 54 只场内 ETF（_universe.md 前四类）· 各自全历史（第 61 个交易日起）· 多头/空仓 0-1 · 信号当日收盘成交 · 未计佣金滑点 · 无风险利率 0

## 策略规则

- **指标**：`mid = MA(close, 35)`、`std = STD(close, 35)`、`upper = mid + 2 * std`（下轨算而不用）
- **开多**：`close > upper` 且前一日 `close <= upper`（要求「上穿」，避免同一段趋势重复发信号）
- **平仓**：`close < mid`（跌回中轨即退出，不等下轨）
- **无反向开空**；盘中触碰不算，只看收盘；无信号时空仓等待
- **止损**：默认关闭（`PARAMS['STOP']=None`），敏感性见下文

> 实现：`rule.py`（参数权威源，指标在规则内自算 —— 指标库只预计算 BOLL(20,2)）· 引擎/统计复用 `../backtest.py` 与 `pipeline/bt_stats.py`。

> 口径：单笔=建/平仓收盘价收益（未计费用）；胜率=盈利笔数/总笔数；盈亏比=平均盈利/|平均亏损|。本策略是**趋势跟踪**：胜率不高、靠少数大盈利覆盖多次小亏，单看胜率会误判；**模拟结果，非投资建议。**
