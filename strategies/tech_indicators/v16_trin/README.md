# TRIN（阿姆氏指标）市场广度择时 · 技术指标家族变种 **v16**

> 2026-11-02 按用户提供的「TRIN / 阿姆氏指标」说明落地。
> 与 v9/v10 同属**状态机型变种**：自带 `rule.py` / `data.py` / `backtest.py` / `scan.py`，
> 不进 `compare.py` 的单信号横截面表（那套引擎按 `(close, 指标)` 重算，口径不可比），
> 也不进家族每日固定的 6 策略汇总表（它是**市场级**信号，不是一个「逐只标的的列」）。

回答一个问题：**全市场是不是刚经历了一轮恐慌放量？如果是，明天买、持有 20 天。**

## 1. 指标与规则

```
TRIN = (上涨家数 ÷ 下跌家数) ÷ (上涨成交额 ÷ 下跌成交额)
```

- ≈ 1：多空平衡；> 1：下跌端相对放量；< 1：上涨端相对放量。
- 经典读法是「TRIN 高 = 空头占优」，本策略按视频口径把它当**逆向买点**：
  **连续放量杀跌 = 情绪出清**，随后 20 个交易日往往有修复。

策略（`rule.py` 顶部常量，**唯一参数权威源**）：

| 项 | 取值 | 说明 |
|---|---|---|
| 均线 | `TRIN_WIN=5` | 只看 TRIN 的 5 日均，不看单日 |
| 阈值 | `TRIN_TH=1.4` | 视频参数 |
| 确认 | `TRIN_CONFIRM=2` | 连续 2 日 5 日均 > 1.4（视频未写死，1~3 都做了网格） |
| 买入 | 信号次日**开盘** | 510300（沪深300ETF），与视频一致 |
| 卖出 | 第 `HOLD_DAYS=20` 根 K 线**收盘** | 到期无条件卖 |
| 止损 | `STOP=8%` | 收盘较建仓价跌破 -8% 当日收盘止损（视频没给值，取 -8%） |
| 仓位 | 0 / 1，`SIZE=100%` | 不触发就空仓；`SIZE<1` 即视频说的「不满仓」（40%/60%/80% 的对照见回测报告 2.3，近似线性缩放、夏普不变）；**「分批建仓」未编码** —— 它是主观动作，本策略一次性建仓 |
| 成本 | 单边 `FEE=0.03%` | 未计滑点 |
| TRIN 分母 | `FIELD="amt"` | 成交额口径（视频编码口径）；`vol` 为成交量口径，网格里并列 |

**触发是一次性的**（`EDGE_TRIGGER=True`）：条件刚成立那天记一次买点，条件继续满足不重复买；
持仓期间再出现新买点会被忽略（0/1 状态机没有加仓动作）。网格里另有「满足即买」的对照。

## 2. 数据：这个策略唯一真正的工程难点

TRIN 需要的是**全市场每天的横截面**（涨跌家数 + 涨跌成交额），仓库原来的 `_long_klines.json`
只有 54 只 ETF，凑不出这个数。因此新增了一个**跨策略共享的数据类产物**：

- `data/_breadth_daily.json` —— 沪深 A 股每日：`adv / dec / flat`（家数）、
  `adv_vol / dec_vol`（成交量，手）、`adv_amt / dec_amt`（成交额，元）。
- `data/_refresh_breadth.py` —— 生产者：
  - `--full`：并发逐只拉东财**前复权**日线（5,562 只、约 2.5 分钟），聚合后**不落个股明细**，
    只存每日合计；断点续跑（进度在 `data/_bt_caches/breadth_build_state.json`）。
  - `--update`：收盘后一次全市场快照（翻 56 页）追加当日，日常维护用这个。
  - `--status`：看覆盖区间与进度。

口径（写死在脚本与 `_meta` 里）：

- 沪深 A 股（不含北交所、B 股、基金、指数），代码前缀 600/601/603/605/688/689/000/001/002/003/300/301；
- 涨跌方向用**前复权收盘自算**（不用接口的涨跌幅字段，避免除权日被记成暴跌）；
- 停牌 / 0 成交的行直接剔除（自然排除停牌日）；
- **存活偏差**：股票列表是当前存续标的，退市股历史缺失 → 早年家数略少。
  TRIN 是比值，对绝对家数不敏感，偏差可接受，但报告里如实标注。

执行标的 OHLC 是本策略自己的缓存：`v16_trin/data/_v16_vehicle.json`（510300 前复权，单次请求）。

## 3. 选股层（视频的「错杀、放量温和、基本面/逻辑未坏」）

「基本面/逻辑未坏」无法从行情里编码，这里用**价格结构代理**，并明确标注它是代理：

| 条件 | 实现 |
|---|---|
| 错杀 | 20 日收益处于池内后 `SELECT_Q=20%` 分位 |
| 放量温和 | 量比 `vr = vol / vol_ma20 ∈ [0.6, 2.0]`（既不是无量阴跌，也不是恐慌天量） |
| 未破位 | 收盘 ≥ `MA250 × 0.85` |
| 流动性 | 20 日均成交额 ≥ 0.3 亿 |
| 只数 | 按 ret20 从低到高取 `PICK_K=3` 只等权 |

池子 = 家族 54 只场内 ETF（`../_pool.py`），与 v9/v10 同池。

## 4. 结果（2015-01-09 ~ 2026-10-30 · 2868 个交易日）

主口径 510300（视频参数）：

| 指标 | TRIN 择时 | 买入持有 510300 |
|---|---|---|
| 年化 | **+0.42%** | +3.34% |
| 最大回撤 | **-31.72%** | -52.97% |
| 夏普 | 0.10 | 0.25 |
| 持仓时间 | 15.8% | 100% |
| 交易笔数 | 28 | — |
| 单笔胜率 | 57.1% | — |
| 盈亏比 / 利润因子 | 0.87 / 1.16 | — |
| 择时边际（持仓日-空仓日） | **+14.5bp/日** | — |

池子口径（错杀选股 3 只等权，次日收盘成交）：年化 **-0.59%** / 回撤 -24.81% / 持仓 12.6% / 42 笔；
对照「54 只池等权」+5.73% / -31.28%。

详细报告：`backtest/_v16_report.md`（含逐年、108 格参数网格、止损对照、逐笔明细）。

### 怎么读（三条与视频不一致的地方）

1. **视频参数只有「降回撤」的作用**：年化 +0.42% 跑不过买入持有 +3.34%，持仓只有 15.8% ——
   beta 少拿的收益大于择时省下的亏损。它换来的是回撤从 -53% 压到 -32%。
2. **1.4 不是平台，是斜坡**：阈值 1.2 → 1.8，年化单调变差（amt 口径 +3.4% → -1.8%）、
   持仓单调变少（32.7% → 4.0%）、择时边际也变薄（+11.0bp → -6.9bp）。
   「越极端越见底」在 A 股不成立，**越宽松越像加仓信号**。
3. **视频的 8.13% / 胜率 71% 复现不出来**：本样本单笔胜率 57.1%、平均盈利 +6.2%、平均亏损 -7.1%
   （盈亏比 0.87）。差异来源：标的（个股组合 vs 沪深300ETF）、区间、是否复权、是否含滑点，
   以及视频大概率是**样本内挑过参数**的结果。
4. **「不满仓」只改风险不改 alpha**：投入 40%/60%/80% 时年化 +0.35%/+0.43%/+0.46%、
   回撤 -13.6%/-20.0%/-26.0%、夏普都是 0.10 —— 近似线性缩放，解决的是「拿得住」而不是「赚得多」。

> 108 格里夏普最高的是 `vol` 口径 / 阈值 1.2 / 连续 2 日 / 持有 20 日（年化 +10.50%、回撤 -28.41%、
> 夏普 0.77、持仓 29.4%）。**这是看完全部格子后挑出来的，属样本内最优，不能当预期收益。**

## 5. 换标的：沪深300 / 中证A500 / 科创50

`research/_index_compare.py` 用**同一个信号**分别跑三大宽基（指数 + 对应 ETF），
结论是「信号质量随标的波动放大，但收益并不随之变好」：

| 全样本（2015 起） | 沪深300 指数 | 中证A500 指数 | 科创50 指数（2020 起） |
|---|---|---|---|
| 年化 | -0.65% | +1.01% | -3.30% |
| 最大回撤 | -28.44% | -27.69% | -33.73% |
| 笔数 / 胜率 | 27 / 55.6% | 28 / 57.1% | 15 / 40.0% |
| 买入持有年化 / 回撤 | +0.99% / -46.70% | +1.99% / -48.50% | +1.58% / -62.66% |

**分时段才是关键**：2015-2019 策略在沪深300 上 +4.31%/回撤 -15.5%/胜率 69%、
中证A500 上 +8.35%/-11.2%/69%（同期买入持有 +2.94%/+3.48%，回撤仍有 -47%）；
2020-2026 三者全部转负（-4.12% / -4.03% / -3.31%）。
视频的「71% 胜率」正好落在这段 2015-2019 的 69% 上 —— 那是有真实全市场恐慌的年代。

> A500 ETF 2024-10 才有数据（样本不足两年）、A500 指数历史是 2024-09 发布时回溯的；
> 细节与 ETF 口径见 `research/_index_compare.md`。

## 8. 边界与已知局限

- **广度库的存活偏差**：只含当前存续的 5,562 只沪深 A 股，退市股历史缺失。
- **口径差异**：主口径用开盘价成交（视频一致），池子口径只能用共享十年库的收盘价 → 两行不可直接比大小。
- **参数网格是样本内扫描**：用来判断「参数的形状」，不能拿最优格当预期。
- **不做趋势过滤**：单边熊市里 TRIN 会钝化（连续高位可以更高），视频也提到了这一点；
  本策略按原口径**没有**加过滤，如果要用，建议把 `TRIN_CONFIRM` 调高或叠 MA250 闸门后重跑。
- **未计滑点与冲击成本**，场内 ETF 佣金按单边 0.03%。
- **信号频率低**：全期 39 个买点 / 28 笔成交（部分买点落在持仓期内被忽略），
  平均每年约 2~3 笔；样本量小，单笔统计的置信区间很宽。

> 机械规则回测输出，**非投资建议**。
