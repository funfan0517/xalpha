# 技术指标家族 V17 变种 · 趋势四象限闸门（年线位置 × 年线 20 日斜率）

来源：用户 2026-11-02 的「趋势判断」说明（**与 `vol_legs/v5_trend_gate` 同一套规则**）。
本目录是它的可执行实现：象限判定、档位状态机、回测、每日档位——**数据源从 v5 的「七腿场外复权净值」
换成 tech_indicators 家族的「54 只场内 ETF 收盘价」**（池 = `data/_universe.md` 前四类）。

**参数唯一权威源**：`trend_gate.py` 顶部常量（`params()` 负责打包，回测敏感性靠它覆盖）。
**标的池继承家族**：`../_pool.py`（`data/_universe.md` 前四类，54 只），不另立池、不做 A/B 分级。
**与 v5 的关键差异**：带内占比 `{1.0, 0.5, 0.2}` 直接作为该 ETF 的**目标仓位**（家族惯例是 0/1，本变种
保留 v5 的分档——这是「复制这个策略」的核心，不可折叠成 0/1）；无风险利率按家族惯例取 0。

一句话：**趋势判断不是预测，是把已经发生的价格结构压成两个数 —— 收盘价在 250 日均线上/下、
均线自身近 20 日朝上/朝下；两个都朝上才给加仓许可，其余三格都不给。**

## 1. 规则：两个数，四象限

判断趋势只用两个数（第二个是第一个的属性，不算新维度）：

|  | MA250 朝上 | MA250 朝下 |
|---|---|---|
| **close ≥ MA250** | **上涨趋势** → 加至满仓（1.0） | **反弹** → 只持有，不给加仓许可 |
| **close < MA250** | **高位回调** → 降一档（封顶 0.5），不新增 | **下跌趋势** → 满 5 日减半（0.5）→ 满 20 日清至观察（0.2），等右侧 |

右上那格是本变种存在的理由：多数人把「站上年线」当趋势反转，但 A 股大量行情是「跌透之后的
暴力反弹先把价格推回均线上方、而均线还在下行」。价格先动、均线后动，中间这段必须单独分格，
否则「站上年线就加仓」会买在反弹的第一天。

「档位」= **该 ETF 的目标仓位比例**（不是 pp、不是 0/1）。它是**仓位闸门**，不是 0/1 择时。

| 环节 | 参数 | 说明 |
|---|---|---|
| 年线 | `MA_WIN=250` | A 股一年约 240–245 个交易日；美股习惯 200。**混用会让两套回测结论互相矛盾** |
| 斜率 | `SLOPE_N=20` | `ma250[t] − ma250[t−20]` 的符号；5/20/60 在敏感性表 |
| 阶梯帽 | `REDUCE_DAYS=5` / `CLEAR_DAYS=20` | 跌破满 5 日才减半、满 20 日未收复才清至观察 |
| 间隔帽 | `ACTION_GAP=5` | 同一标的两次调仓最小间隔（交易日） |
| 档位 | `FULL=1.0` / `HALF=0.5` / `OBSERVE=0.2` | 是该 ETF 的目标仓位比例 |
| 作用域 | `GATE_ALL=True` | 全部 54 只场内 ETF 套闸门 |

两条判定口径写死，避免事后解释：`close ≥ MA250` 取 ≥（等于均线算「上方」），斜率必须 **> 0** 才算朝上
（持平算朝下，不给加仓许可）。

## 2. 用在哪、不用在哪（这是规则的一部分）

- **逐只 ETF 都套**：原 v5 在「宽基 vs 无现金流锚」上有取舍（vol_legs 组合层带位叠加问题）；
  **本变种是单标的分档，不存在带位叠加**，故 54 只统一套闸门，结论由回测自行验证。
- **不是收益引擎**：闸门把各标的仓位从 100% 压低，换回撤；赚不赚取决于该标的样本里是
  「先在年线下阴跌很久」还是「跌破年线就 V 型反转」。回测结论（诚实版，见 `backtest/_v17_trend_gate_bt.md`）：
  54 只里多数被闸门拖累年化（减仓少亏的 V 型样本少），全池等权组合年化略低于买入持有、回撤更浅。

## 3. 回测结论（场内收盘价口径，诚实版）

报告全文：`backtest/_v17_trend_gate_bt.md`。组合层样本约 **2016 ~ 2026（≈10.7 年）**，受各 ETF 上市日期限制。

### 3.1 组合层（全池等权）

| 组合 | 年化 | 最大回撤 | 夏普 | 平均仓位 |
|---|---:|---:|---:|---:|
| **V17 闸门（全池等权）** | **+3.30%** | **−15.59%** | **0.37** | 约 70% |
| 全池等权买入持有（基准） | +3.97% | 更深（见报告） | — | 100% |

> 全池等权下，闸门年化 **−0.67pp**、回撤更浅、夏普基本持平。等权把 54 只高度重叠的宽基/行业 ETF
> 摊成 broad 代理——结论方向与 v5 一致：**闸门降波动、是否增收益取决于样本里「阴跌 vs V 型」的比例**。
> 机械对照，非投资建议。

### 3.2 逐标的（各自年线成形后起 · 扣费后 vs 买入持有满仓）

- 54 只里跑赢买入持有满仓的约 **30+/54**（多为「阴跌型」行业 ETF：光伏 / 白酒 / 新能源 / 医药 / 养殖），
  年化差 +1~+13pp、回撤显著更浅（如光伏 −38.7% vs −66.5%）；
- 被拖累的约 **20/54**（多为「V 型反转型」宽基/商品：有色 / 日经 / 消费 / 创业板），少赚 0~3pp；
- **闸门的价值与资产的「阴跌倾向」成正比**，与趋势判断准不准关系不大。

### 3.3 四象限定价 / 滞后成本 / 动量对照

与 v5 同构：七条闸门腿换成 54 只 ETF 横截面聚合（约数千个标的·日）。要点：
- 「下跌趋势」格的作用是**砍尾部**（最差单次 20 日 −20% 量级），不是提高均值；
- 滞后实测：确认「进入下跌趋势」时价格距 250 日高点中位已跌 **−13% 量级**，之后 120 日中位再跌约 −6%；
- 6 个月动量与均线法有约 8% 日数分歧（分歧日未来 60 日反而更高），故**不引入动量维度**。

## 4. 三个坑（用之前必须知道）

1. **滞后是设计特性不是 bug**。§3.3 已量化。它买的是「避开年单位阴跌」，不是「躲回撤」。
2. **250 和 200 不是一回事**。A 股一年约 240–245 个交易日 → 中文语境年线取 250；美股习惯 200。
3. **别加过滤器，加频率帽**。震荡市假信号一定存在；解法是限制响应速度（5/20 阶梯 + 间隔帽），
   不是再叠一个指标。

## 5. 每日用法

```powershell
# 每日档位（先刷新家族收盘价），产出 daily/_v17_trend_gate_daily.{md,json,html}
python strategies/tech_indicators/v17_trend_gate/daily/_daily_scan.py

# 跳过联网（用本地 _long_klines.json 缓存）
python strategies/tech_indicators/v17_trend_gate/daily/_daily_scan.py --no-refresh

# 并入每日操作汇总看板（pipeline/daily_digest.py）的板块5「技术指标」第二张策略卡
# （需先跑上面的扫描产出 daily/_v17_trend_gate_daily.json）
python pipeline/daily_digest.py

# 回测（逐标的 + 组合层 + 四象限定价 + 滞后成本 + 动量对照 + 敏感性），产出 backtest/_v17_trend_gate_bt.{md,jsonl} + _v17_quad_dist.png
python strategies/tech_indicators/v17_trend_gate/backtest.py
```

本变种**不在** `run_daily_tech_indicators.ps1` 的默认流程里（每日 6 策略表是 MACD/V3/V6/V7/V9/V10），
但已以 `v17_trend_gate` 为 key 注册进 `pipeline/strategies.json` 的 `daily.block = "tech"`，作为**板块5「技术指标」的第二张策略卡**
由 `pipeline/daily_digest.py` 渲染（先跑 `daily/_daily_scan.py` 产出 json，再跑 `daily_digest.py`）。
`compare.py` 仍不进。

## 7. 与其它变种的关系

| 变种 | 问题 | 方向 | 仓位形态 | 调仓频率 |
|---|---|---|---|---|
| `v11_ma` ~ `v15_boll` | 单指标买卖点 | 指标穿越 | 0/1 | 高 |
| `v16_trin` | 全市场广度择时 | 市场级信号 | 0/1 | 低 |
| **`v17_trend_gate`（本）** | **带内该露多少（年线 + 年线斜率）** | **趋势分档（含「反弹不给加仓」）** | **1.0 / 0.5 / 0.2** | **0.9~2.8 次/年** |

同属「逐标的进出时点」层；与 0/1 单指标变种的区别在于它输出的是**仓位档位**而非买卖开关，
更适合作为「单标的择时减仓/加仓」的叠加层，而非独立买卖信号。
