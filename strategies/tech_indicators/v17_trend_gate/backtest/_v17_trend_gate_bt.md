> 池 = `strategies/tech_indicators/_pool.py`（即 `data/_universe.md` 前四类，**50 只有行情**）；价格 = 家族共享 `data/_long_klines.json` **收盘价**
> 规则来源：用户 2026-11-02 的「趋势判断」说明；实现口径见 `v17_trend_gate/trend_gate.py` 模块 docstring 与 README
> 判断趋势只用两个数：`close` 在 **MA250** 上方还是下方、MA250 自身近 **20 日**朝上还是朝下；两个都朝上才叫上涨趋势，其余三格都不给加仓许可。
> 这是从 `vol_legs/v5_trend_gate` **照搬**的规则与分析，仅把数据源从「七腿场外复权净值」换成「54 只场内 ETF 收盘价」；带内占比 {1.0/0.5/0.2} 直接作为该 ETF 目标仓位（非 0/1）。
> 成交 = 信号当日收盘确定、赚次日收益（家族当日收盘成交惯例）；减仓/空仓部分按无风险利率 **0%** 计息（家族惯例）；未计佣金/滑点。

## 1. 规则（可执行版）

判断趋势只用两个数：`close` 在 **MA250** 上方还是下方、MA250 自身近 **20 日**是朝上还是朝下。两个都朝上才叫上涨趋势，其余三格都不给加仓许可。

| | MA250 朝上 | MA250 朝下 |
|---|---|---|
| **close ≥ MA250** | 上涨趋势 → 加至满仓（100%） | 反弹 → 只持有，不给加仓许可 |
| **close < MA250** | 高位回调 → 降一档（封顶 50%），不新增 | 下跌趋势 → 满 5 日减半（50%）→ 满 20 日清至观察（20%） |

| 环节 | 参数 | 说明 |
|---|---|---|
| 年线 | `MA_WIN=250` | A 股一年约 240–245 个交易日，中文语境年线取 250；美股习惯 200。**混用会让两套回测结论互相矛盾** |
| 斜率 | `SLOPE_N=20` | 年线自身 20 日变化量的符号 |
| 阶梯帽 | `REDUCE_DAYS=5` / `CLEAR_DAYS=20` | 跌破后满 5 日才减半、满 20 日未收复才清至观察 —— **限制响应速度** |
| 间隔帽 | `ACTION_GAP=5` | 同一标的两次调仓最小间隔 |
| 档位 | `FULL=1` / `HALF=0.5` / `OBSERVE=0.2` | 是该 ETF 的**目标仓位比例**（不是 pp，不是 0/1） |
| 作用域 | `GATE_ALL=True` | 全部 50 只场内 ETF 套闸门 |

> **三个坑**：①滞后是设计特性不是 bug（§5 给出实测滞后成本）；②250 与 200 不是一回事；③震荡市假信号一定存在，解法是频率帽（5/20 阶梯 + 间隔帽），不是再叠一个指标。

## 11. 口径与已知边界

- **作用域全池套闸门**：原 vol_legs v5 在「宽基 vs 无现金流锚」上有取舍，本变种是单标的分档、没有 vol_legs 那种组合层带位叠加问题，故 54 只统一套上；结论由 §2/§3 自行验证。
- **滞后是设计特性**：§5 给出实测。目标不是躲回调，是避开年单位阴跌；拿它躲短期波动必然被反复打脸。
- **250 与 200 不是一回事**：A 股一年约 240–245 个交易日，中文语境年线取 250；美股习惯 200。本变种全池统一 250。
- **没有加任何过滤器**：不叠 RSI、不叠成交量、不叠估值分位。震荡市的假信号靠频率帽（5/20 阶梯 + 间隔帽）限制响应速度。
- **观察仓 0.2 不是 0**：留一点仓位避免「清仓后再入场」的两次成本；想彻底清仓把 `OBSERVE` 设 0。
- **未计佣金/滑点、无风险利率按 0**：家族惯例；场内 ETF 实际有佣金与冲击成本，结论偏乐观。
- 参数未做 walk-forward 选优：§9 的敏感性显示结论落在同一量级，不靠某一格参数成立。
