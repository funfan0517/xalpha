# 变种 1 · KDJ + MA10 共振

技术指标策略的**第一个变种**。核心：**KDJ 找超卖/超买，10 日均线定趋势，两者共振再买卖**；口诀「线上多、线下空，均线不破趋势不改」。

## 规则（多头 / 空仓 0-1）

| 方向 | 条件 |
|---|---|
| **买入** | KDJ 超卖金叉（K 上穿 D 且 J<20）后，10 个交易日内价格站稳 > MA10 → 共振进场 |
| **卖出** | 收盘跌破 MA10（线上多、线下空） |
| **持有过滤** | 持仓中 KDJ 反复交叉不动，只要价不破 MA10 就持有 |

参数：KDJ 默认 (9,3,3)；均线 MA10；确认窗口 `WAIT=10`（见 `backtest.py` 顶部常量）。

> **实现说明**：KDJ 超卖(J<20) 与「价站稳 MA10」同日几乎互斥（超卖时价多在 MA10 之下），
> 严格同 bar 共振全池仅 5 笔。故按原文「**随后**…站稳…共振」的**时序**实现：先记超卖金叉，
> 再在窗口内等价格收复 MA10 确认进场。
