# 变种 2 · MACD + KDJ 波段战法

技术指标策略的**第二个变种**。核心：**只做「MACD 在零轴上方 + 缩量回踩不破 + KDJ 金叉」**，其余不做或快跑。
口诀：**零轴上方金叉干，零轴下方全不沾；回踩不破是关键，背离破轴赶紧跑。**

## 规则（多头 / 空仓 0-1）

| 方向 | 条件 |
|---|---|
| **入场** | DIF>0（零轴上方）**且** 缩量回踩不破（未创 10 日新高 + 收盘 > MA20 + 5日均量 < 20日均量）**且** KDJ 金叉（K 上穿 D） |
| **离场** | DIF 跌破 0（破轴即走） |
| **持有** | 持仓中零轴上方的 KDJ 死叉**不动**（对应四组合第 2 种「短期回调可持有」） |

只做四组合里的第 1 种（零轴上 + KDJ 金叉）；零轴下方一律不做。

参数：`PULLBACK_N=10`（回踩窗口）、`SUPPORT_MA=20`（不破支撑），见 `backtest.py` 顶部常量。

> 未量化项：**顶背离**（主观信号）；「放量跌破零轴」由「DIF 跌破 0」一并覆盖。
