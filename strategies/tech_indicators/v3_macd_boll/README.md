# 变种 3 · MACD + 布林通道（自适应窗口）波段

技术指标策略的**第三个变种**。核心：用 **MACD 过滤震荡、定多空**，用**布林通道找突破入场与转势离场**；
布林带平行时不做，只抓开口后的波段行情。**布林窗口随行情自适应**。

## 规则（多头 / 空仓 0-1）

| 方向 | 条件 |
|---|---|
| **入场** | MACD 金叉且站上零轴（DIF>0 且 DIF>DEA）**且** 布林带宽放大（开口）**且** 收盘上穿布林上轨（突破） |
| **离场** | MACD 死叉（DIF 下穿 DEA）**或** 价格自上轨下穿中轨（转弱） |
| **观望** | 布林带平行走平、K 线在通道内震荡 → 无突破即不进场（自然空仓） |

### 窗口自适应（本变种关键）

用 Kaufman 效率比 `ER(20)` 判行情状态并切换布林窗口：

| 状态 | 判据 | 布林窗口 | 用意 |
|---|---|---|---|
| 趋势态 | `ER ≥ 0.40` | **20** | 通道窄，早抓突破 |
| 震荡态 | `ER ≤ 0.30` | **30** | 通道宽，过滤假突破 |

滞回设计，避免状态频繁抖动；倍数 k 固定 2.0；带宽定义为 `(上轨-下轨)/中轨`，开口=`带宽放大`。

> 未量化项：**MACD 顶背离**（主观信号）。
