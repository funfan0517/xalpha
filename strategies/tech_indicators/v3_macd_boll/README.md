# 变种 3 · MACD + 布林通道 波段

技术指标策略的**第三个变种**。核心：用 **MACD 过滤震荡、定多空**，用**布林通道找突破入场与转势离场**；
布林带平行时不做，只抓开口后的波段行情。

## 规则（多头 / 空仓 0-1）

| 方向 | 条件 |
|---|---|
| **入场** | MACD 金叉且站上零轴（DIF>0 且 DIF>DEA）**且** 布林带宽放大（开口）**且** 收盘上穿布林上轨（突破） |
| **离场** | MACD 死叉（DIF 下穿 DEA）**或** 价格自上轨下穿中轨（转弱） |
| **观望** | 布林带平行走平、K 线在通道内震荡 → 无突破即不进场（自然空仓） |

参数：MACD(12,26,9)、BOLL(20,2)。带宽定义为 `(上轨-下轨)/中轨`，开口=`带宽放大`。

> 未量化项：**MACD 顶背离**（主观信号）。
