## 5. 为什么 R-05 低吸几乎不触发（漏斗）

全池全部交易日逐层筛选（自适应窗口的中轨）：

| 层级 | 条件 | 命中日数（占全样本） |
|---|---|---|
| 0 | 全部样本日 | 96,959 |
| 1 | 收盘在中轨上方 0~1% 内 | 10,350（10.67%） |
| 2 | + 当日收涨（收回中轨） | 5,074（5.23%） |
| 3 | + 近 20 日曾高于中轨 2%（真·回踩） | 3,003（3.10%） |
| 4 | + DIF>0 且 DIF>DEA（文档前提条件） | 222（0.23%） |

**根因**：「价格回踩到中轨附近」与「MACD 零轴上方金叉状态」在时间上互斥 —— 价格跌到 20/30 日均线附近时，DIF 往往已经跌破 DEA 甚至跌破零轴（文档自己的 N-04 也在警告这一点）。所以第 4 层把第 3 层砍到不足 1%，`D0` 变体的曝光因此只有 1~2%（等于空仓），它在 510300 上 11~16 笔交易、胜率 9~19%，不是「策略差」而是「几乎不下单」。

> 口径：单笔 = 建/平仓收盘价收益，未计费用。**机械规则输出，非投资建议。**
