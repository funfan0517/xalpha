# 变种 5 · Regime 切换（趋势用突破 / 震荡用抄底）

技术指标策略的**第五个变种**。用 **Kaufman 效率比 ER** 判断市场状态，在两种买卖逻辑间切换：

- **趋势态**（ER ≥ `ER_TREND`）：用变种 3 的「MACD 零轴上金叉 + 布林开口突破」；
- **震荡态**（ER ≤ `ER_RANGE`）：用变种 4 的「黄金三角抄底（近下轨 + MACD 金叉 + KDJ 超卖拐头）」；
- 介于两者之间**滞回**保持原状态，减少来回切换。

ER = `|收盘[t]-收盘[t-N]| / Σ|逐日涨跌|`（最近 N 日），ER→1 趋势、ER→0 震荡。参数 `ER_N=20`、`ER_TREND=0.40`、`ER_RANGE=0.30`。

## 结论（重要）

**ER 切换未能跑赢其组件**：

| 配置 | 中位年化 | 中位最大回撤 | 中位夏普 | 利润因子 |
|---|---|---|---|---|
| Regime 切换（默认 0.40/0.30） | +4.18% | -35.3% | 0.21 | 1.36 |
| 纯 v3 突破（趋势组件） | +3.81% | **-19.2%** | **0.29** | **1.68** |
| 纯 v4 抄底（震荡组件） | +4.25% | -35.9% | 0.25 | 1.62 |

- 切换**继承了 v4 的高回撤，又丢掉了 v3 的干净离场**；
- ER 是**滞后**状态量，边界处反复切换带来额外损耗；
- 「趋势用 v3 / 震荡空仓」可把回撤压到 -15%，但收益代价过大（年化仅 +1.8%）。

→ **naive regime 切换在这批标的上无效**；若要用 regime，需更好的状态量与非对称处理（见报告敏感性节）。
