# 变种 6 · 打分制 · Walk-Forward 样本外验证

对「多指标打分制」做**锚定式滚动 Walk-Forward**，检验其全样本高收益是否过拟合。

## 策略

7 项看多票数（价>MA20、价>MA60、DIF>DEA、DIF>0、K>D、价>BOLL中轨、放量上涨）：
`>= enter` 买入、`<= exit` 卖出（滞回）。参数网格 `enter∈{4,5,6} × exit∈{1,2,3}`（9 组）。

## 验证方法

- **测试年** 2019..2026；**训练窗口** = 该测试年之前的全部历史（锚定式扩张）；
- **选择指标** = 全池「中位夏普」（仅用训练期数据），选出最优参数固定用于紧接的测试年；
- 逐年测试结果**拼成连续样本外（OOS）净值**，与「全样本最优固定参数」「基线 MACD」「买入持有」对照。

## 结论（重要）

1. **不是纯过拟合**：样本外（2019 起全池中位）年化 **+6.84%**、夏普 **0.41**，仍优于买入持有的夏普 0.33，回撤 -28.9% 远小于买入持有 -45.4%。
2. **但样本外跑不赢基准**：收益 +6.84% < 买入持有 +8.90%，也 < 基线 MACD +8.80%（夏普 0.60）。
3. **参数极不稳定**：逐年选出的"最优"参数在 6/3→6/2→5/3→4/3→5/3→5/2→6/1→4/2 之间乱跳，说明"最优参数"主要是噪声。
4. **Walk-Forward 反而略逊于固定参数**（+6.84% vs 全样本最优 5/1 的 +8.08%）——频繁重选增加了噪声，不如用一个稳定参数。

→ 打分制的价值在**风控（低回撤/高盈亏比）**，而非超额收益；相较之下**基线 MACD 更简洁且样本外更强**。
