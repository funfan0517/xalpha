# 变种 6 · 打分制（4 票） · Walk-Forward 样本外验证

对「多指标打分制」做**锚定式滚动 Walk-Forward**，检验其全样本表现是否过拟合。

## 策略

**4 项看多票数**（每日各记 0/1，求和为 score）：

| # | 票 | 条件 |
|---|---|---|
| ① | 双均线之上 | 价 > MA20 **且** 价 > MA60 |
| ② | MACD 多头 | DIF > DEA **且** DIF > 0 |
| ③ | KDJ 多头 | K > D |
| ④ | 放量上涨 | 价涨（close > 前收）**且** 量 > 5 日均量 |

**进出阈值不写死，由参数网格取最优**：`enter∈{2,3,4} × exit∈{1,2,3}`（仅取 `exit < enter`，6 组），
以全池「中位夏普」为选择指标 → 网格最优 **enter=4 / exit=2**（`DEFAULT_PARAM = (4, 2)`，脚本会校验二者一致）。

## 验证方法

- **测试年** 2019..2026；**训练窗口** = 该测试年之前的全部历史（锚定式扩张）；
- **选择指标** = 全池「中位夏普」（仅用训练期数据），选出最优参数固定用于紧接的测试年；
- 逐年测试结果**拼成连续样本外（OOS）净值**，与「网格最优固定参数 4/2」「基线 MACD」「买入持有」对照。

## 参数网格（全样本 · 中位数）

| enter / exit | 中位年化 | 中位最大回撤 | 中位夏普 | 中位曝光 |
|---|---|---|---|---|
| 2 / 1 | +6.20% | -28.90% | 0.40 | 45% |
| 3 / 1 | +5.51% | -23.96% | 0.39 | 34% |
| 3 / 2 | +3.79% | -21.12% | 0.32 | 19% |
| 4 / 1 | +4.64% | -22.35% | 0.34 | 23% |
| **4 / 2 ★** | +3.49% | **-14.90%** | **0.41** | 9% |
| 4 / 3 | +1.62% | -11.44% | 0.26 | 5% |

> 4/2 与 2/1 的中位夏普近乎并列（0.41 vs 0.40）。按夏普选 4/2 得到的是**极低曝光（9%）的防守型**参数；
> 若更看重收益，2/1（+6.20%）是替代选项 —— 但回撤接近翻倍。

## 结论（OOS 2019 起 · 全池 55 只中位数）

1. **网格最优 4/2 是防守型**：中位年化 +3.63%、回撤仅 **-14.00%**、夏普 0.41、曝光 9%；98% 标的回撤小于买入持有。
2. **WF 反而更差**：+2.62% / 夏普 0.23 —— 逐年重选参数引入了噪声（逐年在 4/2→2/1→2/1→2/1→4/1→4/2→4/2→2/1 之间跳动），不如固定用网格最优。
3. **收益仍不敌基准**：4/2 的 +3.63% < 买入持有 +8.01%，也 < 基线 MACD +8.59%（夏普 0.56）。
4. **去掉 ④（触及下轨）后曝光上升**：同口径下 3/2 从上一版的 20% 变为 19%、4/2 的 9% —— 阈值提高后更保守，但不再有「趋势票与超卖票天然互斥」的结构矛盾。
5. **510300 上最优**：4/2 年化 +3.96%、回撤仅 **-6.26%**、夏普 0.63、卡玛 0.63、胜率 50%，风险调整后全面优于买入持有（0.38 / 0.17）。

→ 4 票版打分制依旧是**风控型策略**（低回撤、盈亏比 2.11、利润因子 1.23~1.55），而非超额收益来源。
