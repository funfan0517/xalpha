# 变种 6 · 打分制（5 票） · Walk-Forward 样本外验证

对「多指标打分制」做**锚定式滚动 Walk-Forward**，检验其全样本表现是否过拟合。

## 策略

**5 项看多票数**（每日各记 0/1，求和为 score）：

| # | 票 | 条件 |
|---|---|---|
| ① | 双均线之上 | 价 > MA20 **且** 价 > MA60 |
| ② | MACD 多头 | DIF > DEA **且** DIF > 0 |
| ③ | KDJ 多头 | K > D |
| ④ | 触及/跌破下轨 | 价 ≤ BOLL 下轨 × (1 + 1%)（1% 容差视为「触及」） |
| ⑤ | 放量上涨 | 价涨（close > 前收）**且** 量 > 5 日均量 |

**默认**：`score >= 3` 买入、`score <= 2` 卖出（滞回）。
**参数网格**：`enter∈{3,4,5} × exit∈{1,2,3}`，仅取 `exit < enter`（8 组）。

> 注：①（趋势偏强）与 ④（超卖触轨）天然互斥，实际 score 上限约 4，因此 3 票入场主要靠 ②③⑤ 这类「MACD+KDJ+放量」共振触发。

## 验证方法

- **测试年** 2019..2026；**训练窗口** = 该测试年之前的全部历史（锚定式扩张）；
- **选择指标** = 全池「中位夏普」（仅用训练期数据），选出最优参数固定用于紧接的测试年；
- 逐年测试结果**拼成连续样本外（OOS）净值**，与「默认参数 3/2」「全样本最优固定参数」「基线 MACD」「买入持有」对照。

## 结论（OOS 2019 起 · 全池 55 只中位数）

1. **曝光极低**：默认 3/2 曝光仅 20%，WF 17% —— 5 票中①④互斥使入场条件偏严，多数时间空仓。
2. **回撤控制优秀**：WF 中位最大回撤 -18.6%、默认 3/2 -20.7%，远小于买入持有 -45.4%；98% 的标的回撤更小。
3. **收益仍不敌基准**：WF +3.80%、默认 3/2 +4.66% < 买入持有 +8.01%，也 < 基线 MACD +8.59%（夏普 0.56）。
4. **参数仍不稳定**：逐年选出的参数在 3/2→4/1→4/2→4/1→4/1→4/2→4/2→3/1 之间跳动；WF（+3.80%）反而不如全样本最优固定参数 3/1（+6.07%，夏普 0.41）。
5. **510300 上是例外**：WF 年化 +6.34%、回撤仅 -10.24%、夏普 0.79、卡玛 0.62，大幅优于买入持有（+7.35% / -42.16% / 0.38 / 0.17）。

→ 5 票版打分制仍是**风控型策略**（低回撤、高盈亏比 2.27、利润因子 1.53），而非超额收益来源；
横向比较下**基线 MACD 更简洁且样本外更强**，但 510300 这类宽基上打分制的回撤优势显著。
