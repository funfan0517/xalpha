# 变种 7 · 风格路由（按基金风格自动选策略）

依据 `research/_fund_fit.py` 的发现（最优策略随基金**风格**分化），把 55 只 ETF 按风格路由到不同策略：

| 风格 | 策略 | 依据 |
|---|---|---|
| 避险 | 买入持有 | 债/金银长期单边上涨，择时为负贡献 |
| 防御 | BOLL | 红利/银行等区间震荡，均值回归有效 |
| 中枢 | MACD | 宽基温和趋势 |
| 进攻 | v3 MACD+BOLL | 行业主题高波动强趋势，突破跟随 |

## 结论（重要）

**它没有在夏普/收益上超过单一策略，但换来了显著更低的回撤。**

| 口径 | 风格路由 | 最佳统一策略(MACD) | 买入持有 |
|---|---|---|---|
| 全样本 中位年化 | +5.80% | +7.10% | +5.07% |
| 全样本 中位最大回撤 | **-22.23%** | -30.29% | -47.12% |
| 全样本 中位夏普 | 0.40 | 0.41 | 0.17 |
| 全样本 利润因子 | **1.84** | 1.54 | — |
| OOS 中位夏普 | 0.47（训练映射）/ 0.65（全样本映射） | 0.65 | 0.63 |
| OOS 中位最大回撤 | **-13.9%（全样本映射）** | -19.5% | -29.9% |

- **全样本**：路由夏普 0.40 ≈ MACD 0.41，但回撤更小、利润因子更高（1.84）——本质是「**低暴露版的 MACD**」。
- **样本外（2024+）**：路由（全样本映射）夏普 0.65 = MACD，但**回撤只有一半**（-13.9% vs -19.5%）、曝光 20%。
- ⚠️ **映射不稳定**：用 ≤2023 数据推导的映射与全样本不同（中枢 MACD→v3、进攻 v3→VOL），其样本外夏普掉到 0.47 —— 路由引入了额外的「选策略」噪声。

→ **按风格路由不是"圣杯"**：它提升的是**风险控制（回撤/卡玛/盈亏比）**，而不是收益或夏普；且这种提升高度依赖映射的稳定性。
