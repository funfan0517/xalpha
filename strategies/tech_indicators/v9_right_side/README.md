# 右侧买入（Right-Side Entry · 五票确认）· 技术指标家族变种 **v9**

> **2026-10-28 并入 `strategies/tech_indicators/` 作为变种 v9**（原独立策略 `strategies/right_side/`）。
> 标的池与家族统一：**全池 55 只场内 ETF**（`data/_long_klines.json` ∩ `data/_indicators_hist.json`）。
> 每日不再单独注册 runner/看板卡片，由 `run_daily_tech_indicators.ps1` 第 1-2 步跑本目录的
> `scan.py` → `_scan_report.py`，结果作为 `V9` 列进入家族 6 策略汇总表。
> 本目录的 `rule.py` / `data.py` / `engine` 仍在包根（被 `scan.py`/`backtest.py` 直接 import，勿移动）。

回答一个问题：**基金池里哪些标的现在达到了右侧买入点？**

定位是**买点识别器 / 择时叠加层**，不是收益增强器。它不预测底部，只等「下跌结构已被证伪」的证据同时出现。

## 1. 为什么需要它

「抄底抄到半山腰」的根因不是买贵了，而是**判据用错**：

| 用「价格位置」判断（左侧） | 用「状态转移」判断（右侧，本策略） |
|---|---|
| 跌了 30% / 估值分位 20% / 触布林下轨 | 低点抬高、突破前高、均线上行、零轴上方金叉、放量 |
| 便宜可以更便宜（2021-2022 中概、2022 纳指） | 买在结构破坏**之后**，必然更高、必然放弃第一段 |

代价是结构性的：右侧必然少赚第一段、必然有空仓期。仓库内 `strategies/tech_indicators/_comparison_report.md` 的对照就是证据 ——
**v4 抄底**（近下轨 + MACD 金叉 + KDJ 超卖）中位回撤 **-35.9%**、利润因子 1.54；
**v3 突破**（零轴上 + 布林开口 + 上轨突破）中位回撤 **-17.8%**、利润因子 1.88。同一批标的、同一个引擎。

## 2. 五票确认（`rule.py`，唯一参数权威源）

| 票 | 判据 | 在排除什么 |
|---|---|---|
| **V1 结构止跌** | 近 20 日最低收盘 > 再往前 60 日最低收盘 ×(1+0.5%) | 还在创新低（下跌中继） |
| **V2 结构翻越** | 收盘 > 前 60 日最高收盘（不含当日） | 仍在箱体/下降结构内 |
| **V3 均线转向** | 收盘 > MA20 **且** MA20 较 5 日前抬升 | 下行均线上的反抽（最常见的假右侧） |
| **V4 动能确认** | DIF > DEA **且** DIF > 0 | 零轴下方金叉（那是反弹，不是转折） |
| **V5 量能确认** | 成交量 ≥ 1.5×20 日均量 **且** 当日收涨 | 缩量假突破 |

- **5 票全过 → READY（买点）**
- **4 票 → WATCH（差一票，等次日确认）** —— 明确**不提前埋伏**，提前买就是左侧
- 硬否决：5 日涨幅 > 12%（追高）· 20 日均成交额 < 0.3 亿（流动性）· 因子未就绪
- 离场：收盘跌破**入场结构位**（信号日前 10 日最低收盘）· 或连续 2 日收盘 < MA20

执行口径：当日收盘判定 → **次日收盘**成交（十年库只有收盘价，全程无未来数据）；单边 0.03%；0/1 满仓。

## 3. 结果（55 只场内 ETF · 2016-09 起 · 中位数）

| 指标 | 右侧买入 | 买入持有 |
|---|---|---|
| 年化 | +1.33% | +3.86% |
| 最大回撤 | **-16.77%** | -46.03% |
| 持仓占比 | 9.3% | 100% |
| 择时边际 | **+8.3bp**（34/55 为正） | — |

单笔合并（417 笔）：胜率 44.4%、盈亏比 2.59、利润因子 2.07、平均持仓 21.3 天。
分类均值上，宽基 +3.5%/-12.1%、A股行业 +2.0%/-21.4%、全球QDII +0.8%/-13.9% ——
**QDII 与商品是长期单边上涨资产，降暴露必负贡献**，这是任何择时策略的固有属性（同 lights 的结论）。

**怎么读**：低暴露策略年化低于满仓是结构性的（90% 时间空仓）。判据是 ① 回撤显著压缩 ② 择时边际为正。
两者同时成立，说明买点确实买在「该涨的时候」。

### 为什么是 5 票而不是 4 票

`research/_sweep_report.md`（同池同年限，只改一个维度）：

| 变体 | 中位年化 | 中位回撤 | 单笔胜率 | 利润因子 | 择时边际 | 持仓 |
|---|---|---|---|---|---|---|
| **5 票全过（采纳）** | +1.38% | **-16.77%** | 44.3% | **2.09** | **+7.3bp** | 9.3% |
| 4 票即买 | +1.33% | -25.24% | 38.6% | 1.55 | +3.1bp | 18.1% |
| 3 票即买 | +1.92% | -26.46% | 39.2% | 1.46 | +4.4bp | 26.7% |

放宽票据几乎不增加年化，却把回撤从 -17% 拉到 -25%，且胜率、利润因子、择时边际全面劣化 ——
**多出来的那一票买到的正是「半山腰」**。这是本策略最重要的一条实证。

**主要约束票**：结构翻越（历史满足率 7.1%）与量能确认（7.0%），所以买点约 1% 的交易日触发
（每只每年 ~2.5 个，全池日均 0~1 只）。**频率低是设计目标，不是缺陷**；嫌少就去做左侧，那是另一件事。

```powershell

python strategies/tech_indicators/v9_right_side/backtest.py
python strategies/tech_indicators/v9_right_side/_reportbt.py
# select 走 pipeline 已不适用（策略不再单独注册）；分级产物保留仅作横向比较参考

python strategies/tech_indicators/v9_right_side/_scan_report.py

# 每日一键（家族 runner 的第 1-2 步就是本变种）

# 参数敏感性（改了 rule.py 的阈值后建议重跑）
```

`scan.py --cache` 不刷新行情；`scan.py 510300,512800` 只扫指定标的。
`backtest.py 510300,512800` 是**按代码 upsert**（保留其他标的的行，便于分批回测）；
只有 `--fresh`（或先删产物文件）才会清空重建。

## 7. 边界与已知局限

- **不是收益策略**：年化中位 +1.3% 低于买入持有 +3.9%；它换的是回撤（-46% → -17%）与正的择时边际。
- **执行价偏保守**：十年库无开盘价，按次日收盘成交（比次日开盘更不利），实盘信号质量略好于回测。
- **V2/V5 是稀缺票**：满足率各约 7%，很多标的整段样本只触发 1~3 次；短样本标的（<3 年）统计意义弱。
- **不分层仓位**：0/1 满仓，不回答「买多少」；仓位应由其他策略或人工决定。
- **未计滑点**，仅含单边 0.03% 佣金。
- **趋势策略通病**：震荡市反复止损（趋势离场占离场原因的 90.6%），所以单笔胜率只有 44%。
