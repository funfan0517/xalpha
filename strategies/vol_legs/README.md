# 波动资产操作规则 v1.3（A500 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金）

来源：《波动资产操作规则.md》（`E:/jijin/`，v1.1 2026-10-28：新增 §6 纳指100 / 标普500）。
本目录是它的**可执行实现**：六条腿的标的、参数、状态机、组合层回测、每日操作报告。

**目标带（v1.3，pp of 总资产）**：A500 **5** / 纳指100 **10** / 标普500 **10** / 科创50 **2.5** /
恒生科技 **2.5** / 黄金 **10** = **40pp**。其余 60pp —— 红利 **20**、国债 **30**、货币基金 **10**
—— 不在本策略内（大类仍是 权益 50 / 债 30 / 金 10 / 现金 10）。

> ⚠ 与文档 v1.1 §0 的差异：文档写的是「A500 10% + 纳指 5% + 标普 5%」（A股重、美股轻）。
> v1.3 按确认的目标带改为 **A股减半、美股翻倍**，规则本体（闸门/阶梯/扳机/趋势闸门/再平衡）
> 一条没动，只重标了**份数**：1 份 = 带的 20%（A500 1.0pp、美股/黄金 2.0pp），
> 使「4.5 份满梯 ≈ 带的 90%」这个文档自带的校验式继续成立（见 §3.1-①）。

**v1.2 口径变更：信号、记账、回测、执行**四件事全部统一到**场外基金复权净值**
（`rule.SIGNAL_MODE = "otc"`）。原先的「场内 ETF 收盘 / 美元指数」口径保留为
`SIGNAL_MODE = "exchange"`，回测里两套口径直接对照。

一句话：**仓位带是主锚，信号只决定「何时动、动多少」**。本策略回答的不是「买哪只基金」，
而是「今天该不该动手、动几个 pp」。

## 1. 这是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 组合层六腿操作规则（5 / 10 / 10 / 2.5 / 2.5 / 10pp = 40pp），输出「下一交易日该下的那一单」 | 选基工具（六条腿的标的是固定池，由 §0 直接定档，不做 A/B 分级） |
| 有状态的状态机（阶梯档位、月频帽、连续年线天数、再平衡偏离） | 单指标信号（单看 RSI 或 MA250 会丢掉「已执行到第几档」） |
| 与回测**同一份代码、同一份净值**的每日复算（`engine.run()`） | 拍脑袋的「大概可以买了」 |

红线（§0）：不预测顶底、不用杠杆、不因「跌得多」就跳过扳机。

### 2.2 为什么全部改成场外净值

| 维度 | 场外净值口径（v1.2 主口径） | 场内/美元指数口径（v1.1，保留） |
|---|---|---|
| 信号 | 你实际持有那只基金的复权净值 | ETF 收盘价 / NDX·SPX 美元指数 |
| 回测收益 | **真能拿到的收益**（含汇率、跟踪误差、分红再投） | 价格指数（除息、无汇率、含场内溢价） |
| 场内溢价干扰 | 无 | 有（±0.5%~2%） |
| 汇率 | 含（QDII 是人民币净值） | 美股腿不含 |
| 净值时滞 | 境内 T 日晚、QDII T+1~T+2 | 当日收盘即有 |
| 用在什么场合 | 回答「我能拿到多少」/ 实盘对账 | 回答「信号有多纯」/ 归因分析 |

实测（同策略、同规则，见 `backtest/_vol_legs_bt.md` 第二节）：场外口径年化普遍比场内高
**+0.2~1.0pp**，主要来自**分红再投**（累计净值 vs 价格指数）与起点差；变差的有两档：
「美股闸门不设限」**-1.77pp**（该档美股腿按 20pp 真的满仓持有，汇兑与跟踪误差开始显现，
v1.3 权重翻倍后负面影响也被放大）与「六腿等权」-0.30pp。

### 2.3 桥接规则（唯一的口径妥协）

`023299`（2025-03）与 `017641`（2023-04）成立太晚，250 日窗口不够。处理办法：
用**同类场外老基金**（`000051` / `050025`）的净值接到本基金成立日之前，按拼接日净值缩放
——**只影响窗口早期段**，拼接日之后全是真实执行标的。缩放只改水平不改收益率，且缩放的是
**前段**（保证序列末值 = 基金真实净值，报告里显示的就是实际净值）。
开关：`rule.OTC_USE_PROXY_HISTORY`；关掉后组合层样本从 2026-04 才起算。

### 2.4 记账口径

- 仓位单位：**pp of 总资产**。1 份 = **带的 20%**：A500 1.0pp、纳指/标普/黄金 2.0pp；
  4.5 份满梯 = 4.5pp / 9pp，约等于各自的带（5pp / 10pp）。
  换算成权益账户口径（权益 = 总资产 50%）：A500 1 份 = 权益的 2%，美股/黄金 1 份 = 权益的 4%。
- 未投部分：留在货币基金，按 `rule.CASH_ANNUAL`（1.40%）逐日计息。
- 成本：申购 0.10%；赎回 0.50%，持有 7 天内 1.50%（场外 A/C 类量级）。
- 成交：**收盘后计算、下一交易日下单**。场外基金 15:00 前提交才拿当日净值，所以 t 日算出的
  挂单在 t+1 净值成交，t+1 的收益不会用到 t+1 才知道的信息。
- 各腿净值日期不同（QDII 滞后 1~2 日）：无净值的日子不决策、不成交，持仓按最近净值计值。
- **起点 = 目标带**（5/10/10/2.5/2.5/10，即实际持仓），起点现金为 0 → 加仓只能靠卖出其他腿
  腾挪或追加资金；`--from-zero` 是「规则自己从空仓建到带」的对照口径。
- 每日报告第二节给「**今日理论最优持仓比例**」：规则授权目标（阶梯已建份数 / 趋势闸门档位 /
  黄金保险丝降档）逐腿列出，与目标带、当前市值并排，差额分「会成交」与「只是等条件」两类。

### 3.1 五处文档口径与取法（数字对不上时先看这里）

1. **「1 份 = 权益账户 2%」的分母**。文档 §2 自检写「满梯 9% ≈ 填满 10% 带」：4.5 份 × 2% = 9%。
   v1.3 的目标带让这句话**字面成立**：权益账户 = 总资产的 50%，2% 权益 = **1pp 总资产**，
   A500 带 5pp → 满梯 4.5 份 = 4.5pp ≈ 5pp。所以份数一律取**带的 20%**
   （`CFG["unit_pp"]`：A500 1.0、纳指/标普/黄金 2.0），满梯恒为带的 90%。
   旧权重（A500 10pp、美股 5pp）下同一比例恰好给出 2pp / 1pp，与文档 §9 的
   `unit_pct_equity` 完全一致 —— 这是一次**重标**，不是新规则。
   若你按权益账户记账（权益 50 视为 100），把报告里的 pp 数字统一 ×2。
2. **「仓位带是主锚」vs「阶梯填满带」**。阶梯份数只能把自己填到带的 90%，所以它只在
   「起点低于带」时起作用。实盘默认按**目标带起步**（= 实际持仓），此时阶梯的角色是
   「跌出来的加仓空间」；`--from-zero` 才是「规则自己从空仓建到带」的对照口径。
   两种起点在回测里都跑了（§4 前两行），差距就是现金拖累。
3. **null 闸门的语义**。§1 说「数据不足时该规则不执行」。本实现取「**不生效（不否决）**」，
   并把每条 null 的原因写进每日报告。想更保守（null 视为否决）把 `rule.NULL_GATE_BLOCKS = True`。
4. **美股 ERP 分位的来源**。§6 的定义是 `1/PE(TTM) − 10Y美债` 的分位，但本地**没有 NDX/SPX 的
   TTM PE 月度库**（只有 NDX 的 forward PE，会系统性抬高 ERP，不能顶替）。所以分位走
   `data/_val_inputs.json` 的 `ndx_erp_pct` / `spx_erp_pct`（人工月度复核），当前按文档 §6
   「当前状态读数」（erp 为负 → 分位 <30%）预填 `0.05` → **美股腿当前只减不加**。
5. **§7 的 ±5pp 是绝对阈值，带宽减半后会失效**。A500 带 5pp 时，5pp 阈值等于允许漂到
   **2 倍带**才减持。故改为 `min(5pp, 带×50%)`（`rule.rebalance_pp()`）：
   A500 2.5pp、科创50/恒生科技 1.25pp、美股/黄金 5pp。这是 v1.3 对 §7 原文唯一的阈值改写。

另外两处**主动裁定**：§7 的「回到目标位」默认**只做减持**（`rule.REBAL_BUY_BACK = False`）；
QDII 额度关闭时档位**顺延而非取消**（档位不消耗，恢复后补执行）。

## 4. 回测结论（场外净值口径，诚实版）

样本 2022-08-24 ~ 2026-10-27（4.0 年；受恒生科技联接 012805 于 2021-08 成立 + 250 日窗口限制）。
六腿同尺比：40pp 额度，未投按货基计息，含申赎成本，价格 = 各基金复权净值。

| 组合 | 累计 | 年化 | 波动 | 最大回撤 | 夏普 | 平均投入 |
|---|---:|---:|---:|---:|---:|---:|
| 策略（空仓起步） | 11.4% | 2.73% | 5.4% | -6.2% | 0.25 | 10.6pp |
| 策略（带内满仓起步） | 71.2% | 14.39% | 9.8% | **-9.2%** | **1.32** | 44.3pp |
| 策略（美股闸门不设限） | 42.9% | 9.34% | 8.8% | -11.1% | 0.90 | 29.6pp |
| 静态带（季度回锚） | 71.9% | 14.50% | 10.0% | -9.5% | 1.31 | 45.1pp |
| 买入持有 | 74.2% | 14.88% | 12.4% | -14.7% | 1.09 | 55.0pp |
| 六腿等权 | 55.0% | 11.57% | 9.7% | -11.2% | 1.05 | 39.9pp |

单腿全周期（各腿自己那只场外基金，闸门不设限，隔离阶梯机制）：

| 腿 | 样本 | 阶梯 年化/回撤/夏普 | 一次性满仓 |
|---|---|---:|---:|
| 中证A500(`023299`) | 2010-07~2026-10（15.6 年，含桥接前段） | **5.66% / -30.9% / 0.30** | 5.42% / -43.4% / 0.20 |
| 纳指100(`270042`) | 2013-09~2026-10（12.5 年） | 9.25% / **-23.4%** / 0.66 | 17.31% / -29.5% / 0.79 |
| 标普500(`017641`) | 2013-08~2026-10（12.4 年，含桥接前段） | 7.86% / -27.4% / 0.59 | 12.70% / -30.5% / 0.70 |

结论（四条）：

1. **空仓起步版跑输**（2.73% vs 14.50%）：平均只投入 10.6/40pp —— 美股 20pp 的带被 ERP 闸门
   锁死、A500 带减半后阶梯能补的量也减半。这一档只是「规则自己建仓」的对照，不是实盘用法。
2. **带内满仓起步版**（= 实盘用法）：年化 14.39% 与静态带 14.50% **基本打平（-0.11pp）**，
   回撤 -9.2% 略小 0.26pp，**夏普 1.32 vs 1.31**。规则几乎不创造超额收益，它买的是
   「回撤略小 + 超配自动兑现 + 下跌有加仓路径」。
3. **美股闸门当前读数的机会成本 = +6.6pp/年**（2.73% vs 放开后 9.34%）。v1.3 把美股权重翻倍到
   20pp，这段美股长牛里该成本也随之放大（v1.2 是 +3.3pp）。这是文档 §6 的显式选择：宁可少赚，
   也不在 ERP 为负时加仓。
4. **单腿**：A500 阶梯双赢（5.66% vs 5.42%，回撤 **-30.9% vs -43.4%**，夏普 0.30 vs 0.20）——
   因为 2.5pp 的再平衡阈值让它涨上去就回带，没被填满；纳指/标普阶梯让渡约 **47% / 38%** 的年化，
   换回撤压缩约 **21% / 10%**，夏普仍低于一次性满仓（0.66 vs 0.79、0.59 vs 0.70）
   —— 阶梯买的是买点纪律与持仓心理，不是超额收益。

## 5. 已知局限（用之前必须知道）

- **桥接段不是本基金业绩**：A500（2025-03 前用 000051）、标普（2023-04 前用 050025）的早期段
  是同类老基金，只用于补齐 250 日窗口与回撤阶梯的 52 周高点。看单腿绝对收益时请只认拼接日之后。
- **美股闸门是人工月度复核值**，不是自动分位（理由见 §3.1-④）。分位停在 0.05 就意味着美股腿
  一直不建仓 —— 每月复核 `data/_val_inputs.json` 是本策略的**例行动作**。
- **组合层只有 4.0 年样本**，且这段是「A股熊转牛 + 黄金大牛 + 港股深跌 + 美股长牛」的特定组合。
- **年线闸门是非对称的**：跌破要等 5 日才减半，收复当天就加满。围绕 MA250 的窄幅震荡会反复
  往返（样本内恒生科技 2025-12-30 卖、12-31 买）。进攻腿带减半到 2.5pp 后单笔金额小，
  但**摩擦占比反而更高**：累计手续费 0.17pp / 4 年（占起始净值 0.42%），换手 16pp/年。
- **小带宽腿靠再平衡阈值兜底，不是靠阶梯**：A500 带 5pp 时，止损/回带几乎全靠
  `min(5pp, 带×50%) = 2.5pp` 这个阈值（单腿回撤 -30.9% vs 满仓 -43.4% 就是它的功劳）。
  若把阈值改回绝对 5pp，阶梯填满后它就退化成满仓，回撤会回到 -43%。**改带宽必须同看阈值。**
- **未计**：场外申赎确认时滞（QDII T+2）、大额限购、C 类销售服务费（0.2%/年量级）、
  以及桥接段的指数差异。净值口径已含汇率与跟踪误差（这是相对场内口径的改进）。
- **持仓状态是机械回放**：默认从目标带（= 实际持仓）回放到今天，不是你的真实成交记录；
  真实持仓与之不同时用 `--hold` 覆盖起点。

## 6. 运行

```powershell

# 默认即「目标带起步」（= 你的实际持仓），报告第二节给「今日理论最优持仓比例」

python strategies/vol_legs/scan.py --from-zero

# 组合层回测（两种口径都跑；--mode otc 只跑场外；--quick 跳过闸门敏感性）

python strategies/vol_legs/data.py                  # 六腿序列 + 库状态

python strategies/vol_legs/data.py --refresh-us      # 只刷美元指数(v1.1 口径用)
```

## 8. 需要人工维护的输入

`data/_val_inputs.json`（留空 = 该规则不执行，报告里会标「未维护」）：

| 键 | 含义 | 影响的规则 |
|---|---|---|
| `fomc_days` | FOMC 决议日列表 | 纳指/标普/恒生科技/黄金 禁新仓窗口 |
| `kc50_pb_pct` | 科创50 PB 分位（0-1） | <0.20 禁新增；≥0.90 年线下 1/4 仓试错 |
| `hkt_erp_pct` | 恒生科技 ERP 分位（0-1） | <0.20 禁新增；≥0.70 且在年线上可加 |
| `ndx_erp_pct` | 纳指100 ERP 分位（0-1，**月度复核**） | <0.30 暂停新增（当前 0.05 = 暂停） |
| `spx_erp_pct` | 标普500 ERP 分位（0-1，**月度复核**） | 同上 |
| `tips_fuse_paused` | 10Y TIPS 是否连续 3 月上行 | 暂停恒生科技加仓 |
| `wgrc_fuse` | 央行净购金是否连续 2 季为负 | 黄金目标带 10 → 5 |
| `qdii_limit_closed` | QDII 额度关闭/限大额的腿（如 `["ndx"]`） | 该腿阶梯档位顺延 |

## 9. 与其他策略的边界

- 红利 **20pp** 走《红利池操作规则》（`strategies/dividend/`）；本策略不碰红利腿的买卖。
- 国债 **30pp** / 货币基金 **10pp** 静态，不在此处轮动。
- 40（本策略）+ 20（红利）+ 30（国债）+ 10（货币）= 100pp。
- 本策略只管「六腿各自买多少」，不判断「买哪条腿」（选腿属组合层之上的资产配置决策）。
- **本策略的第一个变种 `v1_ma20/`**（原 `tech_indicators/v8_ma20`，2026-10-28 迁入）：用同一六腿的场外复权净值
  做 MA20 穿越，回答「每条腿什么时候下车」；本策略回答「组合层仓位带怎么摆」。两者可叠加、不可互相替代，
  变种的结论与费率口径见 `v1_ma20/README.md`。**2026-10-30 起退出每日操作板块2 的看板**（`daily.enabled=false`，
  脚本与产物保留，需要时手跑 `v1_ma20/daily/_daily_scan.py`）。
- **第二个变种 `v4_erp_band/`**（2026-10-30 按用户「股债利差（ERP）通道」规则落地；编号沿用创建时的 v4，
  v3 槽位空置）：**不发生在六腿内部**，而是回答「**沪深300 与国债之间摆多少**」——
  `ERP = 100/PE(沪深300) − 10Y国债`，滚动 250 日 MA ± 2σ 通道，利差触上轨 = 低估 → 股票 80%，
  回穿均线退出 → 50%，跌破下轨 = 高估 → 20%；T+1 成交、月末偏离 >5pp 才回锚。
  股票腿用**全收益** H00300（价格指数会漏 2pp/年分红）。结论见 `v4_erp_band/README.md` §5 —— 简版：
  2012-08~2026-10 年化 4.88% vs 同窗口静态 50/50 4.94%（**-0.06pp，无超额**），回撤 -23.5% vs -24.4%；
  反向信号（低估 20 / 高估 80）反而 5.31% 但回撤放大到 -34.9% —— 说明这条信号在 A 股**识别不出方向性优势**，
  它的价值是「情绪刻度 + 再平衡触发器」，不是收益引擎。本变种与主策略**默认不叠加**（叠加前先定谁的额度优先）。
  **2026-10-30 起不出每日看板**（`daily.enabled=false`，它本就不在六腿这一层），脚本保留可手跑
  `v4_erp_band/daily/_daily_scan.py`。
- **变种 `v2_boll_breakout/`**（原 `tech_indicators/v16_boll_breakout`，2026-10-30 迁入；初入时编号 v6，同日改回 v2）：与 `v1_ma20`
  **同一层**（六腿逐腿进出时点），只是指标换成 **BOLL(35,2) 上穿买入 / 跌回中轨卖出**。
  结论见 `v2_boll_breakout/README.md` §5 —— 简版：组合层 2021-10~2026-10 年化 8.73% / 回撤 **-5.30%** /
  夏普 **1.18**（静态带 12.10% / -17.45% / 0.89），**收益让渡、回撤与夏普换回来**；
  真正的长处是**换手只有 MA20 的 1/6**（2~3 笔/年 vs 13~16 笔），扣费后只掉 -1.31pp（MA20 掉 -6.68pp）。
  与 `v1_ma20` 二选一即可，别同时跑在六腿上（会互相打架）；本变种**暂无每日操作脚本**，只有回测入口，
  故在 `pipeline/strategies.json` 里 `daily.enabled=false`（注册但不参与每日流程，也不出看板卡片）。
- **第三个变种 `v3_macd_boll/`**（2026-10-30 由 `tech_indicators/v3_macd_boll` 复制并按六腿口径落地；
  v3 槽位此前空置，编号沿用源变种）：**同一六腿的场外复权净值**上做「MACD 定多空 + 布林开口突破入场 +
  死叉/跌破中轨离场」，布林窗口按 Kaufman 效率比 `ER(20)` 在 20↔30 之间滞回切换。回答的是
  「**什么时候追突破上车**」（与 v1_ma20 的「什么时候下车」同层次、信号更钝）。结论见
  `v3_macd_boll/README.md` §5 —— 简版：共同窗口 2021-11~2026-10 年化 5.55% / 回撤 **-4.89%** / 夏普 0.93
  vs 静态带 11.09% / -17.45% / 0.80，**只降回撤不增收益**；笔数只有 2~4/年（v1_ma20 是 13~16），
  扣费后 3.74%（-1.81pp）—— 成本不再是决定性变量。注意它是**突破追涨型**，与主策略「跌了才加仓」的阶梯
  方向相反，**不可叠加在同一份额度上**。**2026-10-30 起进每日操作板块2**（`daily/_daily_scan.py`，
  随 `run_daily_vol_legs.ps1` 第 2 步运行，看板卡读 `daily/_v3_macd_boll_daily.json`），顶替 v1 / v4 的卡片。
