# 波动资产操作规则 v1.4（中证A500 / 沪深300 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金）

来源：《波动资产操作规则.md》（`E:/jijin/`，v1.1 2026-10-28：新增 §6 纳指100 / 标普500）。
本目录是它的**可执行实现**：七条腿的标的、参数、状态机、组合层回测、每日操作报告。

**目标带（v1.4，pp of 总资产）**：中证A500 **2.5** / 沪深300 **2.5** / 纳指100 **10** /
标普500 **10** / 科创50 **2.5** / 恒生科技 **2.5** / 黄金 **10** = **40pp**。
其余 60pp —— 红利 **20**、国债 **30**、货币基金 **10** —— 不在本策略内
（大类仍是 权益 50 / 债 30 / 金 10 / 现金 10）。

> ⚠ 与文档 v1.1 §0 的差异：文档写的是「A500 10% + 纳指 5% + 标普 5%」（A股重、美股轻）。
> v1.3 按确认的目标带改为 **A股减半、美股翻倍**；**v1.4（2026-11-02）再把 A股那 5pp 对半拆成
> 中证A500 2.5 + 沪深300 2.5**（新增第七腿，额度合计不变）。规则本体（闸门/阶梯/扳机/趋势闸门/
> 再平衡）一条没动，只重标了**份数**：1 份 = 带的 20%（A500·沪深300 0.5pp、美股/黄金 2.0pp），
> 使「4.5 份满梯 ≈ 带的 90%」这个文档自带的校验式继续成立（见 §3.1-①）。

> ⚠ **拆腿不是加分散度**。中证A500 与沪深300 的成分重叠约八成、场外序列在 2025-03-27 之前
> **完全相同**（A500 的桥接基金就是沪深300 的 `000051`，见 §2.3）。这一拆的真实作用是把
> 「A股核心 5pp」变成**两个各自跑闸门/阶梯的执行出口**，不是多出一个资产类别。

**v1.2 口径变更：信号、记账、回测、执行**四件事全部统一到**场外基金复权净值**
（`rule.SIGNAL_MODE = "otc"`）。原先的「场内 ETF 收盘 / 美元指数」口径保留为
`SIGNAL_MODE = "exchange"`，回测里两套口径直接对照。

一句话：**仓位带是主锚，信号只决定「何时动、动多少」**。本策略回答的不是「买哪只基金」，
而是「今天该不该动手、动几个 pp」。

## 1. 这是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 组合层七腿操作规则（2.5 / 2.5 / 10 / 10 / 2.5 / 2.5 / 10pp = 40pp），输出「下一交易日该下的那一单」 | 选基工具（七条腿的标的是固定池，由 §0 直接定档，不做 A/B 分级） |

红线（§0）：不预测顶底、不用杠杆、不因「跌得多」就跳过扳机。

### 2.2 为什么全部改成场外净值

| 维度 | 场外净值口径（v1.2 主口径） | 场内/美元指数口径（v1.1，保留） |
|---|---|---|
| 信号 | 你实际持有那只基金的复权净值 | ETF 收盘价 / NDX·SPX 美元指数 |
| 回测收益 | **真能拿到的收益**（含汇率、跟踪误差、分红再投） | 价格指数（除息、无汇率、含场内溢价） |
| 场内溢价干扰 | 无 | 有（±0.5%~2%） |
| 汇率 | 含（QDII 是人民币净值） | 美股腿不含 |
| 净值时滞 | 境内 T 日晚、QDII T+1~T+2 | 当日收盘即有 |
| 用在什么场合 | 回答「我能拿到多少」/ 实盘对账 | 回答「信号有多纯」/ 归因分析 |

实测（同策略、同规则，见 `backtest/_vol_legs_bt.md` 第二节）：场外口径年化普遍比场内高
**+0.4~1.1pp**，主要来自**分红再投**（累计净值 vs 价格指数）与起点差；变差的有两档：
「美股闸门不设限」**-1.54pp**（该档美股腿按 20pp 真的满仓持有，汇兑与跟踪误差开始显现，
v1.3 权重翻倍后负面影响也被放大）与「七腿等权」-1.27pp。

### 2.3 桥接规则（唯一的口径妥协）

`023299`（2025-03）与 `017641`（2023-04）成立太晚，250 日窗口不够。处理办法：
用**同类场外老基金**（`000051` / `050025`）的净值接到本基金成立日之前，按拼接日净值缩放
——**只影响窗口早期段**，拼接日之后全是真实执行标的。缩放只改水平不改收益率，且缩放的是
**前段**（保证序列末值 = 基金真实净值，报告里显示的就是实际净值）。
开关：`rule.OTC_USE_PROXY_HISTORY`；关掉后组合层样本从 2026-04 才起算。

> ⚠ **`000051` 现在有两个身份**：既是中证A500 的桥接基金，又是沪深300 这条腿自己的执行标的。
> 后果：**2025-03-27 之前两条腿的场外序列逐值相同**，单腿回测里那一段的两条腿成交日、回撤、
> 阶梯档位完全一致（见回测报告第四节 A500 / 沪深300 两张表的前段）。这不是 bug，是数据边界
> —— 看这段时只读「阶梯 vs 满仓」的相对关系，别把两条腿当成独立的两份证据。

### 2.4 记账口径

- 仓位单位：**pp of 总资产**。1 份 = **带的 20%**：中证A500/沪深300 0.5pp、纳指/标普/黄金 2.0pp；
  4.5 份满梯 = 2.25pp / 9pp，约等于各自的带（2.5pp / 10pp）。
  换算成权益账户口径（权益 = 总资产 50%）：A500·沪深300 1 份 = 权益的 1%，美股/黄金 1 份 = 权益的 4%。
- 未投部分：留在货币基金，按 `rule.CASH_ANNUAL`（1.40%）逐日计息。
- 成本：申购 0.10%；赎回 0.50%，持有 7 天内 1.50%（场外 A/C 类量级）。
- 成交：**收盘后计算、下一交易日下单**。场外基金 15:00 前提交才拿当日净值，所以 t 日算出的
  挂单在 t+1 净值成交，t+1 的收益不会用到 t+1 才知道的信息。
- 各腿净值日期不同（QDII 滞后 1~2 日）：无净值的日子不决策、不成交，持仓按最近净值计值。
- **起点 = 目标带**（2.5/2.5/10/10/2.5/2.5/10，即实际持仓），起点现金为 0 → 加仓只能靠卖出其他腿
  腾挪或追加资金；`--from-zero` 是「规则自己从空仓建到带」的对照口径。
- 每日报告第二节给「**今日理论最优持仓比例**」：规则授权目标（阶梯已建份数 / 趋势闸门档位 /
  黄金保险丝降档）逐腿列出，与目标带、当前市值并排，差额分「会成交」与「只是等条件」两类。

### 3.1 五处文档口径与取法（数字对不上时先看这里）

1. **「1 份 = 权益账户 2%」的分母**。文档 §2 自检写「满梯 9% ≈ 填满 10% 带」：4.5 份 × 2% = 9%。
   不变量始终是「1 份 = 带的 20%，满梯 4.5 份 ≈ 带的 90%」，变的只是带：
   v1.3（A500 5pp）→ 1 份 = 1pp；**v1.4（A500 2.5pp + 沪深300 2.5pp）→ 1 份 = 0.5pp**
   （`CFG["unit_pp"]`：A500 0.5、沪深300 0.5、纳指/标普/黄金 2.0）。
   旧权重（A500 10pp、美股 5pp）下同一比例恰好给出 2pp / 1pp，与文档 §9 的
   `unit_pct_equity` 完全一致 —— 这是一次**重标**，不是新规则。
   若你按权益账户记账（权益 50 视为 100），把报告里的 pp 数字统一 ×2。
2. **「仓位带是主锚」vs「阶梯填满带」**。阶梯份数只能把自己填到带的 90%，所以它只在
   「起点低于带」时起作用。实盘默认按**目标带起步**（= 实际持仓），此时阶梯的角色是
   「跌出来的加仓空间」；`--from-zero` 才是「规则自己从空仓建到带」的对照口径。
   两种起点在回测里都跑了（§4 前两行），差距就是现金拖累。
3. **null 闸门的语义**。§1 说「数据不足时该规则不执行」。本实现取「**不生效（不否决）**」，
   并把每条 null 的原因写进每日报告。想更保守（null 视为否决）把 `rule.NULL_GATE_BLOCKS = True`。
4. **美股 ERP 分位的来源**。§6 的定义是 `1/PE(TTM) − 10Y美债` 的分位，但本地**没有 NDX/SPX 的
   TTM PE 月度库**（只有 NDX 的 forward PE，会系统性抬高 ERP，不能顶替）。所以分位走
   `data/_val_inputs.json` 的 `ndx_erp_pct` / `spx_erp_pct`（人工月度复核），当前按文档 §6
   「当前状态读数」（erp 为负 → 分位 <30%）预填 `0.05` → **美股腿当前只减不加**。
5. **§7 的 ±5pp 是绝对阈值，带宽减半后会失效**。带 5pp 时，5pp 阈值等于允许漂到
   **2 倍带**才减持。故改为 `min(5pp, 带×50%)`（`rule.rebalance_pp()`）：
   中证A500/沪深300/科创50/恒生科技 **1.25pp**、美股/黄金 5pp。这是 v1.3 起对 §7 原文唯一的阈值改写
   （v1.4 拆腿后 A500 的阈值随之从 2.5pp 降到 1.25pp —— **改带宽必须同看阈值**，见 §5）。
6. **两条 A股宽基腿的闸门性质不同**（v1.4 新增的坑）。A500 的「不设限」是因为**没有数据**
   （PE 只到 2024-09，月度样本 25 个 < 36 门槛）；沪深300 的「不设限」是因为**数据说中间**
   （月度样本 136 个，分位 63% 落在 30~70）。两者行为当下相同、性质完全不同：前者补数据源
   就会改变行为，后者只能等分位跑到两端。

另外两处**主动裁定**：§7 的「回到目标位」默认**只做减持**（`rule.REBAL_BUY_BACK = False`）；
QDII 额度关闭时档位**顺延而非取消**（档位不消耗，恢复后补执行）。

结论（五条）：

1. **空仓起步版跑输**（2.15% vs 14.06%）：平均只投入 10.5/40pp —— 美股 20pp 的带被 ERP 闸门
   锁死、A股两条腿合计仍只有 5pp 能补。这一档只是「规则自己建仓」的对照，不是实盘用法。
2. **带内满仓起步版**（= 实盘用法）：年化 14.01% 与静态带 14.06% **基本打平（-0.06pp）**，
   回撤同为 -9.5%，**夏普 1.28 vs 1.26**。规则几乎不创造超额收益，它买的是
   「回撤略小 + 超配自动兑现 + 下跌有加仓路径」。
3. **美股闸门当前读数的机会成本 = +6.7pp/年**（2.15% vs 放开后 8.89%）。v1.3 把美股权重翻倍到
   20pp，这段美股长牛里该成本也随之放大（v1.2 是 +3.3pp）。这是文档 §6 的显式选择：宁可少赚，
   也不在 ERP 为负时加仓。
4. **单腿**：A500 阶梯双赢（5.60% vs 5.28%，回撤 **-30.9% vs -43.4%**，夏普 0.30 vs 0.19）——
   因为 1.25pp 的再平衡阈值让它涨上去就回带，没被填满；纳指/标普阶梯让渡约 **47% / 38%** 的年化，
   换回撤压缩约 **21% / 10%**，夏普仍低于一次性满仓（0.66 vs 0.79、0.59 vs 0.70）
   —— 阶梯买的是买点纪律与持仓心理，不是超额收益。
5. **新增的沪深300 腿是 A500 的镜像，不是独立证据**。15.7 年里阶梯 4.77% vs 满仓 4.16%、
   回撤 -30.9% vs -43.4%，形状与 A500 一模一样（2025-03 前两条腿的场外序列就是同一只 `000051`）。
   实盘意义是「同一笔 A股 5pp 额度分两个出口执行、各跑各的阶梯」，不是多出一份独立样本。

## 5. 已知局限（用之前必须知道）

- **桥接段不是本基金业绩**：A500（2025-03 前用 000051）、标普（2023-04 前用 050025）的早期段
  是同类老基金，只用于补齐 250 日窗口与回撤阶梯的 52 周高点。看单腿绝对收益时请只认拼接日之后。
  **沪深300 没有桥接**（000051 自己 2009-07 起就有净值），但反过来它是 A500 的桥接源 ——
  **2025-03-27 之前两条 A股宽基腿的净值逐值相同**，那一段的「两条腿」不是两份独立信息。
- **美股闸门是人工月度复核值**，不是自动分位（理由见 §3.1-④）。分位停在 0.05 就意味着美股腿
  一直不建仓 —— 每月复核 `data/_val_inputs.json` 是本策略的**例行动作**。
- **组合层只有 4.0 年样本**，且这段是「A股熊转牛 + 黄金大牛 + 港股深跌 + 美股长牛」的特定组合。
- **年线闸门是非对称的**：跌破要等 5 日才减半，收复当天就加满。围绕 MA250 的窄幅震荡会反复
  往返（样本内恒生科技 2025-12-30 卖、12-31 买）。进攻腿带减半到 2.5pp 后单笔金额小，
  但**摩擦占比反而更高**：累计手续费 0.18pp / 4 年（占起始净值 0.45%），换手 17pp/年。
- **小带宽腿靠再平衡阈值兜底，不是靠阶梯**：A500/沪深300 带 2.5pp，止损/回带几乎全靠
  `min(5pp, 带×50%) = 1.25pp` 这个阈值（单腿回撤 -30.9% vs 满仓 -43.4% 就是它的功劳）。
  若把阈值改回绝对 5pp，阶梯填满后它就退化成满仓，回撤会回到 -43%。**改带宽必须同看阈值。**
- **拆腿后 A股两条腿的档位会「各买各的」**：同一段下跌里 A500 可能已补到第 3 档、沪深300 还在
  第 2 档（两者的 52 周高点与 dd 不完全同步），合计仍可能把 5pp 用满 —— 这是设计意图，
  但报告里的「阶梯进度」要**两行一起看**，别看一行就以为 A股 只建了半仓。
- **两条 A股腿的费用档不同**：沪深300 走 A 类 `000051`（申购 0.10% / 赎回 0.50%），A500 走
  C 类 `023299`（申赎 0，年销售服务费 0.2% 量级）。阶梯一份只有 0.5pp，来回打脸时 0.5% 的赎回费
  占比不低；回测按这两档分别计入（变种 `FEE` 表），主策略引擎按 `rule` 里的同一档费率。
- **未计**：场外申赎确认时滞（QDII T+2）、大额限购、C 类销售服务费（0.2%/年量级）、
  以及桥接段的指数差异。净值口径已含汇率与跟踪误差（这是相对场内口径的改进）。
- **持仓状态是机械回放**：默认从目标带（= 实际持仓）回放到今天，不是你的真实成交记录；
  真实持仓与之不同时用 `--hold` 覆盖起点。
