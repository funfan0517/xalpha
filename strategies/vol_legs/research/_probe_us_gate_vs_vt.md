# v7（年线闸门）vs v9（波动率目标）：同一把尺子 + 32 年样本
> 由 `research/_probe_us_gate_vs_vt.py` 生成。池 = 纳指100 + 标普500，两腿等权 50/50；
> 长样本价格 = **指数收盘**（`.INX` 1990-01 起 / `.NDX` 1994-01 起，**不含分红**），信号与执行同一条序列；
> 空仓按 1.40% 逐日计息；T 收盘决策 → T+1 收盘成交 → T+2 起承担收益；成本按 `Σ|Δw|` 单边扣。
> 长样本区间 **1995-01-03 ~ 2026-11-04（31.8 年）**，两条腿窗口都已预热完毕。
> ⚠ **数据清洗**：雪球 `.NDX` 在 1994-01-03 从 796.56 跳到 395.53（−50.4%），是**指数重定基不是崩盘**（之后走势与真实纳指一致）。`_clean_break()` 把断点前整段丢弃，所以长样本从 1995 起 —— 不处理会在 1994 年凭空造出 −30% 回撤，把结论整段污染。

### 0.2 翻转的原因：2000-2002（两篇 README 都点名「样本没覆盖」的那一段）

**两台机器的失效模式正好互补，而且长样本把两边都验了一遍**：

1. **波动率目标永远减不到 0**：`w = min(1, 15%/vol)`，就算 vol 冲到 80% 也还有 19% 仓位。2000-2002 是**持续 31 个月、边跌边反弹**的空头市场（不是一次急跌）：静态同期 -68.26%，v9 只修到 -34.77%、窗口回撤 -42.11%，是全部防守档里最差的一档。
2. **年线闸门有两个月的盲窗**：纳指 2000-03-27 见顶，闸门要等 5 月底「连续 2 个月在年线下」才走，那两个月指数已经跌掉一大截 —— 纯闸门（B3）的**全样本最大回撤就发生在这一段**：2000-03-27 → 2000-05-23，-30.09%。加上波动层后这一段被摊薄（v7 默认的全样本最大回撤挪到了 2008：2007-10-31 → 2009-03-09，-21.85%）——因为 2000 年 3 月末纳指 vol20 已经 **48.9%**（4 月末 86%），`20%/vol` 当场把仓位压到 4 成。

**这就是 v7「闸门 + 波动层」两层结构的独立证据**：v7 自己的 README 是用 2012-2026 的 2020/2022 论证的，而 2000-2002 这段**没有参与任何参数标定**的样本给出了同一个结论 —— 两层各修对方的洞，缺一层就漏。

> **v7 骨架上，TV 是一根「回撤刻度」而不是「收益旋钮」，而夏普有个很浅的甜点**：TV 关闭 → +14.84% / -30.09% / 夏普 0.75；TV20% → +12.90% / -21.85% / 夏普 0.77；TV25% → +13.88% / -24.60% / 夏普 0.78。**年化与回撤同步上升**（TV 越低仓位越保守），夏普从 0.75 抬到 0.77~0.78 就平了。所以「TV20% 是不是选对了」的答案是：**在长样本上它落在夏普甜点附近，同时把回撤从 -30.09% 压到 -21.85%** —— 2012+ 的 QDII 口径（最后一列）给出的是同一方向，两根独立样本没有打架。
> **v9 骨架就完全不同**：它没有闸门，TV 是唯一的刹车，于是 TV 越低回撤越浅、但 TV 一高（≥30%）回撤就冲到 −60% 以上 —— 那里根本不存在「甜点」，只有「你敢不敢一直满仓」这一个问题。**这就是「有闸门 vs 没闸门」的差别。**

### 0.4 两个「没测过」的新候选

- **C1 = 把 v9 的月中补丁装到 v7 的骨架上（闸门 × TV20 + 快减/快补）**：+12.91% / -23.21% / 夏普 0.79，相对 v7 默认：年化 +0.01%、夏普 +0.02、回撤深 1.36pp。分窗口看是**教科书式的交换**（正 = C1 比 v7 默认好）：2020 窗口 +5.02%、2000-2002 +3.30%（赚），2008 +0.03%（基本打平）、2022 -0.22%（赔）。**它值得装，但只值 0.02 夏普** —— 与 v9 自己的结论（n=1、尾部保险）完全一致。
- **C2 = 12 个月绝对动量 × TV20（TSMOM）**：+12.00% / -27.14% / 夏普 0.70，**没打过 MA200**（+12.90% / -21.85% / 夏普 0.77）。原因是时间戳：纳指 2000-03 见顶，MA200 + 2 月确认 5 月底就走人，12 个月动量要等到价格跌破一年前（2000 年底）—— 晚了大半年，2000-2002 窗口收益 -20.24% vs -13.86%。**所以「MA200 是运气吗」：不是。样本外它比教科书的 TSMOM 更适合这个标的。**

### 0.5 给「做美股」的结论

1. **骨架选 v7，不选 v9。** 决定性证据是 2000-2002 的窗口回撤：v9 -42.11%、v7 -21.14%（静态 -75.43%）。买美股要防的正是这种「跌三年 + 反复反弹」的行情，而波动率目标在结构上只能按比例减、减不到底。
2. **v9 不是没用，它的主场是急性行情**：2020 窗口 v9 +8.80% vs v7 +2.93%、2022 窗口 v9 -17.48% vs v7 -11.82%。**它更适合做「短促急跌」的那条腿**（比如给已有的 v7 仓位套一层），而不是单独当美股主策略。
3. **通道决定成本结论**：场外 QDII A 类（单边 0.6%）上 v7 调仓 70 次、v9 249 次，落地年化 +12.49% vs +12.16%（v7 领先 0.34pp）；场内 ETF / 0.03% 通道上两者打平（+13.17% vs +13.13%）。**做场外 QDII 的，v7 的成本结构赢；做场内低费通道的，v9 的浅回撤才付得起。**
4. **波动层保留（TV20~25%）**：长样本上它是「回撤刻度」，把最大回撤从 -30.09% 压到 -21.85%，代价是年化 1.93pp，夏普基本不变（0.75 → 0.77）。**上一版（纯闸门）不差，但要接受 2000 年那种 -30.09% 的两月盲窗。**
5. **要更聪明的，只有 C1 一条（加月中补丁）**；TSMOM 替代 MA200 是退步。而且 C1 的收益与 v7 默认一模一样（+12.91% vs +12.90%），换来的只是 2020 那一次少赔 5pp —— **愿意为尾部多付 48 次调仓（187 → 235）就装，不愿意就不装。**

## 8. 读法与边界

1. **「哪个更适合美股」必须拆成两个问题**：①骨架用趋势还是波动 —— 长样本 31 年给出「趋势」；②在趋势骨架上要不要波动层 —— 长样本与 2012+ 都说「要」，它压的是 2000 年那种「闸门两个月盲窗」的回撤。**两个问题的答案方向一致，不冲突。**
2. **1987 不在样本里**（`.INX` 1990 起）、**1985-1993 也不在**（`.NDX` 1994 年那次重定基把前段废掉了）。2000-2002 与 2008 在 —— 这是相对两篇 README 的唯一实质证据增量。
3. **不含分红 / 汇率 / 溢价**：长样本是「机制口径」，不是收益预期。场外实盘还要再扣 QDII 跟踪误差与通道时滞（v7 的月末成交比 v9 的次日成交更容易落地，这一点在 0.5 的成本表里只体现了费率、没体现时滞）。
4. **v9 的 2.0% 空仓计息没有沿用**：本表统一 1.4%（见 v9 README §5：2.0% → 1.4% 的差别是 0.07pp 年化，可忽略）。
5. **不做网格搜索、不挑参数**：v7/v9 默认参数一行未改；两个新候选（C1 混血、C2 TSMOM）在跑之前写死；§6 是邻域扰动而非择优。
6. **v7 的 TV20 在长样本上没有被打脸**：夏普 0.75（关闭）→ 0.77（TV20）→ 0.78（TV25），回撤 −30.09% → −21.85% → −24.60%。**用户 2026-11-05 选定的 TV20 落在甜点附近，往上挪到 25% 也说得过去，往下（12~15%）才开始明显付年化。**
7. **本报告不能回答的**：下一次危机的形态。v7 的两层分别对应「慢熊」与「高波动急跌」，如果下一次是「低波动阴跌 + 无反弹」（日本 1990 式），两层都会偏慢 —— 长样本里的 2000-2002 已经是最接近的样本，但它仍然有剧烈反弹。
