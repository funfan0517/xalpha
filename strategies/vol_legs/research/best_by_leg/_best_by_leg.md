## 3. 口径与维护

1. **净值口径分两类**：V1 / V2 / V3 / V4 / V5 / V6 / 主策略 = **场外复权净值**（含分红再投与汇率，是账户上能拿到的收益）；V13 = **场内 ETF 量价**（信号更纯，但要扣场内佣金与溢价）。跨这两类比较时先看「费率口径」列。
2. **费率一律取含费**：V1 / V2 / V3 的产物把零费当主列（`ann` / `sharpe`）、含费放在 `ann_fee` / `sharpe_fee`，本清单**取含费**（A 类腿 0.10% 买 + 0.50% 卖）；V5 / V6 / V7~V10 / V13 / 主策略的默认口径本身含费；V4 含月末回锚费用。差异极大，别忽略：沪深300 腿上 V1 MA20 零费 +4.23% → 含费 **-4.28%**（一年 235 笔，成本吃光全部超额）。
3. **样本必须看**：`规则信号用全历史算、统计窗口另截` 是仓库惯例，各行 `start`/`end` 差异很大（科创50/恒生科技只有 4~5 年，A500/沪深300 有 16~17 年）。年化差 ±3pp 内属抽样噪声。
4. **A500 与沪深300 不是两份独立证据**：2025-03-27 之前两条腿的场外序列同源自 `000051`，这两年半里它们的成交日、回撤、档位完全一致（见 `README.md` §2.3）。
5. **维护方式**：某变种重跑回测 → 重跑本脚本 → 清单自动更新。新增变种时只需在 `_best_by_leg.py` 的 `collect()` 里加一个适配器（取它的 `backtest/_*_bt.jsonl` 并筛出默认口径那一行），同时在本文件 §2 说明它是否参与排序。
6. **每日流程里的位置**：本清单是**横向决策参考**，不是每日信号。每日动作仍由 `run_daily_vol_legs.ps1` 产出（主策略七腿 + 变种层 v2/v3/v4/v6/v9）。
