## 3. 口径与维护

1. **价格口径分三组**：V1 / V2 / V3 / V7~V10 / V12 / V13 / 主策略 = 真实指数（六条指数腿走真实指数，黄金走场内 518880）；V4 / V6 = 各自固定口径（V4 沪深300 指数 × ERP，V6 场内 518880）。跨口径比较时先看「费率口径」列，别把两组的年化直接相减。
2. **费率一律取含费**：V1 / V2 / V3 的产物把零费当主列（`ann` / `sharpe`）、含费放在 `ann_fee` / `sharpe_fee`，本清单**取含费**（A 类腿 0.10% 买 + 0.50% 卖）；V6 / V7~V12 / V13 / 主策略的默认口径本身含费；V4 含月末回锚费用。差异极大，别忽略：A 类腿一年 12~15 笔、单笔往返 0.6%，一年就吃掉 7~9pp，能把跑赢买入持有的腿直接打成负的（逐腿「年化拖累」见 v1 报告的「成本」表）。**但「都含费」≠「费率相同」**：V13 单边 5bp、V7~V10 单边 10bp、A 类往返 60bp、黄金场内佣金+滑点约 16bp 往返。2026-11-17 复核（换手线性外推、夏普 ∝（年化−货基）/波动）：**七条腿里只有标普500 的第一名对费率敏感** —— V13 在自身 5bp 下 0.590，按 10bp 重算 0.578，仍高于 V9 的 0.529 / V7 的 0.529；但按 A 类往返 60bp 外推只剩 ≈0.46，与 V7 的 0.45~0.49 落在同一档 —— **这一格在真收费口径下不值得挑**（V13 赚的就是低换手）。其余六条腿的第一名与第二名的差距都 ≥0.05 且第一名本身不是 5bp 口径（黄金的 V13 只排第 2），所以费率口径改不了它们的结论。
3. **样本必须看**：`规则信号用全历史算、统计窗口另截` 是仓库惯例，各行 `start`/`end` 差异很大（科创50/恒生科技约 5~6 年，A500/沪深300/美股约 20~22 年，黄金约 12 年；V12 的科创50/恒生科技自 2021 起、黄金自 2014-09 起，与 V13 同量级）。年化差 ±3pp 内属抽样噪声；V13 普遍晚入市约 1 年，避开 2005~2006 段，跨策略夏普不宜当作同窗口精确对账。
4. **A500 与沪深300 不是两份独立证据**：现在是两条独立指数序列（`SH000510` vs `SH000300`，无桥接段），但成分重叠约八成、结论高度相关，别当成两个互不相干的市场来加总（见 `README.md` §2.1）。
5. **维护方式**：某变种重跑回测 → 重跑本脚本 → 清单自动更新（含 §0 前三名）。新增变种时只需在 `_best_by_leg.py` 的 `collect()` 里加一个适配器（取它的 `backtest/_*_bt.jsonl` 并筛出默认口径那一行；非执行腿给 `layer="诊断"`），同时在本文件 §2 说明它是否参与排序。
6. **名次会随产物变动**：排名按夏普，样本/费率一改就可能换位（±0.05 夏普内的差别等于噪声）。要机读就把 `_best_by_leg.jsonl` 的 `rank` 字段当索引用，别在别处硬写策略名。
