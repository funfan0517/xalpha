# V10 变种 · 美股两腿纯波动层（日频 · 无方向 · 连续仓位）

`vol_legs`（波动资产操作规则 v1.4）的**第十个变种**，2026-11-05 落地。

- **标的池只有两条腿**：纳指100（`270042`）+ 标普500（`017641`/`050025` 桥接）；
  **两条腿各算各的波动率**（这就是「自适应」的字面含义）。
- 规则权威源：`vol_layer.py` 顶部常量（`params()` 打包）。
- 一句话：**仓位 = `min(1, 20% / vol20)`，没有方向判断 —— 永远做多，只按波动决定露多少。**

> 它来自一个反直觉的实测结果（`v8_golden_cross/research/_probe_vol_layer.md`）：
> 在 v8 金叉之上加波动层（夏普 0.73）**反而打不过「只有波动层、没有方向门」**（夏普 0.85）。
> 既然方向门在短样本里是净扣分项，就把它单独做成一支，让「纯风险预算能做到多少」可被独立检验。

## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 方向判断 | **没有** |
| 仓位 | `min(1, TV / vol20)`，TV = **20%** |
| 波动率 | `vol20` = 20 日收益标准差 × √252，**每条腿各算各的** |
| 死区 | `|Δ仓位| < 10pp` 不动手 |
| 看盘频率 | **每日收盘**（月末档作对照） |
| 成交 | `t` 日收盘决策 → **`t+1` 收盘成交** → 新仓位自 `t+2` 起承担收益 |
| 上限 / 下限 | 100% / 0%（不加杠杆） |
| 空仓 | 未投部分按货基 `rule.CASH_ANNUAL`（1.40%）逐日计息 |
| 成本 | 单边 **0.1%**（文档主口径）；0.6% 场外现实口径见 §4 |

**「自适应」= 仓位随本腿实时波动率自适应，不是目标自适应。** v8 的专项实测给了三组反面证据：
目标随长期波动漂移（TV ∝ vol250/中位）最多与常数 TV 打平且换手更高；分位五档明显更差（夏普 0.50）；
估计子（max(20,60)/blend/EWMA）也都不如纯 vol20。**所以 TV 写死 20%，不引入任何会漂移的锚。**

## 2. 与 v7 / v8 / v9 的分工（四支别混）

| | `v7_us_gate` | `v8_golden_cross` | `v9_vol_target` | **`v10_vol_layer`（本变种）** |
|---|---|---|---|---|
| 方向判断 | 有（价格 vs MA200） | 有（MA50/MA200） | 无 | **无** |
| 仓位 | 二元 × 波动层 | 二元 × 波动层 | 连续 0~100% | **连续 0~100%** |
| 决策频率 | 月末（+2 月确认） | 日频 | 月末 + 月中补丁 | **日频** |
| 调仓（14.2 年） | 70 | 132 | 249 | **157** |
| 定位 | 回撤优先 | 对照组（带方向） | 低频风险预算 | **纯风险预算（高频）** |

**v10 与 v9 是同一件事的两个速度**：都不猜方向、都只按波动缩放。差别只在频率与换手 ——
v9 月末定仓（一年 18 次），v10 日频重算（一年 11 次，死区挡掉了大部分微调）。

**三条要点**：

1. **它是四支里年化最高、夏普第二的**（+13.51% / 0.85），而且**唯一一支不需要任何方向判断**。
   对买入持有的夏普优势是 **+0.07**（0.85 vs 0.78），代价是年化 −1.64pp —— 典型的「用收益换平滑」。
2. **它和 v7 / v9 打平在夏普（0.85 vs 0.86 / 0.88），但路径不同**：v7/v9 的月末制让它
   回撤·月末只有 −11 ~ −13%，v10 因为日频重算、月度采样时又撞上月中低点，月末口径反而 −16.64%。
   **别用月末口径比较它** —— 它是日频策略，日频回撤 −18.78% 才是它的真实体验。
3. **风险预算贡献了绝大部分，方向判断贡献很小**：v8（方向 + 波动层）0.73 < v10（只波动层）0.85。
   **在这段样本里，猜方向是负贡献。** 这不是说方向永远没用（见 §6），而是说
   **如果你要选一个「不加方向判断」的方案，这一支是它的完整实现**。

## 4. 参数敏感性（组合层 · 只改一格）

| 档位 | 年化 | 回撤·日频 | Calmar(月末) | 夏普 | 平均仓位 | 调仓 |
|---|---:|---:|---:|---:|---:|---:|
| **基准（TV20 · vol20 · 死区 10pp）** | +13.51% | −18.78% | 0.81 | 0.85 | 92% | 157 |
| TV 12% / 15% / 18% / 22% / 25% | +10.86% / +12.40% / +13.21% / +13.83% / +14.13% | −13.54% / −15.99% / −17.65% / −19.44% / −21.26% | 1.11 / 0.98 / 0.90 / 0.79 / 0.75 | 0.84 / 0.87 / 0.86 / 0.84 / 0.83 | 79~95% | 439 / 288 / 207 / 134 / 96 |
| vol10 / vol60 | +12.82% / +12.94% | −20.30% / −20.69% | 0.70 / 0.74 | 0.81 / 0.78 | 92% / 91% | 314 / 68 |
| 死区 0 / 5 / 20pp | +13.67% / +13.66% / +13.56% | −18.88% / −18.89% / −18.99% | 0.81 / 0.81 / 0.78 | 0.85 / 0.85 / 0.84 | 92~94% | 1576 / 337 / 66 |
| 仓位下限 25% / 50% | +13.60% / +13.88% | −18.78% / −20.70% | 0.82 / 0.83 | 0.85 / 0.85 | 92% / 93% | 155 / 145 |
| 成本 0.03% / 0.60% | +13.58% / +13.03% | −18.73% / −19.13% | 0.82 / 0.76 | 0.85 / 0.81 | 92% | 157 |
| 现金 0% / 2.0% | +13.39% / +13.56% | −18.90% / −18.73% | 0.80 / 0.82 | 0.84 / 0.85 | 92% | 157 |
| 人民币净值信号 | +13.83% | −19.50% | 0.78 | 0.84 | 94% | 147 |

- **TV 是「要多平」的旋钮**（12%→25% 单调平移，夏普 0.83~0.87 一条平带，没有尖峰）。
  12% 那份看起来 Calmar 最高（1.11），但年化只有 +10.86%、调仓 439 次 —— **别只看 Calmar**。
- **死区是「要多省」的旋钮**：0 → 1576 次、10pp → 157 次、20pp → 66 次，收益几乎不动。
  **10pp 是性价比拐点**（0 到 10 省了 90% 的换手，年化只差 0.16pp）。
- **vol10 太快、vol60 太慢**（0.81 / 0.78），20 日居中最好 —— 与 v7 同一条经验。
- **成本敏感度是软肋**：0.03%→0.6% 掉 0.55pp（一年 11 次调仓，v7 只有 5 次）。
- **人民币净值信号反而更好 0.32pp** —— 说明这一支对信号源细节不敏感（它只取波动、不取方向）；
  用美元指数的理由是**可复核、无时滞**，不是收益更高。

## 5. 压力窗口与逐年

| 窗口 | 本变种 收益 | 静态 收益 | 本变种 回撤 | 静态 回撤 |
|---|---:|---:|---:|---:|
| 2018Q4 急跌 | −12.01% | −14.65% | **−15.84%** | −19.10% |
| 2020 疫情 | +3.26% | +9.87% | **−18.15%** | −28.17% |
| 2022 加息熊市 | −16.12% | −19.63% | **−18.41%** | −23.21% |
| 2025 至今年内 | +13.84% | +20.76% | **−17.24%** | −19.37% |

- **2020 是它的主场**：回撤 −28.17% → −18.15%，靠的是「波动率 5 天爆表 → 仓位自动降」，
  **不需要任何人判断方向**。但注意该窗口收益仍低于静态（+3.26% vs +9.87%）——
  **它救的是回撤，不是收益**。
- **代价年集中在牛市**：2019（−4.38pp）、2020（−8.23pp）、2025（−6.29pp）持续少赚。保险费，不是 bug。
- 挣钱的年份是 2022（+3.52pp）、2018（+0.44pp）—— 全部是熊市年。

## 6. 边界（先读，再信数字）

1. **没有任何方向保护，这是设计而不是缺陷**：它回答的是「把方向判断全部拿掉，只靠风险预算能做到什么」。
2. **治急跌、不治慢熊**：阴跌段波动率会回落到 20% 以下，仓位就回到满仓。
   2000-2002（纳指 −83%）与 2008 不在样本内（QDII 净值 2012 起）—— **这部分全是外推**。
   这也是它和 v7 的根本差别：v7 有「价格跌破年线」这条独立信息，v10 没有。
3. **月末回撤口径对它不利**：日频 −18.78% vs 月末 −16.64%，差距小于其他变种，
   但它月度采样常撞在月中低点（2020-03、2022-10），**跨策略比较时看日频那一列**。
4. **换手不低**：157 次 / 14.2 年 ≈ 一年 11 次，0.6% 场外口径掉 0.55pp。怕摩擦就调宽死区或用 v9。
5. **两条腿仓位可以不同**（纳指 90% / 标普 95% 均值，最低 23% / 29%）——
   别把它当成「一个组合一个仓位」的策略。
6. **不做参数搜索**：TV=20% 借自 v7/v8 默认，§4 给了 19 档邻域。

| 检查 | 结果 |
|---|---|
| 恒满（下限 100%）净值 == 买入持有（零费） | ✅ |
| 仓位 ∈ [下限, 100%]（不加杠杆、不穿透下限） | ✅ |

| **缩仓日恒有 仓位 × vol20 == TV**，误差 < 1e-9 | ✅ |
