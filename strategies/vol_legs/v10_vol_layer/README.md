# V10 变种 · 全七腿 ER 自适应波动层（日频 · 无涨跌方向 · 连续仓位）

> 2026-11-17 标的池由 ndx/spx 两腿扩为 **rule.LEG_ORDER 全七腿**（中证A500 / 沪深300 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金）。
> **同日按用户指定，把 `ER20/10 + 10pp 幅度死区 + 5 日时间死区`（`_probe_er_adaptive_7legs.md` 的 D 方案）设为默认策略**；固定 TV20 降为 `ADAPTIVE=False` 对照档。
> **本变种只做分腿回测，不做组合回测**：没有跨腿等权净值、没有 v7/v8/v9 组合对照。当前读数一律以 `backtest/_v10_vol_layer_bt.md` 的分腿表为准。

`vol_legs`（波动资产操作规则 v1.4）的**第十个变种**，2026-11-05 落地。

- **两层自适应**：①仓位随本腿 `vol20` 变；②TV 随 ER(20) 趋势纯度在 20%/10% 间切换。
- 规则权威源：`vol_layer.py` 顶部常量（`params()` 打包）。
- 一句话：**仓位 = `min(1, TV(ER) / vol20)`；趋势干脆 TV20、来回磨 TV10；不判涨跌，只决定露多少。**

## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 涨跌方向 | **没有** —— ER 只判路径效率，不判多空 |
| 风险预算 TV | ER(20) ≥ **0.40** → 趋势态 **20%**；≤ **0.30** → 震荡态 **10%**；中间维持（滞回） |
| 仓位 | `min(1, TV(ER) / vol20)` |
| 波动率 | `vol20` = 20 日收益标准差 × √252，**每条腿各算各的** |
| 死区 | 幅度 `|Δ仓位| < 10pp` 不动手；时间距上次调仓 < **5 交易日**不动手（默认 D 档） |
| 看盘频率 | **每日收盘**（月末档作对照） |
| 成交 | `t` 日收盘决策 → **`t+1` 收盘成交** → 新仓位自 `t+2` 起承担收益 |
| 上限 / 下限 | 100% / 0%（不加杠杆） |
| 空仓 | 未投部分按货基 `rule.CASH_ANNUAL`（1.40%）逐日计息 |
| 成本 | 单边 **0.1%**（文档主口径）；0.6% 场外现实口径见分腿表 |

## 2. 自适应研究：从全部腿找规律

早期 `probe_adaptive/_v10_adaptive_tv.md` / `probe_vol_anchor/_v10_vol_anchored_tv.md` / `probe_er/_v10_er_adaptive_tv.md` 只测 ndx/spx 两腿，属于沿革探索；**结论不能只靠两条腿下**。全腿证据在：

- `research/probe_er/_v10_er_adaptive_7legs.md`（7 腿 × ER × 抑制调仓）—— **默认档来源**
- `research/probe_vol_anchor/_v10_vol_anchor_7legs.md`（7 腿 × 波动锚反相 × 抑制调仓）
- `research/probe_adaptive/_v10_adaptive_universe.md`（7 腿 × 状态变量 × k 幅度 0~2）

从全腿表现得到的规律：

1. **跨腿证据最强的是 ER**（6/7 腿严格过线，含强基线腿纳指）；D 档（+5 日死区）在纳指后段 0.95、A500 0.58、科创50 0.12，且比原生少 10~15% 调仓。
2. **波动锚正相自我抵消**：波动高→TV 高使分子分母同步放大，仓位≈常数；反相只有 **3/7 过线**（标普500、科创50、恒生科技），A500 / 沪深300 / 纳指 / 黄金均未过线。
3. **ER 反相全线垫底**；ER 必须正相（趋势干脆→TV20、来回磨→TV10），**黄金完全不需要自适应**（固定 TV10 基线 0.76/后段 1.45，所有方案均未过线）。
4. **k 幅度符号因市场而异**：全幅 0~2 在美股是灾难、在 A 股三腿反而最优——**不存在通吃 7 腿的幅度**。
5. **代价是调仓**：纳指 ER 原生 496 次 vs 固定 TV20 的 163 次；0.6% 场外口径下多出的调仓会吃掉优势。

> 探针原本身只给结论、未改代码；**2026-11-17 按用户指定把 ER-D 升为默认**，固定 TV20 保留为对照档。

## 4. 已知边界

1. **没有涨跌方向判断，但有 ER 趋势状态门**：ER 只判路径效率；慢熊里会切 TV10% 档，比原纯波动层好，但仍不是价格方向门。
2. **治急跌，慢熊只缓解不免疫**：阴跌段 vol 会回落，但 ER 转震荡态后 TV=10%，仓位不会回到满仓；2000-2002 不在样本内，是外推；2008 在样本内但不是慢熊。
3. **日频换手不低**：默认 D 档已用 5 日时间死区压过一轮，但仍高于固定 TV20；场外 0.6% 口径的拖累见回测对应档。怕摩擦就调宽幅度死区、关掉 ER 或改用 v9。
4. **各腿独立**：每条腿各算各的 ER、波动、仓位与最低仓位；不存在「一个组合一个仓位」。
5. **默认档来自全腿研究**：`research/probe_er/_v10_er_adaptive_7legs.md` 的 D 方案；回测表给了 12 档逐腿邻域（含 5/10/20pp 幅度、0/5/10 日时间、固定 TV20/TV10 对照）。
