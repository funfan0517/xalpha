## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 涨跌方向 | **没有** —— ER 只判趋势纯度，不判多空 |
| 风险预算 TV | ER(20) ≥ 0.40 → 趋势态 20%；≤ 0.30 → 震荡态 10%；中间维持（滞回） |
| 仓位 | `min(1, TV(ER) / vol20)`，趋势态 20% / 震荡态 10% |
| 波动率 | 20 日收益标准差 × √252，**每条腿各算各的** |
| 死区 | 幅度 `|Δ仓位| < 10%` 且距上次调仓 < 5 日不动手 |
| 看盘频率 | **每日收盘**（月末档作对照） |
| 成交 | 信号日收盘决策 → **次一交易日收盘成交** → 收益自 T+2 起 |
| 上限 / 下限 | 100% / 0%（不加杠杆） |

> **两层自适应**：①仓位随本腿 `vol20` 变；②TV 随 ER(20) 趋势纯度在 20%/10% 间切换。全腿证据见 `research/probe_er/_v10_er_adaptive_7legs.md`：ER 在 6/7 腿严格过线（黄金不过），D 档在纳指后段 0.95、A500 0.58、科创50 0.12，且比原生少 10~15% 调仓。

> 第 5 条（`仓位 × vol20 == TV(ER)`）是这一支的**定义式断言**：波动层实现正确时，缩仓日必须满足当日 TV 状态（趋势态 20% / 震荡态 10%）。原「组合恒满 == 等权复利」「两腿与 v8 探针逐位对齐」两条属于组合层，已随组合回测一并移除。

## 4. 口径与已知边界

1. **没有涨跌方向判断，但有趋势状态门**：ER 只判路径效率（趋势干脆/来回磨），不判多空；默认档会在震荡态把 TV 压到 10%。逐腿读数见 §2。
2. **治急跌，慢熊只缓解不免疫**：阴跌段 vol 会回落，但 ER 转震荡态后 TV=10%，仓位不会回到满仓；这比原纯波动层好，但仍不是价格方向门。2000-2002 不在样本内（外推），2008 在样本内但不是慢熊。
3. **日频换手不低**：默认 D 档已用 5 日时间死区压过一轮；逐腿调仓次数见 §2，场外 0.6% 口径拖累见对应档位。怕摩擦就调宽幅度死区、关掉 ER 或改用 v9。
4. **各腿独立**：每条腿各算各的 ER、波动、仓位与最低仓位；不存在「一个组合一个仓位」。
5. **默认档来自全腿研究**：`research/probe_er/_v10_er_adaptive_7legs.md` 的 D 方案；§2 给了 12 档逐腿邻域（含 5/10/20pp 幅度、0/5/10 日时间、固定 TV20/TV10 对照）。
