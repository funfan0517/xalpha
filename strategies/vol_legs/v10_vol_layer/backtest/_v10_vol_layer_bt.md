# 波动资产 · V10 变种：美股两腿纯波动层（日频 · 无方向 · 连续仓位）
> 池 = **只有纳指100 与标普500**（`vol_layer.POOL`），与 v7 / v8 / v9 同池。
> 信号 = **美元指数**（`.NDX` / `.INX`）收盘；执行 = 场外 QDII **人民币复权净值**；空仓按货基 1.40% 计息 · 单边成本 0.1%。
> 规则权威源 `v10_vol_layer/vol_layer.py` 顶部常量。

## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 方向判断 | **没有** —— 永远做多，只决定露多少 |
| 仓位 | `min(1, TV / vol20)`，TV = 20% |
| 波动率 | 20 日收益标准差 × √252，**纳指与标普各算各的** |
| 死区 | `|Δ仓位| < 10%` 不动手 |
| 看盘频率 | **每日收盘**（月末档作对照） |
| 成交 | 信号日收盘决策 → **次一交易日收盘成交** → 收益自 T+2 起 |
| 上限 / 下限 | 100% / 0%（不加杠杆） |

> **「自适应」= 仓位随本腿实时波动率自适应**，不是目标自适应。`v8_golden_cross/research/_probe_vol_layer.md` 实测：目标随长期波动漂移最多与常数 TV 打平且换手更高；分位五档明显更差（夏普 0.50）。**所以 TV 写死 20%，不漂移。**

## 8. 口径与已知边界

1. **没有方向判断，这是设计而不是缺陷**：它的职责是回答「把方向判断全部拿掉，只靠风险预算能做到什么」。答案是：**这段样本里 0.85 夏普，高于买入持有 0.78，也高于加了金叉门的 v8（0.73）**。
2. **治急跌、不治慢熊**：阴跌段波动率会回落，仓位回到满仓。2000-2002 与 2008 不在样本内（QDII 净值 2012 起），**这部分是外推**。
3. **日频换手较高**：157 次 / 14.2 年 ≈ 一年 11.0 次。场外 0.6% 口径下年化再掉约 0.6pp，怕摩擦就调宽死区或改用 v9（月末制）。
4. **两条腿各算各的波动**：纳指与标普的仓位可以不同（这是「自适应」的字面含义）——回测里两腿的调仓次数、最低仓位也确实不同，别把它当成「一个组合一个仓位」的策略。
5. **不做参数搜索**：TV=20% 借自 v7/v8 的默认值，§4 给了 19 档邻域。
