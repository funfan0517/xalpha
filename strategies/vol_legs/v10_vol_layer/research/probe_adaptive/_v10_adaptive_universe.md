# V10 自适应策略全景：公式推导 + 新状态 + k 幅度 0~2（实测）

> 2026-11-16 生成。只研究、不改生产代码。TV0 = 20%（基准 k=1）；成本 0.1%、空仓 1.40%、vol20 + 死区 10pp + T+1、预热 300、后段 40%。

## 0. 波动层公式：到底有几个旋钮

`仓位 = min(1, k · TV0 / vol20)`。能自适应的只有三处：

| 旋钮 | 已有研究 | 结论 |
|---|---|---|
| vol 估计子（10/60/max/blend/EWMA） | v8 `_probe_vol_layer.md` §3 | 全不赢纯 vol20，「窗口别太长别太短」只是别选错 |
| TV0 随长期波动漂移（∝vol250） | v8 §4 / `../probe_vol_anchor/_v10_vol_anchored_tv.md` | 正相自我抵消、反相才有效；最多打平且更贵 |
| **风险预算倍率 k（本探针）** | 之前三种自适应都在切 k，但幅度锁在 [0.5,1] | 扫幅度 + 新状态 |

> **k 的含义**：k=1 → TV20 基准；k=0.5 → TV10（半仓目标）；k=0 → 完全空仓；k=2 → TV40（vol<40% 时几乎满仓）。所以 k 是「风险预算倍率」，不是收益目标——调 k 就是调愿意为这条腿注多少风险。

> 之前三种自适应（趋势方向 / 波动锚 / ER 纯度）本质都是「用状态把 k 切成两档」，只是状态变量不同，k 的上下界一直是 0.5/1。本探针新增 4 种状态变量，并把 k 幅度从 [0.5,1] 打开到含 [0,2] 的六档。

## 1. 方法

- 状态变量（True=好状态→k_hi）：ER 趋势纯度（已有）/ 回撤深度（浅为好，**新**）/ vol 变化率（下降为好，**新**）/ 距年线距离（**新**）。
- k 幅度：窄 .75-1.25 / 现有 .5-1 / 中幅 .5-1.5 / **全幅 0-2** / 熊市空仓 0-1 / 只高倍 1-2。
- 固定基线 = 常数 k=0.5（TV10）与 k=1（TV20）；严格判定 = 后段夏普赢两者、全样本 ≥ 两者最大值。

## 4. 结论

- **纳指100严格赢 2 个**：ER趋势纯度×现有 .5-1 (TV10/20)、ER趋势纯度×中幅 .5-1.5。
- **标普500严格赢 2 个**：距年线×窄幅 .75-1.25、距年线×现有 .5-1 (TV10/20)。
### 1. 用户要的全幅 0-2：美股失败、A股反而是最优 —— 这是本探针最重要的发现

- **美股两腿上全幅 0-2 是灾难**：纳指全样本 **0.40** / 后段 0.52（基线 0.75/0.81）、标普 **0.19 / 0.08**（基线 0.50/0.60），所有状态变量配全幅都垫底。原因在公式里：k=0 → 坏状态**完全空仓**，而 ER 趋势态只占 24%、误判多，一次误判就踏空整段上涨；k=2 → 好状态 TV40%，`min(1, 0.4/vol20)` 在 vol<40% 时恒为 1，**把波动层的平滑作用抵消掉**。两头一叠加，等于「该平的没平、该在的没在」。
- **但 A股三腿上全幅 0-2 反而最好**：A500 全样本 0.62 / 后段 0.22、沪深300 0.66 / 0.29、恒生科技 0.08 / 0.45（基线恒科还是负的）。这三条腿年化低、波动大、回撤深，「坏状态完全空仓」从踏空变成**保护**——同样的 k 幅度在不同风险特征的市场里符号相反。
- **原理结论：k 的合理幅度不是一个数，它取决于那条腿的「踏空成本 vs 挨跌成本」**。美股是长牛、踏空成本极高 → k 下界不能到 0，上界不必到 2；A股是震荡市、挨跌成本极高 → k 放到 0-2 反而对。**所以不存在一套通吃 7 腿的 k 幅度**，必须逐腿定。

### 2. 新增的四种状态：只有一个真正过线

- **距年线（新）在标普上过线**：窄幅 .75-1.25 = 全 0.52/后 0.65、现有 .5-1 = 全 0.52/后 0.64，都严格赢两个固定档，**且调仓只有 184/206 次**（波动锚方案要 400+）。它不是新 TV 值，是「站上年线给足预算、跌破收一点」的连续版择时——和 `_v10_adaptive_tv.md` 的 MA200 两档同源，但窄幅让调仓大降。
- **回撤深度（新）设计意图最好、实测没过线**：它是唯一针对「慢熊」的状态（深回撤降 k，补 V10 原生只治急跌的洞），但纳指 0.71/0.77、标普 0.46/0.53 都没赢基线——**等回撤已经发生再降 k 太晚**，和均线一样滞后，慢熊里 vol 早已回落、仓位本来就回来了。
- **vol 变化率（新）没过线**：纳指 0.71/0.75、标普 0.47/0.63。它和波动锚重复计价——波动锚用 vol 水平分位、它用 vol 的一阶导数，在美股上都没带来新信息，只多出调仓（纳指 573 次）。

### 3. 与前三种自适应合起来看

- 纳指仍是 **ER 趋势纯度** 独占（现有档 0.79/0.87、中幅 0.75/0.81 过线）；标普扩为 **距年线**（本探针）与 **波动锚/MA120**（前两版）两条路，其中距年线调仓最低。
- **七种状态（趋势方向/波动锚/ER/回撤/vol变化率/距年线，外加 vol 估计子）里，真正稳定过线的只有 ER 与距年线两种**，且各管一条腿——再次印证「没有通吃两腿的自适应」。
