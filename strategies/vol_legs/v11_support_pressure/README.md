# V11 变种 · 支撑/压力位 × 期望值（**事件研究**，不是仓位规则）

来源：`E:\qianwen\jijin\支撑压力位期望值策略.md`（抖音「熊猫讲技术分析」口播拆解，2026-10-15 发布）
—— 作者**未给样本量、周期、品种、成交成本、胜率统计口径**，属方法论主张而非回测证据。

一句话：**这是一张「这笔交易值不值得做」的验伪报告，不是一套要上仓位的策略。**
它把那份文档 §4 自己规定的四步验证**逐条执行**，结论是「趋势用法可以留着、四个概率数字只有两格对上
（且都不是『可以做多』那格）、『到线就买』在这一层是负增量」。

> ⚠ **本变种刻意不输出年化 / 最大回撤 / 夏普**。家族其它变种（v1~v10）都是 NAV 择时回测，
> 本变种不是 —— 文档 §4.3 明令「只看信号日后 20/60/120 日前向收益分布 vs 买入持有，
> 不在小样本上报年化/回撤」。少了这三项不是漏写，而是**遵守被验证方的验证方案**。

## 2. 规则（写死版，参数唯一权威源 = `support_pressure.py`）

| 环节 | 定义 | 参数 | 与文档的关系 |
|---|---|---|---|
| **趋势** | `close > MA200` **且** `MA200 − MA200(20 日前) > 0`；**每月最后一个交易日判定、次月整月沿用** | `MA_WIN=200` `SLOPE_N=20` `TREND_FREQ="monthly"` | 文档 §4.1 原文。注意 **v5 用的是 MA250 日频**，两者不可混用 |
| **支撑** | 最近一个**已确认**摆动低点（`SWING_N=10`，滞后 10 日确认），回看 250 日 | `SUP_MODE="pivot"` | 「前低」。`"profile"`（时间密集区下沿）作对照 |
| **止损** | `支撑 − 0.5 × ATR14`，`ATR14 = mean(|Δclose|, 14)` | `STOP_ATR=0.5` `ATR_N=14` | 文档 §4.1。**无 H/L，ATR 取 close-to-close 下界**（止损更紧 = 对策略不利，保守偏置） |
| **目标** | `entry + 5R`（R = entry − stop）；结构目标（上方枢轴高点）单列对照 | `RR=5` | 文档口播「赚 1000 / 亏 200 = 5:1」 |
| **到线** | `0 ≤ close/support − 1 ≤ 2%`，**破位（close < support）不算回踩** | `BAND=0.02` | 文档铁律①「支撑破了就走」 |
| **冷却** | 同一腿两个事件至少隔 20 个交易日 | `COOLDOWN=20` | **本实现新增**：否则一次触线连出十几笔，把 §4.2 的「≥50 笔」守门绕过去 |
| **跟踪** | 从 t+1 起逐日看收盘，先触止损/目标者了结，满 120 日算到期 | `HOLD_MAX=120` | — |

两个口径妥协（都在报告 §11 里明写）：

1. **只有收盘价**（场外复权净值 / `data/_long_klines.json` 都无 OHLCV）→ ① ATR 用 close-to-close
   下界；②「成交密集区」降级成**时间密集区**（收盘价落点分布）；③「阳线确认」用「涨幅 ≥0.25×ATR」。
2. **止损只能收盘确认**，所以实际亏损常超过 1R（池化中位 MAE −1.19R）—— 这不是记账误差，
   是场外净值口径的真实约束（你不可能在支撑下方 0.5×ATR 挂一个精确止损）。

## 3. 回测结论（完整版见 `backtest/_v11_support_bt.md`）

七腿 = 主策略 `rule.LEG_ORDER`，价格 = 场外**复权净值**。池化 237 笔（每笔一票），
逐腿只有标普500（51 笔）过 ≥50 门槛。

| 指标 | 文档口播 | 实测（七腿池化） |
|---|---|---|
| 上涨趋势支撑「撑住」 | ≈70% | **41%**（20 日收盘未破支撑）/ **46%**（未触止损） |
| 触 5R 目标 | （隐含 70%） | **27%** |
| 止损 | 30% | **70%** |
| 期望值 `p×5R − (1−p)×1R` | **+3.2R** | **+0.65R**（按文档公式）/ **+0.40R**（按逐笔实际路径） |
| 上涨趋势压力位突破 | 60~70% | **75%**（20 日）/ **90%**（60 日）✅ 方向对、更极端 |
| 下跌趋势压力位「压住」 | ≈70% | **32%**（20 日）/ **16%**（60 日）❌ **方向反了**（2026-11-06 补测 §7.3） |
| 下跌趋势支撑撑住 | 30~40% | **32%** ✅ 两格对上之一 |

八条硬结论：

1. **四个概率数字只有两格对上，且都不是「可以做多」那格**。上涨趋势撑住 41%（口播 70%）、
   下跌趋势压住 32%（口播 70%）、触 5R 27%、EV +0.40R —— 量级全都远离口播。
   **错的是把「胜率 70%」和「盈亏比 5:1」当成两个可以同时取的参数**：
   实测止损距离中位 1.6%，5R 目标意味着要涨 8.1%，这两件事在同一止损距离上无法并存（报告 §5 分桶）。
2. **「一直等到贴线才买」是负增量 —— 本变种最硬的一条**。C1（只有趋势）f60 **+3.64%** →
   C2（贴到 2% 内）**+2.98%**（−0.66pp）；但把「到线」放宽到 3%/5%/8% 就转正
   （+0.65 / +0.59 / +0.80pp）。**精确说法是「贴线买差」，不是「接近支撑差」**：
   越等到贴线越差，在支撑上方 3~8% 介入反而更好。机制：贴到前低往往正处下跌动能末端，插破概率最高。
3. **「止损放支撑下方一点点」是负优化**。止损放宽到 1.0 / 1.5×ATR，EV 从 +0.40R 抬到 **+0.61R / +0.79R**；
   A股两条宽基腿 f60 超额为正（+0.83 / +1.52%）但 EV 为负（−0.42 / −0.44R）——
   **正的前向收益被执行方式吃掉了**。
4. **与 v5 高度共线**：82% 的事件日本来就处在 v5 的上涨趋势里。真要用趋势，v5 已经做了；
   v11 只多给「哪一天到线」，而这条增量在 §3 的结论 2 里是负的。**故本变种不与主策略 / v5 叠加。**
5. **对上的两格都指向同一动作：不抄底、不逆势空** —— 恰好是 A 股能执行的那半边（另一半做空落不了地，
   文档 §3.4 自己承认）。这也是本变种唯一**建议保留**的内容。
6. **压力层两格（文档第 2、3 格）都不能用**（第 3 格 2026-11-06 补测，报告 §7.3）：上涨趋势里压力位
   60 日被突破 **90%**（口播 60~70%，方向对但更极端）→ 只能当「不逆势空」的约束；
   下跌趋势里反弹到压力位「压住」只有 **32%**（20 日）/ **16%**（60 日）（口播 70%，**方向反了**），
   而且事件组 f20 比同腿「下跌趋势日均值」还高 **+0.60pp** —— 既不是更差的做空点，也不是更好的买点，
   只是「下跌趋势」这件事的重复计价。所以 **v11-gate 没有压力层不是漏了**：
   四格里没有一格能变成可执行的正贡献规则。
7. **换趋势口径不改变任何一格**（2026-11-06 补测，报告 §7.4）：把趋势判定从 MA200·月频换成
   v5 的 **MA250 + 20 日 + 日频**（先验证两套掩码逐日一致率 **100%**，19,115 个共同交易日），
   四格读数最大只差 **3pp** —— 撑住 41%→42%、压力位突破 75%→73%、下跌侧压住 32%→33%、
   下跌侧撑住 32%→29%。**作者的四格不是败在「趋势怎么定义」，而是败在支撑/压力本身没有那 70% 的黏性。**
   顺带修正了 §6 敏感性表里「趋势改 MA250（v5 口径）」那一行 —— 它原先只改 `MA_WIN=250`、
   仍是**月频**，名不副实；现已改为真正的 MA250 + 日频（211 笔 / 撑住 42% / EV +0.44R）。
8. **右侧交易（站上前高再买）同样没有增量**（2026-11-06，`research/probe_breakout/`）：293 笔
   「首次收盘站上已确认前高」的样本，60 日平均 **+2.70%**；但同一批腿「处在上涨趋势里的普通一天」
   就有 **+3.88%**，**控掉趋势后超额 -1.18%**。按趋势内外分组：趋势内 193 笔 **-0.29%**（v5 已覆盖）、
   趋势外 100 笔 **+0.23%**（都在噪声内）。加 0/1/2% 突破缓冲只是把样本从 293 缩到 206，
   总超额几乎不动（-1.18% → -0.94%）。执行面更差：20 日平均最大回撤 -2.49%、
   **65% 的样本买入后 20 日内又跌回前高下方**（站稳率只有 34%）。
   根因是 §7.1 的「60 日 89~90% 会突破」—— 突破是**常态**，以常态事件当触发器的设计先天缺信息。
   **换成「突破 + 回踩不破」更差**（§8）：293 次突破里 171 次（58%）能等到「回踩 ±2% 且收盘不破」，
   但买入组 60 日超额 **-1.94%**（突破即买是 -1.18%）；`wait` 5/10/20 日 × `band` 1/2/3% 九档
   全在 **-1.48% ~ -2.16%**，没有一档转正。唯一改善的是**拿得住**：站稳率 34% → 51%。
   机制与 §3 同一条——回踩把买点挪到突破回落之后，等于「贴着前高买」，而「贴线买」早已被证是负增量。

## 6. 与主策略 / 其它变种的关系

- **不叠加、不进每日流程**（`pipeline/strategies.json` 里没有它，`daily.enabled` 也就不存在）。
  v11 的事件是「几十笔/十几年」级别，做每日看板没有意义；`gate/daily/` 也只是**手跑**的复盘表。
- 与 **v5 的关系（B 层）**：`v11-gate 纯趋势`（MA200 月频）与 v5（MA250 日频）年化在约 1pp 内互有
  胜负，但换手只有 v5 的 45~60% —— 它是「v5 的慢速对照」，不是替代品（§7 与 `gate/README.md` §7）。
- 与 **v5_trend_gate** 同族但不同层：v5 用 MA250 日频把仓位带切成 1.0/0.5/0.2 三档；
  v11 用 MA200 月频 + 位置条件做**事件研究**，不产生任何仓位。82% 共线说明它不是新信号。
- 与 **v9_vol_target / v7_us_gate** 无关（那是美股两腿的风险预算与年线闸门）。
- 与**主策略的回撤阶梯**不冲突也不互补：主策略的阶梯是「跌了才加仓」，v11 的事件是「跌到支撑才买」，
  两者都在跌的时候动手，但 v11 已被本报告证明是负增量 —— **不要把它接到主策略上**。

## 7. B 层：仓位化复算（`gate/` · v11-gate）—— 一句话，支撑位连仓位口径也过不了

把 §3 的四条结论原样翻译成仓位规则（趋势不成立→观察仓 0.2 / 距支撑 ≤3% 贴线→半仓 0.5 /
`close < support` 破位→清仓 + 冷却 20 日 / 不做空），七腿 NAV 回测（成本与记账复用 v5）：

| | 七腿（2022-08~2026-11） | 五腿长窗口（2014-08~2026-11） |
|---|---|---|
| 买入持有 | +14.47% / -12.52% | +13.26% / -19.61% |
| V5 默认 | +12.74% / -9.95% | +9.52% / -16.72% |
| **v11-gate 纯趋势**（去支撑层） | +12.37% / -12.37% · 8.6 次/年 | +10.67% / -19.61% · 6.5 次/年 |
| **v11-gate 完整** | +8.99% / -11.51% · **61 次/年** | +5.67% / -12.36% · 45.7 次/年 |

**支撑层是确定的负贡献**：撤掉它年化 +8.99% → +12.37%（+3.38pp）、换手 61 → 8.6 次/年，
回撤几乎不动（-12.37% → -11.51%）。拆开看，「只留破位清仓」+7.18% 且回撤**反而更深**（-16.05%，
卖在低点等价格站回支撑 +3% 才回补，正好错过反弹第一段）；「只留贴线减半」+11.11%（-1.26pp，
多出的 1.37pp/年 成本 > 0.66pp/60 日的收益增量）；「开 ATR 跟踪止损 1.5×ATR」-0.32%/年、118 次/年、
曝光 16%（**§3 结论 3 的口径边界**：单笔 + 固定 5R 才成立，逐日跟踪就是高频割肉）。

所以 A、B 两层给的是**同一答案的两个独立证据**（单笔口径 + 逐日仓位口径都指向「支撑位不是 alpha」），
剩下的趋势层与 v5 等价、只是更省交易 —— **故 `gate/` 也不上线**。细节（消融 16 档 / 逐腿 / 逐年 /
三段 / 图 / 今日操作表）见 [`gate/README.md`](gate/README.md)。

## 8. 已知局限（用之前必须知道的）

- **只有收盘价**（无 OHLCV、无成交量）—— 见 §2 的两处口径妥协。ATR 与「密集区」都是降级实现。
- **支撑/压力有主观性**：本实现用「机械摆动点 + 冷却」压到可复现，但不等于原作者的看图方式。
  `SWING_N=5/10/20`、`BAND=1%~8%` 的实测在报告 §9/§8.1。
- **前向窗口重叠**（事件间隔 20 日，60/120 日窗口会叠），**没做 block bootstrap**，
  所以「超额」的显著性未检验 —— 本报告只报方向和量级。
- **A500 与沪深300 不是两份独立证据**（2025-03-27 前场外序列逐值相同，见 `../README.md` §2.3），
  池化里这两条腿占 33%，看池化数字时当一条。
- **成本未计入**（事件研究看价格前向收益）；真要执行还要扣申赎费 + 场外 T+1/T+2 确认时滞。
- **没有 walk-forward**（参数是文档写死的，不是在本样本上选的）—— 这一点反而比家族里那些
  「调参到最优」的变种干净。

> 模拟结果，非投资建议。
