# v11-gate · 支撑位闸门（父目录事件研究的**仓位化复算** · 回测后判定不上线）

**位置与身份**：本目录是 `v11_support_pressure/` 的**仓位层**（代号 `v11-gate`），不是独立变种 ——
2026-11-10 由原独立目录 `v12_support_gate/` 并入，v12 这个编号取消，产物统一为 `_v11_gate_*`。
父目录的 `support_pressure.py` 回答「这笔交易值不值」（单笔 R 口径，**刻意不报年化/回撤**），
本目录回答「这条腿今天该露出多少带」（逐日仓位 + NAV 口径，报年化/回撤/夏普）。
**趋势 / 支撑 / ATR 是同一份实现**（直接 import 父目录的 `build`），改口径只改父目录，这里自动跟随。

用父目录（事件研究）的四条结论造一个可执行的仓位规则，然后在**七条腿**上跑 NAV 回测。
结论先说：**支撑层（贴线减半 + 破位清仓）是确定的负贡献，年化 -4~-5pp、换手 ×7，回撤一点没改善；
只剩趋势层可用，而它与 v5 基本等价（只是交易少一半）。所以本层不进每日流程。**

|---|---|---|
| 买入持有 | +14.47% / -12.52% / Calmar 1.16 | +13.26% / -19.61% / 0.68 |

## 1. 规则（参数权威源 = `support_gate.py`）

档位是「占本腿目标带的比例」，与 v5 同一语义（0.2/0.5/1.0）：

| 条件（收盘后判定，次日收盘成交） | 档位 |
|---|---|
| 上涨趋势不成立（MA200 下行 或 价在 MA200 之下，**月频判定**） | 观察仓 0.2 |
| 趋势成立，距支撑 > 3%（不贴线） | 满带 1.0 |
| 趋势成立，距支撑 ≤ 3%（**贴线**） | 半仓 0.5 |
| `close < support`（**跌破支撑**，无论趋势） | 空仓 0 + 冷却 20 日 |
| 破位后价格未重新站上「支撑 + 3%」 | 空仓 0（不回补） |
| （可选 `STOP_USE`）从持仓期最高点回撤 ≥ 1.5×ATR | 空仓 0 + 冷却 |

限速：非风控换档至少隔 10 个交易日（滞回 2pp 防在贴线边界抖动）；**破位/止损的减仓不受限**。

每条规则与其 v11 依据的对应，因为「对应关系」本身也是被检验的对象：

| 规则 | v11 的依据 | v11-gate 回测的裁决 |
|---|---|---|
| 趋势不成立 → 观察仓（不抄底） | v11 §7.2 下跌趋势撑住只有 32% | ✅ 保留（是纯趋势层的一部分） |
| 贴线 → 半仓 | v11 §8.1 距支撑 ≤2% 时 f60 低 0.66pp | ❌ 净负：-1.60pp（+1.37pp/年 成本 > 收益） |
| 破位 → 清仓 | 文档铁律①「支撑破了就走」 | ❌ **最差的一层**：单独 -5.82pp，回撤反而更深 |
| 不用 0.5×ATR、改 1.5×ATR | v11 §9 EV 从 +0.40R 升到 +0.79R | ❌ 逐日跟踪版 -0.29%/年、117 次/年（口径不兼容） |
| 不做空 | A 股无工具；v11 §7.1 上涨趋势里压力位 60 日突破 90%、§7.3 下跌趋势里「压住」只有 32% —— 压力层两格都不构成可执行信号 | ✅ 保留（约束，不产生信号） |

## 2. 为什么「支撑位」在 NAV 口径下更差

v11 用**单笔**口径测量支撑位（触线日买入后 60 日收益），v11-gate 用**逐日仓位**口径。三个放大机制：

1. **成本放大**：单笔口径不计交易次数，NAV 口径每次换档都要付 0.1%/0.5% + 0.1% 滑点。
   支撑位是**高频穿越**的噪声位（七年里 A500 破位 40+ 次），换手从 8.6 涨到 61 次/年，成本 0.36pp → 1.73pp/年。
2. **错过上涨**：破位清仓后要等价格**重新站上支撑 +3%** 才回补，正好错过反弹第一段。
   实测「只留破位清仓」的回撤反而从 -11.56% 恶化到 -16.05% —— 卖在低点，回撤更深。
3. **口径不兼容**：v11 的「1.5×ATR 止损 EV 更高」是在**单笔 + 固定 5R 目标**下测的；
   逐日跟踪止损把同一个 1.5×ATR 变成「跌 1.5 个 ATR 就清仓」，一年 117 次，曝光只剩 16%，年化 -0.29%。

> 一句话：**v11 的 0.5~1pp/60 日的弱信号，搬到逐日仓位后会被成本和「错过上涨」放大成负贡献。**
> 两个**独立口径**给同一答案（支撑位不是 alpha），这个结论比任一单独口径都结实。

补一个反证（`backtest/_v11_gate_bt.md` §6 消融 ⑥）：把趋势口径换成 v5 的
**MA250 + 20 日 + 日频**后，完整版从 `+8.99% / -11.51% / 夏普 0.78` 抬到
`+9.82% / -9.02% / 1.17`（换手 61.4 次/年），回撤明显变好、但仍比纯趋势的
`+12.37% / -12.37% / 1.16` 低 **2.55pp/年**。也就是说**支撑层的负贡献不依赖趋势怎么定义**——
换年线只是把「破位」的信号时点挪了几天，没改变「贴着前低买、跌破就清」这件事的成本结构。

## 5. 今日操作（手跑 · 不进每日流程）

v11-gate **不上线**（`pipeline/strategies.json` 不注册、`run_daily_all` 不含它、不出看板卡片），
所以「今日操作」是一份**手跑**产物：用途是核对规则、看支撑层在扣多少仓，**不是操作指令**。

```powershell
python strategies/vol_legs/v11_support_pressure/gate/daily/_daily_scan.py               # 先刷新场外净值再算
python strategies/vol_legs/v11_support_pressure/gate/daily/_daily_scan.py --no-refresh  # 只用本地缓存
```

产物 `daily/_v11_gate_daily.md` / `.json`，四块：

| 板块 | 回答什么 |
|---|---|
| 今日操作（明日成交） | 今天哪些腿换档（决策日 T 盘后、成交日 T+1 收盘净值）：`加仓 / 减仓 / 其余维持` 一张表 |
| 逐腿一句话 | 每条腿的档位 + 成因（`why`）+ 距支撑 + 距 MA200 + 纯趋势档 |
| 七腿档位表 | 净值 / MA200 / 斜率 / 距 MA200 / 趋势 / 支撑 / 距支撑 / 冷却 / **两列档位** / 占带 / pp / 今日动作 / 还缺什么 / 数据新鲜度 |
| 近期动作流水 | 最近 120 个交易日有动作的日期（决策日，次日成交） |

**两列档位的用意**：「档位（完整）」含支撑层，「档位（纯趋势）」只有 MA200 月频闸门。
两列不同 = 今天支撑层在扣仓 —— 而它在七腿上净负（§2），差异列的作用是**提醒它在扣**，
不是要你听它。

⚠ 读这份表要记住一件事：**「同时破位」是普跌的常态**。2026-11-09 七条腿**全部空仓**（2026-11-05 也是）
（每条都跌破了各自最近一个确认前低），而纯趋势档里有 1 条是满带 —— 这正是支撑层
「同时清仓、再同时错过反弹第一段」的形态，也是它在 NAV 口径上比 v11 单笔口径更差的原因。

单腿操作图（版式对齐 v5 的 `_v5_trend_{leg}.png`）：上格 = 净值 + MA200 + 前低支撑阶梯 +
四态底色 + ▲▼ 操作点；中格 = 距支撑%（绿带 0~3% = 贴线）；下格 = 带内档位阶梯。

## 6. 已知局限

- **七腿窗口只有 4.2 年**（恒生科技 2021-08 上市，预热 250 日后才可比）；长历史只有「五腿」，
  缺科创50/恒生科技两条进攻腿。所以**没有一段完整的高波动熊市**同时覆盖七腿。
- **组合日历是七腿交集**（A股/美股/港股节假日不同），4.2 年只剩约 1000 个可比交易日，
  单腿 4000 日的样本没有被组合层用满。
- **C 类腿销售服务费未计**（023299 / 011609 / 012805，约 0.2%/年）—— 与 v1~v9 同一处妥协，
  所以高换手配置的成本被**低估**，负结论只会更强。
- **没有 walk-forward**：参数（MA200 / 月频 / 3% / 20 日冷却）全部来自 v11 文档或 v11 的消融，
  没有在本样本上做网格搜索 —— 这也是「纯趋势层 +12.37% 不是过拟合产物」的唯一依据，
  但它同样不构成「未来也会 +13%」的证据。
- **单腿与组合的额度不同**（单腿满带 vs 组合 40pp 归一化），绝对收益不可横向比。

## 7. 与家族的关系

- **不上线**：`pipeline/strategies.json` 不注册、`daily/` 只有手跑脚本（§5）、不与主策略/v5 叠加。
- 与**父目录 v11** 是「同一份口径的两种测量」：v11 单笔、v11-gate 逐日仓位，结论一致。
- 与 **v5** 是「等价但更省交易」的关系：v11-gate 纯趋势换手 8.6 vs 14.5 次/年，年化差 0.37pp
  （七腿）/-1.15pp（五腿，v11-gate 反而高）。**不构成替换理由**，留作对照。
- 与**主策略的回撤阶梯**无关：主策略「跌了才加仓」，v11-gate 支撑层「跌破才清仓」，方向相反且已被证伪。
