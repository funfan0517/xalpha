# 波动资产 · v11-gate（v11 的仓位层）：支撑位闸门 · 七腿回测

> **把 v11 事件研究的四条结论翻译成仓位规则**，然后在七条腿上做 NAV 回测。
> v11 回答「这笔交易值不值」（单笔 R 口径，**不报年化/回撤**，见 `../../`（父目录的事件研究））；
> 本层回答「这条腿今天该露出多少带」（组合 NAV 口径）—— 两者的趋势/支撑/ATR 是**同一份代码**
> （v11-gate 直接 import v11 的 `build`），口径不会漂移。
> 成本、滑点、货基利息、NAV 记账全部复用 `v5_trend_gate`（`fee_of / portfolio / run_leg`），
> 所以「v11-gate vs V5」的差异**只来自规则**。

## 1. 规则（参数权威源 = `support_gate.py`）

| 条件（收盘后判定，次日收盘成交） | 档位（占本腿目标带） |
|---|---|
| 上涨趋势不成立（MA200 下行 或 价在 MA200 之下，月频判定） | 观察仓 0.2 |
| 趋势成立，距支撑 `> 3%`（不贴线） | 满带 1.0 |
| 趋势成立，距支撑 `≤ 3%`（**贴线**） | 半仓 0.5 |
| `close < support`（**跌破支撑**，无论趋势） | 空仓 0 + 冷却 20 日 |
| 破位后，价格未重新站上「支撑 + 3%」 | 空仓 0（不回补） |
| （可选 `STOP_USE`）从持仓期最高点回撤 ≥ 1.5×ATR | 空仓 0 + 冷却 |

限速：非风控换档至少隔 **10 个交易日**（滞回 `HYST=2%` 防在贴线边界抖动）；
**破位/止损的减仓不受限速** —— 风控优先。

每条规则都对应 v11 的一条实测结论：

| 规则 | v11 的实测依据 |
|---|---|
| 趋势不成立 → 观察仓（不空仓、不抄底） | v11 §7.2：下跌趋势里支撑撑住只有 32%，但趋势本身有 +1.00% 的 60 日超额 |
| 贴线 → 半仓 | v11 §8.1：距支撑 ≤2% 时 f60 比「趋势日均值」低 0.66pp，3% 以上转正 |
| 破位 → 清仓 | 文档铁律①「支撑破了就走」—— **本层实测它是负贡献（§7 第 2 条）**，保留在规则里是为了让「被证伪」这件事有数字，不是为了推荐 |
| 0.5×ATR 止损**不用**，改用结构位 | v11 §9：止损放宽到 1.0/1.5×ATR，EV 从 +0.40R 升到 +0.61/+0.79R |
| 不做空 | A 股散户没有工具；v11 §7.1 实测上涨趋势里压力位 60 日突破 90% |

## 7. 结论：支撑位层不能迁移，趋势层站得住但与 v5 等价

**一句话**：按 v11 的结论全部实现后，v11-gate 跑输 v5 **3.75pp/年**、Calmar 从 1.28 掉到 0.78 —— **不是因为实现错了，而是「支撑位」在逐日仓位口径上比在单笔口径上更没用**。

1. **支撑层整体是负贡献**：去掉支撑层（纯趋势 MA200 月频）年化 +12.37%，装上后 +8.99%（**-3.38pp**），回撤几乎没变（-12.37% → -11.51%），动作从 8.6 次/年 涨到 61.0 次/年。
2. **主因是「破位清仓」**：只留破位清仓、不做贴线减半 → 年化 +7.18%、回撤 -16.05%（比纯趋势的 -12.37% **更深**）。也就是说**「跌破支撑就走」在七腿宽基上既亏收益又不减回撤** —— 它卖在低点，然后要等价格重新站上「支撑 + 3%」才回补，正好错过反弹第一段。这是 v11 §7.2「下跌趋势支撑撑住只有 32%」的另一面：撑不住是常态，但**破位后继续跌的概率并没有高到值得清仓**（否则回撤该更小）。
3. **「贴线减半」也是负的，但两个负贡献不叠加**：只留贴线减半 +11.11%（**-1.26pp**）、只留破位清仓 +7.18%（-5.19pp）、两者都开 +8.99% —— 清仓之后「贴线」这个状态本来就很难再触发，所以完整版介于两者之间、不是相加。零成本档显示完整版的成本拖累 **1.72pp/年**、纯趋势只有 **0.36pp/年**，差出的约 **1.37pp/年** 就是多出来的 44 次/年交易的代价 —— 收益增量（v11 测到的 0.66pp/60 日）撑不住这个成本。
4. **ATR 跟踪止损完全不可迁移**：-0.32%/年、118 次/年、曝光只剩 16%。v11 §9「1.5×ATR 比 0.5×ATR 好」成立的前提是**单笔 + 固定 5R 目标**；逐日跟踪止损把同一个 1.5×ATR 变成高频割肉 —— **结论的口径边界比结论本身更重要**。
5. **留下的只有趋势层，它的价值是「省交易」不是「更高收益」**：v11-gate 纯趋势 七腿窗口 +12.37%/-12.37%/Calmar 1.00、动作 8.6 次/年；V5 默认 +12.74%/-9.95%/1.28、14.5 次/年；V5 关波动层 +13.14%、11.4 次/年。三者年化在约 1pp 内互有胜负，**但 v11-gate 纯趋势的换手只有 v5 的 45~60%** —— 等价于「v5 的省交易版本」，不是新 alpha。五腿长窗口同理：+10.67% vs v5 +9.52%，换手 6.5 vs 14.4 次/年，但回撤 -19.61% 比 v5 的 -16.72% 更深。差异来自「MA200 月频」vs「MA250 日频」，不是新增信息；而 MA200/月频是**文档写死的、不是在本样本上选的**，所以也没有理由假设它未来更好。
6. **所以 v11-gate 不上线**（`pipeline/strategies.json` 不注册、不进每日流程）。如果将来要用，只用 `USE_SUPPORT=False` 这一档（纯趋势），并明确它是**v5 的慢速对照**、不是替代品。v11 四条结论里唯一可迁移的是**「不抄底、不逆势空」这条约束** —— 它是「不做某事」，不产生仓位信号。

> 最值得记住的一条：**事件研究里的弱信号（0.5~1pp / 60 日）搬到逐日仓位后，会被交易成本和「错过上涨」放大成负贡献**。v11 的净结论是「支撑位不是 alpha」，v11-gate 用另一种口径又验证了一遍 —— 两个独立口径给同一答案，这个结论就可以信了。

> **模拟结果，非投资建议。**
