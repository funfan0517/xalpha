> 裁决口径（先定好再看数）：① **八态增量** = S1 夏普 − 曝光匹配夏普（恒定仓位一直拿着），这是「八态层到底有没有信息」的唯一不含调参偏差的检验；② **CAP 重估必须是两折样本外都赢**（C1/C2 的全样本夏普天然偏高，含调参偏差）；③ 量能不是指数成交量的腿只给方向、不给裁决。

## 结论：七条腿的优化方向不一样，别用同一把尺子

### 1. 八态层的价值分两类：A股**提夏普**、美股**压回撤**

| 腿 | 八态增量（夏普） | 回撤：恒定仓位 → S1 | 读法 |
|---|---:|---|---|
| 科创50 | **+0.66** | −21.5% → −16.6% | 5.8 年：把 0.03 的恒定仓位打成 0.70 |
| 沪深300 | **+0.44** | −38.7% → −31.8% | 20 年：0.30 → 0.73 |
| 中证A500 | **+0.38** | −42.5% → −30.2% | 20 年：0.33 → 0.71 |
| 标普500 | **+0.16** | −31.7% → **−14.9%** | 20.8 年：0.44 → 0.60，**回撤砍半** |
| 纳指100 | 0.00 | −30.9% → **−14.8%** | 20.7 年：夏普持平，**同样收益换一半回撤** |
| 恒生科技 | −0.01 | −25.8% → −24.0% | 5.1 年：层没帮上也没拖累（腿本身 −2.6%/年） |
| 黄金 | −0.01 | −16.6% → −26.6% | 11.7 年：与「恒定 48%」打平，**且回撤更差** |

**美股两腿不是「不成立」，此前那个负结论是口径造成的。** 上一版用场内 ETF（人民币、含汇率与溢价、2014 起 11 年）做价格、用 ETF 自身量做 `rvol`，得到 ndx −0.10 / spx −0.25；换成 `NDX`/`INX` 指数收盘 + 指数成交量、样本拉到 20.7/20.8 年后变成 0.00 / **+0.16**，而且两腿的最大回撤都从 −31% 砍到 −15%。这条本身就是方法论教训：**跨市场比结论之前先把口径统一**（价格、量能、窗口三件事）。

⚠ 但 A股三腿的增量**在衰减**：hs300 前半夏普 1.03 / 后半 **0.33**，a500 1.00 / **0.33**，kc50 只够切两折（5.8y）。后半折仍显著高于同折的曝光匹配（0.12~0.15），但「八态层 vs 一直拿着」的差距从 0.6 收窄到 0.2 —— 这与 `beat_best` 里沪深300找不到稳定跑赢 V2 的候选是同一件事。**A股三腿的边际在变薄，不是消失了**。

美股两腿的机制与 A股不同：长牛里八态层平均只给 52% 的许可，所以它**放弃了收益、换来回撤**（spx +5.62%/−31.7% → +6.12%/−14.9%；ndx +8.71%/−30.9% → +7.81%/−14.8%）。这与家族已有结论同向：**方向层在美股上是「风控」不是「alpha」**（`v8_golden_cross` 金叉门在波动层之上是负优化）、**要收益该换波动率目标**（`v9_vol_target` 纳指 0.89 / 标普 0.85）。

### 2. 「按本腿 fwd5 重估 CAP」这条路**不可复制**（负面结论）

v12.1 的做法（拿本腿的次日/5 日期望重估 `CAP`）在沪深300 上成立，但铺到其余六腿后：

| 腿 | C1 样本外（前/后） | C2 样本外（前/后） | S1 | 判断 |
|---|---|---|---:|---|
| 中证A500 | 0.10 / 0.66 | 0.01 / 0.88 | 0.71 | 两折相差 0.6~0.9，**不成立** |
| 沪深300 | 0.32 / 0.93 | 0.08 / 0.66 | 0.73 | 前折崩到 0.08，**不成立** |
| 科创50 | 0.26 / −0.04 | 0.59 / −0.44 | 0.70 | 后折为负，**不成立** |
| 纳指100 | 0.59 / 0.53 | 0.53 / 0.33 | 0.63 | 两折都赢不了 S1，**不成立** |
| 标普500 | 0.85 / 0.48 | 0.88 / 0.16 | 0.60 | 前折赢、后折崩（0.16），**不成立** |
| 恒生科技 | 0.08 / −0.49 | −0.39 / −0.27 | −0.21 | 全负，**不成立** |
| 黄金 | 0.70 / 0.44 | 0.47 / 0.43 | 0.61 | 一折赢一折输，**不成立** |

> 原因：`CAP` 是 8 个格子 × 少量样本，一折（10 年、300~500 个态样本）估出来的排序，在另一折上复现不了。**「用同一套数据估映射、再用同一套数据评分」的漂亮数字都是这样来的** —— 本表 C1/C2 的全样本夏普（0.69~0.74）与样本外（0.01~0.93）的差距，就是调参偏差的量级。**七条腿没有一条能靠重估 `CAP` 稳定赢过 S1。**

### 3. 但规格 `CAP` 在美股上是**系统性偏保守**的（这是「方向」不是「结论」）

换了真指数后，美股两腿的态期望几乎全是正的：标普的 `强回调` fwd5 **+0.31%（t=4.2）**、`慢涨` +0.10%（t=2.6）、`弱反弹` +0.22%（t=2.2）都显著为正，合起来占 **69%** 的日子，而规格分别给 50% / 50% / 20%；纳指更极端，`慢跌`（10% 的日子）fwd5 **+0.44%（t=2.2）**、`弱反弹` **+0.47%（t=3.9）** 也压到 20%。这说明**规格的映射是「A股震荡市」的产物**，在长牛里它把仓位系统性压低 —— 这正是「回撤砍半、夏普不涨」的来源。

把这几格抬上去的候选 C1（`慢涨`/`强回调`/`急跌`→100%）确实把夏普抬到 0.69/0.70，但**样本外只在单折成立**（标普 0.85/0.48、纳指 0.59/0.53），且平均许可是 80%~81%（等于换了风险预算，不是同一把尺子的改进）。所以结论是：**方向明确（美股该更进取），但幅度不可由 20 年单一样本定** —— 要么接受「这一层只管压回撤」，要么走 `v9` 的波动率目标。

### 4. 黄金：删掉方向层、只留波动层

八态层在黄金上与恒定仓位打平（0.61 vs 0.62），但 `σ覆盖 15%` 把 S1 推到 **0.75 / 回撤 −18.90%（vs −26.60%）**：后折夏普 0.76 → **1.03**、前折基本不动（0.43 → 0.42），即**改善全部来自高波动的后半段**。这与 `v6_gold` 的「B 控回撤」完全同向（黄金上纯波动目标 15% 最好、叠方向闸门反而更差）。⚠ 但 σ 覆盖的最优值落在**网格边界**（15% 最好、20% 0.71、25% 0.67，没有内部峰），等价于「整体少拿一点」，不是找到了甜点 —— 与 v6-B 的 `VOL_TARGET=15%` 是同一件事的两种实现。

### 5. A股三腿：优化空间不在 CAP / σ，在执行成本

- **CAP 重估无效**（见 §2）：hs300 已是 v12.1 口径（0.73），kc50 的三条旋钮 + σ覆盖 25% 就是它自己的局部最优（重估掉到 0.46/0.32）。
- **σ覆盖在 A股上是负的**：hs300 全网格 0.70/0.73/0.73（＝S1），kc50 0.55/0.65/0.70 （15%/20%/25%，25% 即现状）—— A股的波动层压不出超额，因为八态层本身已经在压仓位。
- **加迟滞换低成本不行**：`UP_CONFIRM=3` 把换手砍一半（kc50 49→16 次/年），但夏普 0.70→0.40、a500 0.71→0.63、hs300 0.73→0.67。**省下的摩擦（0.13pp）买不回夏普**。
- 所以这三条腿真正剩下的是**执行层**：31~49 次/年、0.53~0.70pp 摩擦。碎调来自 σ 覆盖而不是 CAP 换档：kc50 的调仓 S0 161 次 → S1 271 次（+110 次全是 σ 微调），hs300 546 → 677（+131 次）。方向应是「只在跨档时下单 / σ 覆盖加死区」，但 `portfolio_ops` 已测过 `deadband` 在**组合层**无效（`CAP` 档距 20~50pp 太大，能削的只有 σ 那一层）—— 这块本研究**没有动**，是下一步唯一还剩的执行层工作。

### 6. 恒生科技：这条腿本身是负的，层救不了

换真指数（`HKHSTECH`）后样本 5.1 年、S1 **−2.60%/年、夏普 −0.21**，八态增量 −0.01（与恒定 37% 打平）。它的八态后验几乎全负（`急涨` fwd20 −2.68%、`弱回调` −3.29%、`慢涨` −2.06%），六条候选里最好的只有 −0.08。也就是说：**这段窗口里恒生科技是下跌腿，八态层能做的只是少亏**（回撤 −25.8% → −24.0%），救不回来。它在 `portfolio_ops` 里已经是「唯一在拖累组合的腿（+0.21）」，本表给出的方向是**降级为诊断腿或换 `v3_macd_boll`**（5.0 年、0.39），而不是在 v12 里调参数。
