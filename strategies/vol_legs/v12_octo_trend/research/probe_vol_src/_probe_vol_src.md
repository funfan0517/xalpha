## 4. 结论

**一句话：两条腿都略差，P3「补齐量能来源」不成立。** 数据本身没问题（覆盖率 99.9% / 100%、状态一致率约 90%），是「换分母」这件事没有增量 ——**八态在这两条腿上的失效不是数据源造成的**。

- **黄金**：夏普 0.82 → 0.77（-0.05）、回撤 -12.8% → -12.8%、年化 +7.42% → +7.09%；四组配对里 1/4 组数值变大，**符号反转 弱回调−强回调** → **不采纳**。
  - ⚠ **更要紧的是符号本身**：现行量能下四组配对只有 **2/4** 组为正（弱回调−强回调、急跌−慢跌），换新量能后 **1/4** 组为正（急跌−慢跌）。八态的定义是「前者应当好于后者」，**负号这一格说明该腿的八态层在自身样本上不成立** ——这与 `opt_7legs` 的诊断一致（这两条腿的增量本来就接近噪声）。在这种前提下换量能只能改判几天仓位，救不了分离度。
  - 现行里符号**正确**的那几组怎么变：`弱回调−强回调` +0.26pp → -0.15pp、`急跌−慢跌` +0.35pp → +0.35pp。
- **恒生科技**：夏普 0.08 → 0.05（-0.03）、回撤 -18.1% → -15.6%、年化 +2.35% → +1.95%；四组配对里 3/4 组数值变大，无符号反转 → **不采纳**。
  - ⚠ **更要紧的是符号本身**：现行量能下四组配对只有 **1/4** 组为正（强反弹−弱反弹），换新量能后 **1/4** 组为正（强反弹−弱反弹）。八态的定义是「前者应当好于后者」，**负号这一格说明该腿的八态层在自身样本上不成立** ——这与 `opt_7legs` 的诊断一致（这两条腿的增量本来就接近噪声）。在这种前提下换量能只能改判几天仓位，救不了分离度。
  - 现行里符号**正确**的那几组怎么变：`强反弹−弱反弹` +0.33pp → +1.39pp。

> 判据顺序是「先验口径、再看好坏」：配对分离度的符号与幅度是规格 §4 的验伪尺子，整条策略的夏普只是第三条。若分离度变差却在回测里变好，那是**巧合**，不该采纳。
