## 1. 两个数 → 九宫格

**数一 · 方向分 S**（计数，不是 AND —— 链式 AND 的落空率是算术必然）

| 票 | 条件 |
|---|---|
| s1 | `MA20 > MA60` |
| s2 | `MA60 > MA60(20 个交易日前)` |
| s3 | `close > MA250` |

`S ≥ 2` → 向上 ｜ `S = 1` → 中性 ｜ `S = 0` → 向下

**数二 · 力度**：`close > MA20` 连续 ≥2 日为**站上**；`< MA20` 连续 ≥2 日为**跌破**；其余（穿越首日）为**未定**。

| 方向 ＼ 力度 | 站上 | 未定 | 跌破 |
|---|---|---|---|
| **向上** | 上涨 → 许可 **1.0** | 强势整理 → hold | 回调 → **hold**（默认）/ **1.0**（回调加仓，研究对照，见 §2） |
| **中性** | 修复 → **0.5** | 震荡 → hold | 走弱 → 0.5（停加仓） |
| **向下** | 反弹 → hold（只持有） | 弱势整理 → **0.2** ⚠ 承重件 | 下跌 → hold@1–4d → 0.5@5d → 0.2@20d |

**急跌兜底**（唯一跨格覆盖）：`dd20 = close / 20日收盘高点 − 1 ≤ −10%` → 许可 = min(许可, 0.2)；
`dd20 > −8%` 结束兜底状态（趋势判断仍靠格子）。触发后 **T+1 减半、T+2 到目标**。
（阈值 `−15%` 已于 2026-11-10 调为 `−10%`，效果见 §5。）

**迟滞**：降格立即生效；升格需**连续 15 个交易日**维持新值。

## 3. 回测结果（场内 ETF 价格口径 · 单边 5bp · 空仓计 1.4% 货基 · 兜底 −10%）

逐腿（单一口径；与文档版只在「向上×跌破」一格不同，实测差异在噪声内，见 §2）：

| 腿 | 样本 | 年化 | 最大回撤 | 平均许可 | 恒持年化 |
|---|---|---:|---:|---:|---:|
| **沪深300**（执行） | 2014-03 ~ 2026-11（3070 根） | +9.13% | −24.2% | 51% | +7.17% |
| 纳指100 | 2014-07 ~ 2026-11 | +11.62% | −17.7% | 67% | **+19.54%** |
| 标普500 | 2015-03 ~ 2026-11 | +9.43% | −22.7% | 68% | **+14.36%** |
| 科创50 | 2022-01 ~ 2026-11 | −3.52% | −28.9% | 28% | −0.29% |
| 恒生科技 | 2022-08 ~ 2026-11 | **+4.15%** | −15.9% | 37% | −1.43% |
| 黄金 | 2014-10 ~ 2026-11 | +8.97% | −16.8% | 61% | **+11.06%** |
| **中证A500**（执行） | 2025-12 ~ 2026-11（212 根） | +3.60% | −8.5% | 57% | −11.61% |

> A500 只有 0.84 年（563360 于 2024-10 上市，预热 290 根后所剩无几），该行**不具信息量**。

组合层——**以下是研究口径（6 腿等权/等波动），不是执行口径**；实际下单只用 `CORE_LEGS` 两腿
（A500 样本不足单列；等波动 = 滚动 60 日波动倒数配权）：

| 组合 | 年化 | 最大回撤 | 夏普 |
|---|---:|---:|---:|
| 九宫格 · 等权 | **+9.22%** | −10.40% | 0.95 |
| 九宫格 · 等波动 | +8.41% | **−8.96%** | 1.09 |
| 恒持 · 等权 | 12.78% | −20.80% | 0.79 |
| 恒持 · 等波动 | **+15.07%** | −18.17% | **1.11** |
| v5（MA250+20）· 等权 | +11.28% | −18.31% | 0.83 |
| v5（MA250+20）· 等波动 | +12.66% | −17.31% | **1.14** |

**结论要分两层读，别只看第一层**：

1. 等权口径下，九宫格确实把恒持的夏普 0.79 拉到 0.95、回撤 −20.8% → −10.4%，代价是年化少 3.6pp。
2. **但一旦换成等波动配权，恒持的夏普也升到 1.11，反超九宫格的 1.09** —— 说明"夏普改善"里
   很大一块来自**配权**而不是选时。换句话说：九宫格在等波动框架下是个"更平的低波动版本"
   （回撤 −8.96% vs −18.17%），不是"更优的风险调整工具"。
3. 同口径下 **v5 的 MA250+20 在年化和夏普上都优于九宫格**（12.66% / 1.14 vs 8.41% / 1.09），
   只是回撤深一倍（−17.31% vs −8.96%）。九宫格的定位因此很清楚：**极低回撤偏好者的选择**，
   不是 v5 的替代品。

## 4. 已知失效点（文档 §7 + 本仓库实测）

1. **高波动标的被 15 日迟滞削弱**：科创50 −3.52%（恒持 −0.29%）。2024-09-24 急涨里格子依次走到
   「向上×站上」，但升格要连续 15 日，到 10-08 见顶全程只有 0.2 仓；随后回落又触发兜底。
   文档 §7.7 已预警「`hold_days=15` 在高波动品种上可能过钝」。
   但**「按 MA20 穿越频率自适应」修不了它**：各腿年穿越 25~37 次、科创50 只有 25.1（池内最低），
   按「穿越越频繁→迟滞越短」，它反而会拿到**最长**的 h —— 前提就不成立（`_optimize.md` §1）。
   兜底触发天数占比（−10% 口径）：科创50 16.4%、恒生科技 14.1%、沪深300 5.5%、纳指 4.9%、
   标普 4.0%、黄金 1.6%。
2. **兜底会被「涨太快后的正常回落」误触发**（科创50 2024-10 就是例子），它衡量的是跌速不是趋势。
   改到 −10% 后触发更频繁，这是"回撤 −12.66% → −10.40%"的对价。
3. **A500 样本不足**（文档 §7.1 的 290 根预热要求，预热后只剩约 212 根）：研究组合不纳入
   （`_optimize.py` 的 `POOL`），但 2026-11-10 用户指定它进执行范围 —— **它的信号只能当参考，
   不能当统计证据**。
4. **`("向下","未定") = 0.2` 是承重件**，不要改成 hold（文档 §7.11：MDD −29.6% → −34.4%）。
5. **回调加仓几乎不生效**：两版在 6 条腿上的调仓数差 2~6 次、年化差 0~1.0pp，方向不一致。
   原因就是第 1 条 —— 回调撑不到 15 日。

## 5. 优化：已落地、被否掉、与剩余工程债

四份证据：`research/_v13_sweep.md`（单参数扫描）、`_v13_optimize.md`（组合/分段/v5 对比）、
`_v13_walkforward.md`（样本外）。口径：**文档原版**（回调格 `hold`）。

**已落地**

| 改动 | 效果（6 腿组合） | 依据 |
|---|---|---|
| 兜底 `−15%` → **`−10%`** | 年化 9.36%→9.22%、回撤 −12.66%→**−10.40%**、夏普 0.87→**0.95** | `_optimize.md` §1 |
| 组合配权 等权 → **等波动**（滚动 60 日） | 年化 9.22%→8.41%、回撤 −10.40%→**−8.96%**、夏普 0.95→**1.09** | `_optimize.md` §1 |
| **A500 退出研究组合**（仅单列） | 0.84 年样本，进组合只贡献噪声 | `_optimize.md` §1 |
| **口径定稿为文档原版**（回调格 = `hold`，2026-11-10） | 文档版 9.26% vs 回调加仓 9.32%、夏普都 0.95 → 无差异，按规则源取 `hold` | `_sweep.md` §1 |

**被数据否掉（记录下来，避免下次重试）**

- **自适应迟滞**（按 MA20 穿越频率缩放 h）：**原提案方向无增量** —— 组合 +8.87% / −10.40% / 0.91，
  比只改兜底的 +9.22% / −10.40% / 0.95 年化低 0.35pp、夏普低 0.04。**反向**（穿越频繁→迟滞长）
  是 +9.83% / −10.69% / **1.02**，夏普首次超过 0.95，但只看 6 段里 3 段赢，而且增益来自
  "h 被拉到 17~18"（本质是更长迟滞）而非"自适应"本身 → 列为**待验证**，不落地。
  见 `_optimize.md` §1「P1c 方向检验」。
- **`h=20`**：夏普 0.91，低于 `−10%` 单改的 0.95。
- **`confirm=5`（力度确认 2 日 → 5 日）**：样本内看是平台（c=3~8 年化 8.4~9.1、回撤单调改善，
  c=2 是整条曲线的低点），但 walkforward 里对沪深300 只有 2/3 窗口改善、黄金有升有降、
  其余腿无差别 → **样本外无一致增益，不采纳**（`rule.CONFIRM_DAYS` 仍是 2）。
  教训：单看「邻域是否平台」还不够，平台也可能只是同段样本的平滑。

**剩余工程债（仍没做，别当成已解决）**

- **反向自适应迟滞待验证**：样本内 +9.83% / −10.69% / 夏普 1.02，但只 3/6 段赢固定 h=15，
  且增益等价于"把 h 拉到 17~18"。要落地必须先过分段 + walkforward 两道闸。
- **分段只有 2/6 段跑赢 v5**（2015、2018 赢；2020/2022/2024-09/2025-26 输）——
  优势集中在长熊与股灾，牛市必然落后。这是风格，不是缺陷，但不能说成"全面更优"。
- **样本外 walkforward 已做，结论是「只有沪深300 通过」**（`research/_v13_walkforward.md`，
  2026-11-10）：参数冻结 `h=15 / confirm=5 / 兜底−10%`，按各腿自身样本等分，第 2 窗起算样本外。
  沪深300 **2/3** 窗口夏普赢恒持（唯一输的那窗只差 0.04）；黄金 2/3；
  恒生科技表面 1/1，但它只有 1 个样本外窗口且正是 2024-09 后的港股反弹段，**不构成证据**；
  纳指100 / 标普500 各 1/3、科创50 0/1 → 与「快出慢进不适合牛长熊短市场」一致。
  另：每折重新选出的 `(h, confirm)` 在 h10c3 / h10c5 / h15c7 / h20c7 之间乱跳，
  说明「最优参数」不存在，只能用固定值。
- **成本低估**：单边 5bp 未计 QDII 腿（513100 / 513500）的溢价与冲击。
- **现金收益口径**：1.4% 货基 vs 文档纯价格指数 → 年化系统性偏高约 `空仓时长 × 1.4%`
  （当前许可均值 53% → 约 +0.66pp）。

## 6. 每日操作

执行范围 = `rule.CORE_LEGS`（中证A500 + 沪深300）。§1 只列这两个标的的操作，§2 的全腿状态表
用「范围」列区分 **核心 / 观察 / 诊断**，其余腿的许可变化只在 §1 末尾以「不执行，仅供观察」提示；
等波动配权也只在这两个标的之间归一（`combo_target` = 核心标的的目标暴露合计）。

```powershell
# 每日：今日需操作的腿 + 全腿状态 + 近 120 日动作流水
python strategies/vol_legs/v13_quad_9grid/daily/_daily_scan.py
#   → daily/_v13_daily.md / _v13_daily.json

# 图：只画执行范围（价格 + 三均线 + 背景色带 + 许可阶梯 + 操作点）+ 许可热力图
python strategies/vol_legs/v13_quad_9grid/research/_plot_grid.py
#   → research/_v13_grid_{a500,hs300}.png + _v13_grid_heatmap.png
```

输出结构（对齐 v5 的 `daily/`）：

| 段 | 内容 |
|---|---|
| §1 今日需操作 | 只有许可变化的腿；兜底触发时显式写「T+1 减半、T+2 到 20%」 |
| §2 全腿状态 | S / 背景 / 力度 / 格子 / 今日与昨日许可 / 兜底 / 组合权重 / 目标暴露 |
| §3 动作流水 | 近 120 个交易日的每次调仓（幅度） |

> 「目标暴露」= 等波动权重 × 许可，是**上限**语义；许可只约束上限，不给目标仓位。
> 表格里的许可是"当日仍可持有"的值，兜底两笔减仓在途时要看 §1。
