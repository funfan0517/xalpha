## 一句话

以**高量日为锚**（D0）→ 定 3 天观察窗（D8）→ 窗内按 **价相对支撑 S / 压力 R + 量态 + K 线形态**
给 **观 / 减 / 清 / 上车**。原文是**个股短线的持仓风控清单**，不是买入信号发生器。

## 为什么这个变种必须换数据源

这是 V1~V13 里**唯一不能在场外净值口径下实现**的变种：
全部判据建立在**成交量与影线**上（D1 高量 / D3 实体上影下影 / D8 观察窗），而场外复权净值
只有一条收盘净值 —— 没有量、没有开高低，规则一条也算不出来。

→ 只能走**场内 ETF 前复权日线 OHLCV**（与 `v1_2_ma_trend_pv` 同源）。
代价有两条，都写在报告里：① 美股两腿只能用人民币 ETF 代理（多一层汇率）；
② 停牌/一字板会挡住成交（已实现「顺延并单独计数」）。

2026-11-07 把 OHLCV 库从 `v1_2_ma_trend_pv/data/_ohlcv.json` 上移到
**`strategies/vol_legs/data/_ohlcv.json`**（家族级共享，判据是「别的变种也会用」，
AGENTS.md §8.1）。v1-2 与本变种共用一份，不各存一份漂移。

## 规则（六层，全部落在 `vol_notes.py`）

| 层 | 实现 | 参数 |
|---|---|---|
| 高量锚点 D0 | **D1c**：`V ≥ 前 60 日 95% 分位`（默认）；D1「量>前三日最大」、D1b「2×MA20」作对照 | `CFG['high_vol_mode']` |
| 观察窗 D8 | 高量日后 `D0+1 … D0+3`，**到期不重置、不滚动** | `window_days` |
| 支撑 S | 最近一个高量日的**实体低点** `min(O,C)`（不是影线低点）；没有新高量日就一直是它 | `support` |
| 压力 R | 最近 3 个高量日的**实体高点** `max(O,C)` | `resist_n_highvol` |
| 上车 | B1 支撑上方底分型 / B2 支撑上方红三兵 / B3 上影线被阳实体突破 / B4 = B3 且前一日高量 | §3.1 |
| 减仓 | S3 窗内高低点下移 / S4 压力下顶分型 / S5 压力下绿三兵 / S6 上影碰压力过不去 / S7 连红≥4 见放量阴 / S8 缩量下影次日阴 / S9 上涨趋势高量大长腿 / T7 价不过高量过高 | §3.2/§3.4 |
| 清仓 | S1 观察窗内 `C < S` / S10 大量次日阴 | §3.2 |
| 观望 | S2 破位次日收阳（不追回）/ W1 高量当天不加仓；W2~W8 只统计不产动作 | §3.3 |
| 冲突消解 | `清仓 > 减仓 > 买入 > 观望`（默认）；`CONFLICT_MODE="watch"` 切 W9 原意 | `CFG['priority']` |
| 仓位 | 清仓 0 / 减仓 ×0.5 / 观望不变 / 上车 ×1.0 / 重仓 ×1.5（**受腿上限约束 → 截断 1.0**） | `CFG['position']` |

**三个实现裁定**（数字对不上时先看这三条）：
1. **「重仓 ×1.5」被截断**：家族不变量是「目标带 = 该腿上限」，1.5 倍带顶穿上限。
   默认 `POS_CAP=1.0`，B4 与 B3 实际仓位相同，差别只在信号层；`HEAVY_UNCAP=True` 是诊断档。
2. **S 的有效期 ≠ 观察窗**：S/R 取「最近的高量日」，观察窗只约束 S1/S3/S2 三条。
3. **W9「矛盾=观望」不建分支**：规格 §4 的优先级已经把卖出类提前拦下，
   本实现按 §4 执行并要求统计**冲突率**（实测 4%）；想验证 W9 原意切 `CONFLICT_MODE="watch"`。

## 回测结论（细节见 `backtest/_v13_volume_bt.md`）

**口径**：七腿场内 ETF · 2013-07 ~ 2026-11 · **T 日收盘信号 → T+1 开盘成交** · 单边 7bp · 空仓计货基 1.40%。

| 上线池（科创50 / 恒生科技 / 黄金，2021-08~2026-11） | 年化 | 最大回撤 | 夏普 | 平均投入 |
|---|---:|---:|---:|---:|
| **V13 成交量清单** | **+1.83%** | **-18.67%** | 0.05 | 60% |
| 带权买入持有（同池同权重） | +11.06% | -31.02% | 0.60 | 100% |
| 同曝光买入持有（固定 60%） | +7.39% | -19.04% | 0.62 | 60% |

1. **定义层的断言成立**：D1 在七条腿上的触发频率 **25.0%~28.5%**，与 iid 理论 25.0% 无差别
   （复现了规格 §7 对沪深300 指数的实测 25.8%）—— 原文的锚点在定义层**不含异常信息**。
   换 D1c 分位后年化 +1.87% → +1.83%（-0.04pp），但换手 43.7x → 30.8x。
   **换判据是可测性的前提与降换手的手段，不是收益来源。**
2. **收益层的断言不成立**：上线池 **0/3** 条腿跑赢「同曝光买入持有」。
   回撤看着比满仓浅（6/7 条腿），但**同曝光口径下 -18.67% vs -19.04% —— 持平**。
   即：**压仓位不需要这套规则**，而同样的投入水平上它的择时是负贡献（-5.57pp/年）。
3. **规格 §8 的边界判断是对的**：宽基（`563360`/`510300`）与 QDII（`513100`/`513500`）
   在失真检验里量价相关性最低（corr +0.22 vs 上线池 +0.43），收益上 0/4 跑赢同曝光。
   上线池只留 `588000` 科创50 / `513180` 恒生科技 / `518880` 黄金（后者文档未点名，按「谨慎可试」）。
4. **信号层方向对、强度不足**：买入类 D+60 均值 **+2.76%** vs 减/清类 **+1.17%**，
   但差（1.59pp）小于组内离散度（买入 +2.55%~+3.13%、减/清 -0.10%~+2.57%）。
5. **硬伤是动作频率**：逐腿 **55 次/年**、换手 **32x/年**、成本拖累 **2.58pp/年**；
   9 条减仓规则在震荡市里反复触发。加「同向动作间隔 5 日」限速只能把成本压到 +1.56%，救不出正超额。
6. **唯一有正面价值的是「冲突时不动」**：`CONFLICT_MODE="watch"` 年化 +3.17%（+1.34pp）、
   换手降到 29.6x —— 原文的元规则在这一层上省钱。
7. **降频能抹平负 alpha，但造不出正 alpha**（报告 §8b）：日频 30.8x 换手、2.58pp 成本；
   改成 5/10/20 日调仓后年化 +5.65% / +9.30% / +5.48%，10 日档看似跑赢同曝光。
   但**把「哪一天调仓」错开 0..N−1 日，相位中位只有 +7.51%（N=10，标准差 2.0pp）**，
   与同曝光 +7.39% 持平 —— 单相位读数不可引用（`CFG` 的 `REBAL_EVERY` 就是这个诊断开关）。

> 结论落点：**这是持仓者的「今天该不该减」检查表，不是择时策略**。
> 正确的用法是把 W1/W9 这类**约束**（高量当天不加仓、矛盾不动）装进现有腿，
> 而不是把整套清单当独立变种上线（v12 对「破位就走」的证伪是同一个答案的第二次出现）。
