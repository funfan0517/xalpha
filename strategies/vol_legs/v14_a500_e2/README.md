## 规则

`(V3 MACD+BOLL 开口突破 + V12 八态趋势许可) / 2` ——
两条**跨信号族**的信号等权：V3 要 MACD 零轴上 + 布林开口（追涨），
V12 是 regime × 位置 × 速度 × 量能的许可上限（含按腿波动层）。t 日收盘出决策，**t+1 收盘成交**；
空仓按货基 1.40% 计息。

> ⚠ **V12 那一半会随 v12 的规则变化**：2026-11-19 起 v12 的波动层按腿配置
> （A500 走 ER20 自适应 20%/10% + 10pp/5日死区，见 `v12_octo_trend/research/er_vol_layer/`），
> 所以本策略的权重会跟着变。要冻结旧口径，只能在这里另存一份 v12 的历史实现。

逐日权重来自各变种**原生引擎**，经 `strategies/vol_legs/_top3_bridge.py` 隔离加载，不重写规则。
成本为**研究同尺口径**：单边 10bp（不是该腿原生费率），故绝对数与 `best_by_leg.md` 不可直接对账。
回测先在全样本上算信号、再截预热窗（状态层不会在窗口起点被重置），故数字与研究报告
「先截窗再算信号」略有差异；**相对结论与超越关系不变**。
