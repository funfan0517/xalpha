# V1 变种 · MA20 穿越（六腿逐腿择时）

`vol_legs`（波动资产操作规则 v1.3）的**第一个变种策略**，原为 `tech_indicators/v8_ma20`，
2026-10-28 迁入本目录，**标的池与口径全部改为主策略的六腿**。

一句话：主策略回答「**组合层仓位带怎么摆**」（阶梯 / 年线闸门 / 再平衡），
本变种回答「**每条腿什么时候下车**」（净值跌破 MA20 就走，站上再回）。

## 1. 规则（0/1）

| 方向 | 条件 |
|---|---|
| **买入** | 场外复权净值上穿 MA20（今值 > MA20 且 昨值 ≤ 昨日 MA20） |
| **卖出** | 场外复权净值下穿 MA20 |
| **持有** | 未发生穿越 → 维持原仓位（0/1，不加减仓、不止损止盈、**无 MA60 牛熊过滤**） |

- 「上穿买 / 下穿卖 + 其余维持」在数学上等价于「净值在 MA20 上方即持有」的状态序列
  （首次站上必是上穿），实现用状态式，无逐日循环。
- 参数：`ma20.py::MA_WIN = 20`。

## 2. 池与口径（与主策略**完全一致**）

| 维度 | 取法 | 来源 |
|---|---|---|
| 标的池 | `rule.LEG_ORDER` 六腿：A500 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金 | `strategies/vol_legs/rule.py::LEGS` |
| 价格序列 | 场外**复权净值**（累计净值，含分红再投 / 汇率 / 跟踪误差） | `data.series_for_leg(leg)` |
| 成交 | T 日盘后算信号 → **T+1 净值成交**（`pos = sig.shift(1)`） | 主策略 §2.4 |
| 空仓 | 按货基 `rule.CASH_ANNUAL`（1.40%）逐日计息 | `ma20.CASH_DAILY` |
| 组合层权重 | 按目标带归一化：A500 .125 / 纳指 .25 / 标普 .25 / 科创50 .0625 / 恒生科技 .0625 / 黄金 .25 | `ma20.W` |

不另立池、不做 A/B 分级；增删腿只改 `rule.LEGS`，本变种自动跟随。

## 5. 回测结论（场外净值口径 · 2026-10-28）

逐腿（各自 MA20 成形日起，样本 5~17 年不等）：

| 腿 | 样本 | 年化 | 回撤 | 买入持有年化 | 买入持有回撤 | 年化差 | 年笔数 | 扣费后年化差 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 科创50 | 2021-03 ~ 2026-10 | **+14.94%** | -24.66% | -0.27% | -58.34% | **+15.21pp** | 13.0 | +15.21pp |
| 恒生科技 | 2021-08 ~ 2026-10 | -6.14% | -43.06% | -10.71% | -53.13% | +4.57pp | 16.0 | +4.57pp |
| 中证A500 | 2009-07 ~ 2026-10（含桥接） | +5.25% | -33.77% | +4.51% | -43.43% | +0.74pp | 13.6 | +0.74pp |
| 黄金 | 2013-08 ~ 2026-10 | +6.78% | -23.46% | +9.29% | -30.84% | -2.51pp | 14.3 | **-9.51pp** |
| 标普500 | 2012-06 ~ 2026-10（含桥接） | +6.17% | -25.25% | +13.45% | -30.50% | -7.28pp | 13.8 | **-13.58pp** |
| 纳指100 | 2012-08 ~ 2026-10 | +8.63% | -19.48% | +17.19% | -29.47% | -8.56pp | 13.5 | **-14.36pp** |

组合层（六腿共同窗口 2021-10 ~ 2026-10，按带权归一化，满仓 = 40pp）：

| 组合 | 年化 | 最大回撤 | 夏普 | 平均投入 |
|---|---:|---:|---:|---:|
| V1 择时（不计费） | 8.10% | **-9.20%** | **0.86** | 57% |
| V1 择时（扣申赎费） | **1.42%** | -13.56% | 0.00 | 57% |
| 静态带（恒定持有） | **11.08%** | -17.45% | 0.81 | 100% |
| 六腿等权 | 6.79% | -23.23% | 0.37 | 100% |

四条结论：

1. **降回撤有效**：六腿回撤**全部**更小（组合层 -9.2% vs -17.5%），夏普 0.86 vs 0.81。
   这是它唯一稳定的贡献。
2. **增收益只在「买入持有本来为负」的腿上**：科创50（-0.27% → +14.94%）、恒生科技（-10.71% → -6.14%）；
   美股与黄金单边上涨，MA20 择时只能少赚。
3. **成本是决定性变量**：逐腿 13~16 笔/年，A 类腿（`270042` / `017641` / `000216`）每笔往返 0.6%，
   **组合层年化从 8.10% 掉到 1.42%** —— 这条规则放在场外基金上，成本足以吃掉全部超额。
4. **和主策略不是替代关系**：主策略的阶梯/闸门本身就是低频择时；本变种更适合当「已建仓后该不该临时下车」的参照。

## 6. 已知边界

- **成交时滞**：QDII 腿净值本身滞后 T+1~T+2，实盘信号比回测更慢一步；回测已按 T+1 成交折算，但仍偏乐观。
- **桥接段**：A500（`000051`）/ 标普（`050025`）的早期样本用同类老基金桥接，只用于撑 MA 窗口，不是本基金业绩。
- **C 类销售服务费未计**（`023299` / `011609` / `012805`，约 0.2%/年），三条 C 类腿的扣费后数字偏乐观。
- **未计**：大额限购、QDII 额度关闭顺延、赎回确认时滞。
- 组合层只有 2021-10 起的共同窗口（受恒生科技联接 `012805` 成立日限制）。
