# V1 · 量价家族（价格 × 成交量）· 波动资产七腿逐腿择时

`vol_legs`（波动资产操作规则）的**第 1 号变种家族**。原 `v1_ma20`（纯 MA20 穿越）在
**2026-11-07** 改组为「量价」家族：同一个七腿池、同一个层次（逐腿进出时点），
里面并排放**两条口径不同、要回答的问题也不同**的子策略。

一句话区分家族与主策略：
**主策略回答「组合层仓位带怎么摆」**（阶梯 / 年线闸门 / 再平衡 / 季度），
**本家族回答「每条腿什么时候该上车、什么时候该下车、上多少」**。两者可叠加，不可替代。

## 1. 两条子策略

| | **V1-1**（`v1_1_ma20/`） | **V1-2**（`v1_2_ma_trend_pv/`） |
|---|---|---|
| 一句话 | 净值在 MA20 上方就持有（**纯价基线**） | 20/60/250 + 量能 + ATR/ADX（**量价纪律**） |
| 信号口径 | 场外**复权净值** | 场内 ETF **前复权日线 + 成交量** |
| 仓位 | 0 / 1 全仓 | 0 ~ 100%，`2% 风险 ÷ 止损幅度` |
| 止损 | 无（只有下穿 MA20 离场） | 结构性 ATR 止损 + 移动保护 |
| 换手 | 13~16 笔/年 | 1~2 笔/年 |
| 单边成本 | 场外申购 0.10% / 赎回 0.50% | 场内 7.5bp（免印花税） |
| 结论 | 降回撤有效，**成本吃光全部超额**（组合层 7.79% → 0.55%） | 成本可忽略，但**也没跑赢同曝光买入持有**（-0.16pp） |
| 每日脚本 | 有（`daily/_daily_scan.py`） | 有（`daily/_daily_scan.py`） |
| 上看板 | 否（2026-10-30 起 `daily.enabled=false`） | 否（新建，`daily.enabled=false`） |

### 为什么要分成两条而不是一条

1. **口径不能合并**：量价规则必须有成交量，而场外复权净值**没有成交量**。
   V1-2 因此只能走场内 ETF；V1-1 保留了"你账户里真正拿到的净值"这条口径。
   两条腿的收益**不可相减**，只能各自与同期买入持有比。
2. **对照价值**：V1-1 是"多了一个量能维度到底值不值"的对照组 —— 答案是
   **值在换手（成本）上，不值在收益上**（详见各子策略 README）。

## 2. 共同点（家族级纪律）

- **池**：`rule.LEG_ORDER` 七腿（中证A500 / 沪深300 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金），
  权重按 `rule.LEGS[*]["band"]` 归一化（Σ=40pp）；增删腿只改 `rule.py`。
- **空仓计息**：未投部分按货基 `rule.CASH_ANNUAL`（1.40%）逐日计息，不假设 0 收益。
- **成交纪律**：T 日收盘算信号、`pos = *.shift(1)` 生效（家族统一口径）。
- **不做 A/B 分级**：七腿全部出信号。

## 5. 家族结论（2026-11-07）

- **降回撤靠"降暴露"就够了**：两条子策略的回撤都远小于买入持有（V1-1 -9.2%、V1-2 -5.1%
  vs 静态带 -20.4%），但这是因为它们平均只在场 57% / 15%；
- **超额没有证据**：V1-1 扣费后组合年化 0.55%，V1-2 与同曝光买入持有差 -0.16pp；
- **真正的差别是换手与成本**：13~16 笔/年 → 1~2 笔/年，年化拖累从 -7pp 量级降到 -0.2pp；
- **量能这一维没有正的边际信息**（`v1_2_ma_trend_pv/research/attrib/_attrib.md`）：
  关掉量能门槛年化 **+1.34pp**、夏普 0.59→0.95；四层持有型过滤器（MA20 → +年线 → +ADX → +量能）
  的择时超额**全为负**（-2.51 → -1.14pp），「+量能」一步的增量仅 +0.25pp；
- **决定结果的是暴露，不是信号**：风险预算 2%→10% 年化 +1.99pp（夏普不动），
  「半底仓 + 半信号」把平均投入从 15% 抬到 32%、年化到 4.48%，但同曝光后仍 -1.02pp —— 只是加了杠杆；
- 所以本家族的合理用法是**当作纪律模板/参照系**（"已建仓后该不该临时下车"），
  而不是当作能替代主策略的收益引擎；想降回撤，直接用主策略的阶梯/闸门更省事也更高收益。
