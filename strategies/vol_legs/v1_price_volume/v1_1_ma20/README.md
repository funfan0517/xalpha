# V1-1 · MA20 穿越（七腿逐腿择时 · 纯价基线）

`V1 量价家族`（`../README.md`）的**第一条子策略**，也是家族里唯一的**纯价基线**：
只看价格，不看成交量。原名 `v1_ma20`（原 `tech_indicators/v8_ma20`，2026-10-28 迁入 `vol_legs`），
**2026-11-07 家族改组**：`v1_ma20/` → `v1_price_volume/v1_1_ma20/`，规则本体未改。

一句话：主策略回答「**组合层仓位带怎么摆**」，本子策略回答「**每条腿什么时候下车**」
（净值跌破 MA20 就走，站上再回）。它与 V1-2（`../v1_2_ma_trend_pv/`）的分工见家族 README。

## 1. 规则（0/1）

| 方向 | 条件 |
|---|---|
| **买入** | 场外复权净值上穿 MA20（今值 > MA20 且 昨值 ≤ 昨日 MA20） |
| **卖出** | 场外复权净值下穿 MA20 |
| **持有** | 未发生穿越 → 维持原仓位（0/1，不加减仓、不止损止盈、**无 MA60 牛熊过滤**） |

- 「上穿买 / 下穿卖 + 其余维持」在数学上等价于「净值在 MA20 上方即持有」的状态序列
  （首次站上必是上穿），实现用状态式，无逐日循环。
- 参数：`ma20.py::MA_WIN = 20`。

## 2. 池与口径（与主策略**完全一致**）

| 维度 | 取法 | 来源 |
|---|---|---|
| 标的池 | `rule.LEG_ORDER` 七腿：A500 / 沪深300 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金 | `strategies/vol_legs/rule.py::LEGS` |
| 价格序列 | 场外**复权净值**（累计净值，含分红再投 / 汇率 / 跟踪误差） | `data.series_for_leg(leg)` |
| 成交 | T 日盘后算信号 → `pos = sig.shift(1)`（家族统一口径） | 主策略 §2.4 |
| 空仓 | 按货基 `rule.CASH_ANNUAL`（1.40%）逐日计息 | `ma20.CASH_DAILY` |
| 组合层权重 | 按目标带归一化：A500 .0625 / 沪深300 .0625 / 纳指 .25 / 标普 .25 / 科创50 .0625 / 恒生科技 .0625 / 黄金 .25 | `ma20.W` |

不另立池、不做 A/B 分级；增删腿只改 `rule.LEGS`，本子策略自动跟随。

## 5. 回测结论（场外净值口径 · 数据至 2026-11-06）

逐腿（各自 MA20 成形日起，样本 5~17 年不等）：

| 腿 | 样本 | 年化 | 回撤 | 买入持有年化 | 买入持有回撤 | 年化差 | 年笔数 | 扣费后年化差 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 科创50 | 2021-03 ~ 2026-11 | **+14.85%** | -24.66% | -0.25% | -58.34% | **+15.10pp** | 12.9 | +15.10pp |
| 恒生科技 | 2021-09 ~ 2026-11 | -6.41% | -43.06% | -9.41% | -53.13% | +3.00pp | 16.1 | +3.00pp |

组合层（七腿共同窗口 2021-09 ~ 2026-11，按带权归一化，满仓 = 40pp）：

| 组合 | 年化 | 最大回撤 | 夏普 | 平均投入 |
|---|---:|---:|---:|---:|
| V1-1 择时（不计费） | 7.79% | **-9.20%** | **0.83** | 57% |
| V1-1 择时（扣申赎费） | **0.55%** | -14.07% | -0.11 | 57% |
| 静态带（恒定持有） | **10.25%** | -17.45% | 0.73 | 100% |
| 七腿等权 | 5.47% | -22.91% | 0.28 | 100% |

四条结论：

1. **降回撤有效**：七腿回撤**全部**更小（组合层 -9.2% vs -17.5%），夏普 0.83 vs 0.73。这是它唯一稳定的贡献。
2. **增收益只在「买入持有本来为负」的腿上**：科创50（-0.25% → +14.85%）、恒生科技（-9.41% → -6.41%）；
   美股与黄金单边上涨，MA20 择时只能少赚。
3. **成本是决定性变量**：逐腿 13~16 笔/年，A 类腿（`270042` / `017641` / `000216` / `000051`）每笔往返 0.6%，
   **组合层年化从 7.79% 掉到 0.55%** —— 这条规则放在场外基金上，成本足以吃掉全部超额。
   （V1-2 存在的理由之一就是这个问题：换到场内、并把笔数降到 1~2 笔/年。）
4. **和主策略不是替代关系**：主策略的阶梯/闸门本身就是低频择时；本子策略更适合当
   「已建仓后该不该临时下车」的参照。

## 6. 已知边界

- **成交时滞**：QDII 腿净值本身滞后 T+1~T+2，实盘信号比回测更慢一步；回测已按 `pos = sig.shift(1)` 折算，但仍偏乐观。
- **桥接段**：A500（`023299`←`000051`）/ 标普（`017641`←`050025`）的早期样本用同类老基金桥接，
  只用于撑 MA 窗口，不是本基金业绩。
- **C 类销售服务费未计**（`023299` / `011609` / `012805`，约 0.2%/年），三条 C 类腿的扣费后数字偏乐观。
- **未计**：大额限购、QDII 额度关闭顺延、赎回确认时滞。
- 组合层只有 2021-09 起的共同窗口（受恒生科技联接 `012805` 成立日限制）。
