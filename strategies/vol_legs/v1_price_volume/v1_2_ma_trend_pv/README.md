# V1-2 · 20/60/250 量价趋势跟随（七腿逐腿择时）

`vol_legs` → **V1 量价家族** 的第二个子策略。家族说明见 `../README.md`，纯价基线见 `../v1_1_ma20/`。

一句话：**年线（250）定牛熊、60 日线控生死、20 日线找波段**；用扣抵预判均线拐头、
用放量确认进场、用 ATR/ADX 过滤震荡、用风险预算换算仓位、用小止损换大盈亏比。**不预测，只跟随。**

## 1. 规则（原始描述 -> 实现）

| 环节 | 原始描述 | 实现 | 参数 |
|---|---|---|---|
| 大环境 | 股价在年线上方，年线走平或上倾 | `close > MA250` 且 年线扣抵向上 | `SMA_SLOW=250` |
| 均线扣抵 | 比较最新价与 N 天前被扣掉的价格 | `up_N = close > close.shift(N)` —— 数学上**等价于** `MA_N` 今日上行（`MA_t−MA_{t−1} = (P_t−P_{t−N})/N`） | — |
| 波段/生死线 | 20 日找切入，60 日控生死 | `MA20 > MA60`（中期多头排列）+ 站上/跌破判定 | `SMA_FAST/MID=20/60` |
| 量能 | 成交量 ≥ 20 日均量 1.5 倍 | 近 3 日内出现 `量比 ≥ 1.5` | `VOL_MULT=1.5` |
| 趋势激活 | ADX > 25 激活，ADX < 20 休眠 | 突破型要求 `ADX ≥ 25`；任何建仓要求 `ADX ≥ 20` | `ADX_ON/OFF` |
| 建仓①突破 | 放量上穿 60 线（20 线金叉 60 线） | 近 5 日上穿 MA60 且 收盘 ≥ MA60 + max(1ATR, 2%) | `BRK_ATR/BRK_PCT` |
| 建仓②回踩 | 缩量回踩 60/20 线托举，放量中阳站回 20 线 | 近 10 日回踩到 MA20 附近（≤+1%）+ 站上 MA20 + 今日收盘上行 + 放量确认 | `TOUCH_PCT` |
| 建仓③粘合 | 三线粘合后放量长阳脱离 | 近 10 日三线极差 ≤ 2.5%，放量长阳（≥2%）站上三线最高 | `SQUEEZE_*` |
| 仓位 | 单笔风险 ≤ 2%，仓位 = 风险 ÷ 止损幅度 | `size = min(1, 2% / stop_pct)`，上限 = 该腿额度 | `RISK_PCT/MAX_POS` |
| 初始止损 | 回踩低点下方 / 有效跌破 60 线（3%~5%） | `min(close − 1.5ATR, 近10日最低 − 0.5%)`，夹在 [3%, 8%] | `STOP_ATR` |
| 移动保护 | 沿 20 线持有，跌破且威胁 60 线时减仓 | 跌破 MA20 **且** 距 MA60 ≤2% 减半，站回恢复；浮盈 ≥4ATR 后叠加 `峰值 − 6ATR` 移动止损 | `THREAT_GAP/TRAIL_*` |
| 清仓 | 放量击穿 60 线 / 年线拐头向下 | 止损、放量或有效（>2%）跌破 MA60、年线转弱（价在年线下且年线向下） | `BREAK_MA60_PCT` |
| 摩擦成本 | 双边佣金 + 印花税 + 滑点 | 场内 ETF **免印花税**：单边 7.5bp（佣金万 2.5 + 滑点 5bp） | `COST_ONE_WAY` |
| 冷却 | —（工程约束） | 平仓后 5 个交易日不再开新仓 | `COOLDOWN` |

两处与原文的**工程化偏差**（方向不变，只为让规则能跑出信号）：

1. 「放量中阳**同一天**站回 20 线」拆成「近 3 日放量确认 + 今日收盘上行 + 近 10 日回踩过 20 线」。
   严格同日实测 **2 笔 / 11 年**（`rvol≥1.5` 的那天通常已经把价格顶到 MA20 上方很远，不会再"穿"）。
2. 「20 日线金叉 60 日线」在回踩路径用 `MA20 > MA60`；在突破路径放宽到「20 线在 60 线 −1% 以内」。
   刚上穿 60 线时 20 线必然还在下方，要求严格金叉会让突破型信号**全部消失**（实测 0 笔）。

## 2. 数据口径（与 V1-1 最本质的分歧）

- **必须用场内 ETF**：量价规则要有成交量，而**场外基金净值没有成交量**。
  信号序列 = `xa.get_daily` 的前复权日线（O/H/L/C/V），本地缓存 **`data/_ohlcv.json`**（仓库级）
  （与 `tech_indicators/v18_volume_notes` 共用，判据是「别的策略也会用」，见 AGENTS.md §8.1；
  2026-11-09 从 vol_legs 家族级再上移），脚本 `ohlcv.py` 增量刷新。
- 七腿信号码：`563360`（A500）· `510300`（沪深300）· `513100`（纳指，**人民币代理**）·
  `513500`（标普，**人民币代理**）· `588000`（科创50）· `513180`（恒生科技）· `518880`（黄金）。
- 美股两腿用人民币 ETF 代理而非美元指数 `.NDX/.INX`：美元指数本地库**只有收盘价、没有成交量**。
  代价是信号里掺了汇率 —— 这是"要量"必须付的第二笔代价。
- 执行也建议走**场内 ETF**（与信号同源、单边 7.5bp）；走场外联接等于用"没有量的净值"执行"用量算的信号"，
  且申赎成本高一个量级。

组合层（并集窗口 2014-01 ~ 2026-11，12.8 年；缺数据的腿不占权重、权重在可用腿间归一）：

| 组合 | 年化 | 最大回撤 | 夏普 | 平均投入 |

五条结论（照数据说）：

1. **回撤压得住**：七腿回撤中位 -8.8% vs 买入持有 -33.3%，**7/7 全部更小** ——
   但这是"平均只在场 11% 额度"换来的，不是择时本事的证据。
2. **同曝光口径下择时≈中性**：3/7 条腿加分，中位 **0.00pp**（最好 科创50 +2.23pp，最差 纳指100 -1.16pp）。
3. **组合层不及"固定同额投入"**：+3.20%（扣费）vs 同曝光买入持有 +3.36% → **-0.16pp**，
   夏普 0.59 vs 0.96。即：在这七条长期上行的宽基/商品 ETF 上，**这套量价择时没能跑赢"只按同样暴露持有"**。
4. **分市结构很干净**：熊市里策略的日均收益恒等于货基（+0.6bp）—— 年线与 ADX 休眠确实把它挡在熊市之外；
   代价是牛市也常常空仓（牛市日均 +1.4~2.8bp vs 买入持有 +3.4~9.3bp）。
5. **成本不再是问题**（与 V1-1 的关键差别）：年笔数 1~2 笔，累计成本 0.3%~2.7%，年化拖累 0.06~0.24pp；
   V1-1 的 13~16 笔/年会把超额全部吃光。**低频是它唯一明确优于 V1-1 的地方。**

## 3b. 归因与优化建议（`research/attrib/_attrib.md`）

把「哪一维在起作用」拆开测了一遍（全部离线、同一份缓存）：

| 实验 | 结果 | 读法 |
|---|---|---|
| 成交再滞后一天 | +3.20% → **+3.41%**（夏普 0.59 → 0.64） | 回测**没有靠**「当天收盘成交」占便宜，不必加保守系数 |
| **关掉量能门槛** | +3.20% → **+4.54%**（夏普 0.59 → **0.95**） | 量能门槛是**负贡献**：它让信号变少，没让它变准 |
| 关掉 ADX 休眠 | +3.20% → +3.93%（夏普 0.77） | 同上，ADX 只是把交易数从 79 降到 100→79，收益跟着降 |
| 关掉移动止损 + 减半 | +3.33%（回撤明显恶化） | 唯一**确实降低回撤**的部件，但代价是收益 |
| 风险预算 2%→5% / 10% | +4.97% / +5.19%（回撤 -8.7% / -10.4%） | 只是**加杠杆**：收益和回撤同步放大，夏普几乎不动 |
| 持有型过滤器 ①→④（MA20 → +年线 → +ADX → +量能） | 择时超额 -2.51pp → -1.95pp → -1.39pp → **-1.14pp** | **四层全是负超额**；「+量能」这一步的增量只有 +0.25pp（噪声量级） |
| 半底仓 + 半信号（底仓 50% + 信号 50%） | +4.48% / 回撤 -9.14% / 夏普 0.62，平均投入 15%→32% | 收益变大**只是因为暴露变大**；同曝光后仍 **-1.02pp** |

**结论一句话**：**这套「量价」在日线 ETF 上没有正的边际信息** —— 量能看起来像确认、
实际是滞后；所有「让它更保守」的开关都在同步砍收益。真正决定结果的是**暴露多少**（风险预算 / 底仓比例），
而那是仓位管理问题，不是信号问题。

**因此优化方向只有三条**（按性价比）：

1. **不要把它当收益引擎**，当「低暴露纪律模板」：止损纪律、风险预算、ADX 休眠这套骨架可复用，
   但别指望它跑赢同曝光基准；
2. **想降回撤就用主策略的阶梯/闸门**：满仓静态带 12.8 年 +14.16% / -20.37% / 夏普 0.95，
   砍半暴露后仍有 ~8.5%/年 —— 比绕道日频择时高效得多；
3. **要真做「量价」，把量能放到横截面**（哪条腿在放量 → 加仓），而不是时序择时：
   时序上量能增量 ≈ 0，横截面未测（需要多标的池，属另一个课题）。

## 6. 已知边界

- **口径不可混算**：收益是场内 ETF 价格口径（无分红再投、含折溢价与汇率），落到场外账户会不同；
  美股两腿用 513100 / 513500 代理，信号里掺汇率。
- **样本长度差异大**：A500 只有 1 年（零信号）；科创50 / 恒生科技 2021 起；其余 2014~2015 起。逐腿不可横比。
- **交易太少**：每腿每年 1~2 笔，单腿只有 4~21 笔样本，胜率/盈亏比的置信区间很宽；
  原始描述给的"胜率 35%~42%、盈亏比 3.2~4.5"在本仓库标的上**无法验证**（实测胜率中位 54%、盈亏比中位 2.30）。
- **成交时滞**：`pos = w.shift(1)`，即 T 日收盘信号按 T 日收盘价成交（家族统一口径）。
  严格再滞后一天的效果**已量化**（§3b：+3.20% → +3.41%，方向为正、噪声量级），不必再加保守系数。
- **止损是收盘口径**：日内触发按收盘判定、次日生效，比真实盘中止损**更保守**（滑价更大）。
- **参数敏感性已测**（§3b / `research/attrib`）：关掉 ADX、量能、移动止损的 Δ年化分别是
  +0.73 / +1.34 / +0.13pp —— 都在噪声内，但**方向一致**（关掉过滤器反而更好）。
  止损区间 [3%,8%] 与 `6ATR/arm4` 是看着回测选的，存在轻度拟合风险，结论（跑不过同曝光基准）在四组候选里一致。
- **未计**：ETF 折溢价对成交价的偏离、QDII 代理的溢价波动、大额冲击成本、分红除权再投。
