# 波动资产 v1–v7 变种横向对比

> 数据来源：各变种 `backtest/*.jsonl`（v1.4 拆腿后于 2026-10-30 前后重跑）。
> 口径：**单腿全周期**（隔离主策略阶梯、闸门不设限）——
> v1/v2/v3 用各基金全历史（A500≈17 年、纳指/标普≈12 年、其余≈15 年），v5 用其回测窗口。
> 「年化超额(pp)」= 策略年化 − 买入持有年化；正值 = 跑赢买入持有。
> 组合层（4 年同窗）结论见各变种 `README.md`，本表只看**单标的时机本身**有没有价值。

## 0. 先说清楚：v1–v7 不是同一类东西

只有 v1/v2/v3 是「逐腿时机」且覆盖全部 7 个标的；v5 是趋势闸门（默认只套 3 腿）；
**v4/v6/v7 是沪深300 单标的的三种方法论研究**（股债配置 / 定投节奏 / 退出时机），根本不在「逐标的」维度上。

| 变种 | 类型 | 覆盖标的 | 回答的问题 |
|---|---|---|---|
| v1 MA20 穿越 | 逐腿时机（下车） | **7 腿** | 每条腿什么时候下车 |
| v2 BOLL 突破 | 逐腿时机（进出） | **7 腿** | 突破上车 / 跌回中轨下车 |
| v3 MACD+BOLL | 逐腿时机（追涨） | **7 腿** | 什么时候追突破 |
| v4 ERP 股债通道 | 沪深300×国债 配置 | 只沪深300 | 股债摆 20/50/80 |
| v5 趋势闸门 | 逐腿闸门（默认 3 腿） | 7 腿（宽基不套） | 四象限加/减仓许可 |
| v6 估值分位智能定投 | 沪深300 定投节奏 | 只沪深300 | 定投怎么投 |
| v7 中期趋势+急跌退出 | 沪深300 退出时机 | 只沪深300 | 什么时候退出 |

## 2. 跨标的的规律（最有用的结论）

1. **美股（纳指/标普）是时机的死穴**：三种时机全部大幅跑输买入持有（−8 ~ −15pp）。长牛里「纪律性减仓/下车」纯属拖累 —— v5 不套宽基是对的。
2. **港股（恒科）是时机的甜区**：v1/v2/v3 全赢（+4.8 / +13.9 / +18.8pp），但 **v5 的闸门反而亏**（−1.0pp）—— 港股宽幅震荡，趋势闸门被反复打脸。
3. **A股宽基（A500/沪深300）**：v2(BOLL) 最稳（+3.9 / +4.0pp），v3 次之，v1 微利；v5 不套故中性。
4. **科创50**：波动大、时机红利最高（+12 ~ +17pp），但绝对回撤仍 −10 ~ −25%。
5. **黄金**：长牛里时机略亏（−1 ~ −5pp），回撤改善是唯一的获得感。
6. **v5 默认「只套三腿」只在科创50 上真赚钱（+2.4pp），在恒科/黄金上都是负贡献** —— 默认依据并不扎实，恒科尤其该慎套。

> ⚠ **A500 与沪深300 两列是「镜像」不是两份证据**：2025-03-27 之前两条腿的场外序列就是同一只 `000051`，所以它们的超额/回撤几乎成对出现，别当成独立验证。

## 3. 沪深300 单标的方法论研究（v4 / v6 / v7）

这三个不碰其他 6 个标的，只在沪深300 上回答不同问题，彼此不冲突、可与主策略七腿并存：

| 变种 | 回答的问题 | 年化 / 回撤 / 夏普 | 对比基准 | 结论 |
|---|---|---|---|---|
| **v4 ERP 股债通道** | 沪深300 与国债摆多少（20/50/80） | 4.88% / −23.5% | 50/50 静态 4.94% / −24.4% | **无超额（−0.06pp）**，只是情绪刻度 + 再平衡触发器，不是收益引擎 |
| **v6 估值分位智能定投** | 沪深300 定投节奏（五档） | G2 6.09% / −34.2% / 0.33 | 买入持有 6.77% / −46.1% / 0.23 | 让渡 0.68pp 年化，换回 12pp 回撤、夏普 0.23→0.33 |
| **v7 中期趋势+急跌退出** | 沪深300 何时退出 | 默认 5.97% / −47.1% / 0.25 | 买入持有 5.72% / −46.1% | **回撤反而更差**（年化 +0.24pp 但回撤 −1.05pp）：退出条件是「事后」的，砍在半山腰又错过反弹；加「趋势破位」的 R-B03 变体才到 7.29% / −34.5% |

## 4. 一句话总览

- **真·逐标的对比只看 v1/v2/v3**：规律高度一致 —— **美股别择时、港股猛择时、A股温和择时、黄金少择时**；所有时机都降回撤，但只有在「非长牛」资产上才换来回报。
- **v2(BOLL) 是 A股宽基最优**，v3(MACD+BOLL) 是港股/科创最优但美股亏最惨。
- **v4/v6/v7 是沪深300 的三种「配置 / 定投 / 退出」思路**：v4 无超额、v7 默认版甚至伤回撤，只有 v6 的定投在夏普上有实打实改善。
