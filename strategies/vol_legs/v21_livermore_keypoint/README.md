# v21 · 利弗莫尔关键点买入法（沪深300 单腿 + 7 腿验证）

> **用户 2026-11-19 视频口径**（利弗莫尔关键点买入法，2005–2026 沪深300）。
> 这是一套**趋势确认 + 资金管理**的风控策略，**不是长期持有的替代品**。
> **未稳定：不进 `run_daily_vol_legs.ps1`，也不进每日看板**（2026-11-19 用户要求）。
> 机械规则输出，非投资建议。

## 结论先说（比数字重要）

回测（2006-01 ~ 2026-11，沪深300 真实指数，10bp / 空仓货基 1.40% / 次日收盘成交）：

| 口径 | 年化 | 最大回撤 | 夏普 | 累计 | 平均仓位 |
|---|---:|---:|---:|---:|---:|
| **v21 主口径（只止损）** | +3.10% | −46.70% | 0.08 | +84.7% | 86% |
| 一把抄底（回撤 20% 满仓） | −0.66% | −71.60% | −0.09 | −12.4% | 100% |
| 买入持有 | +7.21% | −72.30% | 0.23 | +304.3% | 100% |

四条必须知道的事实：

1. **只有两笔建仓**。2008-04 第一笔试仓在 −10% 止损（实际成交 −11.8%，因为收盘判定 + 次日成交）；
   2008-11 重新建仓、2009-02 加满 100%。此后首买价止损线（1788.5）从未被触及。
2. **主口径会退化成长期持有**。视频没有固定止盈，止损锚在**首买价**，所以 2009 年之后
   这套规则事实上就是「满仓不动」—— −46.7% 的回撤就来自 2009–2014 这段满仓下跌。
   这正是「不抄底、只在浮盈加仓、单笔亏 10% 就砍」的代价：它换来的是**不爆仓**，不是收益。
3. **加「新高回落 15%」退出 = 用收益换回撤**。回撤从 −46.7% 压到 −26.6%，
   年化从 +3.10% 掉到 +1.49%、夏普归零（`research/_sweep.md` 有 8%~20% 的整条曲线）。
   默认不启用，`PARAMS["exit_mode"]` 可切。
4. **跨标的是唯一像样的样本外**。同一套规则：标普500 +10.99% / −33.92% / 0.61
   （买入持有 +8.78% / −56.78% / 0.38）、纳指100 +15.73% / −35.56% / 0.75
   （+14.26% / −53.71% / 0.57）—— **在「深跌后能创新高」的市场它才有效**；
   科创50 −10.32%、沪深300 +3.10%，说明这条规则赚的是「危机后的均值回归」，
   不是通用 alpha。样本只有 2 笔，**先别实盘**。

## 7 腿回测（2026-11-19，`backtest/_v21_7legs.md`）

同一套规则铺到全族 7 条腿（hs300 / a500 / ndx / spx / gold / kc50 / hkt），每腿 1/7、
逐日再平衡、每腿独立跑（10bp、空仓货基 1.40%）：

| 口径 | 年化 | 最大回撤 | 夏普 | 累计 |
|---|---:|---:|---:|---:|
| **v21 7 腿等权** | +7.93% | −28.59% | 0.54 | +416.7% |
| 等权买入持有 | +7.80% | −54.41% | 0.43 | +403.0% |
| 共同窗口 2021-08 起 · v21 | +6.79% | −28.59% | 0.34 | +43.1% |
| 共同窗口 2021-08 起 · 买入持有 | +4.91% | −28.06% | 0.25 | +29.9% |

- **组合层有价值**：收益持平、回撤少 25.8pp、夏普 0.43 → 0.54 —— 这是「风控层」的典型形状。
- **单腿层没有通用 alpha**：年化赢过买入持有的只有 ndx / spx / hkt，夏普只有 ndx / spx；
  A 股腿是「回撤减半、年化砍半」（沪深300 −72% → −47%，+7.2% → +3.1%）。
- **黄金腿几乎不触发**（11.8 年只建仓 1 次、曝光 1%）：这条规则不适用于黄金。
- 科创50 / 恒生科技是负贡献（−10.3% / −7.9% 年化）—— 假突破反复止损。
- 样本结构：只有 hs300/a500/ndx/spx 有 20 年，黄金 2014-08、科创50 2021-01、
  恒生科技 2021-08 才起，所以「7 腿」只有后半段是真的。

## 规则（口径逐条落定）

| 变量 | 口径 | 为什么这么定 |
|---|---|---|
| 触发场景 | 距 252 日最高收盘回撤 ≥ 20% | 只在深调里允许开仓，牛市突破不参与 |
| 关键点 | 过去 20 日**最高收盘价**（不含当日） | 用收盘不用盘中最高，避免假突破 |
| 建仓 | T 日收盘确认 → **T+1 收盘**成交 20% | 场外基金只能按收盘净值成交 |
| 加仓 | 相对**首买价** +5% / +10% / +15% → +20% / +20% / +40% | 每根 K 线最多一档；只在浮盈时加，不摊平 |
| 止损 | **收盘价** ≤ 首买价 × 0.90 → T+1 收盘清仓 | 不用盘中最低价（场外无法盘中成交） |
| 退出 | 主口径**只止损**（视频无固定止盈） | 备选 `trail` / `hold_days`，见研究报告 |
| 成本/计息 | 单边 10bp；空仓货基 1.40% | 与 v14~v20 同尺；场外 A 类真实费率单列 |
| 价格 | 沪深300 价格指数 `SH000300` | 不含分红再投（约 −2.0~2.5pp/年） |

`engine.weight(px)` 返回的是**实际持仓序列**（已含 T+1 成交滞后），不是决策序列 ——
首买价 / 已加档数 / 止损线都是路径依赖的，不能用 `decision.shift(1)` 表达。
所以 `run()` 不再 shift，`_plot_leg_core` 传 `lag=0`。

## 边界

- **样本内**：阈值全部来自视频，沪深300 只有 2 笔建仓；`_sweep.md` 的邻域对照**不是**过拟合豁免。

  美元/港币腿不含汇率，A500 在 2024 年前属于「假想可投」。
- 指数不会停牌/涨跌停；执行载体 `000051` 的申赎确认时滞、跟踪误差不在模型内。
- 价格指数不含分红再投，跨策略比较时先按 −2.0~2.5pp/年 折算。
