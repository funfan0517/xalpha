## 结论先说

- **7 腿等权组合（每腿 1/7、逐日再平衡）**：年化 **+7.93%** / 最大回撤 **-28.59%** / 夏普 **0.54** / 累计 +416.7%；同期等权买入持有 +7.80% / -54.41% / 0.43 / +403.0%。**收益基本持平（+0.13%），回撤少 25.8pp、夏普 0.43 → 0.54** —— 这正是「风控层」该有的样子：不加工收益，砍掉左尾。
- **逐腿**：年化赢过买入持有 **3 条**（纳指100、标普500、恒生科技），夏普赢过 **2 条**（纳指100、标普500）；**同时赢两项的只有 纳指100、标普500** —— 都是美股腿。
- **A 股腿是「回撤减半、年化砍半」**：沪深300 −72% → −47% 但 +7.2% → +3.1%；中证A500 −71% → −49% 但 +8.3% → +4.1%。**黄金腿几乎不触发**（13 年只建仓 1 次、曝光 1%），等于拿 1/7 的钱躺平在货基；科创50 / 恒生科技是真负贡献（假突破反复止损，−10.3% / −7.9% 年化）。
- **样本结构决定了一半结论**：hs300 / a500 / ndx / spx 有 ~20 年样本，黄金 2014-08 起、科创50 2021-01 起、恒生科技 2021-08 起。2006–2013 组合只有 4/7 在场，2021 前 5~6/7 —— 「7 腿」只有后半段是真的。
- **共同窗口（2021-08-03 起，7 腿齐）**：组合 +6.79% / -28.59% / 0.34 vs 等权买入持有 +4.91% / -28.06% / 0.25 —— 收益更高、回撤没更小、夏普略好，这段最接近「今天起用这条规则」。
- 结论：**组合层有风控价值（同收益、半回撤），单腿层没有通用 alpha**。它不适合单独作为某条腿的择时（A 股腿收益砍半），更不适合在规则还没稳定时进每日流程；比较合理的用法是当「深跌后的分批建仓纪律」叠加在已有仓位框架上。

## 口径与边界

- **1/7 等权不等于生产权重**。生产带的权重是 a500 2.5 / hs300 2.5 / ndx 10 / spx 10 / kc50 2.5 / hkt 2.5 / gold 10（pp of 总资产），美股权重是 A 股的 4 倍；等权是为了「同一规则在 7 个市场上的胜率」，不是组合建议。
- **每腿独立、不共享资金**：某腿满仓时其余腿不会因此减仓，组合层不带跨腿风控；逐日再平衡到 1/7 也不计换手成本（只在腿内部计 10bp）。
- **美元腿不计汇率**：NDX / SPX 是美元指数，QDII 人民币份额还受汇率与额度影响；恒生科技是港币。跨币种比较只看「规则是否成立」，不看真实人民币收益。
- **A500 用的是 SH000510 指数**（2005 起），实际可买载体 023299 成立于 2024；组合里 2024 年前那份 A500 属于「假想可投」，与其他腿的历史不可完全等同。
- **停牌/涨跌停**：指数与 ETF 层面基本不存在；QDII 溢价、申赎确认时滞不在模型内。
- 年化上赢过买入持有的 3 条（纳指100、标普500、恒生科技）里，只有纳指/标普是**真赢**（全程长牛），恒生科技属于「少亏」；A 股两条腿夏普没赢，但把回撤从 −72% 压到 −47%。这条规则赚的是「危机后均值回归 + 长牛延续」，离开长牛就只剩回撤控制。
