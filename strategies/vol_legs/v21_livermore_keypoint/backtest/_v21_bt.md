> 由 `strategies/vol_legs/v21_livermore_keypoint/backtest.py` 生成。**用户 2026-11-19 视频口径**，样本内结果，非投资建议。

## 规则（口径已统一）

| 变量 | 落定口径 |
|---|---|
| 触发场景 | 距 **252 日**最高收盘回撤 ≥ **20%** 才允许新开仓 |
| 关键点 | 过去 **20 日最高收盘价**（不含当日），`收盘价 > 关键点` 才算突破（不用盘中最高） |
| 建仓 | T 日收盘确认 → **T+1 收盘**成交 **20%** |
| 加仓 | 相对**首买价** +5% / +10% / +15% 各一次，+20% / +20% / +40%（每根 K 线最多一档） |
| 止损 | **收盘价** ≤ 首买价 × 0.90 → T+1 收盘清仓（不用盘中最低价） |
| 退出 | 主口径只止损（视频无固定止盈）；备选 `trail` / `hold_days` 见 `research/_sweep.md` |
| 成本/计息 | 单边 0.10%（研究同尺）· 空仓货基 1.40% |
| 价格 | 沪深300 真实指数（`SH000300`，价格指数，不含分红再投） |

## 口径与边界

- **样本内**：阈值直接取自视频，没有做参数搜索；但 2005–2026 只有**两笔**建仓，`research/_sweep.py` 的邻域对照只用于判断稳健性，**不能**当样本外证据。
- **不含分红再投**：沪深300 价格指数低估约 2.0~2.5pp/年；v21 长期在场（曝光 86%，2009-02 加满后未再退出），所以和买入持有一样被这条压低。
- **指数不会停牌/涨跌停**：本条腿执行载体是场外 `000051`（按收盘净值成交），个股的涨跌停/停牌问题在指数层面不存在，但 QDII/联接的跟踪误差与申赎确认时滞不在模型内。
- **一把抄底基准**定义：首次回撤 ≥ 20% 当天满仓（本样本是 2007-11-28 / 4648.75）、之后一直满仓、无止损。自买入价的最大浮亏 **-65.0%**，表里 −71.6% 是**净值口径**（自净值高点）—— 视频说的 −57% 是浮亏口径，两者不可直接对账。
- 全场只有 6 笔成交，A 类真实费率与 10bp 的差异 <0.1pp（成本不是这条策略的问题）。
- 不加仓不摊平、只在浮盈时加仓是这套规则的核心；把 `add_anchor` 换成加权均价后金字塔更容易半途而废（见 `research/_sweep.md`）。
