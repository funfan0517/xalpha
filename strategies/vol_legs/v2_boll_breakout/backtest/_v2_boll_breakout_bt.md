# 波动资产 · V2 变种：BOLL 上轨突破（七腿逐腿择时）
> 池与主策略**完全一致**：`rule.LEG_ORDER` 七腿（中证A500 / 沪深300 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金） · 价格 = 场外**复权净值**（含分红再投 / 汇率 / 跟踪误差）
> T 日盘后算信号、**T+1 净值成交** · 空仓按货基 1.40% 计息 · 主表零费用，成本另算（见「成交时滞 × 费率」）
> 原 `strategies/tech_indicators/v16_boll_breakout/`（54 只场内 ETF 全池），2026-10-30 迁入 vol_legs 并改为七腿口径。

## 规则

- **指标**：`mid = MA(close, 35)`、`std = STD(close, 35)`、`upper = mid + 2σ`（下轨算而不用）
- **开多**：`close > upper` 且前一日 `close <= upper`（要求「上穿」，同一段趋势不重复发信号）
- **平仓**：`close < mid`（跌回中轨即退出，不等下轨）
- **无反向开空**；盘中触碰不算，只看收盘；无信号时空仓等待
- **止损**：默认关闭（`PARAMS['STOP']=None`），敏感性见下文
- **波动上限**：`PARAMS['TV'] = 20%`（设 None 关闭）—— 持仓时仓位 × `min(1, TV / σ20年化)`，入场判定不变。**下面各主表已含这一层**（2026-11-13 起），纯 0/1 的对照见「波动上限层」一节

> 规则与参数权威源 `boll.py::PARAMS`；指标在规则内自算，不依赖指标库；绩效统一走 `../engine.metrics()`（无风险利率 = 货基 1.40%）。

## 口径与已知边界

- **成交口径**：场外基金 15:00 前提交才拿当日净值，盘后算出的信号只能按 T+1 净值成交，故回测 `pos = sig.shift(1)`；QDII 腿（纳指/标普/恒生科技）净值本身滞后 T+1~T+2，实盘还会再慢一步（敏感性表里 T+2 一档）。
- **A500 / 标普的样本前段是桥接**（A500 `000051`、标普 `050025`），只用于把 BOLL 窗口撑起来，那段不是本基金业绩；看绝对收益请只认基金成立日之后。
- **组合层只有共同窗口**：受恒生科技联接（`012805`，2021-08 成立）限制。
- **未计**：大额限购、QDII 额度关闭时的顺延、赎回确认时滞、C 类销售服务费。
- **只看收盘**：回测只有日频净值，涨跌停/停牌与盘中触碰无法体现。
