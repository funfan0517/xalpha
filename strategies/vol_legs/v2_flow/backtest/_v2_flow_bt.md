# 波动资产 · V2 变种：资金渗透率（份额拥挤度）闸门
> 池 = 主策略六腿（`rule.LEG_ORDER`：A500 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金），带宽不改（5/10/10/2.5/2.5/10 = 40pp）
> 信号 = 头部 4 只 ETF 的**合计份额季度净申购率**（`head_fund_ratio_rules.md` 渗透率的分子，价格项在比值里抵消）→ 近 3 年**分位**（拥挤度）
> 规则 = 拥挤度 ≥90% → **半带** · ≤30% → **满带** · 中间维持（只在带内做减法）· T 日盘后算、**T+1 净值成交** · 半仓部分按货基 1.40% 计息

## 规则

| 拥挤度 c（净申购率的 3 年分位） | 目标仓位 | 含义 |
|---|---|---|
| c ≥ 90% | 0.5 × 目标带 | 资金涌入速度处于 3 年最高 10% —— 拥挤，临时打对折 |
| c ≤ 30% | 1.0 × 目标带 | 净申购率处于 3 年最低 30% —— 筹码出清，回到满带 |
| 30% < c < 90% | 维持 | 死区，不因噪声来回切换 |

> 拥挤度用分位而非 z-score：份额序列是季报阶跃 + 线性内插，厚尾；分位对极端值稳健，且可跨腿比较（黄金年均份额增长 20% 与科创50 的 50% 不同量纲）。

## 结论（诚实版）

1. **逐腿是「风险折扣器」，不是收益放大器**：2/6 条腿年化跑赢买入持有，但只有 2/6 条腿回撤更小（且**全在美股腿**：标普500、纳指100）。其余四条腿的回撤与买入持有完全相同 —— 因为其唯一一次档位切换发生在 2026-09 之后，没赶上 2022~2024 的大回撤，闸门无法为已发生的亏损止血。最典型是标普500：回撤 -16.01% vs -30.50%（**改善 +14.5pp**），代价只有 -0.99pp/年；纳指100 回撤 +3.0pp、代价 -0.87pp/年。慢牛腿（黄金）上则只是让渡收益。
2. **组合层不占优**：各腿拥挤不同步，半仓期与回撤期不重合 —— 组合回撤只改善 +0.61pp，收益却少了 2.80pp/年。所以 v2 **不适合单独当择时用**，它的正确用法是「与主策略叠加时的一票减仓许可」。
3. **换手极低（≈1 笔/年，见逐腿表）**：季报口径 + 死区，成本不是问题（对比 V1 的 13~16 笔/年，扣费后年化从 8.10% 掉到 1.42%）。
4. **信号有约 1 个季度时滞**：份额只披露到最近季报，季内资金变化进不了信号（M-03）；敏感性表里 hi/lo 在 80~95% / 20~50% 之间摆动，年化 12.4%~15.0%，均不敌静态带 —— 说明结论对阈值不敏感（不是调参没调好）。

## 口径与已知边界

- **份额 = 季报期末总份额**（东财 gmbd），期内线性内插；锚点之前不产出（M-01）。
- **头部名单按最新季报净资产取前 N**（R-01），名单变动用「份额加权增速」吸收（M-02）。
- **美股 / 港股 / 黄金没有标的指数流通市值口径**，只算分子（合计份额）；由核心恒等式，斜率不受影响（M-04）。
- **A500 只有 2025-04 起的信号**（头部 ETF 2024-10 才上市），此前该腿按「不执行」保持满带。
- **未计**：C 类销售服务费（0.2%/年）、大额限购、QDII 额度关闭顺延、赎回确认时滞。
