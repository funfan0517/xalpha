# V3 变种 · MACD + 布林通道（自适应窗口，六腿逐腿择时）

`vol_legs`（波动资产操作规则 v1.3）的**第三个变种**，2026-10-30 由
`strategies/tech_indicators/v3_macd_boll` 复制而来，**标的池与口径全部改为主策略的六腿**。
（v3 槽位此前空置，编号沿用源变种。）

一句话：主策略回答「**组合层仓位带怎么摆**」（阶梯 / 年线闸门 / 再平衡），v1_ma20 回答
「**每条腿什么时候下车**」，本变种回答「**每条腿什么时候追突破上车、什么时候下车**」——
用 MACD 定多空，用布林开口突破定位进场，用死叉或跌破中轨离场。

## 1. 规则（0/1）

| 方向 | 条件 |
|---|---|
| **入场** | `DIF>0` 且 `DIF>DEA`（零轴上金叉状态）**且** 布林带宽放大（开口）**且** 收盘上穿布林上轨（突破） |
| **离场** | `DIF` 下穿 `DEA`（死叉）**或** 收盘自上轨下穿中轨（转弱） |
| **观望** | 布林带平行走平、净值在通道内震荡 → 无突破即不进场（自然空仓） |

### 窗口自适应（本变种关键）

用 Kaufman 效率比 `ER(20)` 判行情状态并切换布林窗口：

| 状态 | 判据 | 布林窗口 | 用意 |
|---|---|---|---|
| 趋势态 | `ER ≥ 0.40` | **20** | 通道窄，早抓突破 |
| 震荡态 | `ER ≤ 0.30` | **30** | 通道宽，过滤假突破 |

滞回设计（中间地带维持上次状态），倍数 `k = 2.0`，带宽 = `(上轨−下轨)/中轨`，开口 = 带宽放大。
参数权威源：`macd_boll.py` 顶部常量（`MACD_FAST/SLOW/SIG`、`W_FAST/W_SLOW/K`、`ER_N/ER_HI/ER_LO`、`WARMUP`）。

> 未量化项：**MACD 顶背离**（主观信号）。

## 2. 池与口径（与主策略**完全一致**）

| 维度 | 取法 | 来源 |
|---|---|---|
| 标的池 | `rule.LEG_ORDER` 六腿：A500 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金 | `strategies/vol_legs/rule.py::LEGS` |
| 价格序列 | 场外**复权净值**（累计净值，含分红再投 / 汇率 / 跟踪误差） | `data.series_for_leg(leg)` |
| 成交 | T 日盘后算信号 → **T+1 净值成交**（`pos = sig.shift(1)`） | 主策略 §2.4 |
| 空仓 | 按货基 `rule.CASH_ANNUAL`（1.40%）逐日计息 | `macd_boll.CASH_DAILY` |
| 组合层权重 | 按目标带归一化：A500 .125 / 纳指 .25 / 标普 .25 / 科创50 .0625 / 恒生科技 .0625 / 黄金 .25 | `macd_boll.W` |

不另立池、不做 A/B 分级；增删腿只改 `rule.LEGS`，本变种自动跟随。

**与源变种的两处必然差异**（换池后绕不开）：

1. MACD(12,26,9) / BOLL / ER **本地自算**。源变种读 `data/_indicators_hist.json`，那是场内 ETF 的
   预计算指标库，场外基金代码（`023299` 等）不在其中。算式与 `_gen_indicators.py` 一致
   （`ewm(span=...).mean()` + `rolling(w).mean()/std()`），实测在 `510300` 上与库值逐值吻合
   （最大差 5e-7，来自库的 4 位小数截断）。
2. 样本从第 **61** 个交易日起算（`WARMUP = 60`，MACD 的 EMA 与 ER(20) 需要收敛），与源变种同口径。

### 5.5 结论（四条）

1. **只降回撤，不增收益**：六腿回撤 **6/6 全部更小**，组合层 -4.89% vs 静态带 -17.45%
   （约 1/3.6），夏普 0.93 vs 0.80 —— 但年化 **-5.54pp**（平均只投入 18%，其余躺货基 1.40%）。
2. **增收益只在「买入持有本来为负」的腿上**：恒生科技（-11.55% → +7.26%）、科创50
   （-4.65% → +9.26%）；美股两条长牛腿让渡最多（纳指 -14.34pp、标普 -11.90pp），黄金 -5.05pp。
   逻辑上这是**突破追涨型**规则的必然：单边上涨里它大部分时间在场外，而下跌趋势里它躲得开。
3. **成本这次不是决定性变量**（与 v1_ma20 相反）：年笔数 2.1~3.9/年（MA20 是 13~16），
   三条 A 类腿年化拖累 -2.3~-2.5pp，组合层 5.55% → 3.74%（-1.81pp）。费用仍吃掉约 1/3 的
   毛收益，但不像 MA20 那样「吃掉全部超额」。
4. **定位是保险，不是收益引擎**：2022 年它 +1.71% vs 静态带 -12.26%（+13.97pp），
   2023–2025 三年连续落后 12.9 / 17.5 / 18.6pp（累计落后约 65pp）。买这个保险的保费，
   就是趋势行情里的缺席成本。

## 6. 与主策略的关系（重要）

- 主策略 §2/§5/§6 的阶梯是「**跌了才有加仓路径**」，本变种是「**突破了才上车**」——
  两者方向相反，**不可叠加在同一份额度上**；若要叠加，先定谁的额度优先（建议：主策略管带位、
  本变种只管「带内已建仓位要不要临时下车」）。
- 与 v1_ma20 是同一层次的两个信号：本变种笔数更少（2~4 vs 13~16 笔/年）、成本更低，
  但进场更晚（要等 MACD 零轴上金叉 + 布林开口突破）。

## 7. 已知边界

- **成交时滞**：QDII 腿净值本身滞后 T+1~T+2，实盘信号比回测更慢一步；回测已按 T+1 成交折算，仍偏乐观。
- **桥接段**：A500（`000051`）/ 标普（`050025`）的早期样本用同类老基金桥接，只用于撑指标窗口，
  不是本基金业绩。
- **C 类销售服务费未计**（`023299` / `011609` / `012805`，约 0.2%/年），三条 C 类腿的扣费后数字偏乐观。
- **未计**：大额限购、QDII 额度关闭顺延、赎回确认时滞。
- **组合层只有 2021-11 起的共同窗口**（受恒生科技联接 `012805` 成立日限制），4.9 年样本不足以支撑
  参数稳定性结论；窗口/ER 阈值等参数未做敏感性扫描（源变种也未做）。
- **曝光天然很低（12~19%）**：这不是缺陷而是规则定义（无突破即空仓），但也意味着**仓位是稀疏的**，
  组合层收益对少数几笔交易高度敏感。
