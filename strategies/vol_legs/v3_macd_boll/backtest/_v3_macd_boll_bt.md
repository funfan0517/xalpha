# 波动资产 · V3 变种：MACD + 布林通道（自适应窗口）· 七腿回测

## 规则

| 方向 | 条件 |
|---|---|
| **入场** | DIF>0 且 DIF>DEA（零轴上金叉状态）**且** 布林带宽放大（开口）**且** 收盘上穿布林上轨（突破） |
| **离场** | DIF 下穿 DEA（死叉）**或** 收盘自上轨下穿中轨（转弱） |
| **观望** | 布林带平行走平、净值在通道内震荡 → 无突破即不进场（自然空仓） |
| **窗口自适应** | Kaufman 效率比 ER(20)：≥0.40 → 趋势态窗口 20（窄通道早抓）；≤0.30 → 震荡态窗口 30（宽通道滤假突破）；带滞回，k=2 |
| **波动上限** | `TV = 20%`（设 None 关闭）：持仓时仓位 × `min(1, TV/σ20年化)`，入场判定不变。**下面各主表已含这一层**（2026-11-13 起） |

> MACD(12,26,9) 与 BOLL 由净值本地自算（源变种读场内 ETF 的预计算指标库，场外基金代码不在其中）；样本自第 61 个交易日起算。MACD 顶背离为主观信号，未纳入量化。

## 口径与已知边界

- **成交口径**：场外基金 15:00 前提交才拿当日净值，盘后算出的信号只能按 T+1 净值成交，故回测 `pos = sig.shift(1)`；QDII 腿（纳指/标普/恒生科技）净值本身滞后 T+1~T+2，实盘还会再慢一步。
- **A500 / 标普的样本前段是桥接**（A500 `000051`、标普 `050025`），只用于把 MACD/BOLL 窗口撑起来，那段不是本基金业绩；看绝对收益请只认基金成立日之后。
- **信号是「突破追涨型」**：只在开口突破时进场，与主策略「下跌才有加仓路径」的阶梯逻辑方向相反，两条规则**不可叠加在同一份额度上**（叠加前先定谁的额度优先）。
- **组合层只有共同窗口**：受恒生科技联接（`012805`，2021-08 成立）限制，七腿同日有净值的时间远短于单腿样本。
- **未计**：大额限购、QDII 额度关闭时的顺延、赎回确认时滞、C 类销售服务费。
