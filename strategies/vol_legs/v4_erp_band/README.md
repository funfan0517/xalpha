# V4 变种 · 股债利差（ERP）通道（沪深300 × 10Y 国债）

`vol_legs`（波动资产操作规则 v1.3）的**第二个变种**。与 `v1_ma20` 不同，它**不发生在六腿内部**，
而是回答一个更上层的问题：**沪深300 和国债之间，股债比例摆多少**。

一句话：主策略回答「六腿各多少 pp」，`v1_ma20` 回答「每条腿何时下车」，本变种回答
「**股 vs 债 的 80/50/20 该按什么刻度切**」。

不猜涨跌：只按「股债利差相对自己的历史位置」决定仓位。

## 1. 规则卡（逐条 → 代码）

参数唯一权威源：`erp.py::CFG`（改参数只改那里）。

| # | 用户给的规则 | 代码 |
|---|---|---|
| 1 | 输入：沪深300 收盘/点位 + 10Y 国债收益率（%），取共同交易日、缺失前向填充 | `erp.erp_frame()`（以沪深300 交易日为基准，`ffill_limit=10` 天，填不到就剔除） |
| 2 | 沪深300 盈利收益率 = 100 / PE | `df["erp"] = 100/df["pe"] − df["y10"]` |
| 3 | 股债利差 = 盈利收益率 − 10Y 国债，单位均为 % | 同上（国债直接用百分比数值，如 1.62 表示 1.62%） |
| 4 | 滚动 MA 与 STD；上轨 = MA+2σ，下轨 = MA−2σ | `erp.add_band()`，`CFG["window"]=250` / `CFG["k"]=2.0`（`std(ddof=0)`） |
| 5 | 低估 = 利差**触及或突破上轨**（上轨 = 极端低估） | `erp.signal_series()`：`erp >= upper` → state = +1 |
| 6 | 高估 = 跌破下轨（视频没重点讲，对称实现） | `erp <= lower` → state = −1 |
| 7 | 退出 = 利差回穿均线（或回至 MA+0.5σ） | `CFG["exit_frac"]`（默认 0 = 回穿均线；0.5 = MA+0.5σ，回测里两档都跑） |
| 8 | 信号 +1：股票 60~80% / 债 20~40%；−1：股票 20~40%；0：50/50 或维持上期 | `CFG["eq_cheap"]=0.80 / eq_neutral=0.50 / eq_expan=0.20`；`hold_on_neutral` 控制「维持上期」 |
| 9 | 再平衡：每月/每季，避免日内频繁交易 | `rebal_freq="M"` + `rebal_tol=5pp`：**信号切换日必动**，其余只在月末偏离 >5pp 时回锚 |
| 10 | 收盘后信号、次日成交，扣费率与滑点 | `erp.run()`：T 日收盘算 → **T+1 收盘净值成交**；两侧各扣申购 0.10%/赎回 0.50% |
| 11 | 绘图：复刻参考图 + 再画一个近三年 | `erp.plot_overlay()`（单面板双 Y 轴：利差/均线/±2σ vs 指数点位，Wind 截图同款）→ `backtest/_v4_erp_band.png`（全样本）/ `_v4_erp_band_3y.png`（近三年） |
| 12 | 参数需回测校准（窗口未披露，先用 250 日；备选 120/5 年） | `backtest.py` §5 敏感性：120 / 250 / 500 / 750 / 1250 日 |

### 1.1 三处「规则没写、但不定就跑不下去」的口径

> **窗口已定：250 日**（2026-10-30 由用户比对确认 —— 主图 `_v4_erp_band.png` 与视频口径一致，
> 且比 5 年窗口版本更接近其 Wind 参考截图）。窗口的选择不按「哪张图好看」，见 §5.1 的敏感性表
> （120~1250 日超额 -0.67 ~ +2.94pp、**不单调**）。

1. **PE 用哪个口径**。本实现用中证官网 `index-perf` 的 `peg`（**滚动 PE / TTM**，2011-06 起才有）。
   换成静态 PE 会把整条 ERP 曲线**平移**一个常数，而通道是「ERP 相对自己 MA±2σ」——
   平移在 MA/STD 里相互抵消，**信号基本不变**，变的只是 ERP 的绝对读数。
2. **「触及」按水平判还是按金叉判**。取**水平**：只要 ERP 还在上轨上方就一直是低估态。
   理由正是视频那句「历史低估可能持续数月」—— 金叉判定会在第二天就退出。
3. **滞回带**。进 2σ / 出 0σ（或 0.5σ）。不设滞回带的话，ERP 在上轨附近抖动会天天翻信号，
   换手费和摩擦会把任何优势吃掉（§5.2 有数据）。

## 2. 数据

| 用途 | 端点 | 落到 |
|---|---|---|
| 沪深300 日频收盘 + PE(`peg`) | 中证官网 `index-perf`（`000300`） | `data/_bt_caches/csi_000300.csv`（`date,close,peg`，跨策略数据类） |
| 沪深300 **全收益**指数（回测股票腿） | 同一接口（`H00300`） | `data/_bt_caches/csi_H00300.csv`（`date,close,peg`） |
| 10Y 中债到期收益率（日频，%，25 年） | 东财 `RPTA_WEB_TREASURYYIELD` | **本变种自用** `v4_erp_band/data/bond10y_long.csv` |
| 真实债券基金（对照） | 复用缓存 | `data/_bt_caches/nav_003377.csv` |

- **为什么股票腿必须用全收益 H00300**：价格指数每年漏掉约 2pp 分红，对「股 vs 债」的对比是
  系统性偏差，会把股票端低估整整 2pp/年。信号仍用 `000300` 的 PE（分红不影响 PE 口径）。
- **为什么 10Y 中债不放在共享缓存**：`data/_bt_caches/bond10y_d.csv` 是**股息策略生产**的文件，
  它的 `load_bond_cn()` 按 **12 年窗口整体覆盖**写入。2026-10-30 实测：本变种把历史补到 2002 年，
  股息流程跑一次就把它截回 2013-09，于是本变种的样本起点、债券腿年化、全部回测数字**静默变化**
  （债券 4.18% → 4.77%，样本起点 2012-08 → 2014-09，没有任何报错）。
  所以本变种自存一份 25 年的 `data/bond10y_long.csv`（AGENTS §8.4 ②「策略数据」），
  共享文件只在私有缓存缺失时作**只读兜底**，并告警历史长度。
- 沪深300 的两个缓存仍是「单调增厚」写入（并集、新值覆盖旧值），已补到 2005-01（PE 从 2011-06 起有值）。
- 抓取失败**沿用缓存并告警**（`erp._WARN`），不静默假装刷新成功。

## 4. 运行


## 5. 回测结论（2012-08-22 ~ 2026-10-29 · 14.2 年 · 含费）

完整报告 `backtest/_v4_erp_band_bt.md`。默认参数：250 日 / ±2σ / 回穿均线退出 /
低估 80 中性 50 高估 20 / 月末偏离 >5pp 回锚 / 合成国债 D=8。

| 组合 | 累计 | 年化 | 波动 | 最大回撤 | 夏普 | 平均股票仓位 |
|---|---:|---:|---:|---:|---:|---:|
| **策略（ERP 通道）** | +91.8% | **+4.88%** | +11.30% | **-23.48%** | 0.31 | 51% |
| 策略（不计费） | +101.4% | +5.26% | +11.30% | -23.44% | 0.34 | 51% |
| **反向信号（低估 20 / 高估 80）** | +102.7% | +5.31% | +12.33% | -34.88% | 0.32 | 49% |
| 静态 50/50（月末回锚） | +93.3% | +4.94% | +10.65% | -24.38% | 0.33 | 50% |
| 静态 80/20 | +123.6% | +6.07% | +17.12% | -38.87% | 0.27 | 80% |
| 买入持有沪深300（全收益） | +142.8% | +6.71% | +21.36% | -46.06% | 0.25 | 100% |
| 买入持有债券（合成 10Y，D=8） | +74.9% | +4.18% | +3.03% | -8.25% | **0.92** | 0 |

六条结论（都是这一轮跑出来的，不是猜的）：

1. **它不产生超额**：年化 4.88% vs 静态 50/50 的 4.94% = **-0.06pp/年**。
   它买到的是**回撤略小**（-23.5% vs -24.4%）和「低估敢重仓、高估不加仓」的纪律，
   不是收益。相对买入持有沪深300 是 **-1.83pp/年**（但回撤只有一半）。
2. **方向检验没通过**：把仓位对调（低估 20 / 高估 80）反而 5.31%（+0.37pp，夏普同为 0.32），
   但回撤放大到 **-34.9%** —— 反向的「超额」全部来自「更长时间满仓股票」这个 beta。
   **在本样本里，这条信号对收益的方向性贡献识别不出来。**
3. **「低估 ≠ 立刻上涨」在数据上成立**：低估态未来 60 日平均 +3.12%（上涨概率 63%）、
   高估态 +2.39%（62%）—— **几乎没差**；低估态 10% 分位仍有 **-10.47%**。
   只有把视野拉到 250 日才看出区别（低估 **+14.82%** vs 高估 **-3.58%**），
   而这条规则的实际持仓周期通常不到 250 日。
4. **A 股的现实是「高估区间常常在涨」**：§4 的区间表里，高估段
   2014-12~2015-08（+12.0%）、2016-12~2018-03（+13.8%）、2020-07~2021-05（+8.4%）
   **全是正收益** —— 那是动量最强的阶段；而低估段 2021-07~2023-01 是 **-12.9%** 的价值陷阱。
   这是「用估值做仓位」在 A 股最难堪的一面。
5. **参数比规则本身更重要，也就更容易骗自己**：窗口 120/250/500/750/1250 日的超额是
   **-0.67 / -0.06 / +1.59 / +2.94 / +0.98pp**。看起来「500~750 日最好」，
   但那两档样本起点被推后 1~2 年，且 1250 日又掉回来 —— **不单调**，是抽样运气。
   按这张表挑窗口就是最标准的过拟合。**默认仍取 250 日**（视频口径 ≈1 年）。
6. **分半样本不稳**：前半段（2012-08~2019-09）超额 **+0.24pp**、后半段 **-0.08pp**。
   逐年跑赢静态 50/50 只有 **7/15** 年，最大单年落后是 2017 年 **-9.2pp**（那一年低估值一直
   不出现，规则把 50% 锁死，沪深300 涨 24%）。

### 5.1 那它还有什么用

- **当情绪刻度**：ERP 在历史什么位置，比「感觉贵不贵」靠谱；报告里每天给 ERP/MA/上下轨。
- **当再平衡触发器**：极端低估（上轨）时提醒你把股票补到 80%，极端高估时提醒你降到 20%
  —— 这正是「避免高位满仓」的机械执行版，人类自己做往往做不到。
- **不要当收益引擎**：它跑不过买入持有，也跑不过静态 50/50。

## 6. 已知局限

- **样本 14.2 年，起点 2011-06（PE 最早可得）**。参考图从 2005-04 起（Wind 数据），
  含 2008 年「利差飙到天上」的极端低估区 —— 本样本**没有**。别把结论外推到 2008 型危机。
  同一限制的另一面：2012-2026 恰好是「A 股估值中枢持续下移」的十四年，
  对「低估值买入」这类规则是最不友好的样本之一（**这条要说清楚**）。
- **PE 口径**：中证官网 `peg` 是滚动 PE，与视频的 Wind 口径可能有 0.5~1 倍 PE 的差；
  对**信号**影响很小（平移抵消），对**ERP 绝对读数**影响明显。
- **债券腿是合成的**：`D×Δy` 忽略凸性与骑乘；`D=8` 接近 10Y 国债，但多数人拿的是久期 3~4 的
  纯债基金（回测里 `003377` 一档：超额 -0.83pp、绝对收益低 2pp）。
- **未计**：场外申赎确认时滞（T+1~T+2）、大额限购、指数基金跟踪误差、分红税。
- **只有沪深300**：用户要求「先只在沪深300 测试」。扩展到中证A500 / 中证500 / 恒生等，
  需要各自的 PE 日频序列（中证官网都能取）+ 对应债券锚，`erp.py` 里换成参数即可
  （`fetch_hs300(code=...)` 已支持任意中证指数）。
  > **中证A500 已做成平行变种：`a500/`**（2026-10-30）。沪深300 版的文件与产物**未动**。
  > 它复用本目录的 `erp.py` / `backtest.py`，只换标的数据源，详见 `a500/README.md`。
  > ⚠ A500 的 PE 只有 2024-09 起（指数发布日），样本约 2 年、通道就绪后仅 271 个交易日 ——
  > 那里的年化/夏普**不能当结论**，只能看当前读数。
- **每日报告的「当前仓位」默认 = 上一交易日的目标位**，不是你的真实持仓；用 `--hold` 覆盖。

## 7. 与其他策略的边界

- 主策略（`../`）管**六腿各多少 pp**（阶梯 / 年线闸门 / 再平衡）；
- `../v1_ma20/` 管**整腿进出时点**；
- **本变种管「股 vs 债」的顶层比例**，用的是沪深300 与 10Y 国债，不碰六腿。
  它与主策略可以并存的唯一方式是：把主策略的「权益 50 / 债 30」这个大类比例交给本变种决定，
  六腿内部仍按 v1.3 的仓位带走。**两者叠加时请先想清楚谁的额度优先**，本变种默认不接管主策略。
