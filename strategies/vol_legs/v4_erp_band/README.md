# V4 · 股债利差两带滞回（0.8 买满 / 0.2 清空 / 中间维持）

> **2026-11-03 变更**：原 v4（`erp.py` 的百分位 + 趋势过滤、80/50/20 两带）与原 v8
> （离轨确认）两个变种已删除；本规则（原 v10）提升为该家族的 **v4 主口径**。
> 被删变种的 ERP 通道/记账引擎 `erp.py` 与 10Y 债券长序列**原样并入本包**，
> 旧 v4 的信号（`erp.py` 自带的 `state/event/target`）保留为**对照基准**，不再单独成策略。
>
> **2026-11-06 变更**：阈值维持 0.8 / 0.2 不动；新增**带内趋势提前**（读 v5 的 `MA250+20`
> 四象限：B0 内「上涨趋势」→ 立刻买满、B2 内「下跌趋势」→ 立刻清仓）。默认启用，
> 回测 14.2 年只多触发 3 次，年化 +12.02%→**+12.40%**、夏普 0.63→**0.65**，详见 §6。

规则本体：`ladder.py`。z = ERP 在「250 日 MA ± 2σ」通道里的归一化位置（0 = 下轨/最贵，1 = 上轨/最便宜）。

| 带 | z 区间 | 仓位（股票占比） | 历史天数 |
|---|---|---|---:|
| B0 | z ≥ 0.80 | **满仓 100%** | 23% |
| B1 | 0.20 ≤ z < 0.80 | **维持上个仓位**（不主动调仓） | 55% |
| B2 | z < 0.20 | **清仓 0%** | 22% |

> 原始表述（用户 2026-11-03）：「0.8 以上（满仓）、0.2-0.8（维持上个仓位）、0.2 以下（清仓）；
> **从某个带内离开时执行带内的操作**。」

## 1. 执行口径：离带才动手（`hold_left`，已确认）

| 事件 | 执行该带的操作 | 有效方向 |
|---|---|---|
| 离开 B0（z 跌回 0.80 之下） | 满仓 **100%** | **买入** |
| 离开 B1（跨 0.80 或 0.20） | 维持 —— **不动** | 不动 |
| 离开 B2（z 升回 0.20 之上） | 清仓 **0%** | **卖出** |

→ 整条规则就是一条**滞回**：z 向下跌破 0.80 买满、向上升破 0.20 清空、中间不动；
状态只有 {100%, 0%}，同一份 z 从上面下来和从下面上来持仓不同（路径依赖）。

**带内趋势提前（2026-11-06 起默认启用，`CFG["trend_intra"]=True`）**：B0 带内读到 v5 的
「**上涨趋势**」象限就立刻买满、B2 带内读到「**下跌趋势**」就立刻清仓，不必等离带。
它不改上面那条滞回的主体，只在带内多开一个触发口；中间两态（反弹 / 高位回调）不动作。
14.2 年只多触发 **3 次**（见 §6），差异在噪声内 —— 为什么这么少，见 §6 的「互斥」解释。

`CFG["ladder_mode"]` 固定为 `hold_left`，**不要改**。读法 B（`hold_new`：进入哪个带就用哪个带的仓位，
等价于「z 升破 0.80 买、跌破 0.20 卖」）只保留为回测对照 —— 方向相反，年化差 **5.21pp**。

## 2. 规则卡

参数唯一权威源：`ladder.py::CFG`（改参数只改那里）；通道参数在 `erp.py::CFG`。

| # | 规则 | 代码 |
|---|---|---|
| 1 | ERP = 100/PE(沪深300) − 10Y国债；通道 = 250 日 MA ± 2σ；z = (ERP−下轨)/(上轨−下轨) | `erp.py` |
| 2 | 每天收盘读 z → 带号 b（`0.80` / `0.20` 两条界） | `band_of` |
| 3 | **跨带才动手**：新仓位 = W(旧带)，`W(维持带)` = 保持当前仓位 | `ladder_series` |
| 4 | 死区：跌落要 `z ≤ 边界−band_tol`、升破要 `z ≥ 边界+band_tol`（默认 0） | `CFG["band_tol"]` |
| 5 | 带内不调仓；月末偏离目标 >5pp 才回锚（100% 仓位下股票会漂移） | `rebal_freq="M"` / `rebal_tol` |
| 6 | 成交 T+1 收盘净值；两腿各扣申购 0.10% / 赎回 0.50% | `erp.run()` |
| 7 | 满仓 = 债券砍到 0%，清仓 = 100% 债券 | `CFG["weights"]` |
| 8 | 首个就绪日落在维持带 → 用 `CFG["init_w"]`(50%) 起手 | `CFG["init_w"]` |
| 9 | **带内趋势提前**：B0 内读到 v5「上涨趋势」→ 立刻买满；B2 内读到「下跌趋势」→ 立刻清仓（不等离带） | `trend_quad` / `CFG["trend_intra"]` |

一次跨两带（跳空）按**一次**调仓处理，取所跨第一条边界做死区过滤。

**四条硬结论：**

1. **收益显著强于旧口径，但代价是回撤**。+12.40% vs 旧 v4 口径 +6.34% / 静态 50-50 +5.00%，
   夏普 0.65 全表最高（除纯债 0.92）；但最大回撤 **-38.96%**，比旧口径大 12pp，与静态 80/20
   (-38.87%) 同级。平均股票仓位 67% —— 这是「高暴露 + 滞后择时」，不是低波产品。
2. **费率不再是生死线**（与 4 带版最大的差别）。只有 **15 次信号调仓（约 1.1 次/年）**，
   场外换 ETF 只差 **+0.70pp/年**；累计费用 26.1% 主要来自月末回锚的小额调仓。
   4 带版是 234 次、费用 69.6%、拖累 3.9pp/年 —— 结论完全反转：**这条用场外基金做也还行**。
3. **「离带才动手」就是 alpha 来源**（别改成进带即动手）：读法 A +12.40% vs 读法 B +7.19%，
   差 **5.21pp**。机制见下表 —— A 在满仓带里平均只持 89%（B 是 100%）、在清仓带里还持 73%（B 是 0%），
   买卖两头各晚一拍，方向上是**动量**。
4. **「维持」这一档本身就值钱**：把中间带换成固定半仓（100/50/0）或三档定仓（80/50/20），
   调仓次数从 15 涨到 **127** 次、累计费用涨到 40%~72%，年化反而掉到 7%~8%。
   中间那 55% 的天数**什么都不做**，正是这条规则的省费设计。

**计划 vs 实际（读法 A 的「两头都没动」）：**

| 带 | z 区间 | 本带操作 | 实际平均 | 天数占比 | 该带后 250 日沪深300 |
|---|---|---|---:|---:|---:|
| B0 | z ≥ 0.80 | 100% 满仓 | **89%** | 23% | +16.8% |
| B1 | 0.20 ≤ z < 0.80 | 维持（不动） | **55%** | 55% | +13.1% |
| B2 | z < 0.20 | 0% 清仓 | **73%** | 22% | -2.2% |

分带前提仍然成立（后 250 日收益单调递减），但 B0 与 B1 只差 3.7pp —— 中间段几乎没有信息量，
这正是它被设成「维持、不动」而不是一档固定仓位的原因。

## 5. 稳定性与参数

- **带边界两头都掉**：整体平移 −0.10 / −0.05 / 0 / +0.05 / +0.10 → 年化 **+7.46% / +10.12% / +12.40%
  / +13.46% / +5.96%**。下移 = 买点提前、卖点推后（仓位更重）反而更差；上移 = 仓位更轻也崩。
  沿对角线看是一个中间高、两头掉的孤峰，说明 0.8/0.2 不是拟合出来的 —— 按用户口径固定，别挑最高那档。
  （补：把 64 组 `(hi, lo)` 网格全跑一遍，`hi∈[0.75,0.90] × lo∈[0.15,0.25]` 是一片 9.8%~13% 的
  **高原**，0.8/0.2 在其中排第 5，3×3 邻域平均只低 0.4pp —— 结论不变，但它不是尖峰。）
- **死区**：场外口径 0 / 0.02 / 0.05 / 0.08 / 0.10 → +12.40 / +11.40 / +11.90 / +11.05 / +10.85%
  （不单调）；ETF 口径同样 ±1pp 以内。→ 死区不值得调参，取 0.03~0.05 纯当防抖。
- **仓位刻度**：100/维持/0 → +12.40%（-38.96%）；80/维持/20（旧口径 80/20）→ +9.76%（-31.11%）；
  100/50/0 → +8.55%（-33.23%，127 次）；80/50/20 → +7.28%（-28.15%，127 次）。
  正收益确实来自「敢满仓」，不是来自债券腿。
- **滚动窗口**：120 / 250 / 500 / 750 日 → **+4.37% / +12.40% / +9.56% / +8.99%**。
  120 日几乎无效（还不如同窗口 50/50），250 日是必须的。
- **分半样本两段都赢**：前半段 +15.69%（ETF +16.37）vs 旧口径 +7.47%；
  后半段 +8.87%（ETF +9.51）vs 旧口径 +4.99%。
- **逐年**：场外口径下跑赢旧口径 **9/15** 年；主要领先年份 2014（+55.9 vs +24.8）、2015、2019、2020、2025。

## 6. 已知边界

- **样本里只有 15 次信号**，统计上什么都说明不了；且「维持带」占 55% 天数、期间什么都没发生，
  等于一半样本闲置。样本起点受 PE（2011-06 起）与 250 日预热限制，不含 2005-2011 的极端低估区。
- **回撤是真实成本**：-38.96%，与静态 80/20、买入持有同量级。2015 股灾与 2018 全程在场
  （回测按 T+1 收盘净值、无滑点；真实做下来场内买卖价差、跟踪误差还要再打折）。
- **没解决病根**：z 仍是「相对自身 250 日均值的标准化偏离」，锚会追着 ERP 漂移
  （`research/_erp_trend_diag.md` §4，原 v4 的诊断报告随引擎一并保留）。本口径只是把这种漂移
  **利用**了一次（靠滞后把它变成动量），没有修正它。
- **带内趋势提前的可操作空间很小**：B0 内「上涨趋势」只占 **37/804 日**、B2 内「下跌趋势」只占
  **1/755 日** —— 这是 `corr(ERP, 价格) = -0.856` 的直接结果（z≥0.8 时价格已跌够，MA250 斜率
  几乎必向下）。14.2 年多触发 **3 次**（2018-05-08 / 2020-02-04 买满、2024-05-24 清仓），
  年化 +0.38pp、回撤不变，在 15 次交易的噪声内。放宽到「只要斜率>0」触发 7 次反而更差（+11.83%）。
  参数 `CFG["trend_intra"]`，口径由 `CFG["trend_ma"]=250` / `trend_slope=20` 定，直接复用
  `v5_trend_gate` 的 `indicators`（用本策略 `close` 近似会有 **7.5%** 的交易日判成不同象限）。
- **锚健康度 H 只观测、不交易**：`H = 1 − |z − ERP 1250 日分位|`（分位 0=最贵、1=最便宜），
  背离 `|z − 分位| > 0.4` 判「脱钩」。每日报告 `daily/_v4_erp_band_daily.md` §6 给当前值与
  最近脱钩段，看板卡片也带一行。实测脱钩占 **14.5%** 天数、26 段、中位 **4 个交易日**，
  只与 2 次信号重叠 —— 「脱钩期冻结」的 +1.3pp 由这 2 次决定，**样本不足以做成交易开关**。
  参数在 `ladder.py::CFG` 的 `health_window` / `health_minp` / `health_dis`，不参与信号。
- 满仓 100% 意味着债券腿真的清空；债券腿是 D=8 合成国债指数（忽略凸性与骑乘）；
  未计申赎时滞、限购、分红税差。
