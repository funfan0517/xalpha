# 波动资产 · V4 变种：股债利差（ERP）通道 —— 沪深300 × 10Y 国债

> 样本 **2012-08-22 ~ 2026-11-02（14.2 年）** · 数据：本地缓存 `csi_000300.csv` · 至 2026-11-02 / 本变种缓存 `data/bond10y_long.csv` · 至 2026-11-02 · 自 2002-01-04
> 信号：`ERP = 100/PE − 10Y`，滚动 250 日 MA ± 2σ 通道，再把**下轨→上轨归一化到 0→1**；**T 日收盘算信号 → T+1 收盘成交**，买卖两侧扣申赎费，月末偏离 >5pp 才回锚。
> 机械规则输出，**非投资建议**。

## 1. 规则与参数（权威源 `erp.py::CFG`）

| 项 | 取值 | 说明 |
|---|---|---|
| 通道窗口 | 250 交易日 | 视频没披露，先用 ≈1 年；敏感性见 §5 |
| 轨宽 | ±2σ（总体标准差） | 定义通道上下边界，供 z 归一化 |
| 买入触发 | z ≥ **0.90** 且趋势上行 | z 把「下轨→上轨」看成 0→1，z≥0.9 = 利差落在通道上 90% 区间（极便宜） |
| 卖出触发 | z ≤ **0.10** 且趋势下行 | z≤0.1 = 通道下 10% 区间（极贵） |
| 趋势过滤 | 源 **erp** / 窗口 **20** 日 | 序列 > 其均线 = 上行；避免「够低但还在跌 / 够高但还在涨」时误动手 |
| 仓位 | 买入 **80%** / 中性 **50%** / 卖出 **20%** | 沪深300 占比（of 股债两部分） |
| 再平衡 | 信号切换日必动；M 末偏离 >5% 才回锚 | 「避免日内频繁交易」 |
| 成本 | 申购 0.10% / 赎回 0.50%（两条腿各自） | 切换一次两条腿都要付 |
| 债券腿 | 10Y 收益率合成（久期 8 年） | 与信号同一个 instrument；真实债基对照见 §5 |

> 状态占比（3446 个交易日）：买入持有 **54.3%** / 中性（未触发） **3.2%** / 卖出空仓 **42.5%**。一旦触发即长期停在买入/卖出态，**换手很低、仓位长期停在极端档**（与「触上轨=低估、触下轨=高估」的硬门槛相比，多了一道趋势确认）。

## 8. 结论与已知局限

1. **它不是收益机器**：策略年化 +6.20%，相对静态 50/50 +1.28pp、相对买入持有沪深300 -0.46pp（回撤 -27.44% vs -46.06%）。它买到的是**仓位纪律**——利差高就敢多拿股票、利差低就主动降下来，而不是预测涨跌。
2. **买入持有 ≠ 立刻上涨**：买入持有态下 60 日平均 +3.54%、上涨概率 58%，10% 分位仍有 -9.45% —— 历史上买入持有态动辄持续一年以上（§4 有区间长度），中途还会继续下跌。
3. **PE 口径会平移整条曲线**：本实现用中证官网 `peg`（滚动 PE，2011-06 起）。换静态 PE 或换 Wind 数据，ERP 的水平会变，但**通道是相对自己的 MA±2σ**，平移在 MA/STD 里相互抵消 → 信号与时点基本不变。真正会变的是「ERP 的绝对读数」。
4. **10Y 国债 vs 你的债券腿是两回事**：信号用 10Y 收益率，回测债券腿用 D=8 的合成国债指数。若你实际持有短债/货币，回测里的债券腿波动被**放大**了（§5.6）。
5. **样本只有 14.2 年，且起点 2011-06（PE 最早可得的日期）** —— 参考图从 2005 年起（Wind 数据），含 2008 年那种「利差飙到天上」的极端低估区，本样本**没有**覆盖到。所以图中的历史结构比本报告更极端，别把本报告的结论外推到 2008 型危机。
