## 1. 定位：与 v6_gold 的区别

| | **v5.1（本变种）** | **v6_gold** |
|---|---|---|
| 问题 | 黄金仓位**给几成**（0/20/…/100%） | 这笔钱**怎么拿**（A 保险丝 / B 波动目标 / C MACD） |
| 信息源 | 波动 + **实际利率水平（FRED DFII10）** | 只有价格 |
| 输出 | 六档目标仓位 + 滞后防抖 | 三条互斥口径，B 是连续仓位 |
| 换手 | 低（3.5 笔/年，45 笔 / 12.8 年） | 极低（A 0.8 次/年、B 1.1 次/年） |
| 结论 | +9.61% / −12.33% / 夏普 **1.02** | B：+9.79% / −15.25% / 夏普 0.80（12.1 年窗口） |

**两者共用同一个风险机制，不要同时跑**：B 是「纯波动目标 + 连续仓位」，本变种在它之上
多了**实际利率闸门**与**20pp 档位量化**（可手工执行、换手更低）。要同时跑必须先定额度归属。

## 2. 规则（逐条）

```
scale = clip(10% / 120 日已实现波动, 20%, 1)        # 风险预算
gate  = 1.0 if DFII10(T−1) > 0.5%+0.15pp            # 实际利率闸门（带死区）
      = 0.5 if DFII10(T−1) < 0.5%−0.15pp
      = 上一状态（死区内不动）
e*    = 量化(clip(scale × gate, 0, 1), 20%)          # 六档：0/20/40/60/80/100%
操作  = |e* − e| ≥ 1 档（20pp）才动，否则持有
成交  = T 日收盘算信号 → T+1 收盘成交
```

**为什么是这两件事**：

1. **波动目标解决「承担多少风险」**。黄金的波动聚集是真的（20 日波动 8%~38% 之间摆），
   固定仓位等于在波动冲高时被动加风险 —— 2026 年那一轮就是典型。按 10% 目标反算仓位，
   波动翻倍就自动砍一半。这不是 alpha，是风险归一化。
2. **实际利率用「水平」而不是「变化」**。v5.0 用 `DFII10` 的 10 日变化（±25bp）→ 日频噪声、
   净贡献 −0.21pp。水平值才有信息：20 年样本上它与**未来 12 个月**金价收益正相关
   （年度非重叠点 +0.63；2006-2012 / 2013-2019 / 2020-2026 三段分别 +0.54 / +0.63 / +0.77）。
   机制是实际利率均值回复：利率越低，未来越可能上行，对金不利 —— 所以实际利率过低时只拿一半预算。
   13 年里这条闸门真正起作用是 2020-2021（实际利率 −1% 附近、金价见顶）与 2015 前后。
3. **闸门加死区**（`0.5 ± 0.15pp`）。2015 年利率在 0.50% 附近来回穿越，无死区会在 80%↔40%
   之间抖：105 笔 → 45 笔，年化 +9.43% → +9.61%，夏普 0.97 → 1.02。

**被降级为「仅展示」的三件套**（代码保留，不再驱动仓位）：

| 因子 | 证据 | 处理 |
|---|---|---|
| 价格趋势 `f_p`（MA5/10 + 20 日突破贴边） | 单独用 +5.57% vs 恒半仓 +5.28%，换手 40+ 笔/年；加在风险预算上会拖累 | 仅展示 |
| 实际利率 10 日变化 `f_r` | 净贡献 −0.21pp，日频上是慢变量 | 仅展示（改成**水平**后进闸门） |
| 资金流 `f_f`（东财主力 / 上交所份额） | 主力接口硬上限 120 天；份额有全史但顺势把回撤从 −16.2% 恶化到 −23.8%、逆势只修回撤不增收益 | 仅展示 |

## 3. 回测结论（`backtest/_v5_gold_score_bt.md`）

场内 `518880`，**2014-01-23 ~ 2026-11-18（12.8 年）**，T+1 收盘成交、单边万 2.5、空仓计货基 1.40%：

| 口径 | 年化 | 累计 | 最大回撤 | 夏普 | Calmar | 平均仓位 | 调仓 |
|---|---:|---:|---:|---:|---:|---:|---:|
| **策略（风险预算 × 闸门）** | +9.61% | +210.75% | **−12.33%** | **1.02** | 0.78 | 59% | 45 |
| 恒满仓（买入持有） | **+9.81%** | +217.72% | −35.25% | 0.55 | 0.28 | 100% | 0 |
| 恒定半仓（e≡50%） | +5.83% | +101.46% | −18.34% | 0.58 | 0.32 | 50% | 0 |
| 纯现金（货基） | +1.40% | +18.74% | 0.00% | 0.00 | — | 0% | 0 |
| *旧 v5.0（价格趋势 + 利率变化）* | *+6.06%* | *+106.9%* | *−19.84%* | *0.57* | *0.31* | *51%* | *769* |

四条硬结论：

1. **同样的年化、三分之一的回撤**：年化只差 0.20pp，回撤浅 22.9pp，夏普 1.02 vs 0.55。
2. **它同时跑赢「恒定半仓」**：年化 +3.78pp、回撤浅 6.0pp。旧 v5.0 恰好卡在恒半仓附近 —— 这一版才真正分开。
3. **两个部件都不能少**：只风险预算 +9.66% / −16.22% / 夏普 0.81；只利率闸门 +9.91% / −35.25% / 0.69；
   合起来 +9.61% / −12.33% / 1.02。风险预算负责「波动冲高时减仓」，闸门负责「实际利率过低时只拿一半」。
4. **不是单点拟合**：400 组参数（波动目标 × 窗口 × 闸门阈值 × 低配乘数）里，
   **回撤比满仓浅 400/400、夏普高于满仓 400/400**；同一套规则在 **XAU 20 年**上
   夏普高于买入持有 **400/400** 组（策略 +7.87% / −13.93% / 0.76 vs 买入持有 +9.28% / −44.65% / 0.45）。
   方向一致的是「回撤更浅、年化接近」，**不是「年化更高」**。

分段（同一套参数不重标定）：IS +6.27% / −9.40% / 0.73；OOS1 +6.77% / −6.82% / 0.76；
OOS2 +21.21% / −12.33% / 1.73。三段共同点是**回撤稳定在 7%~12%**，满仓在 20%~35% 之间摆。

## 6. 已知边界（用之前必须知道）

1. **不是 alpha，是风险归一化**：它不预测方向。想要「更高年化」这套规则给不了；
   它给的是同样的年化、三分之一的回撤。
2. **利率闸门是慢变量、独立事件少**：13 年里只切换过个位数次，真正被它躲开的主要是
   2020-2021（实际利率 −1% 附近、金价见顶）与 2015 前后。20 年 XAU 与三段子样本方向一致，
   但**独立 regime 段数远少于 50** —— 只能算「有经济学解释的中等证据」。
3. **闸门是绝对阈值（0.5%）**，不做滚动分位：好处是可解释、不随样本漂移；坏处是若未来长期
   处于实际利率 >1% 的新常态，闸门会长期开着，规则退化成纯波动目标 —— 这是可预期的退化，不是失效。
4. **段数不足 50**：完整往返 17 段、调仓 45 笔。低换手的风险预算天然达不到规格的 ≥50 门槛，
   证据由「400 组参数面方向一致性 + 20 年 XAU 外推 + 三段 IS/OOS 同向」补强。
   **若要求严格满足段数门槛，本规则应降级为「描述级」。**
5. **样本 2014-01 起（120 日波动就绪）**：比 ETF 上市晚半年，四个口径同窗口比较，不影响可比性。
6. **XAU 20 年不是严格样本外**：阈值与波动目标都在 518880 这 13 年里定的，XAU 只能排除
   「这一段特有的运气」，不能排除「黄金这 20 年的整体特征」。
7. **与 v6 / v9 不叠加**：`v6_gold` 的 B 口径与本策略共用同一风险机制，同族 `v9_vol_target`
   的黄金腿也在同一标的上跑波动目标；三者要叠加必须先定额度归属。
