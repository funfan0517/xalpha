> 规格来源：`E:\qianwen\jijin\gold_rules_v2.md`（黄金仓位操作策略 · 简化版 · 编码 + 回测规格）。

> 该目录已于同日按用户要求整体删除、状态机下沉为 `../_trend_gate.py`；本变种复用空出的 v5 编号。
> 它与 v6 一样**不发生在七腿内部**，只回答「投给黄金的这笔钱该怎么拿」。

## 1. 定位：与 v6_gold 的区别

| | **v5（本变种）** | **v6_gold** |
|---|---|---|
| 问题 | 黄金仓位**给几成**（0/25/50/75/100%） | 这笔钱**怎么拿**（A 保险丝 / B 波动目标 / C MACD） |
| 信息源 | 价格趋势 **+ 实际利率（FRED DFII10）** | 只有价格（黄金没有现金流锚） |
| 输出 | 单一口径，五档目标仓位 + 滞后防抖 + 事件冻结 | 三条互斥口径 |
| 换手 | 高（约 40 笔/年，档位相邻跳变就动） | 极低（A 0.8 次/年、B 1.1 次/年） |
| 结论 | **≈ 恒定半仓**（年化 −0.04pp、回撤 +0.2pp、换手 565 笔） | B 是家族里唯一「风险调整后更好」的黄金口径 |

**两者不要同时跑**：都记「黄金这笔钱」，叠加会重复加减同一份额度。

## 2. 规则（逐条对应规格）

计分因子（`factors.py`，回测与每日**共用同一份实现**，规格 §6.5）：

| 因子 | 取值 | 规则 | 实现 |
|---|---|---|---|
| **价格趋势** `f_p` | +1/0/−1 | `close > max(MA5, MA10)` **且** `close ≥ 20 日高 × 0.995` → +1；`close < min(MA5, MA10)` **且** `close ≤ 20 日低 × 1.005` → −1；其余 0 | `factors.f_price`（20 日高/低用 `_ohlcv.json` 的**真实日内高低**） |
| **实际利率** `f_r` | +1/0/−1 | `DFII10` **10 个观测**变化 `Δ ≤ −25bp` → +1，`Δ ≥ +25bp` → −1；**T 日只用 ≤T−1 的值** | `factors.f_rate`（`merge_asof(allow_exact_matches=False)`） |
| **资金流** `f_f` | +1/0/−1 | ①`netin`：主力净流入连续 ≥3 日同向；②`share`：每日份额连续 ≥N 日净申购/赎 | `factors.f_flow` / `factors.f_share` —— **发布口径 `FLOW_MODE="off"`**（见下） |

`score = f_p + f_r (+ f_f)`。**资金流剔除的三层理由**：

1. **主口径没全史**：东财 `fflow/daykline` 对 ETF 只回 **120 根**，且这是**接口硬限制**
   （个股 `600519` 也一样）—— `lmt` / `beg-end` / 换域名 / `kline` 变体全部无效；
   新浪只有当日快照、雪球只有分钟级。实测见 `research/flow_source/_probe_flow.md`。
2. **替代口径有全史，但没用**：ETF 的真实资金流是申赎 → **上交所每日份额**
   （`TOT_VOL`，`2013-07-29` 起 **3234 日 0 缺失**，1 请求/天可取）→ 拿它当 `f_f` 重跑：
   顺势口径回撤 **-17.8% → -22.8%**（更差），逆势口径回撤修回 -14.3% 但年化掉到 +4.1%、
   夏普 0.38，**两个方向都跑输恒定半仓**（回测 §8.2）。
3. **机制上它是结果变量**：`corr(5 日累计申赎%, 次日收益) = -0.015` —— 份额是「涨了才申购」，
   不是预测变量。

所以 `FLOW_MODE="off"` 是**验证过的选择**，不再是「缺数据」的妥协；每日报告仍把份额/主力净流入
当「近期提示」展示（`flow_note`），但**永不进 score**。

信号 → 目标档（规格 §3）：`≥+2 → 100% / +1 → 75% / 0 → 50% / −1 → 25% / ≤−2 → 0~10%`（默认取 0%）。
**置信度**：三因子同向=高、两因子=中、分歧/缺失=低；**缺因子再降一档**（`MISSING_PENALTY`）；
低置信度把目标档**向 50% 收缩一档** → 两因子口径实际只剩 **75% / 50% / 25%** 三档
（`SHRINK="extreme"`：只压极端档，中间档保留信息）。

操作（规格 §4）：**滞后** `|e* − e| ≥ 1 档（25pp）` 才动（`HYST`）；**事件冻结**
（FOMC / 非农 / 核心PCE ±2 交易日内）只许持有或减仓；T 日盘后决策 → **T+1 收盘成交**。

不计分项（规格 §2）：FedWatch / 央行购金 / 内外价差 —— 读人工文件 `data/_gold_hints.json`
（可缺，缺则报「未维护」）；方向冲突时**只标注「观察，谨慎」并降一档置信度，永不改仓位数字**。

### 2.1 「两因子映射」的歧义与本实现的读法

规格括号写「映射同下调一档」，三种读法都站得住，本实现取第 ①（并在回测 §4/§8.1 并列另两种）：

| 读法 | 两因子口径的档位 | 13.2 年年化 | 说明 |
|---|---|---:|---|
| ① **同表 + 缺因子降置信度 + 极端档收缩**（默认） | +2/+1 → 75%、0 → 50%、−1/−2 → 25% | **+5.24%** | 「弱证据不给满配」 |
| ② 不收缩（照原表，可打到 100%/0%） | +2 → 100%、+1 → 75%、0 → 50%、−1 → 25%、−2 → 0% | +5.10% | 两个因子同向就满配，最激进 |
| ③ 全档收缩 | +2 → 75%、+1/0/−1 → 50%、−2 → 25% | +5.15% | 规格 §3 的字面读法 |

三种读法的差 < 0.15pp/年，**结论不依赖这个歧义**。

## 3. 回测结论（`backtest/_v5_gold_score_bt.md`）

场内 `518880`，**2013-08-23 ~ 2026-11-17（13.2 年）**，T+1 成交、单边万 2.5、空仓计货基 1.40%：

| 口径 | 年化 | 累计 | 最大回撤 | 夏普 | Calmar | 平均仓位 | 调仓 | 成本/年 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| **策略（两因子 → 三档）** | +5.24% | +91.73% | **-17.82%** | 0.50 | 0.29 | 48% | 565 | 0.27pp |
| 恒满仓（买入持有） | **+8.68%** | +189.06% | -34.04% | 0.48 | 0.25 | 100% | 0 | — |
| 恒定半仓（e≡50%） | +5.28% | +92.86% | -17.59% | **0.51** | 0.30 | 50% | 0 | — |

三条硬结论：

1. **它买到的是回撤**：-34.04% → -17.82%（改善 16.2pp），代价是年化 −3.44pp。规格 §7 的预期成立。
2. **但它没跑赢「恒定半仓」**：逐项重合（年化 −0.04pp、回撤深 0.23pp、夏普 −0.01），
   而恒半仓换手是 0。消融（报告 §4）里「只价格趋势」+0.29pp、「只实际利率」−0.21pp，
   **按规格 §5「负贡献因子剔除」的标准，两个因子都没过**。
3. **参数不救它**：36 组网格（MA × 突破窗口 × 利率阈值 × 滞后）**0/36 年化跑赢满仓、
   36/36 回撤更浅、36/36 夏普更高**，年化 5.20%~5.74%、夏普 0.50~0.56 —— 方向一致，
   幅度都在噪声内。`HYST=2` 会把规则**完全冻结**（目标档距 50% 最多 25pp，永远够不到 50pp 门槛），
   退化成恒定半仓，所以「加到 2 档」不是防抖而是关掉规则。

其它读数：`HYST=2` 见上；事件冻结覆盖 46% 的交易日，关掉它年化 −0.05pp、回撤反而深 2pp；
尾部尺子（伦敦金现 20 年）显示 518880 短样本**低估尾部约 10.6pp**，所以主表的回撤改善要打折看。

## 6. 已知边界（用之前必须知道）

1. **没有 alpha**：13 年里与「恒定半仓」几乎逐项重合，换手却是 40+ 笔/年。
   按规格 §7「若连回撤都砍不动，回退恒定半仓，不硬留规则」——本样本支持回退；是否上线由使用者决定。
2. **实际利率在日频上是弱信息**：`DFII10` 的 10 日变化 ±25bp 是慢变量，配合 20 日突破很少独立触发；
   本样本利率单边下行段居多，它的「利率上行压仓位」价值没被充分检验。
3. **非农/核心PCE 是发布日近似**（每月首个周五 / 月末最后交易日），节假日顺延未建模，
   影响仅限「事件窗口不许加仓」，最多错 1 个交易日。
4. **资金流因子：主口径无全史、替代口径有害**（`research/flow_source/_probe_flow.md`、
   回测 §8.2）。上交所份额全史已入库，顺势恶化回撤、逆势只修回撤不增收益，两方向都跑输恒半仓；
   但份额是**申赎**、主力净流人是**成交分档**，二者不等价，不能据此外推「所有资金流类因子无效」。
5. **样本 13.2 年、只有一轮完整黄金牛熊**；XAU 尺子（报告 §7）说明更长样本的尾部更深 10.6pp。
6. **与 v6 / v9 不叠加**：`v6_gold` 回答同一个问题（黄金这笔钱怎么拿），
   同族 `v9_vol_target` 的黄金腿也在同一标的上跑波动目标；三者要叠加必须先定额度归属。
