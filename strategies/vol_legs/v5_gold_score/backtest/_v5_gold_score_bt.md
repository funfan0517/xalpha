# V5.1 · 黄金仓位（风险预算 × 实际利率闸门）· 回测

> 口径：`scale = clip(10% / 120 日实现波动, 20%, 1)`；`gate = 1 if DFII10 > +0.50% else 0.5`（死区 ±0.15pp）；`e* = 量化(scale × gate, 20%)`。
> 标的 = 场内 `518880`（信号/执行/回测同一只 ETF），实际利率 = FRED `DFII10`（2003-01-02 起）。样本 2014-01-23 ~ 2026-11-18（12.8 年，起算点 = 120 日波动就绪）。T 日收盘算信号 → **T+1 收盘成交**；单边佣金 0.02500%、滑点 0.00%，空仓按货基 1.40% 计息。
> 参数唯一权威源：`factors.py` 顶部常量（风险预算 + 闸门）+ `score.py` 顶部常量（成本与现金）。

## 0. 先说结论

1. **同样的年化、三分之一的回撤**：策略 +9.61% / -12.33% / 夏普 1.02，买入持有 +9.81% / -35.25% / 0.55。年化只差 0.20pp，回撤浅 22.9pp，**夏普接近翻倍**。
2. **它同时跑赢「恒定半仓」**：恒半仓 +5.83% / -18.34% / 夏普 0.58；本策略年化高 3.78pp、回撤浅 6.0pp。旧 v5.0 口径（价格趋势 + 利率 10 日变化）恰好卡在恒半仓附近，这一版才真正分开。
3. **两个部件都不能少**（§4 消融）：只风险预算 +9.66% / -16.22% / 夏普 0.81；只利率闸门 +9.91% / -35.25% / 夏普 0.69。风险预算负责「波动冲高时减仓」，利率闸门负责「实际利率过低时只拿一半」。
4. **参数面方向一致**（§5）：400 组里回撤比满仓浅 **400/400**、夏普高于满仓 **400/400**、年化跑赢满仓 **49/400**；同一套规则在 **XAU 20 年**上夏普高于买入持有 **400/400** 组。**方向一致的是「回撤更浅、年化接近」**，不是「年化更高」。
5. **利率因子换了口径才活过来**：v5.0 用 `DFII10` 的 **10 日变化**（±25bp）→ 日频噪声、净贡献为负；v5.1 用**水平**（`> 0.5%` 才给满额预算）→ 20 年样本上水平值与未来 12 个月金价收益正相关（年度非重叠点 +0.63，三段子样本 +0.54/+0.63/+0.77）。机制是实际利率均值回复：利率越低，未来越可能上行。
6. **旧 v5.0 口径的结论不变**（§4 末两行）：价格趋势 + 利率变化 + 资金流三件套就是恒半仓的换手版（+6.06% / -19.84% / 夏普 0.57）。这一版把它们降级为「已验证无增量」，只留在对照里。

**当前读数（2026-11-18）**：波动 **22.7%**（目标 10%）→ 风险预算 **0.44**；利率 **+2.91%** → 闸门 **1.00**；目标档 **40%**（= 4.0pp / 10pp）、当前 **40%**、今日动作 **持有**。

## 6. 换手与成本

- 调仓 **45 笔**（3.5 次/年）、完整往返 17 段；累计成本 0.30pp = **0.02pp/年**。
- 换手来自两处：① 波动跨 20pp 档位（多数）；② 利率闸门在 +0.50±0.15pp 之间穿越。
- 闸门死区把调仓从 105 笔压到 45 笔、年化 +9.43% → +9.61%（+0.18pp）、夏普 0.97 → 1.02 —— 2015 年利率在 0.50% 附近来回穿越，没有死区就会在 80%↔40% 之间抖。
- 事件冻结默认**关闭**：新口径下 ±2 日冻结年化 +9.40%、回撤 -13.12%，均不如不冻结（+9.61% / -12.33%）—— 与旧口径的结论相反，所以不给默认值，只留开关。

## 10. 诚实限制

1. **不是 alpha，是风险归一化**：它不预测金价方向；价值来自「波动冲高时少承担风险」与「实际利率过低时只拿一半」。用户若要求的是「更高年化」，这套规则给不了 —— 它给的是同样的年化、三分之一的回撤。
2. **利率闸门是慢变量、独立事件少**：13 年里闸门只切换过个位数次，真正被它躲开的主要是 2020-2021（实际利率 −1% 附近、金价见顶）与 2015 前后。20 年 XAU 与三段子样本的相关性方向一致（+0.54/+0.63/+0.77），但**独立 regime 段数远少于 50**，这条只能算「有经济学解释的中等证据」，不是高频可验证的统计规律。
3. **闸门是绝对阈值（0.5%）**：不做滚动分位。好处是可解释、不随样本漂移；坏处是若未来长期处于实际利率 >1% 的新常态，闸门会长期开着，规则退化成纯波动目标 ——这不是失效，是可预期的退化。
4. **段数不足 50**：完整往返 16 段、调仓 43 笔。规格 §5 原本要求「独立段 ≥50 才写成规则」，低换手的风险预算天然达不到。证据等级由另外三条补强：400 组参数面方向一致性、20 年 XAU 外推、三段 IS/OOS 同向。**如果要求严格满足段数门槛，这套规则应降级为「描述级」。**
