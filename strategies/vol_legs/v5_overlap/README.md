# V5 变种 · 两线重合买点（沪深300全收益 × 二级债基指数）

`vol_legs`（波动资产操作规则 v1.3）的**第三个变种**（`v1_ma20` 逐腿下车、`v4_erp_band` 股债利差通道之后）。

来源：用户 2026-10-30 给的规则 + 参考图（红 = 沪深300全收益、蓝 = 二级债基指数，两线重合/红线跌破蓝线处画圈 = 买点）。

一句话：**不发生在六腿内部，也不做仓位刻度，只回答一个问题 —— 沪深300 什么时候「便宜到可以满仓」**。
规则是「两线重合 → 买 → 持有一年后卖」。

**先说最重要的结论**：用真实的二级债基指数，这条规则 **21.8 年只在 2005-01 那一段成立过**。
参考图里能被圈出 5 次，是因为图里那条蓝线 20 年涨了约 5 倍（≈8.4%/年），比真实债基指数（5.1%/年）
快 3pp 以上。绝对水位不回来了 —— 这是本变种必须先讲清楚的事（详见 §3）。

## 1. 规则卡（逐条 → 代码）

参数唯一权威源：`overlap.py::CFG`（改参数只改那里）。

| # | 你的规则 | 代码 |
|---|---|---|
| 1 | 红线 = **沪深300全收益指数**（不是价格指数） | 中证 `H00300` 日频 → `data/_bt_caches/csi_H00300.csv` |
| 2 | 蓝线 = **二级债基指数** | 没有公开接口 → **自建**：8 只老债基累计净值等权复合（§2） |
| 3 | 两条线放一起、能直接比 | 同锚归一：两条线在锚点都 = 1000（`CFG["anchor"]="2005-01-04"`） |
| 4 | 两线**重合**（跌破或几乎贴合）= 买点 | `R = 红/蓝 ≤ 1 + level_tol`，默认 `level_tol=0.02`（+2%） |
| 5 | 买点后**持有一年**卖出 | 买入后满 `CFG["hold_days"]=250` 个交易日在收盘卖出 |
| 6 | 卖出后若还在重合区 | 立刻续买（`allow_rebuy=True`，即「贴着就滚动持有一年」）；关掉 = 一段只买一次 |
| 7 | 收盘后算、次日成交、算成本 | `lag=1`（T+1 收盘净值成交）；申购 0.10% / 赎回 0.50%；空仓按货基 1.40% |
| 8 | 参考图那种画法 | `plot_overlay()`：双线 + 红线低于蓝线的浅色区 + 白圈编号买点 |

### 1.1 一处「规则没写、但不定就跑不下去」的口径

**「重合」的容忍度**。`level_tol=0` 是严格跌破，`0.02` 是「几乎贴合」。这个 2% 不是随便取的：
2008-10 的底是 **1.104**，差 0.4pp 就抓不到（详见 §5.1 的阈值表）——**这条规则的收益几乎完全由
这个容忍度决定，而这正是它最脆弱的地方**。

## 2. 两条线怎么来

| 线 | 端点 | 落到 |
|---|---|---|
| 红线 沪深300**全收益** | 中证官网 `index-perf`（`H00300`） | 共享缓存 `data/_bt_caches/csi_H00300.csv`（v4 也在用） |
| 蓝线 二级债基指数 | 无公开接口（万得 `885007.WI` 拿不到） | **本变种自建** `data/_v5_bond_funds.csv` + `data/_v5_bond_index.csv` |

**自建口径**：取 8 只 2003~2010 年成立、至今还活着的老债基（二级 4 只 + 一级 4 只），
用**累计净值**（= 分红再投，不是单位净值）算日收益，当日有净值的成员**等权平均**后累积。

| 代码 | 名称 | 类型 | 起始 | 备注 |
|---|---|---|---|---|
| 202101 | 南方宝元债券A | 二级 | 2002-09 | 最长历史，单只对照口径也用它 |
| 240003 | 华宝宝康债券A | 二级 | 2003-07 | |
| 217003 | 招商安泰债券A | 一级 | 2003-04 | |
| 090002 | 大成债券AB | 一级 | 2003-06 | |
| 020002 | 国泰金龙债券A | 一级 | 2003-12 | |
| 100018 | 富国天利增长债券 | 一级 | 2003-12 | |
| 110017 | 易方达增强回报债券A | 二级 | 2008-03 | |
| 485111 | 工银双利债券A | 二级 | 2010-08 | |

- 2005-01 起有 6 只、2010-08 起 8 只全到 → 与红线可比的窗口是 **2005-01 至今**。
- **为什么不用单只基金**：单只选谁都是事后挑选；等权复合 8 只 ≈「当年债基的平均表现」，
  这也正是「指数」二字的含义。单只 `202101` 留作敏感性对照（§5.3）。
- 复合指数年化 **+5.07%**（2005 起），回撤 −4.21%，与「二级债基」这个资产类别的常识量级一致。

## 3. 结构性事实：绝对水位不再回来

| 线 | 年化（2005-01 ~ 2026-10） |
|---|---:|
| 红线 沪深300全收益 | **+8.72%** |
| 蓝线 自建二级债基指数 | **+5.07%** |
| 缺口（≈ 权益风险溢价） | **+3.65pp/年** |

红线每年比蓝线多跑 3.6pp，所以「红线跌回蓝线」的难度逐年变大 —— R 的周期低点是**逐级抬升**的：

| 周期底 | R（红/蓝） | `R ≤ 1` 触发？ | 参考图有没有圈 |
|---|---:|---|---|
| 2005-07 | **0.81** | ✅ | ✅ 圈① |
| 2008-10 | 1.10 | ❌ 差 10% | ✅ 圈② |
| 2014-05 | 1.27 | ❌ 差 27% | ✅ 圈③ |
| 2018-12 | 1.56 | ❌ | ✅ 圈④ |
| 2024-09 | 1.65 | ❌ | ✅ 圈⑤ |

**参考图圈得到 5 次，是因为它的蓝线长得更快**（20 年约 5 倍 ≈ 8.4%/年）：
要么它用的是含较多权益仓位/杠杆的专用指数，要么是示意图。用真实债基指数，只有 ① 真的贴到了
（② 差 10%，③④⑤ 差 27%/55%/65%）。对照图：`backtest/_v5_overlap_troughs.png`。

## 4. 回测结论（诚实版）

样本 2005-01-04 ~ 2026-10-29（21.8 年），含费，T+1 成交。

| 组合 | 累计 | 年化 | 最大回撤 | 夏普 | 买入次数 | 在场 |
|---|---:|---:|---:|---:|---:|---:|
| **A 严格 R ≤ 1.02（你的原话）** | +209% | **+5.51%** | **−22.02%** | **0.57** | 2 | 9% |
| A″ R ≤ 1.20 | +522% | +9.08% | −25.24% | 0.72 | 3 | 14% |
| A‴ R ≤ 1.30 | +853% | +11.32% | −25.24% | 0.83 | 4 | 19% |
| **A 严格 + 卖出后回债基** | +438% | **+8.33%** | −22.02% | **0.93** | 2 | 9% |
| A‴ + 卖出后回债基 | +1334% | +13.50% | −25.24% | 1.01 | 4 | 19% |
| C 对照：z ≤ −1（相对低位） | +45% | +1.78% | **−59.50%** | 0.02 | 13 | 57% |
| 买入持有沪深300（全收益） | +519% | +9.06% | −72.04% | 0.31 | — | — |
| 静态 50/50（月末回锚） | +403% | +7.98% | −44.31% | 0.50 | — | — |
| 买入持有二级债基指数 | +194% | +5.26% | **−4.21%** | **1.82** | — | — |
| 现金 1.40% | +34% | +1.40% | 0.00% | 0.00 | — | — |

四条结论：

1. **严格口径只响一次**：2005-01 触发、T+1 买入，持有一年后信号仍在 → 续买一年，2007-01 下车。
   2006 年 +119.5%。此后 20 年没有任何信号，全程拿着货基/债基。
2. **作为独立策略不合格**：年化 5.51% ≈ 持有债基指数的 5.26%，但波动是它的 3.5 倍、回撤 -22% vs -4.2%。
   「买点很准」和「策略好用」是两件事 —— 它 91% 的时间在场外，收益自然被摊薄。
3. **「空仓时拿什么」比「买点准不准」更决定收益**：把空仓段从货基换成债基（卖出后钱回债），
   同一套买点年化 5.51% → **8.33%**，夏普 0.57 → **0.93**，回撤不变。这是本变种最有用的一条。
4. **放宽阈值到 1.20/1.30 会漂亮很多，但那是事后挑的**：1.20 抓到 2008-10（R=1.104）、
   1.30 再抓到 2014-03（R=1.27）。这些数字只有回看历史才知道，见 §5.1。

## 5. 参数敏感性（完整表在 `backtest/_v5_overlap_bt.md` §5）

### 5.1 R 阈值

| 阈值 | 触发段数 | 买入 | 年化 | 回撤 | 夏普 |
|---|---:|---:|---:|---:|---:|
| R ≤ 1.00 | 2 | 2 | +5.51% | −22.02% | 0.57 |
| R ≤ 1.02 / 1.05 / 1.10 | 1~2 | 2 | +5.51% | −22.02% | 0.57 |
| R ≤ 1.15 / 1.20 | 2~4 | 3 | +9.08% | −25.24% | 0.72 |
| R ≤ 1.25 | 3 | 3 | +8.48% | −25.24% | 0.65 |
| R ≤ 1.30 | 5 | 4 | +11.32% | −25.24% | 0.83 |

> 1.00 → 1.10 结果**完全一样**（2008 的底是 1.104，差 0.4pp）；1.15 一步跳 +3.6pp。
> 这种「差一点就差一整个台阶」的脆弱性，比「阈值调多少最优」更值得记住。

### 5.2 卖点（持有一年 vs 更久）

| 持有期 | A（R≤1.02）年化 | A 回撤 | A‴（R≤1.30）年化 | A‴ 回撤 |
|---|---:|---:|---:|---:|
| 125 交易日 | +2.59% | −22.02% | +7.71% | −25.67% |
| **250 交易日（默认）** | **+5.51%** | −22.02% | **+11.32%** | −25.24% |
| 500 交易日 | +5.98% | −22.02% | +10.98% | −46.06% |
| 一直持有（不卖） | +5.51% | −22.02% | +11.32% | −25.24% |

> A 口径 2005 年买点之后 250 日是 **−2.2%**（买在下跌尾段），真正赚钱的是续买带来的 2006 年。
> **卖点不是这条规则的收益来源，买点才是**；250 日只是你定的机械止盈。

### 5.3 蓝线换一条

| 蓝线 | R 阈值 | 蓝线年化 | 触发段数 | 买入 | 年化 | 夏普 |
|---|---|---:|---:|---:|---:|---:|
| 自建复合（8 只等权，默认） | R ≤ 1.02 | +5.07% | 1 | 2 | +5.51% | 0.57 |
| 自建复合 | R ≤ 1.20 | +5.07% | 2 | 3 | +9.08% | 0.72 |
| 单只 202101 南方宝元 | R ≤ 1.02 | +6.56% | 5 | 4 | +10.40% | 0.73 |
| 单只 202101 南方宝元 | R ≤ 1.20 | +6.56% | 7 | 6 | +8.88% | 0.54 |

> 蓝线换谁，R 的水平就整体平移 → **严格口径的触发次数直接改变**。这是「自建指数」必然的口径风险。
> 结论对「蓝线是谁」敏感，但对「蓝线是债券类资产、年化 4~6%」不敏感。

### 5.4 对照：把「绝对贴合」换成「相对低位」（C 口径，**不推荐**）

`z = (lnR − MA250)/SD250 ≤ −1`：触发 17 段、买入 13 次、在场 57%，年化只有 **1.78%**、
回撤 **−59.50%**、夏普 0.02。最典型的一次是 **2008-03 就触发满仓**，然后完整吃了 2008 年那一段。
**「跌得多」不等于「跌到底」**，而「持有一年」的卖点不会帮你止损 —— 所以主口径坚持用绝对水位。

## 6. 每日怎么用

```powershell
# 盘后跑（已串进 run_daily_vol_legs.ps1 的第 4 步）
python strategies/vol_legs/v5_overlap/daily/_daily_scan.py --capital 2000000

# 真实已经买了：指定买入日，按「买入日 + 250 交易日」算卖出日
python strategies/vol_legs/v5_overlap/daily/_daily_scan.py --buy 2026-01-05 --capital 2000000

# 只是想看放宽到 +20% 的口径
python strategies/vol_legs/v5_overlap/daily/_daily_scan.py --tol 0.20

# 数据刷新 / 回测 / 自检
python strategies/vol_legs/v5_overlap/daily/_daily_scan.py --refresh
python strategies/vol_legs/v5_overlap/backtest.py
python strategies/vol_legs/v5_overlap/overlap.py
```

报告给三件事：**今天两条线各在哪、R 距买点还差多少、下一交易日该买/该卖/不动**。
当前读数（2026-10-29）：红线归一 6192、蓝线归一 2941、**R = 2.106**，阈值 1.02 ——
红线要再跑输蓝线 **51.6%** 才触发，空仓等待。

## 8. 已知局限

1. **样本极小**：严格口径 1 段、放宽到 1.30 也只有 4 段。夏普/胜率在这个样本量下都是轶事。
2. **蓝线是自建的**：8 只老债基等权，换万得 885007.WI 会改变 R 的水平与触发次数（§5.3）。
3. **绝对水位可能永远回不来**：若权益溢价继续按 3.6pp/年 的速度跑赢债券，下一个周期底大概率
   在 1.8~2.0，`R ≤ 1` 不会再触发。用之前先接受这一点，或放宽阈值（并承认那也是事后选择）。
4. **持有一年是机械规则**：不止损、不移动止盈。本口径恰好避开了 2008 那种半山腰买点，同类规则（C）没有。
5. **未计**：场外申赎确认时滞（T+1 收盘成交是乐观假设）、大额限购、指数基金跟踪误差、
   C 类销售服务费；2005-2015 年债基的刚兑/信用环境与今天不同。
6. **`--refresh` 需要网络**：中证官网（H00300）有反爬限流，8 只债基走 xalpha；抓取失败会沿用缓存并告警。

## 9. 与其它策略的关系

- **主策略 `vol_legs/`**：六腿（A500/纳指/标普/科创50/恒生科技/黄金）仓位带 —— 回答「今天该动多少 pp」。
- **`v1_ma20/`**：六腿逐腿 MA20 穿越 —— 回答「每条腿什么时候下车」。
- **`v4_erp_band/`**：ERP 通道（沪深300 × 10Y 国债）—— 回答「股票 vs 债券摆多少比例」。
- **本变种 `v5_overlap/`**：两线重合 —— 回答「沪深300 便宜到可以满仓了吗」。
- 四者层次不同，**默认不叠加**；要叠加先定额度优先（尤其是 v4 与 v5 都动沪深300 的仓位）。

> **模拟结果，非投资建议。**
