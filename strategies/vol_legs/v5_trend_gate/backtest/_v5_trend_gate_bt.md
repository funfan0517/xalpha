# 波动资产 · V5 变种：趋势四象限闸门 · 七腿回测
> 池与主策略**完全一致**：`rule.LEG_ORDER` 七腿（中证A500 / 沪深300 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金）
> 价格 = **真实指数**（`SH000300`/`SH000510`/`SH000688`/`.NDX`/`.INX`/`HKHSTECH`；黄金用 `518880` 实物 ETF）—— 不含分红再投、场内溢价与汇率· T 日盘后算信号、**T+1 收盘成交** · 空仓按货基 1.40% 计息 · 成本 = 真实申赎费 + 单边滑点 0.10%
> 口径边界：执行: 六条指数腿走场外 A 类基金（`LEGS[...]['exec']`），黄金走场内 `518880`；指数只用于「信号 + 回测」。价格指数不含分红再投，对账时 A 股腿按 −2.0~2.5pp/年、美股 −1.3pp/年 折算。
> 规则来源：用户 2026-11-02 的「趋势判断」说明；实现口径见 `v5_trend_gate/trend_gate.py` 模块 docstring 与 README

## 1. 规则（可执行版）

判断趋势只用两个数：`close` 在 **MA250** 上方还是下方、MA250 自身近 **20 日**是朝上还是朝下。两个都朝上才叫上涨趋势，其余三格都不给加仓许可。

| | MA250 朝上 | MA250 朝下 |
|---|---|---|
| **close ≥ MA250** | 上涨趋势 → 加至满带（100%） | 反弹 → 只持有，不给加仓许可 |
| **close < MA250** | 高位回调 → 降一档（封顶 50%），不新增 | 下跌趋势 → 满 5 日减半（50%）→ 满 20 日清至观察（20%） |

| 环节 | 参数 | 说明 |
|---|---|---|
| 年线 | `MA_WIN=250` | A 股一年约 240–245 个交易日，中文语境年线取 250；美股习惯 200。**混用会让两套回测结论互相矛盾**，回测里 MA120/200 都在敏感性表 |
| 斜率 | `SLOPE_N=20` | 年线自身 20 日变化量的符号（同一根线的属性，不是新维度）；5/20/60 日在敏感性表 |
| 阶梯帽 | `REDUCE_DAYS=5` / `CLEAR_DAYS=20` | 跌破后满 5 日才减半、满 20 日未收复才清至观察 —— **限制响应速度，不叠过滤器** |
| 间隔帽 | `ACTION_GAP=5` | 同一腿两次调仓最小间隔（交易日） |
| 档位 | `FULL=1` / `HALF=0.5` / `OBSERVE=0.2` | 是**占本腿目标带的比例**，不是 pp；观察仓与主策略 `rule.OBSERVE_PP` 同比例 |
| 作用域 | `GATE_ALL=True`（生效 = 全部七腿） | 2026-11-03 起默认七条腿全套装年线闸门；`GATE_LEGS`（kc50/hkt/gold）仅作 GATE_ALL=False 的回落三腿子集。历史上默认只套三腿，三腿版在 §3 作对照保留（宽基有估值锚，套上会与均值回归互相抵消） |
| 波动层 | `VOL_USE=True` · `VOL_MODE=adaptive` · `VOL_REF_Q=0.8` · `VOL_GAIN=0.9` · `VOL_WINDOW=120` | 按已实现波动缩放仓位（只减不加），目标 = 自身波动历史 80 分位 × 0.9；默认只压满带（半仓 / 观察仓不动）。见 §2.5 |

> **三个坑**：①滞后是设计特性不是 bug（§5 给出实测滞后成本）；②250 与 200 不是一回事；③震荡市假信号一定存在，解法是频率帽（5/20 阶梯 + 间隔帽），不是再叠一个指标。

> 七条闸门腿：扣费后跑赢「恒持满带」**4/7**，回撤更小 **7/7**（默认已套全部七腿）。
> 逐腿高低：最好的是 **恒生科技**（+8.20pp，回撤 -27.91% vs -59.32%），最差的是 **纳指100**（-5.35pp，回撤 -27.19% vs -53.71%）。**闸门不是收益引擎**：它把各腿曝光从 100% 压低，换回撤，赚不赚取决于该腿在这段样本里是「先在年线下阴跌很久」还是「跌破年线就 V 型反转」—— 前者它赚，后者它亏。
> 平均曝光是**带内占比**：100% = 一直满带，50% = 长期只露一半带。它比收益更能说明这条规则在做什么 —— 它不是择时进出，而是**把带切开按趋势分档**。
> 「打脸」= 减仓后 20 个交易日内又加回的次数（频率帽要防的东西）；「恒持满带」= 同区间不做闸门、一直 100% 带（等价于买入持有 + 一次申购费）。

> **无间隔帽**：+10.29% / -13.62% / 0.91；七腿等权：+5.08% / -27.44% / 0.23。间隔帽在本样本几乎不影响结果（调仓本就稀疏，七腿合计 83 次），它防的是极端震荡，不是拿来提升收益的。

## 6. 与动量法的分歧（三口径里可编码的两个）

结构法（道氏 HH-HL）需要事后确认摆动点、主观且滞后，本实现不编码（只作解释框架）；均线法 = 本变种的四象限；动量法 = 过去 6 个月累计收益为正（表中口径）。

| 组合 | 日数占比 | 未来20日 | 未来60日 | 60日胜率 |
|---|---:|---:|---:|---:|
| 均线多 + 动量多（一致看多） | 48% | +1.14% | +3.79% | 70% |
| 均线多 + 动量空（分歧） | 4% | +3.08% | +8.21% | 76% |
| 均线空 + 动量多（分歧） | 5% | +0.29% | +5.04% | 61% |

> **动量口径的参数敏感度实测**：12 个月动量与均线法的分歧只剩 48/8309 个腿·日（0.6%），6 个月口径是 719/8309（8.7%）—— 因为 MA250 与 12 月动量都在看「过去一年」，信息几乎重合。这就是用户说的「同一套动量规则，窗口从 1 个月调到 12 个月，年化在 0.68%~10.37% 之间摆动」：**窗口比口径更能改变结论**。
> 所以本变种**不引入动量维度**：它要么与年线高度共线（12 月口径），要么在本样本里是反信号（6 月口径）。这也解释了为什么规则只留两个数 —— 每多一个维度，就多一处可以拟合样本的地方。

## 10. 成本

- 费率按**每条腿的实际执行代码**取：A 类（`270042` / `017641`）+ 黄金 `518880` 场内申购 0.10% + 赎回 0.50%（持有 >7 天）；C 类（`023299` / `011609` / `012805`）申赎免费，但收约 0.2%/年销售服务费 —— 后者**未计入**，故这三条腿的扣费后数字偏乐观。
- 另加**单边滑点 0.10%**（双边 0.2%），作为净值公布滞后 / 大额赎回折扣 / QDII 额度的保守缓冲。
- 闸门的调仓是**带内比例**变化（1.0→0.5→0.2），不是清仓再进：一次「减半」只卖半条带，所以换手与成本都远低于 0/1 择时（v1_1_ma20 是 13~16 笔/年，本变种见 §2 调仓/年）。

## 11. 口径与已知边界

- **作用域是规则的一部分**：2026-11-03 起默认套全部七条腿（`GATE_ALL=True`）。历史默认只套科创50 / 恒生科技 / 黄金（无现金流锚），宽基四条腿不套 —— 因为估值锚本身已隐含均值回归，再叠趋势过滤等于同一信号用两次并互相抵消（用户给的 510300 实测：6.45%/18.24% → 4.10%/16.47%，2.35pp 年化换 1.77pp 回撤）。§3 的「三腿套闸门（旧默认 · 对照）」就是这条判断在本库净值上的复核（年化让渡与回撤的变化见该行的 ppt 差列），收益效率上三腿仍更优，当前七腿默认是按用户要求改的。
- **滞后是设计特性**：§5 给出实测（确认时已跌掉多少、之后还会跌多少）。目标不是躲回调，是避开年单位阴跌；拿它躲三个月的波动会被反复打脸（§2 打脸列 = 减仓后 20 日内又加回的次数）。
- **250 与 200 不是一回事**：A 股一年约 240–245 个交易日，中文语境的年线取 250；美股习惯 200。本变种全池统一 250（含纳指/标普腿），否则同一套规则会在两个口径下给出互相矛盾的结论。
- **没有加任何过滤器**：不叠 RSI、不叠成交量、不叠估值分位。震荡市的假信号靠频率帽（5/20 阶梯 + 间隔帽）限制响应速度，而不是再引入一个维度。
- **观察仓 0.2 不是 0**：留一点仓位是为了避免「清仓后再入场」的两次成本，也是主策略`rule.OBSERVE_PP`（0.5pp / 2.5pp 带）的同比例延续；想彻底清仓把 `OBSERVE` 设 0。
- **组合层只有共同窗口**：受恒生科技联接 `012805`（2021-08 成立）+ 250 日年线预热限制，组合层样本明显短于单腿（科创50 2022-05 起、恒生科技 2022-09 起）。
- **无桥接段**：A500 `SH000510`（2005 起）、标普 `.INX`（2005 起）历史足够长。
- **未计**：大额限购、QDII 额度关闭时的顺延、赎回确认时滞、C 类销售服务费。
- 参数未做 walk-forward 选优（本就不追求最优）：§9 的敏感性显示结论落在同一量级，不靠某一格参数成立。
