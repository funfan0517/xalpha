# V6 黄金 · B 加均线闸门：跌破 20 / 60 / 200~250 日均线减到 20%

> 场外 `000216` **2014-09-12 ~ 2026-11-06（12.2 年）**，从 B 的预热完成日算起；T 日收盘决策 → T 日收盘成交（另给 lag=1 的次日口径）；空仓计货基 1.40%；申 0.10% / 赎 0.50% + 滑点 0.10%。
> 闸门定义：`close < MA(win)` 连续 `confirm+1` 日 → 带内占比降到 20%；`close ≥ MA(win)` 连续 `recover+1` 日 → 恢复到波动层目标。最终仓位 = `min(波动层, 闸门)`。
> ⚠ **2026-11-09 起 B 的默认 `VOL_TARGET` 已从 15% 改成 10%**（+9.79% / -15.25% / 夏普 0.80）。本报告的闸门对比仍以 **15%** 为基线（即提问时的口径），10% 基线上加同一条闸门的实测见 §5 末行 —— 结论同向。

## 0. 先说结论

1. **20 日均线闸门是把本金磨光的方案**：MA20 立即版 **-1.55%** 年化（12.2 年累计 -16.67%）、回撤 -33.47%（比买入持有 -32.78% 还深）、夏普 -0.26，**351 次调仓（28.9 次/年）、打脸 162 次、成本 8.80pp/年**。均线越短越糟：MA60 +5.34% / -27.43%，到 MA200 才回到 +7.88%，MA250 +8.75% —— **五档全部不如 B 本身的 +11.60% / -22.00%**。
2. **原因是「跌破就涨」在短均线上更极端**：跌破 MA20 之后 20/60/120 日的平均收益是 +1.21% / +3.11% / +6.14%，下跌占比只有 35% / 38% / 31%（年线口径是 +0.49% / +1.69% / +2.46%）。MA20 共 176 段、平均只有 7 个交易日 —— 等于每 7 天做一次「减 0.8 / 加 0.8」的往返，单次摩擦 ≈ 0.56pp —— 一年 14.5 个往返、成本 8.80pp/年，先把超额吃光。
3. **年线口径（用户上一问）同样全面变差**：MA250 立即版 +8.75% / -23.50% / 夏普 0.62，对照 B 纯波动层 +11.60% / -22.00% / 夏普 0.77 —— 年化 -2.85%、**回撤反而 -1.50%**、夏普 -0.15，调仓从 6 次涨到 76 次（6.3 次/年）。**三项绝对指标没有一项改善。** 它唯一正的地方是与同曝光恒持（70% 仓位，+8.09%）比多 +0.66%，但夏普还低 0.02 —— 抵不掉降仓本身的代价。
4. **唯一能看的是「减得快 + 加得慢」**：减仓不改、把恢复改成「收复后站稳 20 日」→ +9.98% / -18.46% / 夏普 0.76，调仓 20 次、打脸 0 次，平均仓位 62%。回撤改善 3.53pp、夏普持平（0.77 → 0.76），同曝光恒持（62%）只有 +7.35% / -20.84% / 夏普 0.64 —— **这是全表唯一一条明显跑赢自己同曝光对照的闸门**，说明「非对称」才是这套思路的落点。
5. **「减到 20%」砍过头了**：同样跌破即减，减到 50% 是 +9.83% / -20.66% / 夏普 0.69，全面好于减到 20%；减到 0% 是 +8.00% / -26.88%。档位越极端，「少赚的」比「躲掉的」多 —— 这不是参数没调好，是方向问题。
6. **均线与结果是单调的「越短越差」**：MA20 -1.55% → MA60 +5.34% → MA200 +7.88% → MA225 +9.03% → MA250 +8.75%（后两档差 0.3pp，属噪声）；跌破确认加长到 5 日就收敛到 +9.79% / -19.97%，再加长只是少动；lag=1（次日成交）直接掉到 +8.16% / -26.17% —— 这条规则对执行时点极其敏感，说明它抓的是噪声级别的边际。

**一句话**：跌破均线在黄金上**不是下跌的开始，而是正期望的买入区** —— 跌破 MA20 后 20 日平均 +1.21%（下跌占比仅 35%），比年线的 +0.49%（49%）还要强。均线越短，减仓越频繁、越是在正期望处交筹码：MA20 -1.55% / -33.47%，年线 +8.75% / -23.50%，B 本身 +11.60% / -22.00%。真要压回撤，直接降 `VOL_TARGET` 更省：目标 10% = +9.79% / -15.25% / 夏普 0.80、18 次调仓。

## 10. 结论与建议

1. **20 日均线闸门直接排除**：不是「效果差一点」—— -1.55% 年化、回撤 -33.47%、成本 8.80pp/年、162 个打脸回合。短均线在这类资产上只能做成高频往返，而「跌破 MA20 后 20 日平均 +1.21%」说明它减的方向本身就是反的。
2. **年线口径（上一问）也不建议加进来**：跌破即减到 20%、收复即恢复，年化 / 回撤 / 夏普三项全部差于 B 本身；与同曝光恒持比只多 +0.66% 年化、夏普还低 0.02 —— 花 12 倍调仓成本买来的只是一个降仓开关。
3. **要加就加「非对称」**：减仓不动（跌破即减 20%），**恢复改成收复后站稳 20 日** —— +9.98% / -18.46% / 夏普 0.76、调仓 20 次、打脸 0 次。它把回撤从 -22.00% 改善到 -18.46%，夏普基本持平，且明显好于同曝光恒持（Δ年化 +2.63%）。但它仍略逊于「目标 12%」（+10.20% / -18.01%、9 次调仓）—— 它是「想留一条趋势判断」时的版本，不是最优解。
4. **如果目标只是「回撤不超过 -15%」**：把 `VOL_TARGET` 调到 10% 更省 —— +9.79% / -15.25% / 夏普 0.80、只有 18 次调仓，不需要任何趋势判断。
5. **不要和 A 叠加**：A 的 60 日保险丝已经在做「年线下压仓位」，再加一条二态闸门等于同一笔黄金被两套规则重复加减（README §1 的警告）。
6. **这条结论与 v5 的逐腿结论一致**：黄金跌破均线后多次 V 型反转（2016 / 2024 / 2025），闸门减在坑里；均线越短、反转越频繁、减得越不是地方。本报告把它量化到了「多少段、每段多长、减对了还亏在哪」。
