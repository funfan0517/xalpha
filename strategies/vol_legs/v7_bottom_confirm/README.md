# V7 变种 · 抄底确认 v2（地量窗口 + 背离 + 跌速斜线 + 站回VWAP · 证据计数 + 回踩加仓）

`vol_legs` 的**抄底家族**第一支。来源是用户 2026-11-03 定稿的「抄底确认规则 v2」（`E:\qianwen\jijin\V9抄底确认规则_v2.md`），
由 v1 的四条件-AND 版重构而来。**规则权威源 = `bottom.py::CFG`**，本文件与 `backtest/_v7_bottom_report.md` 都从它推导。

一句话：**它不预测底，只确认底部之后、价格已进入上涨趋势（而非反弹）的那一天** —— 即条件 ④（E4，放量阳、
重新站上地量日锚定的 VWAP）达成的当天。在此之前必须已有地量窗口（①）、以及 DIF 底背离或跌速衰竭（②/③ 证据），
才允许试仓；跌破阶段最低点下 3% 或收盘跌破锚定 VWAP 无条件离场。

> **它不是一个买入信号，是一张「可以开始考虑」的许可证。** v2 相对 v1 的核心变化是：① 地量从「当日事件」改成
> 「**锚点窗口开关**」（冻结锚点 d0，t−d0≤60 日）；④ 放量基准回到原文 `>1.5×前5日均量`；③ 跌速衰竭换成**真下压斜线**；
> ② 以 **DIF 为主判据**并带失效条款；**证据计数 → 仓位**（score=E2+E3，首仓 = 风险预算×0.5×折扣）；新增
> **回踩不破加仓**与**走平否决**。详见规则文档 §1 的七处修订。回撤门槛当前为 **15%**。

## 2. 规则卡（v2）

参数唯一权威源：`bottom.py::CFG`。下表的「代码」列是 `indicators()/state_machine()` 产出的字段名。

| # | 规则 | 代码 |
|---|---|---|
| 1 | **锚点冻结**：地量 = `V ≤ quantile(V[t-60:t], 0.05)`；本轮缩量段**首个**地量日冻结为 d0，t−d0 > 60 才改锚 | `indicators()["d0_idx"]` / `e1 = (d0≥0 & t>d0 & t−d0≤60)` |
| 2 | **E1 地量窗口有效**（窗口开关，非当日事件）：`E1 = exists(d0) and (d0 < t ≤ d0+60)` | `["e1"]` |
| 3 | **E2 底背离**：价格创 `div_window`(20) 日新低，而 **DIF 不新低**；且自背离成立日起未再创新低（失效条款） | `["e2"]` |
| 4 | **E3 跌速衰竭**：`close ≥ frl_0.5(t)`（真下压斜线 = `stage_high − 0.5·slope·(t−t_H)`）**或** MACD 柱连 3 日收敛 | `["e3"]` |
| 5 | **E4 触发（唯一当日条件，即「确认日」）**：`V > 1.5×mean(V[t-5:t])` 且 `close ≥ AVWAP(d0,t)` 且 `close > open` | `["e4"]` |
| 6 | **走平否决**：`\|AVWAP[t]−AVWAP[t-20]\| / AVWAP[t-20] < 1%` → 不入场（底部横盘常态，2026-11-04 由 2% 放宽） | `["flat_veto"]` |
| 7 | **前置过滤（带记忆期）**：`MA20 < MA60` 且 距 250 日高点回撤 `≥15%`（`drop_min`）；**确认日前 90 个交易日内曾满足即可**（`filt_memory_days=90`，0=要求当日） | `["filt"]` / `["filt_now"]` |
| 8 | **证据计数 → 信号**：`score = E2 + E3`；`signal = filt & e1 & e4 & (score≥1) & ~flat_veto` | `["score"]` / `["signal"]` |
| 9 | **首仓**：`risk_size = risk(5%) / (1 − 止损/入场)`，首仓 = `risk_size × 0.5 × (0.75 if score==2)`；`size_floor=10% / size_cap=100%` | `state_machine()` |
| 10 | **回踩不破加仓**：首仓后 10 个交易日内「`low ≥ AVWAP 且收阳`」→ 补满 `risk_size` | 同上 |
| 11 | **三条独立风控**：①结构止损 `low ≤ stage_low×(1−3%)`（常驻挂单、当日成交）；②VWAP 止损 `close < AVWAP` → 次日清仓；③走平否决（见 6） | 同上 |
| 12 | **离场（两段式，默认 `exit_mode=ma20`）**：①**试仓期**——收盘跌破成本线（AVWAP）→ 清仓；未跌破 → **满仓**（回踩不破当日即补满，或 `addon_days` 窗口到期补满）；②**满仓后**——收盘跌破 **MA20** → 次日清仓（结构止损仍在）。可切 `batch / rr2 / fib618 / prior_high / none` | `state_machine()` |
| 13 | **入场/再入场**：t 日收盘齐现 → **t+1 收盘**试仓（无前视）；止损后至少隔 `reentry_cooldown`(5) 个交易日且需新的 E4 | `state_machine()` |

### 2.1 为什么 ① 从「当日事件」改成「锚点窗口」

v1 把 ① 写成「当日量 = 60 日最低」并和 ④「放量 ≥2.5×均量」锁死在**同一天**，两者逻辑互斥 → 七腿 14 年只有 8 个信号、沪深300 为 0。

v2 的修法（对应规则文档 §1 第 1、2 条）：
- ① 变成**窗口开关**：存在冻结锚点 d0，且 `t−d0 ≤ 60` 且 `t > d0` 即视为「地量窗口有效」—— 不再要求地量发生在触发当天；
- 锚点 = **本轮缩量段首个地量日，冻结不重置**；仅当超 60 日未触发才改锚（否则阴跌越久越容易「变老过期」，把 2018-10、2024-02 那种「先地量、拖两个月才放量」的情形整段挡掉）。

这样 ② 是「背离生效中」的背景旗、④ 才是当日触发，三者不再要求同日。

**四条结论，按重要性排：**

1. **频率升到「季度级」，本质仍是「确认型许可」而非择时信号**。前置过滤带 90 日记忆期后，全历史 57 轮次（≈4 笔/年）
   已不算稀有；但宽基 ETF（尤其沪深300/A500）仍是最不适用的一档（规则 §7），美股两腿的量还被 QDII 额度/溢价套利污染。
   **样本 n=57 依旧偏小，胜率/盈亏比只能看方向、不能外推**。
2. **相对货基是负贡献，相对买入持有也是负贡献**。组合层六腿共同窗口（2022-06~2026-11）年化 +1.23% vs 货基 +1.40%
   （回撤 −1.23%、平均仓位 2%），择时增量 **−0.40%**。它省下的是**暴露时间**，不是亏损。
3. **瓶颈仍在 E4**（见 §4.2 消融）：去掉 E4 从 37 个信号暴涨到 1292 个。
   E4 要求「放量 >1.5×前5日均量 + 站回锚定 VWAP + 阳线」同日成立 —— 这正说明 E4 是规则的「确认」闸门。
4. **止损锚是「阶段最低点」而不是入场价，所以必须配仓位管理**（见 §6）。

**判定流程（照这个顺序看，别跳）：**

1. 先看**前置过滤**：近 90 个交易日内是否出现过「跌过 15% 且 MA20 下穿 MA60」？没有就不看后面。
2. 再看**地量窗口**：存在冻结锚点 d0 且 `t−d0 ≤ 60`？没有就等下一轮缩量。
3. 然后才是 **E2 背离 / E3 跌速**：它们是背景证据（`score = E2+E3`），决定首仓折扣（score==2 再 ×0.75）。
4. **E4 触发（确认日）**才是当日事件：放量 >1.5×前5日均量、站回锚定 VWAP、且收阳 —— 三者齐了 `signal` 才为真。
5. 还要注意**走平否决**：锚定 VWAP 近 20 日变动 <1%（拉锯）时不入场。
6. 齐现了才试仓，**仓位按止损距离反推**（单笔风险 ≈ 该腿额度的 5% × 首仓 0.5）；之后按**两段式**走：
   试仓期只要「收盘跌破成本线（AVWAP）」就清仓；未跌破则补满（回踩不破当日补，或 10 日窗口到期补）。
   **满仓后只看 MA20**：收盘跌破 MA20 次日清仓（结构止损 stage_low×0.97 作为极端兜底仍在）。

**与本策略本质再强调一次**：E4 达成的那天 = 「放量阳、且站回地量日锚定 VWAP」的那天，是**底部之后确认进入上涨趋势（而非反弹）**的日子。
策略买的是「跌势已经修复到多数人回本」的时刻，不是最低点；所以永远会漏掉一部分底部。

**与主策略的关系**：本变种管「这只标的能不能开始碰」，主策略管「这条腿一共给多少 pp」。两者**层次不同，可以并存**，
但叠加时先定额度优先，不要两套规则同时决定同一份钱。

**不进每日流程**（`pipeline/strategies.json` 里 `daily.enabled=false`）：仍是低频确认型信号（七腿十四年全历史 57 笔），
每天出一张以 ❌ 为主的卡意义有限；需要时手跑上面的脚本，或在深跌月份临时启用。

## 6. 已知的洞（读结论前先看这一节）

1. **规则没有时间止损。** kc50 2022-10 那笔横了 **226 个交易日**才被「再创新低」带出来（−10.7%）——
   止损没触发、止盈没到、新低没破，仓位就一直挂着。`max_hold`（默认 0 = 不启用）是可选补丁，启用即等于**新增规则**。
2. **默认离场已改成两段式 `ma20`，代价是回撤变大。** 试仓期跌破成本线即走、满仓后跌破 MA20 才走，
   持仓中位从 3~5 日拉长到 7~12 日；组合回撤从 −0.64%（batch）放大到 **−1.23%**，年化从 +1.68% 降到 +1.23%。
   这是「让利润奔跑」的必然代价，不是 bug。切回 `batch/rr2` 会在 +8%~+20% 就卖掉一半（旧行为）。
3. **代理口径。** ndx / spx 用人民币场内 ETF，叠加汇率与溢价折价，抄底判定会偏离美股本身形态；且其成交量含 QDII 额度/套利，
   E4 的「放量」不是标的本身量能（规则文档 §7 建议换「成交额分位 + 溢价率」或剔除组合层）。
4. **止损按日线最低价判定。** 日内顺序未知，同一日既触止损又冲高时一律按「先止损」处理（保守）；
   跳空低开按开盘价成交 —— 不假装止损永远精确。
5. **样本偏小**：全历史 57 笔信号（单腿每年 1~2 笔）。**任何关于「未来赚多少」的推断都不成立**，本文所有数字只用于判断方向。
6. **成交量未复权**（`get_daily` 的成交量是原始手数）。拆分/大额申赎日会有台阶，1.5× 阈值是当日相对量，影响有限但不为零。

## 7. 适用性边界（重要：为什么在本仓库池上几乎不触发）

规则文档 §7 明确指出这套方法源自**个股**（价格 50~110 区间，筹码集中在少数人手里），对宽基 ETF 有天然不适：

- **沪深300 / A500 这类超大盘宽基最不适用** ——「60 日最低量」常常只是做市清淡，不等于空头衰竭；
  规则文档原话：「沪深300 为 0 个信号 有一半不是 bug，是不适用」。当前默认在沪深300 上 22 笔（14 年，胜率仅 36%）。
- 相对更贴近原意的是**高波动、散户筹码多的品种**：创业板（159915）、科创50（588000）、恒生科技（513180）。
  本仓库池里 kc50 / hkt 比 hs300 / a500 更贴近，但美股两腿（513100 / 513500）的量被 QDII 额度与溢价套利污染，
  E4 的放量判据在这两腿上**不是标的本身的量能**。
- **建议**：若要真用，应换到 159915 这类品种，并把 ndx / spx 的 E4 量条件换成「成交额分位 + 溢价率」，或在组合层剔除这两腿。
  当前七腿宽基池上，v2 的正确结论是「它少触发、收益≈货基，但触发后多方占优（确认成功率 69%、60 日后中位 +6.5%）」—— 这本身印证了规则文档的适用性边界，不是实现 bug。
