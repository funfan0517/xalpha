# V7 抄底确认 v2（地量窗口 + 背离 + 跌速斜线 + 站回VWAP · 证据计数+回踩加仓） · 回测报告

> 生成：`backtest.py` · 数据截至 **2026-11-04** · 行情 `data/_v7_klines.json`（前复权，成交量原始）
> 规则权威源：`bottom.py::CFG` · 参数：地量分位 q0.05/60日 / 锚点有效期 60日 / 背离(DIF) 20日 / E4 放量 >1.5×前5日均量 / 回撤门槛 15% / 前置 MA20<MA60（记忆 90 日） / 结构止损 −3% / 走平否决 <1% / 止盈 ma20 / 试仓 risk（首仓 50%·score2 折扣 0.75）

## 0. 结论先行

1. **频率升到「季度级」，但本质仍是「确认型许可」而非择时信号**：七腿 14 年合计 **71 个信号日 / 57 笔轮次**（3.95 笔/年，七腿合计），七腿里有 1 条腿全程 0 信号。前置过滤带 90 日记忆期后，它不再「几乎不触发」；但宽基 ETF（尤其沪深300/A500）仍是最不适用的一档（规则 §7），美股两腿的量还被 QDII 额度/溢价套利污染。**样本 n=57 依旧偏小，胜率/盈亏比只能看方向、不能外推**。
2. **相对现金是微弱正贡献，相对买入持有是明显负贡献**：7 腿里 **1 腿**年化高于货基 +1.40%，但只有 **2 腿**高于同标的买入持有。它省下的从来不是亏损（各腿买入持有回撤 −24%~−62%），而是**暴露时间**：平均仓位 2%，其余是货基。定位应当是「现金的择时代替品 / 观察许可」，不是收益放大器。
3. **组合层跑赢现金，但大部分来自暴露时间**：2022-06 起 4 年六腿共同窗口，组合年化 **+1.23%** vs 货基 +1.40% vs 静态带 +17.19% vs 买入持有 +11.48%；比货基高 -0.17%，但**择时增量（组合 − 同曝光被动）只有 -0.40%** —— 信号本身的增量有限，双边成本（申购 0.10% + 赎回 0.50% + 双边滑点 0.20%）把大部分吃掉了。共同窗口只有 50 笔轮次，这个量级下任何「收益」都该当噪声看。
4. **止损锚是「阶段最低点」而非入场价，必须配仓位管理**：入场常在阶段低点上方 10%~25%，止损因此离入场价很远。科创50 固定满仓档回撤 **-12.83%**（超过规则要求的 15%~20%），按止损距离定量（`size_mode=risk`，单笔风险 5%）后降到 **-6.56%**。这不是策略缺点，是「3% 指的是离最低点，不是离成本」的直接后果。
5. **漏底诊断：默认只接住 4/7 个历史大底**（最宽口径 4/7）。这正符合规则的「确认」定位 —— E4 要求放量阳**重新站回地量日锚定的 VWAP**，而地量锚点在下跌途中（含其前的高价成交），深跌时价格远低于锚定 VWAP，要「站回成本线」几乎等于要先涨回地量日前后的均价，V 型反转才够格。所以它系统性漏掉「最低点」，只接住「已经修复到多数人回本」的那一段。仍漏的 3 次卡点 —— 贸易战底（还没有地量锚点（或已过期）、跌速未衰竭（不在 0.5 斜线上方 / hist 未收敛））；疫情底（还没有地量锚点（或已过期）、跌速未衰竭（不在 0.5 斜线上方 / hist 未收敛））；关税底（近 90 日内未出现「MA20<MA60 且回撤≥15%」（当日回撤 16.3%）、今日非阳线、近 20 日无有效底背离（或已失效）、跌速未衰竭（不在 0.5 斜线上方 / hist 未收敛））。
6. **「确认回升」vs「反弹」：样本只有 95 笔，无法下结论**：95 笔买入里 23 笔 20 日内破 stage_low（确认成功率 76%）；改参数前（锚点 90/回撤 20%/2.5×）是 8 笔 / 100%。n 都只有个位数，置信区间覆盖 0~100%，只能说明「规则在极少触发时，触发后的破位率不高于随机」，不能证明它有择时信息量。
**怎么用（结论）**：当「已跌 15% 以上的标的」出现〔地量窗口有效 + 放量阳重新站上地量日锚定 VWAP〕，且期间有过 DIF 底背离或跌速收敛（score≥1）时，**允许**用「该腿额度 5% 的风险预算」试仓（首仓再乘 0.5、score==2 再乘 0.75），止损挂在阶段最低点下 3%；回踩不破再补满。它是「可以开始考虑」的许可，不是买入信号 —— 单腿约每年 1~2 次，且宽基池上质量参差（见 §10）。若要真用，应换到高波动、散户筹码多的品种（如创业板 159915），并把美股两腿的 E4 量条件换成成交额分位+溢价率（见 README §7）。

## 8. 口径与已知的坑

1. **前复权**：`xa.get_daily` 默认前复权，`close>open` 与 `low` 用同一套缩放，判定不受除权影响；成交量是原始手数（拆分日会有台阶，但 1.5× 阈值是当日相对量，影响有限）。
2. **代理**：ndx/spx 两腿用人民币场内 ETF（513100/513500），不是美元指数本身 —— 叠加了汇率与溢价折价，抄底判定会偏离美股本身的形态。这是唯一的口径妥协。
3. **止损按日线最低价判定**：日内顺序未知，若同一日既触及止损又冲高，一律按「先止损」处理（保守）。跳空低开按开盘价成交，成交价 `min(stop, open)`。
4. **止盈/新低是收盘决策、次日收盘成交**：多付一天的滑价，但不需要盘中判断。
5. **组合层不做额度再平衡**：各腿权重按目标带固定，某腿满仓时组合仍留现金。
6. **规则没有时间止损，这是个真实的洞**：kc50 2022-10 那笔横了 **226 个交易日**才被「再创新低」带出来（−10.7%）—— 止损没触发、止盈没到、新低没破，仓位就一直挂着。`max_hold`（默认 0 = 不启用）提供可选补丁，敏感性表里有它的对照；启用它等于**新增规则**，不是原规则的一部分。
7. **1:2 盈亏比在宽止损下几乎等于没设止盈**：止损锚在阶段最低点，止盈价 = 入场 + 2×(入场−止损) 常常在 +20%~+50%，实际出场多半来自「再创新低」。若想要真正的 1:2，应当用**入场价**而不是阶段最低点算风险 —— 但那就改了规则的锚。

### 9.3 为什么「接住底部」和「高胜率」天然冲突

1. **瓶颈在 E4，不在 ②③④ 的组合**：v2 把 ① 改成「锚点窗口」（不再是当日事件）、② 是「底背离生效中」的背景旗、④ 才是当日触发。所以 ②③④ 不再要求同日——真正稀缺的是 ④：放量 >1.5×前5日均量、且阳线、且**站回地量日锚定的 VWAP**。三者同时落在「近 90 日内曾跌 15%+ 且 MA20<MA60」的窗口里（消融显示去掉 E4 立刻从 37 个信号暴涨到 1292 个）。这正说明 E4 是规则的「确认」闸门。
2. **④ 的锚在下跌途中**：地量日锚定的 VWAP 包含地量日**之前**的高价成交，所以 2015-08 与 2016-01 当天 close 比 VWAP 低 18.4% / 8.9% —— 要「站回成本线」，必须先涨回地量日前后的平均成本，V 型反转才能满足。这既是它稀有的原因，也是它算「确认」的原因。
3. **趋势类信号能接住全部 7 个底，但代价完全不同**：hs300 上「收盘上穿 MA20」在 7 个底后 1~16 个交易日内全部出现（7/7），但全历史有 **201 次**（≈15 次/年）。这正是 `../v1_ma20/`、`../v3_macd_boll/` 在做的事，而它们的回测结论是「只降回撤、不增收益」——问题不在能否定位，在噪声与成本。

> **结论**：它买的是「跌势已经修复到多数人回本」的时刻，而不是「最低点」；所以永远会漏掉一部分底部 —— 差别只在漏几次、以及为了少漏要付多少胜率。当前参数（锚点 60 日 / 回撤 15%）是「覆盖」与「准确」的一个折中，再往前走就是普通反弹买入了。
