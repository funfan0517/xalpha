# V7 变种 · 回撤止损（移动止损 · 崩盘保险）

`vol_legs`（波动资产操作规则 v1.4）的**第七个变种**，2026-11-04 按用户「降回撤、牺牲少量收益」的要求，
把「跌破回撤阈值减仓、收复 MA200 回满」的思路正式化。

> **编号说明**：V7 编号此前与 `v7_bottom_confirm/`（抄底确认）共用 —— 那支「跌透了、出现反转证据才碰」，
> 这支「跌快了先躲」，方向相反、不可叠加。**`v7_bottom_confirm/` 已于 2026-11-04 删除**（结论见主 README §9
> 与 git 历史 `8f8161d`），本目录是家族内唯一使用 V7 编号的变种。

规则权威源：`trailing_stop.py` 顶部常量（`params()` 打包）。

一句话：**不猜顶、不预测，只在「从持仓期高点回撤超过 X%」时把该腿目标带砍到 floor，
等价格重新站回 MA200（趋势修复）再回满。** 它是**崩盘保险**，不是收益引擎。

## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 触发减仓 | `close / 持仓期高点 − 1 < −STOP_PCT`（默认 −15%）→ 该腿目标带降到 `FLOOR`（默认 50%） |
| 触发回满 | 减仓态下 `close > MA(REENTRY_MA)`（默认 200）→ 回到满带 100% |
| 回撤锚点 | **随（再）入场重置为当时高点**（标准移动止损口径，不是固定回看 1 年） |
| 预热 | `MA200` 成形前不交易（保持满带起步） |
| 成交 | T 日盘后算信号、**T+1 收盘成交**（与 v1~v6 同一纪律） |
| 空仓计息 | 减仓部分按货基 `rule.CASH_ANNUAL` 逐日计息 |
| 频率帽 | 同一腿两次调仓最小间隔 `ACTION_GAP`（默认 1 个交易日） |

仓位语义 = **目标带上的闸门**：`state ∈ {100%, 50%}` 是「占本腿目标带的比例」，带位仍由主策略
`rule.LEGS[leg]["band"]` 决定。基准对照是**静态带（恒持满带）**。

> **为什么不用「固定回看 1 年高」做锚**：刚回满时价格通常仍低于旧高点，同一段回撤会被反复触发
> （每 2 天止损/回满一次，费用与亏损都爆炸）。锚点随入场重置，才不 flip-flop。

## 2. 为什么是「止损」而不是「趋势闸门（v5）」

美股/A股的大回撤几乎都是**快跌**（2020 几周 −34%、2022 阴跌、2015 三个月 −45%）：
- 慢均线（v5 的 MA250 四象限）要等趋势确认，确认时坑已经挖完 —— 实测把仓位从 100% 软降到
  70~80%，回撤几乎不动（`v5` 在 spx/ndx 上「年化 −2.95 / −2.97pp、回撤只浅 1.0 / 3.0pp」）；
- **移动止损**对快跌反应快：价格从持仓高点跌掉 X% 立刻减仓，收复 MA200 再进，
  正好吃「快跌段」的亏、留住「趋势修复后」的涨。

但代价同样真实（见 §3）：**止损把「快跌 + 趋势修复」的腿保护得很好，却会把「围绕阈值插针」的腿
反复打脸** —— 这是规则的适用边界，不是 bug。

**读法**：
- **回撤改善**集中在 **科创50（−5.3pp）、恒生科技（−8.4pp）、标普500（−7.6pp）**；A500 只有 −1.1pp，
  沪深300 几乎为 0；**纳指100 反而更深（−37.88% vs −29.47%）** —— 它在 2022 阴跌里「卖在坑里、
  追在高处」，是最典型的反例。
- **跑赢静态带的只有科创50（+1.70pp）**；其余六腿都让渡年化（−0.04 ~ −2.64pp）。这是「保险要交保费」。
- 若只看「少量收益换明显回撤」：**标普500（−2.0pp 换 −7.6pp 回撤）、恒生科技（持平换 −8.4pp）、
  科创50（反而 +1.7pp 且回撤 −5.3pp）** 是性价比最高的三条。
- **夏普没变好（−0.25 ~ 0.73）**：本变种改善的是「尾部」，不是「风险调整后收益」——
  减仓期收益归零、回补后追高，波动下降与收益下降基本同幅。别拿它当提升夏普的工具。

## 4. 组合层（七腿共同窗口 2022-06~2026-11 · 4.4 年，按目标带权重归一化，满仓 = 40pp）

> 共同窗口受恒生科技/科创50 场外净值起点限制，**看不到 2015 / 2018 / 2020 的大崩盘** ——
> 这也是「组合层回撤改善很小」的原因：该窗口里七腿组合没有同步大跌。

| 组合 | 年化 | 最大回撤 | 夏普 | 平均曝光 |
|---|---:|---:|---:|---:|
| 静态带（七腿恒持满带） | +15.74% | −12.52% | 1.24 | 100% |
| **V7 默认（七腿全套止损）** | +13.42% | −12.43% | 1.11 | 94% |
| V7 默认 · 不计费 | +13.61% | −12.43% | 1.13 | 94% |
| V7 只套三腿（kc50/hkt/gold · 对照） | +15.61% | −12.43% | 1.27 | 97% |
| 七腿等权（恒定持有） | +10.00% | −17.16% | 0.62 | 100% |

- 七腿默认相对静态带：年化 **−2.3pp**（+13.42% vs +15.74%）、回撤只浅 **0.09pp**（−12.43% vs −12.52%）
  —— 该窗口没有崩盘可保，等于**白交保费**。
- **只套三腿（kc50/hkt/gold）几乎打平静态带**（+15.61% vs +15.74%、回撤同为 −12.43%），
  说明「在哪条腿上用」比「用不用」更重要。
- 不计费 vs 含费差约 0.2pp —— 费用不是本窗口的主要矛盾（调仓少），但**长期/窄止损下会放大**（§5）。

> **这段窗口里，止损参数对回撤几乎无用**：11 档组合全部落在 −12.05% ~ −12.45%，带宽仅 0.4pp。
> 它真正改变的是换手与收益 —— 止损从 10% 放宽到 25%，年化 **单调升**（+12.83% → +15.07%）、
> 调仓次数 **单调降**（86 → 16 次）：更紧的止损在本窗口是**纯付费用**。
> 「清仓 vs 半仓」在组合层只差 2.2pp 年化（+11.23% vs +13.42%），远小于逐腿层的差距 —— 七腿同时插针的概率低。
> 空仓起步几乎无影响（+13.48% vs +13.42%），说明结果不依赖初始仓位运气。
> 参数都写死、不做 walk-forward 选优，结论不靠某一格成立。

## 6. 口径与已知边界

1. **不是万能降回撤**：只对「快跌 + 之后趋势修复」的腿有效。对围绕阈值频繁插针的腿（沪深300、
   纳指100 的部分窗口）会「卖在坑里、追在高处」，扣费后可能更差（§3 逐腿）。
2. **费用是生死线**：A 类场外（申购 0.10% + 赎回 0.50% + 滑点 0.1%）下，止损频繁的腿会被费用吃掉；
   场内 ETF / 免佣账户下净收益明显改善（§4「不计费」列即上限）。
3. **锚点是移动止损口径**：随（再）入场重置为当时高点，不是固定回看 1 年（否则 flip-flop，见 §1）。
4. **黄金放宽到 20%**（`STOP_BY_LEG`）：商品波动结构与股票不同，15% 会频繁误伤。
5. **代理口径**：A500 / 标普前段是桥接（`000051` / `050025`），那段不是本基金业绩；美股腿用场外
   人民币复权净值，叠加汇率与溢价。
6. **未计**：大额限购、QDII 额度关闭时的顺延、赎回确认时滞、C 类销售服务费。

## 7. 与其它变种的关系

- 同属「逐腿进出时点」层（与 v1/v2/v3/v5 同层），但**方向相反于突破型**：v1/v2/v3 是「涨起来才追」，
  本变种是「跌下去才躲」。
- 与主策略可叠加（主策略定带位、本变种定「这条带今天露多少」），但**不要与突破型叠加在同一份额度上**。
- 与 v5 趋势闸门是「互补的两把刀」：v5 用慢均线躲**阴跌**，v7 用移动止损躲**快跌**；
  两者对「插针」都无能为力，只是 v7 的触发更快。
