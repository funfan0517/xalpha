# 波动资产 · V7 变种：回撤止损 · 七腿回测
> 池与主策略**完全一致**：`rule.LEG_ORDER` 七腿（中证A500 / 沪深300 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金）
> 价格 = 场外**复权净值**（含分红再投 / 汇率 / 跟踪误差）· T 日盘后算信号、**T+1 收盘净值成交** · 空仓按货基 1.40% 计息 · 成本 = 真实申赎费 + 单边滑点 0.10%
> 规则来源：用户 2026-11-04 的「回撤止损」思路（跌破近 1 年高 X% 减仓、收复 MA200 回满），权威源 `v7_trailing_stop/trailing_stop.py` 顶部常量

## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 触发减仓 | `close / 持仓期高点 − 1 < −15%`（锚点随（再）入场重置为当时高点，标准移动止损）→ 该腿目标带降到 `50%` |
| 触发回满 | 减仓态下 `close > MA200` → 回到满带 100% |
| 预热 | `MA200` 成形前不交易（保持满带起步） |
| 成交 | T 日盘后算信号、T+1 收盘成交（与 v1~v6 同一纪律） |
| 频率帽 | 同一腿两次调仓最小间隔 1 个交易日 |

> **定位**：这是**崩盘保险**不是收益引擎。它只在「从近一年高点快速回撤」时减仓，等趋势修复再进；对慢牛/阴跌无效，对频繁插针的腿甚至会「卖在坑里、追在高处」。

## 6. 口径与已知边界

1. **不是万能降回撤**：它只对「快跌 + 之后趋势修复」的腿有效。对频繁围绕 −15% 插针的腿（沪深300、纳指100 的部分窗口），会「卖在坑里、追在高处」，扣费后可能更差（见 §2 逐腿）。
2. **费用是生死线**：A 类场外（申购 0.10% + 赎回 0.50% + 滑点）下，止损频繁的腿会被费用吃掉；场内 ETF / 免佣账户下净收益明显改善（§3 的「不计费」列就是上限）。
3. **参数（近高窗口 / 止损宽度 / 回满线）都写死**：不追求最优，§4 已给出敏感性；结论不靠某一格参数成立。
4. **黄金放宽到 20%**（`STOP_BY_LEG`）：商品波动结构与股票不同，15% 会频繁误伤。
5. **代理口径**：A500 / 标普的样本前段是桥接（`000051` / `050025`），那段不是本基金业绩；美股腿用场外人民币复权净值，叠加汇率与溢价。
6. **未计**：大额限购、QDII 额度关闭时的顺延、赎回确认时滞、C 类销售服务费。
