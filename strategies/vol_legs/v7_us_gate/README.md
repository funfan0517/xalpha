## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 信号价 | **美元指数收盘**（`.NDX` / `.INX`），**不是** QDII 人民币净值 |
| 均线 | 200 日简单均线（日频算、月末看） |
| 看盘频率 | 每月**最后一个交易日**收盘 → **次一交易日成交** |
| 闸门层 | 连续 **2 个月**收盘在年线下方 → 纳指 **0%** / 标普 **50%**；否则 100% |
| 深破位豁免 | 首次破位即低于年线 **3% 以上** → **当月就减**，不等第二个月 |
| **波动层** | **最终权重 = 闸门 × `min(1, 20% / vol20)`**，月末用美元指数算 vol20 |
| **死区** | 闸门层没变时，新目标与现仓差 **< 10pp 不调仓**（几 pp 的微调是纯手续费） |
| 回补 | 收盘重新站上年线 → **次月即回到闸门 100%**（同样乘波动层系数） |
| 成本 | 单边 0.1%（文档主口径）；0.6% 场外现实口径见 §5 |
| 空仓计息 | 未投部分按货基 `rule.CASH_ANNUAL`（1.40%）逐日计息 |

> **两层 + 一道闸**：闸门层管「熊市里露多少」（二元、低频，14 年 22 次）；波动层管「高波动期露多少」
> （连续、每月都算）；死区管「值不值得动手」（14 年只动 70 次）。
> **三者不能互相替代**：TV20 下关掉深破，2020-02 那个月会重新变成满仓挨打；关掉波动层，
> 2020/2022 的高波动段又要闸门独自扛；去掉死区，调仓从 70 次涨到 104 次而 Calmar 更低。

> ⚠ 两个已标定的坑：**深破位 3% 是单事件标定**（§10 第 7 条）；**波动层是风险预算不是择时**（§10 第 8 条）。

## 8. 硬断言（8/8）

| 检查 | 结果 |
|---|---|
| 恒满（不触发减仓 + 关波动层）净值 == 买入持有（零费） | ✅ 两腿逐日一致 |
| 闸门层仓位 ∈ {100%, 减仓后比例}；叠加波动层后仍 ∈ [0, 100%] | ✅ 不加杠杆 |
| 决策在信号月末、仓位只在决策日之后生效（T+1，无前视） | ✅ 两腿逐日一致 |
| 截掉最后 6 天重跑，历史仓位不变（无前视） | ✅ 最大差 0 |
| 两腿恒满时组合 == 50/50 手工复利（零费） | ✅ 差 0 |
| 深破位免确认只在首月破位 3% 以上时提前动手（共 8 次） | ✅ DEEP=0 时 0 次 |
| 波动层 `scale == min(1, TV/vol)`、`target = gate×scale ≤ gate` | ✅ 两腿逐条一致 |
| **死区生效**：闸门未变时目标仓位要么不动、要么变化 ≥ 10pp | ✅ 未变的月末对 307 个 |

> 上一版实现里踩过一个真前视：仓位在「成交当日」就赚了当日收益（应为 `state.shift(1)`）。

## 10. 口径与已知边界

1. **样本只到 2012**：不含 2000-2002（纳指 −83%）与 2008 —— 那正是年线闸门唯一「救命」的窗口。
   文档表2/3 的长史（1871/1991 起）才是它真正的证据来源；本仓库这一段只是**样本内复核**。
2. **它治慢熊、不治急跌**：2020 那种 5 周跌完的行情，月末规则结构上抓不到。**深破位只补「月末破位已经很深」
   的部分，波动层只补「高波动期少露一点」**，月内闪崩仍然躲不掉。
3. **只降不升、不加杠杆**：年化让渡是保费，不是 alpha；目标指标是 Calmar 与波动。
4. **QDII 通道风险未计**：额度关闭、限购、溢价、赎回 T+2~T+7；「月末信号 → 次月首个交易日成交」
   实盘可能滑到第二三天。70 次调仓的摩擦权重比纯闸门的 22 次高得多。
5. **净值信号不复现文档结论**（见 §6 第 2 点），别把这句当已验证事实引用。
6. **不做 walk-forward 选优**：参数写死（MA200 / 2 月 / 深破 3% / TV20 / 死区 10pp / 纳指 0 / 标普 50%），§5 已给敏感性。
7. ⚠ **深破位阈值 3% 是单事件标定的**：2 个月确认的滞后只在 2020-02→03 一次上真正付了钱，而 3% 恰好落在
   那次破位（标普 −3.05%）与其余所有首次破位（最近的 2025-03 为 −2.58%）之间的窄缝里 ——
   **样本内漂亮，样本外没有证据**。改用「破位深度 / 月波动」标准化（z 值）不能复现同样的切分
   （新冠那次只有 −0.43σ，与 2019-05 假摔 −0.20σ 分不开）。`DEEP=0` 即退回。
8. **波动层是风险预算、不是择时**：①低波动阴跌（波动率低但一直跌）里它会满仓挨打，与 v9 共同的失效模式；
   ②它把换手从 26 次推到 70 次，**场外 A 类 0.6% 会吃掉 0.57pp**，场内 ETF 或低费率通道更合适；
   ③它不改变方向判断，只按 vol20 缩放 —— **信号源（美元指数）错了，两层一起错**。
9. **死区是「省手续费」参数，不是风控参数**：放宽到 10pp 会让减仓/回补平均慢半拍（因为它只在
   「闸门没变」时才起作用，闸门触发不受影响），代价是波动层对急跌的反应略钝。20pp 开始明显变钝（Calmar 1.11）。
