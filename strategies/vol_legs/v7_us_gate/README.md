## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 信号价 | **各腿真实指数收盘**（美股 `.NDX` / `.INX`、A股/港股指数、黄金 518880），**不是** QDII 人民币净值 |
| 均线 | 200 日简单均线（日频算、月末看） |
| 看盘频率 | 每月**最后一个交易日**收盘 → 次一交易日（次月首个交易日）成交 |
| 闸门层 | 连续 **2 个月**收盘在年线下方 → 减到该腿 `FLOOR`（纳指 0% / 标普 50% / 其余 0%）；否则 100% |
| 深破位豁免 | 首次破位即低于年线 **3% 以上** → **当月就减**，不等第二个月 |
| **波动层** | **最终权重 = 闸门 × `min(1, 20% / vol20)`**，月末用该腿指数算 vol20 |
| **死区** | 闸门层没变时，新目标与现仓差 **< 10pp 不调仓**（几 pp 的微调是纯手续费） |
| 回补 | 收盘重新站上年线 → **次月即回到闸门仓位**（同样乘波动层系数） |
| **日频离场**（默认开） | MA50 在 MA200 下方 → **次日清仓**，不等 2 个月确认；重新金叉即回到闸门算出的仓位（`EXIT="none"` 关闭） |
| 月中补丁（默认关） | `PATCH="fast"` 时叠 v9 快减/快补：5 日跌 ≤−5% 且 vol20 ≥1.4×TV → 提前减；vol20 ≤70%×60 日峰值且站上 MA10 → 补回 |
| 成本 / 计息 | 单边 0.1%（主口径，0.6% 场外现实口径见回测报告 §4）；空仓按 `rule.CASH_ANNUAL`（1.40%）逐日计息 |

> **四层分工，不能互相替代**：闸门层管「熊市里露多少」（二元、低频）；波动层管「高波动期露多少」（连续、每月都算）；
> 离场管「**速度**」——把 2 个月确认窗里那段阴跌提前砍掉；死区管「值不值得动手」。
> 2026-11-17 加入的离场正是补前两者的共同盲区：确认窗内趋势已经坏了，但月末规则还没到触发点。

## 6. 硬断言（9/9 通过）

| 检查 | 结果 |
|---|---|
| 恒满（不触发减仓 + 关波动层 + 关离场）净值 == 买入持有（零费） | ✅ 全池逐日一致 |
| 闸门层仓位 ∈ {100%, `FLOOR`}；叠加波动层后仍 ∈ [0, 100%] | ✅ 全池通过（不加杠杆） |
| 决策在信号月末、仓位只在决策日之后生效（T+1，无前视） | ✅ 全池逐日一致 |
| 截掉最后 6 天重跑，历史仓位**与离场掩码**不变（无前视） | ✅ 最大差 0 |
| 全池恒满时组合 == 7 腿等权手工复利（零费） | ✅ 差 1.3e-15 |
| 深破位免确认只在首月破位 3% 以上时提前动手（全池 44 次） | ✅ `DEEP=0` 时 0 次 |
| 波动层 `scale == min(1, TV/vol)`、`target = gate×scale ≤ gate`（1306 条决策） | ✅ 全池逐条一致 |
| **死区生效**：闸门未变时目标仓位要么不动、要么变化 ≥ 10pp（未变的月末对 955 个） | ✅ 全池逐条一致 |
| **日频离场只减不加**：开离场后仓位逐日 ≤ 关离场 | ✅ 全池逐日成立 |

> 上一版实现里踩过一个真前视：仓位在「成交当日」就赚了当日收益（应为 `state.shift(1)`），
> 这个 bug 让所有档位的回撤看起来一模一样 —— **改时点类规则时必查这一行**。离场掩码同理，走 `shift(1)`。

## 7. 口径与已知边界

1. **组合层样本自 2020-07-27 起**（七腿指数的共同样本，起点由最晚的那条腿决定），
   逐腿样本自 2005-01-03 起（真实指数长库），**完整包含 2008**，但不含 2000-2002（纳指 −83%）。
   两腿 14.2 年（2012-08 起）那一版是扩池前的沿革，读数见 git 历史与回测报告 §5 的文档对照。
2. **信号与执行同源（真实指数）**：收益不含汇率、QDII 跟踪误差与分红再投；美股腿实盘下单场外 A 类，
   对账时按 −1.3pp/年 折算分红。
3. **只降不升、不加杠杆**：年化让渡是保费，不是 alpha；目标指标是 Calmar 与回撤，不是收益。
4. **日频离场的长样本证据强于七腿证据**：31.8 年两腿（Calmar 0.60 → 0.84）比 6.3 年七腿（0.96 → 1.15）更可信；
   单看短样本容易高估。逐腿上 A500 与恒生科技的日频回撤反而更深（见 §3），A 股整体对它不敏感 ——
   **扩池结论跨市场外推要打折**。
5. **`PATCH="fast"` 不进默认档**：只在 V 型急跌窗口有用（2020-02~08 修回来 +8pp），全样本夏普只 +0.01、调仓却多 61 次。
6. **标普减半而非清仓**：文档实测清仓把标普年化压到 10.07%（Calmar 0.54），减半保住更多上行。
   本仓库扩池后换成 2005 起真实指数，「年线+2月确认（清仓）」与「半仓闸门」的 Calmar(月末) 只差 0.04
   （0.32 vs 0.28）—— **口径沿用文档，未按新样本重标**。
7. **QDII 通道风险未计**：纳指/标普 QDII 有额度关闭、限购、赎回 T+2~T+7，「月末信号 → 次月首个交易日成交」
   实盘可能滑到第二三天；141 次调仓的摩擦权重比纯闸门（`TV=0`，49 次）高得多，场外 0.6% 会吃掉 0.87pp（年化 → +7.48%）。
8. **不做 walk-forward 选优**：参数写死（MA200 / 2 月 / 深破 3% / TV20 / 死区 10pp / MA50·200 离场 / 纳指 0 · 标普 50），
   敏感性见回测报告 §4。
9. ⚠ **深破位阈值 3% 是单事件标定的**：2 个月确认的滞后只在 2020-02→03 一次上真正付了钱，3% 恰好落在
   那次破位（标普 −3.05%）与其余首次破位（最近的 2025-03 为 −2.58%）之间的窄缝里 —— **样本内漂亮，样本外没有证据**；
   `DEEP=0` 即退回。
10. **波动层是风险预算、不是择时**：低波动阴跌（波动率低但一直跌）里它会满仓挨打；它每月只在月末调一次，
    月中「当前仓位」不变。
