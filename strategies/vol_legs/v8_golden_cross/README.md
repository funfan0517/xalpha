# V8 变种 · 美股两腿金叉 50/200 × 波动层 TV20（日频 · 连续仓位）

`vol_legs`（波动资产操作规则 v1.4）的**第八个变种**，2026-11-05 落地，**同日起波动层为默认档**。

- **标的池只有两条腿**：纳指100（`270042`）+ 标普500（`017641`/`050025` 桥接）。
- 规则权威源：`golden_cross.py` 顶部常量（`params()` 打包）。
- 一句话：**`仓位 = (MA50 > MA200 ? 1 : 0) × min(1, 20% / vol20)`**，日频、死区 10pp。

> ⚠ **先读结论**：加了波动层之后，回撤从「与买入持有一样深」变成「浅 10pp」，
> 但**年化与夏普仍双双低于买入持有**（+10.82% vs +15.15%、0.73 vs 0.78）。
> 它换到的是 **Calmar 0.71 → 0.93**。而同一层波动层如果不配金叉门（= `v10_vol_layer`），
> 夏普直接到 0.85 —— **在这段样本里，方向门是净扣分项**。两段证据必须一起读，见 §4 与 §8。

## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 信号价 | **美元指数收盘**（`.NDX` / `.INX`），**不是** QDII 人民币净值 |
| 方向门 | `MA50 > MA200` → 1.0；否则 → 0.0 |
| 波动层 | × `min(1, TV / vol20)`，TV = **20%**，`vol20` = 20 日收益标准差 × √252 |
| 死区 | 方向未变时 `|Δ仓位| < 10pp` 不动手 |
| 看盘频率 | **每日收盘**（月末档作对照） |
| 成交 | `t` 日收盘决策 → **`t+1` 收盘成交** → 新仓位自 `t+2` 起承担收益 |
| 上下限 | 100% / 0%（不加杠杆） |
| 成本 | 单边 **0.1%**（文档主口径）；0.6% 场外现实口径见 §5 |
| 空仓 | 未投部分按货基 `rule.CASH_ANNUAL`（1.40%）逐日计息 |
| 预热期 | MA200 未成形（前 199 根）按「已满仓」计，与买入持有同起点 |

**两个旋钮，别混**：方向门决定「能不能持仓」（0 或 1，一年翻 2 次）；
波动层决定「持多少」（0~100% 连续，天天在变，靠死区过滤）。
**v8 的 132 次调仓里只有 28 次来自翻叉**，其余全是波动层的微调。

**为什么默认加这一层**（`research/_probe_vol_layer.md` 实测）：纯二元金叉不是被「打脸太多」
拖死的，是被「转向太晚」拖死的 —— 2020 年价格 03-09 就破年线，MA50 要到 04-30 才穿 MA200
（晚 7 周多），方向信号来的时候坑已经砸完了。**波动信号 5 天就到**，所以这一层买的是反应速度。

**为什么 TV 写死 20%、不搞「自适应」**：目标随长期波动漂移（TV ∝ vol250/中位）最多与常数 TV
打平且换手更高；五种估计子（max(20,60)/blend/EWMA/vol10/vol60）全都不如纯 vol20；
分位五档更差（夏普 0.50）。**波动层不需要自适应，需要常数 TV + 死区。**

## 2. 与 v7 / v9 / v10 的分工（四支别混）

| | `v7_us_gate` | **`v8_golden_cross`（本变种）** | `v9_vol_target` | `v10_vol_layer` |
|---|---|---|---|---|
| 方向判断 | 有（价格 vs MA200） | **有（MA50/MA200）** | 无 | **无** |
| 仓位 | 二元 × 波动层 | **二元 × 波动层** | 连续 0~100% | **连续 0~100%** |
| 决策频率 | 月末（+2 月确认） | **日频** | 月末 + 月中补丁 | **日频** |
| 调仓（14.2 年） | 70 | **132** | 249 | **157** |
| 夏普（同尺子） | 0.86 | **0.73** | 0.88 | **0.85** |
| 定位 | 回撤优先 | **对照组（方向 + 波动两层）** | 低频风险预算 | **纯风险预算** |

**v8 的存在意义是「拆解」**：它把「方向判断」和「风险预算」两层同时装上，
于是可以拿它去问两个问题 —— 去掉波动层会怎样（§5 的「关掉波动层」档）、
去掉方向门会怎样（v10）。**两个答案都是「变好」**，这才是这份报告最有价值的部分。

**四条硬结论**：

1. **波动层把回撤从「与买入持有一样深」压到浅 10pp，Calmar 0.71 → 0.93**，
   代价只有年化 −0.52pp。**这是这一层在 14.2 年里的全部账。**
2. **但它没翻盘**：夏普 0.73 < 买入持有 0.78、年化 −4.33pp。**「更平」不等于「更好」** ——
   如果你只看夏普，这一支在短样本里不该被选。
3. **去掉方向门（v10）夏普 0.85，比留着门高 0.11**；同一层波动层配 v7 的年线门是 0.86。
   **门越钝、边际越负** —— 50/200 金叉是所有门里最钝的（要求快线也翻下去才关门）。
4. **「死叉只减半」是这一支里唯一同时赢过年化与夏普的档**（+12.34% / 夏普 0.82 / 回撤不变）。
   机制清楚：死叉后留 50% 而不是清仓，等于「不赌方向、只降风险」——
   **它其实是在说「方向门不该是全有全无」**，这与 v10 的结论同源。

- **2018Q4 / 2022 它也帮得上**（慢熊里波动率一路上行，本来就该降仓），
  这是它和「纯二元金叉」最大的差别：后者在 2020 完全没降（−28.17% = 买入持有）。

## 7. 硬断言（8/8）

| 检查 | 结果 |
|---|---|
| 恒满（关波动层、下限 100%）净值 == 买入持有（零费） | ✅ 两腿逐日一致 |
| 仓位 ∈ [0, 100%]；关波动层时只落在 {100%, 死叉后比例} | ✅ 两腿均通过 |
| 截掉最后 6 天重跑，历史仓位不变（无前视） | ✅ 最大差 0 |
| **只用「当日之前」的信号重算，仓位不变**（抽样 12 点 · 无前视） | ✅ 全部逐位一致 |
| **缩仓日恒有 仓位 × vol20 == TV，死叉日残仓为 0** | ✅ 两腿均通过 |
| 两腿恒满时组合 == 50/50 手工复利（零费） | ✅ 差 0 |
| 门正确：关波动层时翻转次数 == 调仓次数；开波动层时死叉次日必清零 | ✅ 两腿逐笔一致 |
| 月末档：决策只在月末、仓位 = 最近一次决策的目标（T+1） | ✅ 两腿逐日一致 |

> 第 4、5 条是这一版新增的**真正的前视检验**：`load_signal(..., as_of=)` 把信号**真的截断**
> 到「该净值日之前」再重算仓位，逐点比对 —— 不是嘴上说没有前视。
> 第 5 条是波动层的**定义式**：两种杠杆同时生效时，这条等式必须逐日成立；
> 第一次跑就抓到了一个真 bug（`target_raw` 不接受 `**kw`，报告里的调用直接报错）。

## 8. 长样本证据（1995-2026 · 指数口径 · 不含分红）

| 策略 | 年化 | 最大回撤 | 夏普 | 调仓 |
|---|---:|---:|---:|---:|
| 买入持有 纳指100 | +14.37% | −82.90% | 0.48 | 0 |
| 金叉 50/200（日频，不含波动层） | **+16.08%** | **−35.74%** | **0.72** | 36 |

**四项里赢三项、回撤砍掉 47pp**（`vol_legs/research/probe_published_us/_probe_published_us.md`）—— 这是方向门值得留的全部理由。
**但波动层在长样本里的作用未知**（本仓库没有 1995 起的 QDII 净值），
所以 §4 那个「回撤浅 10pp」**不能外推**。

> **两段证据要一起读**：短样本（2012+，含真实申赎与汇率）说「加波动层后仍打不过买入持有」，
> 长样本（1995+，含两次腰斩）说「方向门砍掉了 47pp 回撤」——
> 前者缺它唯一起作用的两段行情，后者缺你真能拿到的成本与跟踪误差。
> **这就是为什么 v8 保留了两层、而没有直接改成 v10。**

vol 决定它有多高**。▲/▼ 只标 |Δ仓位| ≥ 20pp 的大动作（132 次全画会糊）。

「MA50 还要跌多少才翻空」和「vol 还要升到多少才再降一档」——
**前者决定要不要清仓，后者决定要不要减仓，两条路径不同**。

**当前状态（2026-11-04 收盘）**：纳指 `vol20 = 23.17%` → 目标 **86%**（现仓 97%，明日下调）、
标普 `vol20 = 12.89%` → 目标 **100%**；两腿方向门均为**开**；组合 **19.7pp / 目标 18.6pp**。

## 10. 口径与边界

1. **两段证据都不完整**：短样本证明了波动层（2020），长样本证明了方向门（2000-2008）。
   **单独引用任何一段都会得出错误结论。**
2. **方向门仍然钝**：波动层补得了急跌，补不了「阴跌 + 低波动」——
   那种行情里 vol 不高，仓位照旧接近满仓。
3. **短样本里它打不过买入持有**（年化 −4.33pp、夏普 −0.05）。它只在 Calmar 上赢（0.93 vs 0.73）。
   **选它就必须接受「收益更少、曲线更平」**，别指望它跑赢。
4. **标普这条腿不值得用**（年化 −3.90pp，与旧结论一致）。
5. **换手上升**：一年 9.3 次（旧默认 2 次），0.6% 场外口径掉 0.90pp。
6. **QDII 通道风险未计**：额度关闭、限购、溢价、赎回 T+2~T+7。
7. **不做 walk-forward 选优**：TV=20% 借自 v7 默认，§5 给了 28 档邻域。
