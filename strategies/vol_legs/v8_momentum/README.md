# V8 变种 · 跨资产 12-1 动量（七腿内每月选最强 3 条）

`vol_legs`（波动资产操作规则 v1.4）的**第八个变种**，2026-11-04 新增。
前七个变种都是「单腿进出时点」，本变种是**组合层额度分配**（决定 40pp 分给哪几条腿），
因此没有逐腿表 —— 它与任何单腿时点变种都是**正交**的，可以叠加。

> **编号说明**：V8 编号此前属于 `v8_erp_exit`（已于 2026-11-03 删除并并入 v4，见父 README），
> 本目录接手该编号，是新的一支。

规则权威源：`momentum.py` 顶部常量（`params()` 打包）。

一句话：**不判断单条腿的方向，只在七腿之间汰弱留强** —— 每月末按过去 12 个月（跳过最近 1 个月）
的收益排序，只持有最强的 `TOPN=3` 条腿，其余放货基。

## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 打分 | `score = P[t−21] / P[t−252] − 1`（12 个月，跳过最近 1 个月） |
| 排序 | 每月**最后一个交易日**收盘，对「历史 ≥ 273 根」的腿排序 |
| 选择 | 取最强 `TOPN=3` 条；`MIN_LEGS=3` 时可排序的腿少于 3 条 → **维持当前仓位不动** |
| 权重 | `WEIGHT_MODE="norm"`：选中腿按**各自目标带**比例归一化到满仓（Σ=1） |
| 成交 | 月末盘后算信号、**次一交易日收盘成交**（与 v1~v7 同一纪律） |
| 成本 | 每次调仓按 `|Δ权重|` 扣申赎费 + 滑点 0.1% |

> **为什么跳过最近 1 个月**：截面动量文献（Jegadeesh & Titman、Antonacci 的 Dual Momentum）一致这么做 ——
> 最近 1 个月存在短期反转，纳入反而降信噪比。
>
> **为什么需要 `MIN_LEGS`**：2022 年前只有 5 条腿有场外净值，2013 年前只有 2 条
> （且 A500 早期桥接的 `000051` 与沪深300 同源）。池子太小时「最强 3 条」会退化成
> 把同一条腿当两条堆满仓 —— 那不是动量，是单押。少于 3 条就按兵不动。

## 3. 诚实结论：这个池子上动量没有超额

- **默认档全面落后**：年化 −0.82pp、回撤深 15.7pp、夏普 0.56 vs 0.89。
- **最好的一档「最强 5 条」也只是勉强**：年化 +12.28%（+1.1pp）但回撤 −19.61%（深 2.2pp）、夏普 0.87 < 0.89。
  10 档敏感性里 **2 档年化超过静态带，0 档夏普超过**。
- **换手是致命伤**：默认档每年被费用吃掉 **1.31pp**（180 笔调仓）；不计费也只有 0.64 夏普。
- **失败年份很典型**：2026 年 **−19.20% vs 静态带 −4.29%**（−14.9pp）——
  「最强的腿随即补跌」正是截面动量最脆弱的场景；2016、2019、2020 也都是负贡献。
- 原因不难理解：七腿都是宽基/商品指数基金，**长期同涨同跌**，截面排序的信息量远低于个股池。
  **这不是参数没调好** —— 6/9/12 个月回看、SKIP=0/1、月末/季末、归一化/不归一化，全都试过了。

## 8. 口径与已知边界

1. **本变种在本池上没有风险调整后的超额**（见 §3）。保留它是因为它是**唯一非择时维度**
   （其余七个变种都在猜「什么时候进出」，它只回答「配哪几条」），与 v7 在**覆盖范围**上互补。
2. **换手是生死线**：A 类场外单次往返约 0.6%，默认档一年被吃掉 1.31pp；场内 ETF 或季末调仓能改善。
3. **它会追高**：动量买「过去一年最强」，泡沫末期会重仓最热资产 —— 与 v7（跌破年线减仓）正好互补。
4. **早期样本腿数少**：2013-2015 是 4 选 N、2015-2023 是 5 选 N、2023 起才是 7 选 N。
5. **口径坑（已修）**：信号必须先在**全样本**面板上算好再切回测窗口 ——
   对切片后的 df 重新 `shift(252)` 会把首年误判成「历史不足」，白坐一年货基并虚增收益。
6. **代理口径**：A500 / 标普样本前段是桥接（`000051` / `050025`）；美股腿用场外人民币复权净值。
7. **未计**：大额限购、QDII 额度关闭时的顺延、赎回确认时滞、C 类销售服务费。
8. **不做 walk-forward 选优**：参数写死，§4 已给敏感性。

## 9. 与 v7 叠加（推荐用法）

**v8 决定配哪几条腿 → v7 在它覆盖的两条腿（纳指/标普）上决定露多少**。
v7 的池只有 ndx/spx，所以叠加只在美股两腿上生效；其余腿仍按主策略带位满配。

例：2026-11-03 那期 v8 选出科创50 / 纳指 / 标普（归一化权重 11% / 44% / 44%），
v7 当前对纳指、标普都是满仓（均在年线上方）→ 最终权重 = 带位 × 归一化比例 × 100%。
若 v7 处于减仓态（纳指 0 / 标普 50%），则对应部分立刻留成现金。
