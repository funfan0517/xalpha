# 波动资产 · V8 变种：跨资产 12-1 动量 · 组合层回测
> 池与主策略**完全一致**：`rule.LEG_ORDER` 七腿（中证A500 / 沪深300 / 纳指100 / 标普500 / 科创50 / 恒生科技 / 黄金）
> 价格 = 场外**复权净值** · 月末盘后算信号、**次一交易日收盘成交** · 空仓按货基 1.40% 计息 · 成本 = 真实申赎费 + 单边滑点 0.10%
> 规则权威源 `v8_momentum/momentum.py` 顶部常量。

## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 打分 | `score = P[t−21] / P[t−252] − 1`（12 个月，跳过最近 1 个月） |
| 排序 | 每月最后一个交易日收盘，对「历史 ≥ 273 根」的腿排序 |
| 选择 | 取最强 `TOPN=3` 条；不足则全取；一条都不够则空仓 |
| 权重 | `norm`：选中腿按各自目标带比例归一化到满仓（Σ=1） |
| 成交 | 月末盘后算信号、**次一交易日收盘成交**（与 v1~v7 同一纪律） |
| 成本 | 每次调仓按 |Δ权重| 扣申赎费 + 滑点 |

> **层次**：前七个变种都是「单腿进出时点」，本变种是**组合层额度分配**（配哪几条腿），因此没有逐腿表。它可以与 v7（波动率目标化）叠加：v8 定配哪几条、v7 定每条露多少。

## 8. 口径与已知边界

1. **这个池子上动量没有风险调整后的超额**：七腿都是宽基/商品指数基金、长期同涨同跌，截面排序的信息量远低于个股池；实测最好的一档夏普也只到 0.87（静态带 0.89）。**不是参数没调好。**
2. **换手是生死线**：每月最多换 N 条腿，A 类场外单次往返约 0.6%，默认档一年被吃掉 1.31pp；场内 ETF 或季末调仓能显著改善（§3）。
3. **它会追高**：动量买「过去一年最强」，泡沫末期会重仓最热资产 —— 与 v7（高波动减仓）正好互补，两者叠加才合理。
4. **早期样本腿数更少**：2013-2015 是 4 选 N（无黄金）、2015-2023 是 5 选 N、2023 起才是 7 选 N（科创50/恒生科技 2022 年才有场外净值）。
5. **口径坑（已修）**：信号必须先在**全样本**面板上算好再切窗口；对切片后的 df 重新 `shift(252)` 会让首年被判成「历史不足」，白坐一年货基并虚增收益。
6. **代理口径**：A500 / 标普样本前段是桥接（`000051` / `050025`）；美股腿用场外人民币复权净值，叠加汇率与溢价。
7. **未计**：大额限购、QDII 额度关闭时的顺延、赎回确认时滞、C 类销售服务费。
8. **不做 walk-forward 选优**：参数写死，§3 已给敏感性。
