# V9 变种 · 按腿开关版（标普 010 / 其余 111）

> **2026-11-18 用户定稿**：把 v10 的自适应波动层、v7 的年线闸门、v8 的 50/200 金叉接成三个 0/1 开关，
> 并**按腿分配置**：标普 500 用 `010`（只开年线闸门），其余六腿用 `111`（三个全开）。
> 本目录 `backtest/_v9_vol_target_bt.md` 与每日产物均为该口径；旧口径保留为对照档。
> 模拟结果，非投资建议。

## 0. 当前口径

基础规则仍是 v9 的**波动率目标仓位**（不猜方向，只调风险预算）：

| 环节 | 规则 |
|---|---|
| 信号 | 每月最后一个交易日收盘，算近 20 日收益的年化已实现波动 `vol20 = std(r,20)×√252` |
| 目标权重 | `w = min(1, TV / vol20)`，下限 0（不加杠杆、不做空）；TV = 15%（趋势态）/ 10%（震荡态，仅 111 腿） |
| 不交易带 | 与**当前仓位**差不足 ±5pp 不动手 |
| **快减**（月中） | 5 日跌幅 ≤ −5% **且** vol20 ≥ 1.4×15% → 次日降到公式值 |
| **快补**（月中） | vol20 ≤ 近 60 日峰值的 70% **且** 站上 MA10 → 次日补到公式值 |
| 成交 | 决策日收盘 → 次一交易日收盘成交 → 新仓自 t+2 起承担收益 |
| 空仓 / 成本 | 空仓按 1.40% 日计复利；单边 0.10%，按 `Σ|Δw|` 计 |

在此之上，三个开关按腿叠加（`A/G/X` = 自适应 / 年线闸门 / 金叉）：

| 腿 | A | G | X | 代码 | 含义 |
|---|---|---|---|---|---|
| 中证A500 | 1 | 1 | 1 | 111 | ER 自适应 TV 15%/10% + 月末 MA200 闸门 + 死叉清仓 |
| 沪深300 | 1 | 1 | 1 | 111 | 同上 |
| 纳指100 | 1 | 1 | 1 | 111 | 同上 |
| **标普500** | **0** | **1** | **0** | **010** | **只保留年线闸门；破位减半（不是清仓），不受死叉日频清仓影响** |
| 科创50 | 1 | 1 | 1 | 111 | 同 111 |
| 恒生科技 | 1 | 1 | 1 | 111 | 同 111 |
| 黄金 | 1 | 1 | 1 | 111 | 同 111 |

- **A（v10 自适应波动层）**：Kaufman ER(20) 带滞回，趋势态 TV=15%、震荡态 TV=10%；只改风险预算，不判方向。
- **G（v7 年线闸门）**：月末看 MA200，连续 2 个月在年线下（或首次破位 ≥3%）才减；纳指/其余腿减到 0，标普减到 50%；重新站上即回补。**这里「年线」按 v7 源码取 MA200，不是 v5 的 MA250。**
- **X（v8 金叉）**：MA50 > MA200 才允许持仓；死叉日收盘清零，次日即无敞口（比月末闸门快一天）。

代码落点：`vol_target.py` 的 `SWITCH_DEFAULT` / `SWITCH_BY_LEG` + `leg_params()`；
`build()` 默认按腿套用，调用方显式传 `ADAPTIVE=` / `GATE=` / `XCROSS=` 时以调用方为准。

## 1. 为什么标普单独用 010

八种**全池统一**组合的对照见 `research/_probe_switches.md`。关键两格（七腿等权 / 文档两腿 2:1）：

| 全池配置 | 七腿等权 年化 / 回撤 / 夏普 | 两腿 2:1 年化 / 回撤 / 夏普 |
|---|---|---|
| 000 旧口径（全关） | +5.96% / −19.56% / 0.42 | +14.65% / −19.64% / 0.91 |
| 111 全开 | +6.95% / −6.32% / 0.91 | +11.23% / −11.22% / 0.89 |
| 010 只开年线 | +6.96% / −8.93% / 0.71 | +14.10% / −16.18% / **0.95** |

标普腿上 `111` 把年化从 8.48% 压到 6.36%（自适应层在标普上让渡太多、死叉又砍在 2024 的慢牛里），
而 `010` 年化只让渡 0.25pp、回撤从 −35.37% 修到 −22.12%、夏普 0.53 → 0.56。
其余腿 111 的收益换回撤更划算（尤其 A 股/港股/科创腿在 2022 的深跌）。
**混合后的实际结果比任何全池统一档都好**：七腿等权夏普 0.96 > 0.91，两腿 2:1 夏普 0.98 > 0.95。

## 6. 硬断言（9/9 通过）

前 7 条校验基础引擎（在显式关闭三开关的口径下）：恒满等于买入持有、仓位 ∈ [0,1] 且落点等于公式值、
5pp 漂移死区、信号 t → 仓位 t+1 生效、截断末 6 根不改历史、TV=0 年化等于空仓利率、全池恒满等于手工复利。
新增两条校验本次配置：**按腿开关确实为标普 010 / 其余 111**；**新默认口径仓位不越界且无前视**。

## 8. 边界

- 样本：真实指数 2005 起（黄金 2013、科创 2019、恒生科技 2020），七腿组合共同窗口 2020-07 起；
  信号与回测价格同源，执行走场外 QDII A 类，汇率与跟踪误差未计。
- 三开关来自 8 格同一样本对照，混合配置又是样本内挑的，**有过拟合风险**；本报告是机制对照，不是收益承诺。
- `GATE` / `XCROSS` 引入方向判断，已不是原版「纯风险预算」的 v9；`ADAPTIVE` 仍只调风险预算。
- 旧 README 中 2012 起、单边 0.03% / 空仓 2.0% 的两腿数字属历史沿革，当前读数一律以本文件与 `backtest/*.md` 为准。
