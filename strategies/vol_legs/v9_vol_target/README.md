# V9 变种 · 美股两腿波动率目标仓位（vol20 · TV 15% · 月末定仓 + 月中快减/快补）

`vol_legs`（波动资产操作规则 v1.4）的**第九个变种**，2026-11-04 落地。

- **标的池只有两条腿**：纳指100（`270042`）+ 标普500（`017641`/`050025` 桥接）。
- 规则权威源：`vol_target.py` 顶部常量（`params()` 打包，`TRIGGER` 一档切换）。

一句话：**不判断涨跌，只看眼下这段波动值多少仓位 —— 高波动降仓、波动回落补仓，月末定仓 + 月中校正。**

## 0. 两档，一个开关

| 档 | `TRIGGER` | 规则 | 出处 |
|---|---|---|---|
| **默认（fast）** | `"fast"` | 月末定仓 + **月中快减** + **月中快补** | 2026-11-04 由 `research/_probe_opt.py` 的四道闸门筛出 |
| 文档档（month） | `"month"` | 纯月末定仓，文档 S-A 原样 | `策略规格_v1.0.md`（用户明确「文档只是参考」，故不再是默认） |

两档在代码里只差一个常量；回测报告里都保留，便于随时对照。

## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 信号 | 每月**最后一个交易日**收盘，算近 20 日收益的**年化已实现波动** `vol20 = std(r,20)×sqrt(252)` |
| 目标权重 | `w = min(1, 15% / vol20)`，下限 0（**不加杠杆、不做空**） |
| 不交易带 | 与**当前仓位**差不足 ±5pp → 不动手（省成本） |
| **快减**（月中） | 5 日跌幅 ≤ **−5%** **且** vol20 ≥ **1.4×15%**（=21%）→ 次日就降到当日公式值 |
| **快补**（月中） | vol20 ≤ **近 60 日峰值的 70%** **且** 站上 **MA10** → 次日就补到当日公式值 |
| 成交 | 决策日收盘 → **次一交易日收盘**成交 → 新权重自 **t+2** 起承担收益 |
| 空仓 | 未投部分按 **2.0%** 日计复利（**禁止记 0**） |
| 成本 | 单边 **0.03%**，按 `Σ|Δw|` 计（场外现实 0.6% 见 §5） |

> **两条补丁为什么不算「择时」**：快减的门槛是「跌幅 + 波动已起」——波动率本身就是已实现的风险，
> 不是方向信号；快补的门槛是「波动率离开峰值 30%」+「站上 10 日线」——是「恐慌消退」的确认。
> **全程没有用到任何「涨会继续涨」的判断。**

## 2. 为什么加这两个触发器

月末单点定仓有两个结构性缺陷（详见 `research/_probe_fast.md`）：

1. **减得太慢**：2020-02→03 五周跌完，月末那一眼根本看不到；
2. **补得太晚**：2020-03-31 那次月末决策恰好踩在波动率峰值（80%+）上，**在底部砍仓**，
   然后干等一个月才补 —— 反弹整段让掉。

`research/_probe_opt.py` 用**预注册的四道闸门**（全样本 / 分半 / 剔除 2020 / 参数邻域）
筛了 10 个方向（EWMA 估计量、长短窗口混合、凸性映射、组合层风险平价、单腿×RP 等），
**只有「快减 + 快补」全部通过**，且在 13 档阈值邻域内结论不翻转。

> **不是「哪个参数好看」挑出来的**：口径写死（−5% / 1.4×TV / 70% / 60 日 / MA10 全是常识区间），
> 邻域一年一格地扰动都不翻转，且两条腿同时成立（不是只靠纳指）。

- **纳指**：年化 −2.43pp、回撤 −29.47% → **−16.06%**（+13.41pp）、夏普 0.77 → **0.89**、
  Calmar 0.62 → 1.06。**让渡的收益换成了回撤与夏普**，这是这条腿的净赢。

  回撤改善与纳指相当（13.35pp vs 13.41pp）；标普自身波动只有纳指一半、`15%/11%` 常年顶在满仓，
  只在少数高波动时点动手（6.3 次/年）。
- **补丁在两条腿上都成立**（不是只靠纳指那条腿）：纳指夏普 0.83 → 0.89、标普 0.79 → 0.85。
- **只加一半也行，但效果打对折**：只加快减 → 回撤已修到 **−16.04%**，但年化只有 +13.14%（比月度档还低）；
  只加快补 → 年化 **+14.48%**（最高），但回撤仍是 −17.80%（一点没修）。
  **一头修「减得慢」、一头修「补得晚」，合起来才有 13pp 级的回撤改善。**

## 7. 压力窗口与失效年份

| 窗口 | 区间 | 本变种 | 静态 50/50 | 本变种回撤 | 静态回撤 |
|---|---|---|---:|---:|---:|
| 2020 疫情 | 2020-02-19 ~ 2020-08-31 | **+2.98%** | +9.87% | −15.92% | −28.17% |
| 2022 加息熊市 | 2022-01-03 ~ 2022-12-30 | **−12.04%** | −19.63% | **−13.82%** | −23.21% |
| 2025 至今年内 | 2025-01-02 ~ 2026-11-02 | +12.39% | +20.16% | −14.47% | −19.37% |

- **2020 从「失效」变成「打平」**：文档月度档在该窗口吃 **−3.06%**，本变种 **+2.98%**
  （同期静态 +9.87%）—— 修的是「底部减仓后干等一个月」那一刀。
- **但没修完**：该窗口仍落后静态 **6.89pp**（2020 自然年落后 8.11pp）。VT 要先看见波动才减仓，天生慢半拍；
  再快只能引入方向判断（就不是 VT 了）。
- **2022 是主场**（+7.60pp vs 静态，回撤 −13.82% vs −23.21%）：11 个月慢熊里波动率一路上行，
  它一路降仓 —— **治慢熊，急跌只能减轻不能免疫。**
- **代价在 2018**：−0.68% vs 静态 +0.37%（−1.05pp），相对文档月度档是 **−4.81pp**。
  2018Q4 波动率只冲到 25%（降仓空间小），砍在低位、补在高位。**深跌救命，浅摔亏钱。**

### 7.1 为什么不是「提频」

`_probe_fast.md` 同口径测过：周频反而更差（年化 −0.48pp）；日频 + 10pp 死区的夏普 0.89（与默认档持平）
但**调仓 288 笔**、场外 0.6% 成本后年化只剩 +11.65%。**问题不在采样频率，而在「月中也会发生的事没人管」**；
而补丁只在该出手时出手（17.5 次/年），比天天盯盘省得多。

## 8. 硬断言（7/7）

| 检查 | 结果 |
|---|---|
| 恒满（TV 极大 → w≡1）净值 == 买入持有（零费） | ✅ 两腿逐日一致 |
| 仓位 ∈ [0, cap]，且每次调仓落点 = `min(cap, TV/vol)`，不加杠杆不做空 | ✅ |
| 未达 ±5% 不交易（死区生效） | ✅ |
| 信号 t → 仓位自 t+1 收盘起生效（无前视） | ✅ 两腿逐条一致 |
| 截掉最后 6 天信号重跑，截止日前仓位不变（无前视） | ✅ 最大差 0 |
| TV=0（纯现金）年化 == 空仓 2.00%（禁止把空仓记 0） | ✅ |
| 两腿恒满时组合 == 50/50 手工复利（零费） | ✅ 差 0 |

> 加了日频触发后，**断言 4/5 的写法必须跟着改**：原来的「t+2 生效」是按月末单点写的，
> 换成日频后要验的是「决策当日不得生效 + 截断信号后历史仓位不变」。
> 这一轮真正踩到的是**净值日历与信号日历不同步**（QDII 遇 A 股长假没有净值），
> 跨日历比对时会误报 —— 断言现在跑在信号日历上。

## 11. 口径与已知边界

1. **样本只到 2012**（QDII 场外净值起点）：不含 2000-2002（纳指 −83%）与 2008 ——

2. **它不预测方向**：只调风险预算，所以「低波动阴跌」（如 2015 年 A 股式流动性危机）会因波动率低
   而满仓挨打 —— 这是文档 §9 第 3 条点名的失效模式，快减/快补也救不了（波动率没起来）。
3. **快减的收益来源很单薄**：剔除 2020 整年后，本变种与文档档的年化打平（−0.07pp）——
   它的证据强度是 **n=1**。**把它当「尾部保险」定价，不要当「每年多赚」。**
4. **`cap=1` 是唯一可执行档**：加杠杆需两融，成本与额度不在回测里。
5. **QDII 通道风险未计**：额度关闭、限购、赎回 T+2~T+7、场内溢价。快减/快补要求「次日就动手」，
   实盘可能滑到第二三天；若当天无法申购则该档顺延（**不要为了追规则去买场内溢价**）。
6. **补丁的阈值不是选出来的**：TV15 / vol20 / 漂移 5% 沿用文档；快减/快补的五个阈值取常识区间
   （−5% / 1.4×TV / 70% / 60 日 / MA10），§5 给了 22 档邻域。**只要方向不翻转，就不该继续调它。**
7. **不做 walk-forward 选优**：本变种没有「按折选参」的环节，因此也不存在选参过拟合；
   它的过拟合风险在另一处 —— **结论依赖单一年份**（见 §11.3）。
