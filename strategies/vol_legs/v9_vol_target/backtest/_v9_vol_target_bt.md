## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 信号 | 每月**最后一个交易日**收盘，算近 20 日收益的年化已实现波动 `vol20 = std(r,20)×sqrt(252)` |
| 目标权重 | `w = min(1, 15% / vol20)`，下限 0（**不加杠杆、不做空**） |
| 不交易带 | 与**当前仓位**差不足 ±5% → 不动手（省成本） |
| **快减**（月中） | 5 日跌幅 ≤ -5% **且** vol20 ≥ 1.4×TV → 次日降到当日公式值（修「减得太慢」） |
| **快补**（月中） | vol20 ≤ 70%×近 60 日峰值 **且** 站上 MA10 → 次日补到当日公式值（修「补得太晚」） |
| 成交 | 决策日收盘 → **次一交易日收盘**成交 → 新权重自 **t+2** 起承担收益（R-01） |
| 空仓 | 未投部分按 1.40% 日计复利（**禁止记 0**） |
| 成本 | 单边 0.10%，按 `Σ|Δw|` 计（场外现实 0.6% 见 §5） |

## 10. 口径与已知边界

1. **样本起点口径固定**：信号与回测价格同源，都是 `.NDX` / `.INX` 真实指数 2005-01-03 起（vol20 首个有效日 2005-02）；2000-2002（纳指 −83%）不在样本内，2008 危机完整在样本内且策略已生效。
2. **执行口径另算**：信号与回测用美元指数（不含汇率 / 跟踪误差 / 分红再投），实盘下单场外 QDII A 类人民币净值，对账时按美股约 −1.3pp/年 折算分红缺口。
3. **它不预测方向**：只调风险预算，所以「低波动阴跌」（如 2015 年 A 股式流动性危机）会让它因波动率低而满仓挨打 —— 这是文档 §9 第 3 条点名的失效模式。
4. **`cap=1` 是唯一可执行档**：文档 R-04 禁止杠杆；`cap>1` 需两融，成本与额度不在回测里。
5. **快减/快补只减不能免**：2020 窗口从文档月度档 +5.84% 修到本变种 +4.59%（同期静态 +6.72%，仍落后 2.1pp）—— VT 要先看见波动才减仓，天生慢半拍。再快就只能引入方向判断（就不是 VT 了），§10 的「假摔」风险也随之回来。
6. **快减的反向代价是 2018 型行情**：波动率只冲到 25%（降仓空间小），砍在低位、补在高位，2018 年比月度档更差（逐年表见 §7）。**深跌救命，浅摔亏钱。**
7. **QDII 通道风险未计**：额度关闭、限购、赎回 T+2~T+7、场内溢价 —— 决策日 → 次日成交，实盘可能滑到第二三天；若当天无法申购则该档顺延。
8. **补丁的阈值不是选出来的**：TV15 / vol20 / 漂移 5% 沿用文档；快减/快补的五个阈值取常识区间（−5% / 1.4×TV / 70% / 60 日 / MA10），§4 给了 24 档邻域，全档方向一致。
