> 池 = **只有纳指100 与标普500**（`vol_target.POOL`）。基础规则取自 `G:\tradingagents\us_index_strategy\策略规格_v1.0.md` 的 **S-A**（文档排名第 1）；**月中快减/快补是 2026-11-04 追加的**（用户明确「文档只是参考」），由 `research/_probe_opt.py` 的四道闸门筛出、13 档邻域内稳定。
> 信号 = **美元指数**（`.NDX` / `.INX`）收盘算 vol20；执行 = 场外 QDII **人民币复权净值**；空仓按 2.00% 计息 · 单边成本 0.03%。

## 1. 规则（可执行版）

| 环节 | 规则 |
|---|---|
| 信号 | 每月**最后一个交易日**收盘，算近 20 日收益的年化已实现波动 `vol20 = std(r,20)×sqrt(252)` |
| 目标权重 | `w = min(1, 15% / vol20)`，下限 0（**不加杠杆、不做空**） |
| 不交易带 | 与**当前仓位**差不足 ±5% → 不动手（省成本） |
| **快减**（月中） | 5 日跌幅 ≤ -5% **且** vol20 ≥ 1.4×TV → 次日降到当日公式值（修「减得太慢」） |
| **快补**（月中） | vol20 ≤ 70%×近 60 日峰值 **且** 站上 MA10 → 次日补到当日公式值（修「补得太晚」） |
| 成交 | 决策日收盘 → **次一交易日收盘**成交 → 新权重自 **t+2** 起承担收益（R-01） |
| 空仓 | 未投部分按 2.00% 日计复利（**禁止记 0**） |
| 成本 | 单边 0.03%，按 `Σ|Δw|` 计（场外现实 0.6% 见 §5） |

> `TRIGGER="month"` 关掉「快减/快补」两行 = **文档 S-A 原样**，本报告里作为对照档保留。

## 10. 口径与已知边界

1. **样本只到 2012**（QDII 场外净值起点）：不含 2000-2002（纳指 −83%）与 2008 —— 而波动率目标化最被称赞的正是「泡沫破裂 + 高波动聚类时降仓」，本报告对该场景是**外推**。
2. **信号是美元指数、执行是人民币净值**：两者的差异来自汇率与跟踪误差；`SIGNAL="nav"` 一档把信号也换成净值，可看这处差异的代价。
3. **它不预测方向**：只调风险预算，所以「低波动阴跌」（如 2015 年 A 股式流动性危机）会让它因波动率低而满仓挨打 —— 这是文档 §9 第 3 条点名的失效模式。
4. **`cap=1` 是唯一可执行档**：文档 R-04 禁止杠杆；`cap>1` 需两融，成本与额度不在回测里。
5. **快减/快补只减不能免**：2020 窗口从 −3.06% 修到 +2.98%，但仍落后静态 6.9pp —— VT 要先看见波动才减仓，天生慢半拍。再快就只能引入方向判断（就不是 VT 了），§10 的「假摔」风险也随之回来。
6. **快减的反向代价是 2018 型行情**：波动率只冲到 25%（降仓空间小），砍在低位、补在高位，2018 年比月度档少 4.8pp。**深跌救命，浅摔亏钱。**
7. **QDII 通道风险未计**：额度关闭、限购、赎回 T+2~T+7、场内溢价 —— 决策日 → 次日成交，实盘可能滑到第二三天；若当天无法申购则该档顺延。
8. **补丁的阈值不是选出来的**：TV15 / vol20 / 漂移 5% 沿用文档；快减/快补的五个阈值取常识区间（−5% / 1.4×TV / 70% / 60 日 / MA10），§4 给了 22 档邻域，全档方向一致。
